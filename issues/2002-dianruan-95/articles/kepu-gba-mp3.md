# 科普园地 将音乐旋律随身携带——用GBA听MP3

GBA配上烧卡器后应该怎么用？难道仅仅用来PLAY GAME？非也，非也，GBA潜力巨大，有烧卡器助威更能发挥其强劲的多媒体功能，比如听MP3、看电影、看照片……下面就来谈谈如何在GBA上听MP3。

想要在GBA上实现MP3功能你得具备以下软硬件设施：

1：电脑一台
2：GBA＋烧卡器＋FLASH CARD
3：MP3文件若干
4：GBA上的MP3播放软件
5：音频格式转换软件

其中对电脑的要求并不过高，只需要能流畅地播放MP3即可，声卡采用最普通的AC'97无碍，当然你用顶级创新声卡也没人说你，只不过我会用一种叫做嫉妒的眼光看着你；FLASH CARD的容量推荐128M（256M绝佳），这样大概能够烧进9首普通大小的MP3；而MP3文件作为音源是最重要的，应该挑选那些音质纯正、无噪音的MP3作为音源，从而保证在GBA上得到最佳听觉效果；目前最好的GBA用MP3播放软件是Musicplayer Advance write，严格地说这软件的播放格式并非MP3而是PCM，所以我们得先用音频转换软件将MP3格式转换成PCM格式，而此类软件极多，最常见的有WINAMP、超级解霸等，下面就以实例来介绍将一首MP3文件烧进GBA的方法。

## 一、用WINAMP转换音频格式

虽然MPA软件作者推荐用CoolEdit 2002，不过这软件对我们来说不大熟悉，不谈它。而WINAMP是现在PC装机必备的软件，所以我们就使用它，但是你得确认你的WINAMP版本号在2.77以上，因为2.77上才能支持MP3——PCM这一转换过程，所以如果你的WINAMP版本低于2.77的话可以到http://www.winamp.com/下载最新版本（目前最新正式版本为2.79）。打开WINAMP，如图1，这是WINAMP的主界面，在进行转换之前我们得进行点准备工作，如图所示，将WINAMP的音量调为最大，再将随机按钮和循环按钮取消（不要选上，否则会反复录制），在WINAMP主界面上点击右键，如图2，选择“选项——参数设置”，进入“WINAMP参数设置中心”，如图3，再点击“插件——输入”，选中“Nullsoft磁盘插件v2.0”，点击“配置”按钮，接下来你会看到如图4的“Nullsoft磁盘写入插件配置”窗口，输入目录你随意选择，将“转换格式”勾中，再点击用圆圈划中的部分，这是声音属性的选择，实际上这就是PCM的几种格式，不过GBA上的MPA播放器只支持8000Hz、11025Hz、16000Hz这些频率，且位数只支持16位（声道可以是单声道和立体声的），那么这里就只有8000Hz，16位，单声，8000Hz，16位，立体声，11025Hz，16位，单声，11025Hz，16位，立体声，16000Hz，16位，单声，16000Hz，16位，立体声这六种可以使用的属性，一般是用16000Hz，16位，立体声这种，不过它的容量可是最大的嘿，而如果你不注重音质的话可以选择其他容量较小的属性。以上所说的设置好后，点击“关闭”按钮，然后在WINAMP主界面打开一首MP3文件，点击“播放”按钮，WINAMP就会自动将MP3格式转换成PCM格式，在进行这一步骤时计算机的运行速度会变得很慢，所以建议不要在这个时候运行其他程序。

## 二、用MPA将PCM转换成GBA能识别的格式

接下来让我们用Mpawrite把PCM转换成GBA能识别的格式（下载地址：ftp://downnews:member@download.romman.net/member/TXD/TOOL/MPA2.ZIP），首先打开Mpawrite，在Mpawrite中我们需要进行两个过程：

### 1：将PCM格式转换成MPA格式

如图5，这是Musicplayer Advance write的主界面，将PCM格式转换成MPA格式是在界面的下方进行的，首先在Raw 16-bit PCM file中选择好你录制的RAW文件（需要在文件类型中选择“所有类型”），再在Save MPA file as中选择录制的MPA文件存放位置，然后在Samplerate中选择频率，以及在channels中选择声道，需要注意的是，这里的选择应该和你在WINAMP中选择的保持一致，否则……（根据笔者实验，这个频率跟声音有以下关系：在这里选取的频率如果和刚才在WINAMP中保持一致的话，声音就不变，如果频率增大的话）

### 2：将MPA文件连同MPA播放器一起“烧”成.gba文件

请继续看图5，下面是最关键也是步骤——“Save written file as”是选择最终生成的GBA文件（后缀名：.gba）存放位置，当然，也需要取一个Musicplayer的界面。

名字，而下面的Musicplayer Advance write则是Musicplayer这一播放器的位置，这个视你将MPA解包时选择的位置而定。再下面需要先在Song filename中选择你刚才制作好的MPA文件的位置，然后在Song name中输入该歌曲的名称，令人遗憾的是：该软件并不支持中文字符，所以在这里只能输入英文或者汉语拼音，输入后点击“Add to list”，在下面的表格中你就会看到结果，这一切完毕后请“慎重”地检查一遍，确认无误之后点击右边的“Write”写入文件！而如果要将另外的MPA文件添加到已经做好的*.gba文件中也是在这一步进行，方法是在Song filename中选择MPA文件，在Song name中输入该歌曲的名称，最后点击“Add to list”——这样周而复始，你就能制作出属于自己的MP3专辑！

在GBA上应该怎么使用这个播放器呢？我们可以先在模拟器上试用一番，如图6，这是Musicplayer的界面，呵呵，还是有模有样的吧。

其实操作相当简单，A键是播放，B键是停止，上下键在歌曲之间选择，而L则是将按键锁住，怎样？挺人性化吧。这个可以防止误操作。而解锁则是GBA的热启动方式：同时按住“A，B，START，SELECT”。不过，笔者试用之后感觉最爽的是这个软件的屏幕保护的功能，因为听MP3是不需要屏幕的，所以该软件加入这样一个功能：当我们没有碰GBA的按键超过一段时间时，屏幕自动关闭，这样就节省了电力（可以按“R”来选择时间控制），这个和黄金太阳或马力奥中的屏幕保护同理。

最后，让我们将烧卡器连上PC，打开Flash Advance Writer，将制作好的MP3文件传到FLASH CARD里面，接下来就请你拿出GBA，慢慢享受这高科技为您带来的快感吧……

# GBAX完全解密版

我跟大家说说现在市场GBA烧录机的情况总共有N种：gbax、gbas、intellence card，对录卡……

先说说gbax，作为最先的前辈，它拥有最大的市场。它共出过四批货，第一批货只有32m的，但有速度的一些问题，国内那时应该没有什么商家敢进货，呵呵！第二批在国内有人开始尝鲜了，分为64，128，第三批则是turbo版，分为64，128在卡带上都有turbo的标志，这几批开始得到大家的支持喔（我也是这时候买的128，结果256两天后公布，吐血），turbo比普通gba卡带大一些，用着不太亮，还有gbax的卡带都比较费电。

对录卡巨便宜，不过非要到boss那去交线费，不值得！！只有64m，小卡不错，大概160rmb就可以拿到。对于第5期电软那个号称最强的烧录机，本人持保留意见，低不成（有聪明卡128），高不就（gbax256是最高端的）？

个人感觉是d卡带用电的三倍以上，11月初，gbax划时代出了一个gbax pro版的，有64，128，256m。卡带是普通gba卡带的大小，费电是turbo版的0.5，支持eep（其他版本需要补丁，或需转换rom）。有的店可能是屯了一些老货，所以64，128还是大卡，强烈推荐大家要买的话，一定要选pro版。记忆方面前三批只能支持sram，pro种支持eep喔。gbax好像是台湾出的，价格比gbas便宜一些，卡大，不值买了，记忆支持eep。聪明卡则是最近冒出来的，128为大卡，为北通代理，比较便宜（相对gbax），128只要580元！

还有一个usb gbax，有64，128m，它有一个特殊卖点，可以烧gb游戏（其它的都不行，gbax需要gb brige，不过只看过图片，太不方便，还没发售，估计要跳票）128只要799rmb——www.r1.com.mo。

编串用语话：在gba的rom里面，记忆分为四种，sram：黄金，火焰，机战A（大信看事实为准，用gbax turbo就是能玩）。eep：分为32k（可以用gep转化为sram）马里奥A1，final fight，street fight。64k（也可以转为sram），只有一个游戏，马里奥A2。

烧录程序有两个littlewrite、faw，前者是最好的，强烈推荐，用了前者，你会把后者一脚踢开的……

最后个人的建议，有铁着首选gbax pro 256，铁少者，还是换卡吧，gbax的市场肯定会大洗牌的……（rclijj@etang.com）
