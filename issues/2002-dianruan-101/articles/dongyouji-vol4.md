**全新日语情报攻略**

东游记已经进入到第四期了。不知道这样的介绍方式对大家的日语提高是否有帮助。目前来头准备从游戏最基础的内容开始入手，虽然对高手用处不大，但对于刚刚接触游戏或是对一些专用名词还不太了解的朋友相信多少会有些提高，这样我们也就达到目的了。

## 操作手柄

controller（英）

コントローラ（日）

又名"控制器"、"摇杆"、"操纵杆"等多种称呼。其实就是控制游戏进行的操作平台。过去的手柄大多是与主机合于一体的（比如AC），最早出现与主机分离式的手柄则是从PC-ENGINE开始。后来为考虑到可以与游戏专属周边配合，游戏主机开始采用手柄可以自由拆卸的设计，这样一来手柄也可以随意的收取了。

## 扩充槽

expansion slot（英）

扩张スロット（日）

外接扩充装备所使用的插槽，比方外接PC CARD、USB之类的外接设备就是使用这样的插槽作连接。基本上，在红白机时代的主机上就已有这样的设备了，现在的新主机由于大幅提升了主机的支持能力，因此这类的扩充设备就更隐藏了日后开发周边的可能性。而除了主机之外，有些的游戏主机的手柄也有扩充槽的设计（不过大多都是拿来放记忆卡的场合居多）。

## 记忆卡

memory card（英）

メモリーカード（日）

储存游戏进度或是记录的外接扩充工具，其实不只应用在新主机上，在一般的电子工具之中也随处可见（例如数码相机）。至于应用在游戏上的，最早应该算是红白机时代的"天之声"了。

## 袖珍PS

Pocket Station（英）

ポケットステーション（日）

被戏称为"PS版的VM"（笑）。它不但有记忆卡的功能，而且也可以从PS游戏中下载小游戏作为随身携带的游戏机（其实就跟上述的VM没两样）。不过它的互动性相当高，而且玩小游戏的成绩一样可以与PS游戏作互动，因此袖珍PS上市没多久就造成了"有价无货"的情况。而利用袖珍PS作连动的游戏之中，最有名也最受欢迎的莫过于"随身玩伴"系列了，说这款游戏是完全利用袖珍PS的特性而设计的游戏也一点都不为过。

## 托盘

disk tray（英）

ディスクトレイ（日）

一般的光碟机大致分为"抽屉式"与"内置式（Caddy）"等光碟置入方式。而PS2、XBOX等主机所采用的是"抽屉式"的设计。这类的光碟机是以一个专门的托盘承载光碟之后，再收入主机读取游戏的方式。若此处的设计不当，除了光头不易读到资料外，严重的时还可能会造成刮碟片的惨况（例如XBOX，不过实际上PS2也存在类似情况，只不过比起XBOX来要很多）。此外，托盘的故障率也相当高，可能没多久之后你就得乖乖的带着主机去修理了。

看碟方式然从某种角度来说主要部分都是一样的。而主机中所使用的更稳定一些。两者不同的取得方法。两种置入方式虽然……

## 通信对战线

Game Boy to Parallel Port Cable（英）

対战通讯ケーブル（日）

连结两台主机进行互动或是对战所使用的通讯线，在掌机中是不可欠缺的外设。在比较强调"道具（或物品）交换"的游戏里，利用对战通讯线来和朋友交换道具，可说是更加强了通信对战线的重要性。

## 通VM记忆卡

Visual Memory Card（英）

ビジュアルメモリーカード（日）

DC所使用的记忆卡形式，除了拥有记忆卡的功能之外，并且还可以由游戏中下载小游戏而成为随身携带的游戏机。此外有些游戏采用与VM连动的功能，在VM上进行小游戏的成绩可以与原游戏中连动而取得稀有道具或提升自己角色的能力。举例说明的话，像"SONIC大冒险"、"PSO"、"樱大战3"等游戏就有这样的设计。
