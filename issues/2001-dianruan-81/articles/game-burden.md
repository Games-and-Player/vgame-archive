# 游戏的负累

# ——从史克威尔的亏损想开去

文/特约撰稿人 王骏生

去年秋天的时候，有三家不算太小的公司几乎同时决定退出当年的东京游戏展。

这当然是业界的一大新闻，不过由于一点特殊的关系，当时大家的目光，都集中在了大厦将倾的世嘉，和已经被派金宝公司收购了的SNK身上，至于三大公司的另外一个角色，完全为人所忽视。

那个公司就是史克威尔。

当时所有的人都已经看出，世嘉和SNK的退展，完全是公司经济已经到了濒临崩溃的地步，甚至连参展所需要花费的成本都已经无力支付；而当时所有的人也都相信了史克威尔的解释，真的以为公司是因为没有什么可以出展的东西，而主动放弃这个电玩业传统盛会的。

因为一说到史克威尔，大家就会想到FF系列，就会想到那无与伦比的出色电脑动画，就会想到令人惊叹、可望而不可及的超白金级销量。而这样的一个公司，是绝不会让人和“亏损”这两个字联系起来的。更何况，在那个时候，史克威尔还决定增加FF电影版的投资，并有意以此角逐奥斯卡。

所以这显然确实是史克威尔的一个财务警告，却根本没引起任何人的注意——一直到今年的春天。

坂口博信的辞职，就象一记沉重的闷棍打在人们的头上。直到这个时候，大家才恍然大悟：原来不单是世嘉或者SNK，辉煌至史克威尔如斯的公司，居然也在亏钱。原来游戏真的是那么的重！

似乎是有意呼之欲应的，Merrill Lynch（美林投资银行）在今年三月初发表的一项评议报告中，试图以XBOX涉足电视游戏领域来预测微软，至少在5年内不能盈利。虽然比尔·盖茨对此的回应是“不予置评”，但稍稍熟悉一点业界硬件战手段的人，都明白美林的报告并非空穴来风。如果微软真的想在这场残酷的竞争中取胜，如果微软真想帮这个游戏世界一点新的概念的话，那么落寞的时间恐怕也不单是5年。

可惜，比尔·盖茨并没有这么仁慈，他只是为了赚钱。而为了赚钱，方才证明美林的报告是一派胡言，XBOX也许还会令电玩业震动得更加面目全非。

如果说，15年前的电玩业还是靠创意赚钱的话，那么现在的情况刚好相反：有创意的赚不了钱，想赚钱的根本没创意。

任天堂就是一个很好的例子。

我非常佩服一个能够把皮卡丘秋叶的皮卡丘的东西变成金银铁铜，红蓝白绿紫色的公司，我也承认任天堂抓住了游戏本质的东西，并且让它变得很有魅力。

可惜，这一切都是在真正不朽中得到的。

大家似乎都在等待着什么，但却不太清楚所要等待的究竟是什么。这个目标就象戈多一样，也许会如救世主般出现，也许永远不会来临——也许，也许根本就没有这个目标的存在。

盈利的压力是那么大，使得大家都陷入了一个不愿行动不愿有所变革的临危局面：赚了钱的不想革新，因为他们只想保住手里这点来之不易的利润；亏了本的也不愿冒险，因为他们只愿赌路踏岐庐笛氛气一点残羹。15年前的生机勃勃，15年前的百花齐放，现在都变成了奢侈的空谈。当游戏真正如人所愿成为一个真正的独立的产业的时候，它同时也失去了自己最为宝贵的东西。

那就是自由。

被经济的蝇索牢牢捆绑住的游戏，不再是自由的。在经济杠杆的平衡下，衡量游戏的好坏已经逐渐与游戏性无关。只要能够赚钱的，就是好游戏。

一个关于猫的定律在这里得到了最好的体现：只要能够赚钱的，就是好游戏。

这似乎已成为当今业界最神圣的定律。

我当然希望这一切能够有所改变，不是为了别的，而是为了游戏，和为了玩游戏的自己。

这几年花花绿绿、漂漂亮亮的游戏封面之中，究竟有多少能够保存在我们的记忆之中，我不知道。我只知道，有许多和我差不多年龄的玩家，当他们手里拿着会震动会显示的手柄，玩着有CD般品质音效和电影般画面的游戏的时候，心里想的，却是15年前的许多东西。

那个小小的，以红白两色为主的机器，有着极为简陋的操纵器和粗糙沉重的软件载体，带来的却是至今永远无法忘怀的激情和震撼。

也许我们都已经老了，也许老人注定要被新人取代。但是总有一些属于本质的东西，是很难被淘汰抹杀的——一盘鱼、美丽诱人的外表常使我们迷惑。

一些属于游戏而生的东西。我们被游戏发展着；我们成为了游戏的负累，游戏最终也卖了我们。

我并不指望在CD-ROM的黑陶中成长起来的玩家，也去寻找那种与我相同的感受。试图把馒头配咸菜时的那种鲜香教给一个吃惯了麦当劳的孩子，是一个永远也难以实现的幻想中的神话。

少数人的热情，决定不了发展的必然规律。

总有一些老公司倒下，也有一些新公司站起来。老的公司留下了经验，新的公司带来了革命。这个社会，也就在这样的过程中慢慢发展着。

有人说，任何发展总是螺旋式上升的。在今天被否定的许多东西，也许在不久之后，又将被人重新捡起。我相信这是真的。

也许在那一天到来的时候，游戏和我们，都不再有那么沉重的负累，也许在那一天到来的时候，游戏和我们，能够重又真心相拥。

我期待着，尽管这期待近乎奢望……
