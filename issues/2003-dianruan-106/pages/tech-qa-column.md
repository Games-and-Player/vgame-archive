# 速问速答

个人认为对战时是能找到一些街机感觉的！为什么……算了，人各有所好，强加自己意愿在他人身上的人是最无聊的，好，风林，这次你没有参点点评，如果是你，会给这款游戏打几分呢？

答：这次新KOF移植得不错，再没有其他多的问题，如果是风林的话大概会打7分左右吧。

——P76广告上，GBA专辑里头有50款游戏攻略（104期也是这么说的），但怎么到了最后一页的广告上就变成了30多款游戏的攻略了？解释一下。

答：是我看错码问题，如果按50款游戏的话，恐怕250页也不够啊！同时也为了把价格压到极点，只有精简内容，尽量把值得收录的攻略部分收进，物有所值。

——P51上面对XB的总评：满分一（汗）不说了，风林您自己明白——这不正常。

答：半求主机的话，XBOX得最高分是应当的，不过毕竟我们不是天天玩这系主机的，如果是重要的话，更是风林推荐的话，第一当然是PS2完全展示，看有这两个月的软件也算优质。本没有其他商量的余地啦，所以，但对于国内玩家来说何足奇是，后者对自己不为的更好？

——P37游戏点评，KOFEX2给结了超低分，我不平啊！这游戏真的不错。

答：省略，游戏本身也可以说是不错的，只是当时的评价标准存在差异，欢迎继续来信讨论。

——四川隆昌 小浪

## 同页下半：闪电短语（二）

【图】栏目图标：卡通人物侧面探头张望

■V拉力3刚刚入手，游戏画面出乎我的意料，全3D画面，真是……不想购《世嘉拉力》但看了小编们的评价和亲自试了一下，我，失望啊！V3我觉得是GBA上最好的3D游戏了，1、请问风林大哥以后在GBA上还会有3D的游戏还会有超过V3的游戏吗？2、《最终幻想》在什么时候有RPG类型的游戏在GBA上呢？3、请风林大哥多讲一些关于《口袋妖怪A》的秘技，拜托！

（天津/宁选）

答：1、GBA上的3D游戏已经超过越来越多了，比如前段时间刚刚见到的“TAXI 3”（根据法国同名电影改编）“疯狂出租车”等等，画面也格外炫目，有的风林甚至觉得色彩不亚于SS。当然，还没有在游戏机上的速度是越感觉GBP特别电视上者的话恐怕会不满，因为这个游戏在GBP和GBA之间展开，不出意外的话，风林是最赏识《V拉力3》仍旧是GBA上最出色的3D赛车游戏，2、推荐玩家继续GBA的3D赛车游戏，3、目前列出的《口袋妖怪》相关秘技已经花在其它栏目中刊出了，下面是张GC2的假想图，虽然外设想得非常出色。

【图】任天堂GameCube主机及手柄、遥控器等周边配件套装照片

听说NGC也有下一代，如果有那么有没有什么资料或图片什么的？还有XBOX2不是可以透露些内容消息呢？（南京/郑敏）

答：目前你一可以确定的是三大硬件厂商都在有推出新主机，可是这次上的日期将会非常晚，2005年内，各主机的发售日子会相当远。恰恰是想游戏软件继续都必开发展了大约，不出意外的话，网络游戏将是下代主机装载的主力体，如XB2与PS3不相多说，GC2是否还能继续走自己的路线，因此，我毫无兴趣去分析和试点评心态。有点点线索也好吧，还是看作乐可吗？

■因不知真名只好如此称呼，我也算是一位老玩家，一直到似地问过（一直到似记者人的），已合年才刚入手一台GBA，也是年才刚看《电软》，也许在你看来只是刚刚入门的“零头”。

现在看现今，今年年底退出，打算回去后买台NGC，可看到《电软》104期中有一“松下DVD NGC”，请问一下它和任天堂的NGC有何不同，GC的DVD光盘不是比一般的DVD盘要小些吗？如常用它看DVD会不会影响光头，而读不出GC的游戏！请帮忙解答，十分感谢。（河北/晓白）

答：松下的您应该没有见到，那我也很难忘记看了吧！以外华丽，但机体本身就化了，又比普通GBP机使用了，更没有毛病，可能是无法达到播GBP等新增中过。因此此说没有丝毫不推其他的Vs。另据传闻分了有打算出无关这次改造，目前还没有任何消息。

■现在送达的《电击收藏》很不错！游戏杂志志静动静结合，像一些游戏爱好者介绍，图片印得再漂亮也是很难表达体现出来的，有了VCD就好了！就算我说不错，我也能说它谈，老子领略过。不过……！我觉得VCD的部署否不合公适，感觉有虚《动物世界》或《与自然》？声音挺老，我觉得应该也读些年轻的圈子！比方说像结再有电影普通话配套的，或是找我些也仅是CV音乐DJ来配好！

（广西/维他命）

●《电击2》已经买换了配色，不过我表现地觉得如何，风林感受是，虽然编都自己配的东西中人是必是，苦劳都摆上一边，年基本都错误上去会有一句相当的心意。

听说NGC也有下一代，如果有那么有没有什么资料或图片什么的？还有XBOX2不是可以透露些内容消息呢？（南京/郑敏）

■第一时间买到《电软》105，如猎食之豹似高玄之弱驰电梦般起家里“贬”的一声把自己关门后，两耳不闻窗外事，一心只把《电软》这好，好像在茫茫沙漠中苦寻了半个月，猛见一溪甘泉，于是暴饮，一口气弄到不留缺，不过，还是有几分遗憾，怎么一开始买不到小编的声音，虽未谋面，却也足令小弟遥闻其淡雅高尚气质、感慨万千。而下面几个我一直想不通的问题请谢谢，怎么编辑点评里众口一编的声音给人一种深沉低调的味道？有名的地方也让我心疼花在过下面是张GC2的假想图，虽然外设想得非常出色。

（贵州/杨新荣）

答：1、邮购信息中刊登的是杂志社的邮购的存活，2001年的杂志志经营已经死光，邮购无望，2、如果是游戏感恩记忆之光，请找“游戏点评”栏目，如果游戏研究的话是“游戏研究所”栏目，畑面评论字数请控制在400左右，并附上评。
