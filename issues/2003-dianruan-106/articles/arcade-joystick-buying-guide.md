# 街机摇杆选购指南

【图】蓝色PS制式街机摇杆照片；游戏摇杆按键特写照片

摇杆做为很多街机迷的必备之物，已经不是什么稀罕东西了，但真正能够按照自己所渴望的一次购买到适合心意的摇杆的玩家却并不是很多，这其中的原因就有对于摇杆的不了解。在此少将想将自己的一些经验说一下：

其实说起来一款摇杆的好坏并不是一定的，有些摇杆在有的人用来顺手之极，而有些人却觉得难以驾驭，这和每个人使用的方法和习惯是有很大的关系的。但是采购摇杆相对来说是件比较麻烦的事情，因为如果要把每一款摇杆都拿在手上试用，并打上几局自己想玩的游戏的话，那就要花费很长时间，而专卖店BOSS的脸色也不会好看的啦。因此我在购买时应该先对自己所看中的产品作一下“先读”（呵呵，那是大概评估一下产品啦，然后再决定是不是要上机试用。如果一开始就难以满足自己的要求的，也就没有在上面浪费时间的必要。

“摇杆，摇杆”，摇杆做为一种仿制的输入设备，它的方向杆自然是最重要的一环。而方向杆的好坏主要取决于以下几点：

1. 方向杆底端内环的形状。
2. 方向杆的倾斜角度。
3. 方向杆的高度。
4. 方向杆上面的手托。

■首先是第一点底端内环的形状。所谓“内环”就是指方向杆底盘内制约方向杆倾斜范围的那个圈，也就是将方向杆倾斜到最大角度时转360度时所形成的那个环形。而现在的摇杆内环主要有圆形和八角形两种。八角形的内环有着定位准确，方向指向容易的特点，也就是说在八个主要方向移动的时候由于有边角指示所以不容易误输入，这点对于格斗游戏来说是相当重要的。而圆形的内环有着转向轻的特点，无论向任何方向移动都非常的流畅，这正好是射击类游戏所追求的感觉。

而说说选用哪种内环的摇杆是要根据使用者常玩的游戏类型来决定的。在这些附加因素中，即八角形的内环在这些附加条件面前，而圆形的因素不同。有些圆形内环的摇杆完全是由于为了节省成本而简化制作和加装内环所造成的结果，这种摇杆大都有着方向杆可倾角度较大，摇动时感觉较松动等情况（现在这在大多数小摇杆，制作工艺较差的成品和现在PC上用的摇杆的用是的），而真正的圆形内环摇杆的手托也是要球形的（例如SONY原装的摇杆），这种摇杆，无论是从哪一方还是射击游戏都是不适合的。

还要额外说一下SEGA原装摇杆的内环。SEGA原装摇杆的内环比较特殊，是正方形的。也就是说它四个主要方向是四条边，而四个斜方向则是四个角。说起来会觉得有点面而不着边的感觉，但可能是由于SEGA多年的街机制作经验，它们的这个正方形的边边角角是有着严格的设计思路的。具体的指标不太清楚，但只要用过的人一定都会觉得方向杆非常的好用，定位相当准确，可谓指哪打哪儿。而我也用过另一款正方形内环的摇杆，感觉完全不是那么回事了。不过总的来说SEGA原装的摇杆还是来打格斗游戏理想一些的（强烈推荐）。

■第二点是方向杆的倾斜角度，这是指方向杆能达到的最大倾斜程度时与垂直线所构的这个角度。这个角度不能太大，太大则会出现输入指令时间较长的情况，但也不能太小，否则有可能出现误指令的情况。一般来说在10度左右为最佳。既不用太大力气，又可以准确的完成方向指令的输入。当然，这也是因个人而异，对大家购买时还是要根据自己的习惯来定。

■第三点摇杆的高度（也就是它的长度）就不用多说了。太短会对手造成挤压（尤其是上托式摇杆的玩家，因四手指对指腿容易疲劳），而太长则有可能给使用者的用力带来不便（这个对于压式摇杆的情况来说不太有利）。

杆，即用手心或虎口置住手托，向下压方向杆的摇杆影响就要大一些了。这点还需要注意。

■第四点方向杆上面的手托，也就是方向杆顶端的那个球啦！可不要小看这个球啊，它直接关系到使用者的感觉舒适与否。太大太小、太厚都会让使用者感觉不舒服。总之这一点就只好亲自来试用啦。这里要说一下，大多数街机的手托是球形的，但家用摇杆的有商店柱面的（例如SONY原装的摇杆），这种摇杆，无论从对手方还是射击游戏都是不适合的。

其实日本的街机制造商对于上面所提到的第三和第四点是不要要求的，虽然不强制要求，但绝大多数街机厂商都是按这一制造要求来制作机器的。所以我们在街机厅里面所买到的街机的方向杆高度和手托大小都不太多。在家用领域里，尤其是一些国产的摇杆则不一定遵守这个规则，所以有时会出现不适合玩家使用的情况。所以说方向杆这个对于摇杆的手感关系最大的因素上，玩家在选购时一定要以多试用为原则，因为即便找到了一款很满意的产品，它仍有可能会更适合。

下面来说说第二重要的吧，那当然就是按键了。关于按键可说的也有不少，主要有两点就是按键的手感和按键键位的排列了。

现在按键的手感方面主要有两种情况。

一种是偏向轻触，另一种是偏向提示。所谓轻触就是说按键手感较软，无须太大力就可以把它按下。这种情形的优点就是轻快，但是也是显而易见的，就是有时会在无意识时触碰输入，导致误操作。而提示方法则是对于按键有一定力度要求，且在按到底时会有弹性触感反应到手指上，以给使用者提示。这种情况的优点就是对于按键有一定的反力，不容易出现误输入，但缺点就是感觉较硬便，相对来说，射击游戏第一种按键比较好，而格斗游戏则是第二种略好些，不过话说回来，无论是哪种手感的按键，都不能太过分，否则感觉会给使用者带来大大的不便，而有些厂家的产品（如SEGA、HORI）能会结合两种特点于一体的，可以说是有大多数玩家所使用的！这里需要注意的是有些摇杆的按键别出比较硬（有时甚至会给按键按下去时不到底或是感觉要什么东西卡住的情况），这并不属于提示型按键的范畴，主要是由于按键大小和底盘塑质较差的产品，键内部的感弹性胶质欠佳（说白了就是产品的工不行）造成的。这对于摇杆的手感和操作来说都是极为不利的。

而键位排布相对就很难说好坏了，完全是要看使用者的习惯。以八按键摇杆为例来说，其他六键或四键的也一样，大多数产品的两个使按键布局都以左低右高的人体工程学为理排布的，而横排式虹卡是上排XYZL，下排ABCR（这里是以SS的八个键为准的，其它机型请自行对比）。也有些机型是不同的，比如HORI的SS-PS双用摇杆，就是上排LXYZ，下排RABC。而SEGA的SS原装单摇杆更简单，是上排XYZ，下排ABCR，下排则有五个键。这对于比较喜欢用宏定义键（将PPP或LP+LK等来多个键的功能定义在一个键上）并且熟悉标准按键布局的玩家来说是无谓的大麻烦。这点希望大家一定要注意，选购摇杆的时候尽可能了解还是要照自己的习惯来购买的，免得到时候真的因为按错键就对局又被人说是强调夺理呀！而这里注意的一点就是方向杆和指头之间的距离，有些小摇杆之间的距离很近，显得很挤，这对于使用者来说是很要命的情况……

上面所说的都是一些对摇杆“手感”有着直接关系的内容，而且都是可以在不接触的情况下就能猜个八九不离十的。也就是说当拿到一款摇杆的时候可以先空试一下，如果上面的要求感觉比较适合的话，那就可以上机试用啦。反之，一般来说就没有试用的必要了。

最后，祝愿所有喜爱使用摇杆的玩家都能买到一款称心如意的产品，战无不胜。
