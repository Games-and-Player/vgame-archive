本作属于前作资料片性质的作品，主要的乐趣在于收集各种机体的部件和武器，以及在斗技场击败敌人获得隐藏的机体。本作的任务数量大幅增加，但是难度相应很低，大部分任务都可以很轻松地完成，加上篇幅有限，这里只对几个技巧性较强的关卡进行攻略说明。

很多玩家对该系列各种复杂的数据搞得晕头转向，下面就讲一下机体的各种设定，以便于大家组合出最适合自己的强力机体。

## 机体部分数值简明解说　　　　　——基础讲座

### CORE

机体的主要部分，其承载量会影响到手部和辅助部件的重量，而AP是全部部件中最高的。

●MAX WEIGHT（最大荷重）

指所有跟CORE接触的部件的重量，包括头部、手部及武器部都会影响到这一个数值，要装备一些较重的装备，这个数值要求非常高。

●VS-MG-RESPONSE（迎击准确率）

在每一个CORE的前方都装备有对导弹的机炮，当感应到有导弹攻击的时候便会自己迎击，前者是准确率，后者是攻击范围。

●VS-MG-ANGLE（迎击范围）

●EXTENSION SLOTS（辅助零件）

辅助零件空间多的CORE防御力通常都会比较低，反之防御力高的CORE便不可以多装辅助零件了。

### LEGS

玩家可以因自己的作战风格而选择使用两足型、逆关节型、四足型或是装甲车型的脚部。不过要注意的是脚部的承载量，如果承载量太低的话，上身便不能装上一些较重的装备了。

●MAX WEIGHT（最大荷重）

就是脚部的承载量，多数承载量高的脚部，其动作性都是比较低的。

●SPEED（移动速度）

在没有使用推进器时的移动速度，AC的重量跟速度是有着一定关系的。

●STABILITY（安定性）

在使用大型武器或中弹时的冲击和这个数值有着直接关系，可以因这个数值的多少而改变。

●TURNNING SPEED（旋回速度）

机体在转身时的反应，在锁定一些高速移动的机体时，便需要一定的旋回速度。

●ENERGY DRAIN（待机EG）

在机体停下来的时候，机体的ENERGY就会恢复，数值越大恢复得越快。

●JUMP FUNCTION（跳跃机能）

只有装甲车型的脚部不可以跳跃，其他的都没有什么特别。

【图】两张游戏截图：蓝色机体持枪瞄准姿态；黄色多足型机体作战场景

### WEAPON

说到武器，便可以分为左、右手及背部这三种，再分为GUN（右手武器）、BLADE（左手武器）、ARMS（手腕武器）、MISSILE、ROCKET、CANNON以及DOUBLEBACK WEAPON等几种不同类型的武器，还有就是实弹系及能量系等不同类的弹药。

●WEAPON LOCK

武器本身的LOCK ON，分为STANDARD（标准）、WIDE&SHALLOW（阔）、NARROW&DEEP（远距离）以及SPECIAL（超远距离），不过武器本身是会因为FCS的类型而有所改变。

●NUMBER OF AMMO（弹数）

武器的弹数，多数强力武器的弹数也不高，但是玩家可以利用特殊配件来增加武器的弹数。

●ATTACK POWER（攻击力）

武器的攻击力，攻击力高的武器RELOAD时间都会比较长的，然而攻击力低的便会有较高的连射速度。至于手腕武器的攻击力是双倍计算的。

●RANGE（射程）

攻击有效距离，会因为FCS而有所改变。

●AMMO TYPE（弹药类型）／AMMO PRICE（弹药价钱）

弹药类型有实弹系和能量系两种，在使用能量系的武器时，会不断消耗能量的，而实弹系的武器每一发弹药都会计价，所以最好是在ARENA的时候使用为佳。

●RELOAD TIME（充弹时间）

是补充弹药所需的时间，这一项数值低的话，武器的连射速度便会提高，同样的强力武器是需要较长的充弹时间。

【图】机体举枪瞄准射击画面

### HEAD

主要是雷达和地形图这两种机能对头部的影响最大，由于强化人间本身已经有雷达功能，所以在购买头部时，最好以MAP TYPE为首先考虑的对象。

●RADAR

在机体头部的内置雷达，性能方面当然不会有肩部雷达那么好。

●NOISE CANCELER

有防止电波干扰的功能。

●BIO SENSOR

可以锁定一些生物兵器。

●MAP TYPE

在每一个任务时，都会有该地的地形显示，AREA便是将经过的地方记录下来，至于AREA&PLACE NAME便是一开始便清楚整个版图。

●COMPUTER TYPE

战术电脑的辅助，有时会出现一些指示给玩家，实际用途不大。

## 游戏初期重要任务完成指南　　　——基础讲座

本作的关卡非常多，但是内容大同小异，绝大多数关卡只要将敌人全部消灭就可以过关，这里介绍一下游戏初期几个比较有代表性的关卡。

### 侵入者击破　报酬10000

本关任务是排除侵入奇撒拉基地的技术者，地图分为A、B、C三个区域，敌人是地上型守备机和技术者乘坐的MT，到达各个区域的地上型守备机后，接着下一个区域的门的锁就会解除。据自己的攻略经验，在最初抵抵挡的B区域里会出现技术者乘坐的MT，没有什么特别值得注意的，和对付杂兵的方法一样，先攻击了事。

### 可宾集团排除　报酬16000

本任务是排除侵入米拉加的暴走部队集团。由于在交错的街道上大楼林立，所以在移动时要一边用雷达确认敌人的位置一边前进，敌人里面会有MT出现，用不花钱的弹药或直接消灭之，途中间会遇到区域移动，只带自己的雷达通过。

### 无人部队迎击　报酬17000

本任务是排除侵入奇撒拉吉的能源生成设施的无人部队，无人部队的目的是炸毁这里，玩家要阻止他们在容器上安装炸弹。如果炸弹已经装上了，玩家要在炸弹爆炸前把它拆除。本关有修理机，实在没有必要向他求助。

### 护卫资源运输船　报酬11000

本关任务是护卫奇撒拉的大型运输船，运输船内有发电机，玩家必须保护其不被敌人破坏，当发电机被破坏20个时任务即宣布失败，由于玩家非

己的武器也能够破坏电机，所以玩家一定要锁定住敌人后再攻击，另外，发电机每被破坏一个，报酬就会减少，所以还是赶快消灭敌人为好。

### 击退密林部队　报酬17000

本关任务是击退隐藏在密林里的奇撒拉基的部队，这里不能用雷达确认敌人位置，而且地图比较麻烦，惟一的方法就是靠游击战法，玩家朗着大概的方向搜索敌人。是敌人的移动速度很快，所以这以后必须加快步伐才行。地图上的树不会造成障碍，玩家只需飞速前进即可。另外，本关可以搭配僚机。

### 机体的基础能力值

| | |
|---|---|
| OFFENSIVE POINT | 攻击力，所有武器攻击力的总和。 |
| DEFENSIVE POINT | 防御力，所有实弹防御和能量防御的总和。 |
| STABILITY | 安定性，发射炮弹时的后坐力，中弹时的反作用力都和这个数值有关。 |
| MOBILITY | 机动性能，机体动作性能的总和。 |
| MOVING SPEED | 移动性能，机体移动的速度。 |
| TURNING SPEED | 回转性能，这个数值较低的话，机体转身会比较慢。 |
| RISING ABILITY | 上升性能，BOOSTER（推进器）的输出，会因机体的重量而改变。 |
| SUPPORT SYSTEM | 雷达性能，雷达范围及FCS机能的总和。 |
| RADAR RANGE | 索敌范围，将内置雷达及背部雷达的数值总和乘以十分之一便是这个数值。 |
| FCS PERFORMANCE | 照准系统能力，FCS机能的总和。 |
| OVERALL | 总合值，把以上所有的数值加起来便是这个数值。 |
| GRADE | 评价，由综合值得出来的评价。 |
| EP | 机体能量消耗值，右为输出能量，左为机体能量所需数值，两个数的差越大，机体的速度越高。 |
| LEGS WP | 脚部载重量，右边的数值是脚部以外的总重量，左边的数值是脚部的载重量。 |
| CORE WP | 身躯重量，右边的数值是手部及背部装备的总重量，左边的数值是身躯的载重量。 |
| AP | 耐久值，所有部件加起来的耐久值。 |
| WEIGHT | 机体的总重量，会影响到机体的上升能力。 |
