# 科普园地

# GC硬件分析

文/玉林yoyo

任天堂新主机GAMECUBE（以下简称GC）终于在9月14日正式发售了。作为任天堂的128位次世代主机，GC在硬件方面到底有怎样的表现？让我们来详细分析一下。

## CPU：Gekko

GC采用的CPU代号为“Gekko”（壁虎），由IBM制造。

| 项目 | 参数 |
|---|---|
| CPU | IBM PowerPC “Gekko” |
| 制程 | 0.18微米铜配线工艺 |
| 主频 | 485MHz |
| 内部数据总线 | 64位 |
| 外部数据总线 | 64位 |
| 浮点运算 | 1.9GFLOPS |
| 晶体管数 | 约2100万个 |

Gekko是基于IBM的PowerPC 750CXe核心进行定制的，任天堂在原有的基础上增加了50条专用的SIMD指令（称为“Paired Singles”），专门用于加速3D图形计算中的矩阵运算和向量处理。

与PS2的Emotion Engine（EE）相比，Gekko的主频虽然只有485MHz（EE为294MHz），但由于其采用了更先进的超标量乱序执行架构，单位频率的效率更高。特别是在浮点运算方面，Gekko的1.9GFLOPS实际性能与EE的6.2GFLOPS理论峰值之间的差距远没有数字上看起来那么大。

## GPU：Flipper

GC的图形处理芯片代号为“Flipper”（海豚），由ATI（原ArtX）设计。

| 项目 | 参数 |
|---|---|
| GPU | ATI/Nintendo “Flipper” |
| 制程 | 0.18微米NEC嵌入式DRAM工艺 |
| 主频 | 162MHz |
| 内嵌显存 | 3MB（2MB帧缓存 + 1MB纹理缓存） |
| 像素管线 | 4条 |
| 纹理单元 | 每管线1个（共4个），支持8层纹理 |
| 多边形处理 | 理论峰值1200万多边形/秒 |
| 像素填充率 | 648M像素/秒 |

Flipper的独特之处在于其采用了NEC的嵌入式DRAM（eDRAM）工艺。这意味着3MB的显存直接封装在GPU芯片内部，与GPU核心之间的数据传输带宽极高（内部带宽约为10.4GB/s），完全消除了外部显存的带宽瓶颈。

这种设计使得GC在进行Z-Buffer测试、Alpha混合、抗锯齿等需要大量显存读写的操作时效率非常高。实际游戏中GC可以轻松实现全场景4×抗锯齿，而PS2要实现同样效果则需要付出很大的性能代价。

Flipper还集成了音频DSP和I/O控制器，真正做到了“系统级芯片”（SoC）的设计理念。

## 内存系统

| 项目 | 参数 |
|---|---|
| 主内存 | 24MB 1T-SRAM（MoSys） |
| 主内存带宽 | 2.6GB/s |
| A-内存 | 16MB DRAM |
| A-内存带宽 | 81.9MB/s |
| GPU内嵌显存 | 3MB eDRAM |
| GPU内嵌显存带宽 | 约10.4GB/s |

GC的主内存采用了MoSys公司的1T-SRAM技术。1T-SRAM在外部接口上兼容标准SRAM，但内部采用了DRAM的单晶体管存储单元，配合高速缓存逻辑，实现了接近SRAM的速度和DRAM的高密度。24MB的容量加上2.6GB/s的带宽，比PS2的32MB RDRAM（3.2GB/s带宽）略逊，但考虑到GC的GPU内嵌了3MB高速eDRAM，整体内存系统的有效带宽并不落后。

另外的16MB A-内存（Auxiliary Memory）主要用于音频处理和操作系统功能，带宽较低，不参与图形渲染。

## 光盘系统

GC采用了松下开发的8cm专用光盘，容量约为1.5GB。

| 项目 | 参数 |
|---|---|
| 光盘规格 | 8cm专用光盘（基于DVD技术） |
| 容量 | 约1.5GB |
| 数据传输速率 | 2-3MB/s（CAV） |
| 旋转方式 | CAV（恒定角速度） |

任天堂选择8cm光盘而非标准DVD有以下几个原因：
1. **防盗版**：专用规格的光盘很难被普通光驱读取
2. **成本控制**：不需要支付DVD Forum的专利费
3. **读取速度**：8cm盘片由于直径小，旋转惯性小，寻道速度更快

缺点是1.5GB的容量相比DVD的4.7GB明显不足，大容量游戏可能需要使用多张光盘。

## 与竞争对手的对比

| | GC | PS2 | XBOX |
|---|---|---|---|
| CPU | Gekko 485MHz | EE 294MHz | P3改 733MHz |
| GPU | Flipper 162MHz | GS 147MHz | NV2A 233MHz |
| 主内存 | 24MB | 32MB | 64MB |
| 显存 | 3MB eDRAM（内嵌） | 4MB eDRAM（内嵌） | 共享主内存 |
| 光盘 | 8cm 1.5GB | DVD 4.7GB | DVD 4.7/8.5GB |
| 硬盘 | 无 | 无（可扩展） | 8GB内置 |

从纯硬件规格来看，GC的整体性能介于PS2和XBOX之间，更接近XBOX。虽然在内存容量和光盘容量上不如竞争对手，但在GPU架构设计上有独到之处，特别是eDRAM带来的高效率抗锯齿和高速Z-Buffer操作，使得GC的实际画面表现往往超出其纸面规格所暗示的水平。

## 总结

从硬件设计哲学来看，GC体现了任天堂一贯的“性能够用、设计精巧”的理念。整台主机只用了3颗主要芯片（CPU、GPU、内存控制器）就实现了完整的系统功能，这不仅降低了生产成本，也提高了系统的可靠性。

对于开发者而言，GC的编程模型相对简单直观（特别是与PS2的复杂架构相比），这意味着开发者能够更快地发挥硬件的性能。随着开发经验的积累，GC的画面表现还有很大的提升空间。

任天堂能否在这一代主机战争中取得好成绩，硬件只是基础，更关键的还是软件阵容的充实。让我们拭目以待。
