# 电脑战机4（Cyber Troopers Virtual On ~ FORCE）

| | |
|---|---|
| 机种 | ARCADE |
| 厂商 | HITMAKER |
| 类型 | 对战ACT |
| 发售日 | 2001年10月下旬稼动 |

责编 XTT

“两个革命的游戏与一台革命的主机”●一切不出编者所料，莎木2、PSO两大惊世巨作降落XBOX！！！专司市场规划及厂商协力的SOA副总裁CHARLES BELLFIELD指出：“这两部作品正在依据XBOX的架构重新设计，并运用其超高技术特性诸如硬盘以及宽带传导能力。细节处今后会公布。现在，元论铃木裕还是中裕司（天语：世嘉'双裕'，重拳出击！），在为XBOX制作此二作品时弹精竭虑，但二人一定会将具有革命性的GAMEPLAY（游戏性）呈现于XBOX平台。……”（见本页下面）

世嘉街机有四个大的系列，它们是：VR战士，达比赛马，足球射手，电脑战机。这里介绍的是战机最新版——进化周期长达三年的FORCE（4）。

## 九大机体齐聚一堂！——出击准备完毕！

**CUSTOM 基板（Hikaru）+ 先进筐体 + 机师专用卡片系统 + 2on2 对战**

电脑战机从95年诞生至今已经6年。本最新作的开发时间即长达3年。用制作者互重郎（Producer）和山下信行（Director）在回答记者“为什么不使用NAOMI系基板来开发”的疑问时指出，此番使用CUSTOM基板，乃是NAOMI2虽强，却很难实现“二对二”，而如果用Hikaru，就可在挖掘基板潜力之后实现。

闻名遐尔的“炸裂”级操纵感，结合2on2之后如虎添翼！

卡片系统和二对二，是新作两大要素。磁卡不仅会记录个人游戏资料，跟新机体和机体的赋与也有很大关系，其中，新机体又最受瞩目，因为它能给玩家带来更大的对战乐趣。虽然换乘新机体的机会因人而异，但跟战斗的胜负却没有关系。换句话说，就算没获胜，也有机会得到新机体，不过，新机体的性能也未必好。

## 最大注目点：VO4卡片系统

关于卡片系统目前判明的有：1、新机体的换乘（也包括机体新颜色）。2、阶级的赋与。这是指从候补生开始随着胜利而提升，它表示玩家实力，最高阶级是元帅。3、随时可以阅览卡片记录的资料，除战斗次数和胜率之类，还有记录总战斗时间和防御成功次数等资料。

【图：实际使用的VO4卡片样本。上方的空栏会显示最初登录的驾驶员名字、使用机体和阶级。售价300日元，1张卡约能使用30次。卡片使用流程见下面。】

### 这就是售卡机！

【图：VO4卡片售卡机照片，筐体有外挂喇叭】

●上左：首先要在名为VO4端子的售卡体购买卡片并决定驾驶员的名字和机体，然后将取得一张阶级为“候补生”的磁卡。其实这种卡系统早在之前举行的LOCATION TEST中即已启用。●中：插入卡片后再来游戏！当阶级提升或被赋与新机体时，画面会出现“紧急联络”的讯息，这时，要赶紧将卡片插入机台上的VO4端子（端子是免费使用的，由于卡片记录战绩，对战时可马虎不得，要加倍努力才行。可随时通过端子来确认自己战绩）。●上右：利用VO4端子可取得新机体，大概在你玩约20几次时会发生这种事件。只要接受司令部的紧急联络，就能选择是否换乘新机体，只是换过之后就无法搭乘原来的机体。再者，游戏中除了机体的换乘和阶级提升之外，也会发生选择新颜色事件。

### 九大机体分系介绍

机体个性完全不同且高度拟人化动作，因此画华丽度高于电脑战机操作技巧对战时常制激烈，这次九大机体分系为：

- **BAL 系**
- **APHARMD 系**
- **ANGELAN 系**
- **TEMJIN 系**
- **RAIDEN 系**
- **SPECINEFF3 系**
- **FEI-YEN 系**
- **VOX 系**

【图：TEMJIN系的四种机体。此系可称为标配。最右方那家伙拥有比别人大三号的武器，看上去蛮酷的样子。具体不明。】
