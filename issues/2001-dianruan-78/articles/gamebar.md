## 射雕英雄传

| | |
|---|---|
| 机种 PS | 厂商 SCEI |
| 类型 RPG | 媒体 CD-ROM |

相信各位玩友都已玩过该游戏了吧。因为其中的剧情大部份还是照书原数，只要看过书或是电视剧的是很本不用什么攻略的。那玩过之后，大家都有什么想法呢？

我的评价是，这个游戏如果在欧美发售的话，下场肯定很惨。除了剧情，几乎没有什么值得去玩的地方，虽然其中有一些小游戏，但毫无创新，都是其余游戏类型的改版。这种游戏只能卖给那些即是金庸迷又是游戏迷的人，只有这样的人才会支持这种游戏。片头CG制作得太一般，音乐太古板，一成不变的冒险模式，从头到尾只是不断的练级，而且，如果不到最高等级的话，就算打通关也不会把精好练成。我用了大约十六个小时穿版，但嗯好的最高等级才到6级。而该游戏唯一有趣的地方就是嗯好这一点，所以如果不练级就没什么乐趣可享受了。从头打到尾，相当于温习了一遍《射雕》而已。但象我这种不喜欢武侠小说的人，打穿这个游戏完全是看在中文游戏的面子上，但实在太令我失望了。而且网上说此款游戏根本没什么销售量，看来这款游戏制作水平与国际水平还是有很大差距的。充其量（射雕）只能算是半成品，根本不应该拿出来卖。也许我说得过火了点，怎么也该支持一下中文游戏吧。但是别忘了，上星土开始制作中文游戏后不久就灭亡了，看来PS高被淘汰也不会太远了。其实我也是一个PS的支持者，只是事实摆在眼前，不接受也不行呢。现阶段，玩玩DC还挺合适的。如果想再温习一遍《射雕》的话，那就再玩玩这游戏吧，反正也不需要多长时间，不过一遍之后就没有任何价值了，订了原版，现在真有点后悔了，唉……

## 武装任务（GUN SPIKE）

| | |
|---|---|
| 机种 DC | 厂商 SEGA |
| 类型 ACT+STG | 媒体 GD-ROM |

用万众瞩目来形容本作绝不为过。射击代言人彩京加动作大家CAPCOM联合制作的游戏，对于业界玩家来说其震撼力绝不亚于后者与SNK合作的格斗。毕竟对于当今射击类型游戏奇缺的市场而言，本作的出现仅用“”来形容确实有些低估了它。尤其对于DC，更应视为难得之作。

玩后最大的感觉就是“”。说它难吧，的确不简单，不信你就调最高级乘试试能不能用三条命翻版（应有高手可为），但也可以是“”后的成果吧）；说它简单吧，的确不是特变态，打BOSS时几参加重击再加个必杀基本就可以爆掉一个，尤其是中级以下难度，不爱命翻版可调勇如反掌。总之呢，本作在难度方面设计得还算体贴，颇适合各层玩家。

另外，个人玩后感觉本作更要靠近卡普空的风格，又有丧尸又有巨怪而且拳脚方面颇为突出。射击敌人被量较低，而用拳脚当然近身后的代价是最大损失体力，但是对于某些唯恐战术小的BOSS则截好打斧脚打加，速战速决，以免龙长梦多。

游戏每关版图小，但玩来的是极度精悍的画质，相信有的玩友必会认同。

## D之食卓2（Dの食卓2）

| | |
|---|---|
| 机种 DC | 厂商 WARP |
| 类型 AVG | 媒体 GD-ROM×4 |

据说这次饭野贤治真的裁了。历时5年长时间制作的《D之食卓2》在日本的销量都不及十万份。但平心而论，《D之食卓2》还真的是一款优秀的AVG作品。

高质量的CG动画自然不在话下，但游戏的画面始终有些黑暗，或许是故意要突出那种恐怖的效果吧。这样做反而有种吃力不好的感觉。人物的动作质感很真实，从竟跃在雪地里和踩在地板上是不一样的。背景处理也很完美，看着雪一片片地飘下来，心里却滴滴润动着一股说不上来的凉泉。

怪物的设计有些千篇一律，玩过《生化危机》的人对那些林林总总的变体已经是麻木得见怪不怪了。但射击的部分是我不能苟同的。先瞄准，再射击，实在找不出什么好玩的地方。更不可理解的是怪物被打死后尸满的那些液体处理得真是弓虎，随便抓一个PS的游戏来也比它好多了。

而雪地里驾驶雪车疾奔前的时候真是爽极，起伏不平的雪地，加上后面不断截起的碎雪，这一段倒是能刺制成RAC的游戏还大受欢迎入叫好。由此可见WARP的魄力。

或许因为《D之食卓2》的失败，WARP会从此退出游戏界吧；也或许WARP继承了SEGA永不言败的精神，会继续推出《D之食卓3》吧。不管怎么样，我都期待着新的作品。

## 疯狂计程车（CRAZY TAXI）

| | |
|---|---|
| 机种 DC | 厂商 SEGA |
| 类型 RAC | 媒体 GD-ROM |

PERFECT！这款游戏的感觉简直就是完美。很早以前我就希望能有一款RAC游戏是可以尽兴地在街道上狂飙的。要知道，把车开在街上，公路可是被分成两边的，而且面对城市里的多路线，爱怎么走就怎么走，想上哪就上哪，这可比普通赛车游戏爽多了呢！

SEGA果然能巧妙地把握DC的机能，游戏里的车子做得十分细致，连路人猛闪计程车的路与走，拳手投足都表现得十分流畅。

很明显，这款游戏的美式风味很浓，即满足了人的破坏欲，又提供给人了一个发泄的场所，连音乐都听了得让人有种被催着要快点的感觉，而且游戏的模式也很多，真让人有种百玩不厌的样子。唯一不足的就是游戏的背景处理仍有些32位机时代的感觉，远处的景物总是突然出现棱角再现出全貌，或许由同机能有些关联吧！但不管怎么说，DC机主一定要买这款游戏啊！！！

## 心跳纪念品·旅立之诗（DRAMA SERIES VOL.3）

| | |
|---|---|
| 机种 PS | 厂商 KONAMI |
| 类型 SLG | 媒体 CD-ROM×2 |

《旅立之诗》作为心跳纪念品的第三作，就在史克威尔、NAMCO、世嘉等大公司纷纷相互攻劲的同时，仍然能占有一席之地，如果前作《虹色青春》能够体现出游戏是一门细腻的艺术的话，那么《旅立之诗》则要加上一个“”字了。

剧情从主角被推荐做一位编辑到最后强忍伤痛拥骚完成马拉松，中间既不平坦，又不之曲折，完全体现出游戏制作的独具匠心，使游戏全篇前后得绵细腻柔，华美而悠扬。画面上与前作基本相同，采用了静态的背景再加上局部的动感，显得简洁干净，给人一种清新的感觉。至于音乐方面，虽然不象《月下夜想曲》那样能震慑人的心灵，却也自然流畅，让人的听觉神经得到充分的满足与享受。

最大的遗憾大家也早已有目共睹了——没有汉化，所以无法体验她的真正乐趣。但作为一个心跳迷，KONAMI的这份厚礼也是一定要纳入杯中的。如果想真正体会她其中的乐趣，大家恐怕又要培养自己的耐心了。

《旅立之诗》，一份真正的情感，一款经典的作品，一门细腻的艺术。

## 荣誉的勋章 特别版

| | |
|---|---|
| 机种 PS | 厂商 EA |
| 类型 STG | 媒体 CD-ROM |

一直以来，DOOM类的游戏在家用机上是鲜有好评的。也许是硬件设备的限制缺乏表现力，也许是没有了那种与人对抗的刺激，这使得在家用机上除了移植那些PC上的大作之外极少有出色的作品了。不过这款《荣誉的勋章》的出现却弥补了这个空白。

从内容上来看，本作其实是《荣誉的勋章》的女性版本，主角是一批在二战期间驰骋战场的女军官们——由她们的真实事迹改编而来，而监制赫然是大名鼎鼎的斯蒂芬·斯匹尔伯格，看来EA是动了真功夫，游戏任何一部都是尊重史实的，这点对于熟悉二战的玩家应该体会得到。这种细致入真的制作令今游戏在内涵上更增添了一份历史的况重。

本作的游戏性同样不容忽视，3D画面流畅自然，手感相当不错，并且还加入一些解谜的成分。另外敌人的行动也是很有特色，会对玩家的行动作出不同反应，各色武器也被通过伏炸付出来，令玩家在满应味的勃勃的面对现场面对情报。

但作为第一款观点的游戏，在没有连射功能的情况下实在令人头疼。另外还抓了同样的辞源。如在获赔就会令人头疼，不过想以现有的硬件水平来看，不怕那么无法完美也表现主动是不太可能，创时才能成为主流游戏之一——

## 《实况胜利十一人》——精彩的真实足球赛

科乐美的实况足球一直以来受到了玩家的热烈支持，就连一向对足球漠不关心的风林都会踢上两脚，与PERFECT叫叫板，可见在中国玩家中的人气度之高（尽管风林另有想法……）！

文／末日

自从家用机发展到次世代后，游戏的类型也随之壮大起来。体育类游戏也变得更加多彩多姿，可以说现在世界上所有的体育运动几乎都被改编成了游戏，使我们在家也能感受到运动的乐趣。

对体育类游戏（SPG）来说，EA和KONAMI各位都不会陌生，这两家游戏厂商几乎垄断了所有体育游戏的制作。而足球是世界上最有魅力的体育运动，所以EA和KONAMI都制作了风格完全不同的足球游戏。

EA的《FIFA》应该是3D足球游戏的鼻祖，在进入次世代后，玩家接触足球游戏都应该是从《FIFA》开始的，在当时来说，《FIFA》的确是一款上乘的足球游戏，不过与真实的足球比赛真的是相差很远。在《FIFA》中，我们只能享受到进球的乐趣，所以只有在玩的时候才会为之欢呼。直到KONAMI推出《实况胜利十一人3》（《WE3》），我们才真正感受到了足球游戏的魅力。

我想对于足球迷的玩家来说，一定不会错过《WE》的。《WE》将“”二字体现得淋漓尽致，不管是从操作，画面，表现还是内涵来说，KONAMI都制作得非常严谨，也无愧于“”这一美誉。可以说《WE》已远远凌驾于《FIFA》之上，除了画面方面还稍逊于PC版的《FIFA》。

《WE》发展到《WE2000》，每出一新作都会有进步。从球队来看，每一个队的风格都不尽相同，而且强队与弱队之间的差别还是相当明显的。如果两个实力相当的玩家用强弱相差最悬殊的两支球队比赛，除了运气好以外，弱队很难胜出。强队要是最厉了，在往往比赛结束后也只是胜利十人或胜利九人了。在《WE2000》中有一种不算太骗的战术方式。由于弱队常常需要让二到三位球员去盯防强队的一名主力球员，却在其他地方经常出现漏洞人的情况，这在《WE》中是非常致命的。球员受伤系统，是带了个不大不小的忧虑，损失一名球员去飞铲强队的一名重点人物，虽然得到了一张红牌，但无形中却是多了一到二名球员，可以说还是值得的。不过这也只适合用来对付电脑的人工智能（AI），与真人对战时只能算是白白牺牲。

从另一个角度——球员的动作画面来讲，《WE》除了流畅之外还非常细致。传球、接球的动作，带球、过人、假动作等都非常逼真，足以乱真，只有断球动作稍微有些勉强。

从操作系统方面来说，应该是比较容易上手的。PS手柄的键位很多，加上方向键共有12个常用的键位，如果再加上两个键位组合的方式，共有多达78种按键方式。这给《WE》一个很大的展示空间，只要是真实比赛中出现的动作，《WE》一般都可以很简单的表现出来。其中最简单也是最普遍的一个动作就是传地面球，要打好一场比赛，配合是必不可少的。在《WE》中要想一个人过全场是没有什么可能的。后卫就是后卫，他绝对不是主攻手，守住家门才是其自身价值的体现。中场则处于进攻与防守之间，用不同的阵队就要用不同的战术，球队如何配合，是进攻还是防守完全取决于中场。如果中场打好了，那么进攻会更加有力，防守会更加稳固。一旦给前锋传出好球，那得不得分就看你个人的造化了。当然，前锋虽以进攻为主，有时候配合一下，控制一下节奏也会有非常好的效果。比如二过一就为前锋提供了最简单、最有效的配合方式。另外像直塞顶球和穿越球在进攻时非常有效，要感受怎样操作，当然是在掌握了。

从《WE》的整个系统来说，战术安排至关重要。从个人能力到整个球队的阵形选择，要想成为胜利十一人就应该把握每一步都做好。这对于玩者来说有点难度，不过，要是想享受一下进球的乐趣的话，那就自己编一个全能球员或球队吧。《WE2000》中可以输入你自己的名字，再给自己取个明星球员的实况名，加上实况解说和气氛，那种进球时的感觉会让你不知所以，只是比较麻烦而已。

当然，《WE》并不完美，比如人工智能，在游戏中常会出现球的情形，就算明星球员也不例外。还有就是在犯规的判罚方面，有时候会受到裁判的不公正待遇。不过我相信《WE》会越来越成熟，究竟会成为真正的“”。其实就拿“”来说，用手来代替脚本身就是一个很不真实的地方。但科技的力量越来越大，现在已有真实的足球街机了。我相信终有一天会真正用脚来体会《WE》的，而且也会更精彩，让你我共同期待吧。
