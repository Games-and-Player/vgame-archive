# 大墙画廊 彩版 vol.57（续）

——Shadow Phoenix

据说圣诞节前能够搬到新居的SP近来可真是忙得一塌糊涂，每个weekend都会和朋友到处和流连在类似IKEA的地方，秋日前周末的体育运动——壁球和休闲运动——池兰柱坊和Jazz Ya都似乎在生活中消失了，只是偶尔现一下身……等待着春节能够出国玩要的SP却数着兜里不多的钞票边流着热泪边睛下决心要多赚钱，可是……（以上为SP的胡言乱语，请大家不要介意。）

## 作品展示

**《萌动》** 上海 周佳卿
和无辜……风间兄弟的冷色和天草的鲜艳更加突出风间妹妹的纯洁

**《侍魂》** 王丸
也许古京接膝辨的同时也会在各条件下反射地掬出草莓·霸气打得也许是对的，但只是也许……

**《侍魂 医院之病例一》** 北京 张健 严冰
→ 一天……1 → 我突然……2 → 被霸王丸发现……3 → 结果……4
……其实，我当时只觉痒痒、想挠挠，谁知……

如果日本的歌舞伎可以和中国的二胡同台献艺，那死郎就可以来这一衣带水的邻邦发展了！

**《圣战》** 南昌 雷晟
你对天野喜孝老师很是崇敬吧，但为什么是“圣战”呢？也崇拜北野武？

**《KOF97之玛丽新装》** 沙河 李博
3年前的玛丽、3年前的画稿，她你旧那么青春，但我已经老去哦，年少的时光……

**《乔乔冒险之恐怖厨师》** 南宁 萧韦国毅
