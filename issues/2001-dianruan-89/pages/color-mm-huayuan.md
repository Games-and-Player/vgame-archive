# 东京电玩展 MM花园之美丽无敌

TOKYO GAME SHOW SPECIAL REPORT

又到一年东京电玩展时间了。说到电玩展，最美丽无敌的当然是各大厂商的展台MM们了。她们甜蜜的笑容，优雅的动作，配上精心缝制的游戏角色服饰，无疑是展会上最亮丽的一道风景线。让我们跟着镜头一起来领略她们的风采吧！
