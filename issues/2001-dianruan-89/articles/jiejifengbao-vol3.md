# 街机风暴 VOL.3

**终结号**

## 模拟篇

KEYWORD ● SIMULATION

**另类的感觉恍如梦中**

家在游戏厅不但可以钓鱼、打拳、甚至开飞机、巴士、电车，各式各样的游戏都有。各种模拟类的游戏就出现了，现在玩家在游戏厅里不怎么好的人又怎么办？这时好好的玩赛车、音乐、射击游戏，但是技术不好的模拟类的游戏也出了，移植推出了很多街机的游戏，让你在家里就可以尽情享受。当然，必先利其器，欲善其事，过工才能够完全完全的感受到体验游戏的真实。最好还是加买一些“专用控制器”，才能完全体验到街机有发售过的游戏，当然我们也会提供各个游戏的都是在街机有发售过的专属控制器评价如何。

以下介绍的是家用篇的所有对应游戏，“PS”、“PS2”、“DC”等都是比较先进的游乐器，当它们也只是必须要拥有合适的游戏机才行。举凡像“DC”，是你在游戏厅里就可以玩得到了，只因为科技的进步，有许多街机在家里就可以玩得了。

### 1 北斗神拳

以漫画“北斗神拳”为故事背景的一种拳击类游戏，相信这部漫画是许多朋友的“熟客”了，所以也不需要多加介绍。虽然说是拳击机，但不像一般普通的拳击机单纯的比拳头的破坏力，而是比挥拳的精准度、速度、时机。话说回来，要是那些北斗神拳迷看到这个游戏，一定会被里面的语音感动得死去活来，因为游戏里的台词几乎都是漫画中的著名台词和著名场面，记得那句著名的“你已经死了”的台词吗！

机台的正中间一共有六个红色目标，当它们浮出来时就挥拳打回去就行了，够简单吧。只是玩家切记切记，玩的时候一定要将拳套戴上，不然打起来手可是会受伤的啊。另外，挥拳打到目标时，要注意目标上的红灯是不是亮的，如果是亮的才能打，不然会扣我方的体力哦。

| | |
|---|---|
| 厂商 | KONAMI |
| 评价 | ★★★★★★★ |
| 上手难度 | 难 |

**评语**

别以为这个游戏很轻松，其实一直挥拳是很累的，不过在游戏中途偶而会出现一次必杀技，此时就要尽你最大的力量一直挥拳，如果来得及打完，敌人就会受到重创。但过瘾，一定要试试看哦。但是找遍了京城的游戏厅，几乎找不到它的踪影，谁能告诉我啊？！

### 2 Get Bass

在街机之中，若是说到最好玩的钓鱼游戏，那就一定这款了。游戏中挑战的是传说中的�的鲈鱼，这种鱼据说可以从一、两公斤长到十公斤之多，是钓鱼爱好者的梦想。游戏中当然也差不太多，有时只要抓准鱼的影子再投杆，随便就能钓到超过四公斤的鲈鱼。

第一次接触钓鱼游戏的玩家可能会比较不懂，因为在钓鱼之前还需要选好鱼饵，不过其实这并不是最重点，因为游戏本身难度设定并不高，鱼饵并不会造成太大的影响。但是在鱼儿上钩之后就是关键时刻了，你必须保持右边的计量表不能超过标示，不然钓线就会断掉，鱼儿当然也就会跑走了。钓上大鱼的决窍其实不难，因为每个鱼池的大鱼通常都在固定的地方停留，所以你每次钓到大鱼之后把那个地点记下来，下次玩的时候直接往那里投杆，很容易就看得到大鱼的踪影。

关于钓鱼杆上的按钮，有一个类似小摇杆的可以控制左右，调整下杆的地点。而旁边的一颗小按钮则是决定用的，决定好鱼饵或是下杆地点后按一下就行了。钓杆右边则是卷线器，想把鱼儿拉上来就要靠这个了。

|---|---|
| 厂商 | SEGA |
| 评价 | ★★★★★★★★★ |
| 上手难度 | 难 |

**评语**

虽然笔者自己本身对钓鱼并不是很有兴趣，可是这款游戏却让我钓上瘾了。因为每次都会想挑战更大条的鱼，个人的最高记录也慢慢提升，也许就是这种挑战令此款游戏如此受欢迎的吧。

↑ Get Bass的钓杆，用起来真的就像是拿钓杆在钓鱼。

## 电车でGO

### 3 电车でGO

看名称似乎像是赛车型的游戏，其实不然。它是模拟日本实际的电车驾驶，而且号称模仿得很像。电车最重要的是快吗？不是，而是要“准时”。如果你开的电车不准时，不但会交通大乱，而且还要受到乘客抗议哦，这个游戏就是模拟这样的情况而出现的。

首先我们要了解它的重点是什么。你必须在正确的时候进站，而且还须停的跟规定距离相差不超过30公分，听起来好像不难，但其实它难得一塌胡涂，笔者不知道是没天份还是怎么的，没有一次可以开超过三个站的，真是惭愧。

| | |
|---|---|
| 厂商 | TAITO |
| 评价 | ★★★★★★ |
| 上手难度 | 中上 |

**评语**

老实说这是个蛮不错的游戏，可惜稍嫌沉闷，如果是对这方面有兴趣的玩家应该会不亦乐乎吧，难度太高或许会让新手吃足苦头，但小试一下身手，尝尝电车司机的辛苦也蛮有趣的吧。

↑ 电车でGO的控制器就像是迷你型的电车操作杆。

## 娱乐篇

### 4 大头贴

大头贴对于现在的年轻一代来说一定不陌生，适合三五好友，或是情侣一同拍照留念，还可以增进彼此的感情，也难怪会引起相当大的流行风潮。

### 游戏厅小常识 4 修理篇

不知道是玩家玩的比较激动，还是机台不结实，游戏厅的台子经常会出问题，这时候就可以麻烦工作人员来修理一番，玩家在玩游戏的同时，也要好好的使用机台，让下一个玩家也能够享受到游戏的乐趣。

↑ 看这位老兄多辛苦地修这匹“马”啊，爱护哦。

### 5 夹娃娃机

夹娃娃机现在已经是最常见的游戏机之一了，不论是什么样的游戏厅，只要摆上一两台一定有许多MM去抓啊，但里面的玩具娃娃一定要够吸引人哦，不过店家都会把夹子调得很松，然后在夹到东西的时候通常会一直晃啊晃，东西很容易就掉了，运气要很好才夹到。

### 1 赛车类

赛车类专用控制器的评价：再怎么说，街机一台动辄几十万，游戏机用的赛车摇杆也很难比得上，可是笔者认为目前的水准已达到70%以上，因为如果玩家你买到的是有附脚踏型油门的，真实感立刻提升不少。方向盘也有专门锁定在桌上防止滑动的设计也很好，感觉好不好也要看你买到的是那一种赛车摇杆。

枪击游戏控制器的评价：由于街机的枪也并非很真实，所以游戏机的枪击控制器也就跟街机差不远。不过目前游戏机之中以DC的枪击游戏比较盛行，所以先介绍DC的枪击摇杆。它的横宽有点宽，为的是能够插入记忆卡（另售）。重量有点重，另外还可以插入震动包（另售），这样就有跟街机同样的震动效果了（缺点是力量小了点），大致上来说是相当不错的。

## 乐韵四溢

### Drum Mania 控制器

这是模仿街机鼓的控制器，虽然意思已经有了，但是很可惜的真的不怎么样，因为鼓面太小很难打准，而且脚踏板非常难使用，跟街机的差异颇大，拟真度也就大打折扣，评价自然就不高。

| | |
|---|---|
| 厂商 | KONAMI |

**模拟度评价：★★★★★**

↑ 和街机版比较起来，家用版真的差很多啊。

### Keyboard Mania 控制器

这是模仿钢琴键盘的控制器，这个控制实在是太完美了，跟街机比较起来除了可以拆装外，并没有不一样的地方，而且触感超好，买这个回家准没错。

| | |
|---|---|
| 厂商 | KONAMI |

**模拟度评价：★★★★★★★★★★**

这个是KONAMI独创的游戏，控制器却做的相当实用，不但跟街机近乎相同，而且还有能够将按键部份拆下，然后对调便可以更换1、2P的位置，对BM迷是不可不买的好东西。

| | |
|---|---|
