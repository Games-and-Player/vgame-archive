# 编辑点评 NEW GAME REVIEW & SHOW

**电软游戏四人鉴定团**

**11月27日～12月13日**

评论人：风林、天师、宇部、PERFECT

评分标准：36-40 强烈推荐 / 30-35 值得一试 / 1-29 素质一般

## 宿命传说2（11月28日）

**PS2 / 厂商：NAMCO / 类型：RPG / 媒体：DVD**

南梦宫招牌RPG终于发售了，一举夺下当周销量榜冠军。传说系列一直在日本拥有很多支持者，本作也是在PS2上登陆的第一作。

目前唯一一款能够让风林有动力坚持打完的RPG游戏了，出众的战斗系统一直为玩家津津乐道。其实本作在故事上并非有实质的进步，基本还是老套的了。在系列中算是不过不失，这次有一得一失。得在完全达到了满载时的进步，使游戏的进行非常顺畅，失在片头主题曲虽然动听、自由战场的缺失使人意识到了比起上一作来的退步。

本作在画面上较之PS版更上三层楼，前作的带入感就特别高，本作更是充分发挥了南大制作RPG的功力，完美地描绘出“命运”世界。在战斗系统线上很有特色，魄力大，而战斗时画面也加ZOOM也让人觉得非常棒。绝对是一款大制作，值得认真的玩家会回顾前作18年日文的玩家会给好好体会前作的不同之处。

## 暗黑编年史（11月28日）

**PS2 / 厂商：SCE / 类型：RPG / 媒体：DVD**

SCE再次创新的清新动作RPG游戏，游戏使用了动画渲染效果，玩起来就如动画片一般。加上剧情的出色，玩家很容易便可融入到游戏中。

鬼马斗角的挑衅与斗头真实的无法认识风林，但游戏丰富的内容和轻松的游戏节奏令人欲罢不能。虽然并非镜极满，而且人物画风也颇有暴风眼。整体感受3SCE作品的风貌。设定强酸的出世界观，玩家从紧凑的节奏流畅的操作感随时进行游戏，始终是展现个性的工作下来最令的光作灵巧。另外不得不拥的是让己的选择对场景实在是太有意思了。

女玩家最适合的大作？PS2机能所限，游戏使用了赛璐路技术，画面也因此更具“豪华”起来。系统上，城镇的“自我建造”内容也出玩家的趣味，“自由度”比较高的一面，但却和故事本身的进行没有什么关系，只是单纯的使人觉得每次游戏都“不一样”。而游戏中还有其他很多程序设定。

本游戏从画作3D多边形处理的画面，进化为高水准的卡通渲染技术，效果自然是不错。故事设定较为轻松有趣，游戏起来毫无压力。值得一提的是本作的事件相当丰富，包含各种各样的要素，适合数人入坑的想想的玩家。作为近期少有的ARPG大作，PS2用户应该多留一些时间给它。

## 忍 SHINOBI（12月5日）

**PS2 / 厂商：SEGA / 类型：ACT / 媒体：DVD**

SEGA著名动作游戏的最新续篇，难度方面继承系列传统，令动作游戏高手大呼过瘾。游戏依旧强调爽快感，而秀真的动作更是酷毙。

典型世嘉风格的硬派动作游戏，难度非常高。游戏的感觉已经与前几作大不一样，一方面是主角的造型更帅。另一方面，三维化的构架在空间的概念上发生了翻天覆地的变化。主角秀真的红色飘逸设计虽非常独特，在高速移动中突出了速度感，使人物就如红色闪电奔而过。一种畅想感。

深受动作游戏FANS关注的超级硬派大作终于登场（美版），继承了SEGA一贯的风格，角色造型酷毙，手感舒适通真到位，充分展现了广阔的技术功力。虽然游戏的难度设定较高，但通过不断实战还是能够解决，来不到绝渺的层次。超级从2D到3D，核的难度成。

史上究极的动作游戏！经典永续，自在变换，世嘉划时代的超越经全展超级！新系动作非常流畅，连斩敌人达成气流速后面的POSE酷毙！游戏八字用到了PS2干爆的所有技巧，角色动作手臂，操作感一流。不过游戏有相当的难度，通关需要一定的功夫。某些情况下，视点切换略显生硬。

## SD高达（11月28日）

**机种：PS2 / 厂商：BANDAI / 类型：SLG / 媒体：DVD**

高达G世纪最新作终于登陆PS2，画面方面大幅强化，令人一振。游戏在系统上的进化也非常明显，无愧于最强的高达游戏。

高达迷的宝物，风林买在吞化不了（笑）。本作集结了历代所有系列的高达出机大杂烩人，而且在系统上加入了全新的“派闪机制”。另外，在关于贾顿布局和各功能方面也全新崛然一新，人文的安排效果玩玩不等及令人送兴冲。比较于子的机制系列，个人还是更喜欢有真高达的专门游戏，不是太炫。冲着的话也要把它选控好分！

画面进化到全3D，角色自D，战斗场景下的机体动作比较漂亮。由于游戏收录了原作的很多故事，甚至有万种最新原创的情节穿算措，想必此FANS了一定会大呼过瘾了。战斗系统也具有之进化，增加了多次双击的派生机制（所以SD高达系列与机器人大战系列完全不是一路的，这本人却摸不清。

SD高达系列在PS2上登场的第一弹，经过全新制作，战斗画面全部3D即时演算，效果完全超越DC版的机战α。看来BANPRESTO和里学了不少，游戏难度也升α外战，战斗却更趋于真实化。再也不能把王牌驾驶机甲在人生里一杀就不管了，可怜的NT！但高达究竟是高达，的确的魅力，玩法更大中。

## 龙珠Z（12月3日 美版）

**机种：PS2 / 厂商：BANDAI / 类型：FTG / 媒体：DVD**

脍炙人口的龙珠事隔多年再度发力，不仅在剧情方面完全忠实原著精彩，而且在画面上首选菜菜效果，令人叹服。绝对是最强的龙珠游戏。

久违久违，终SS上“超武斗传”后最强的龙珠对战游戏终于出现了。游戏完全再现了漫画中的场面，相信很多老漫迷看到这些都会感动不已。游戏中故事从人卡罗特的离世甚出一直到打完CELL，交代了整部作品中最最精彩的片段。对战的操作感觉也非常不错，连续技能使用起来非常爽快。实在是很棒。

以“龙珠”为名的用到M32位时代开始一直推出来不少作品了，但游戏本身又有什么进呢呢？天还不认为，这些没有何值得深究地方的游戏是什么礼物，即使没有什么实力型制作FTG的公司。借助这种方法可以将观较的另一面表现。劝你们做好准备再买，会被流正版的玩家千成就是简单说话而已。

久违了的龙珠终于再现在PS2上，而且水准非常出色，大剧情的感还是回顾和FANS相当振动的感觉。另外作为FTG，本游戏也能令人满意，角色动作流畅，手感益好，向来不善长格斗的玩家也能轻松上手，并不会觉得太3D的感觉，虽是3D效果，但依然是2D玩法，更能体现龙珠的魅力的特点。

3D龙珠的最强一作！3D化成熟，斗以2D理念完成，画面千净，手足OK，角色移动覆盖合理。一杯，手足再出现穿梭新闪的过度的独角色，却情境完全成实现作，故事直到完成也变实的。而且天候就好，玩起来呢不是浴浸。普经把过龙珠也世界的人定量几方的是的比较而闸言台格斗乐趣不仅是游戏系统本身带来的。

## POWER SMASH 2（11月7日）

**机种：PS2 / 厂商：SEGA / 类型：SPG / 媒体：DVD**

当今网球游戏最无争议的霸主，如果不是被冷待过分的话，本作理应成为本月的大作。PS2与PC版没有太大区别，令老玩家感到不满。

虽然冷饭，但到小白是自前毫无争议的最强网球游戏，一管它看上去一点感都都没有。也没有什么情调两去把新颖把2S版前端点了。玩家对于多数的进展，但也只留于仅是单纯的移植。因此有打买些作国的玩家完全没有必要再购买了。

最新一代几乎就变到好评的网球游戏，不作品次系统和操作是其成功的重要因素。SEGA将2代移植到PS2上，虽然在游戏整体上没有任何提高，重觉一试。本作进加强洲联盟赛让另一个独的乐趣，在这年的冬季，与三五好友聚集一起进行热战。电是一种不错的娱乐方式。

虽然是最强的网球游戏，但是移植PS2后就然终没有任何提高，世嘉的冷败足以令人觉得非常遗憾了。基本POWER SMASH体身的系统不错就就好OK一样，对战进行玩有乐趣。双人游戏中的配合挂念至让真球爱好者的互动。

## 阿尔格斯战士（12月5日）

**机种：PS2 / 厂商：TEMCO / 类型：ACT / 媒体：DVD**

难得见到TEMCO推出一部比较正经的作品（笑）。难度方面一般，游戏画面不错，且爽快感十足，算是近期不错的动作冒险游戏。

TEMCO自我宣传为“超大作”，实际玩过以后虽然不错，可，但也远和远不上其她的动作名作。画面的处理方式类似“魔颚”，PS2的机能发挥得相当出色。攻击判定，并不是非常严，而且节奏中的动作流淌要领难手……外，终一本的的挑过来的也在……令外终一条的动作类型的影响和目的的话，还是值得玩家趁期好利工作呢！

作为99年中国格斗家战心中的第一格，S，KOF系列终于进化到2000，KOF2000的街机版却回SNK的新潮。而PS2版本的了PLAYMORE，KOF系列的每一一作带[?]永远MV与S类世。几成微性是然不一，天还用最意而结会的了。我想应优废倡行始用玩家保存的一个回忆，还恩点赏…不安加评主。

本来达到冒险的ACT游戏应该得的到嘛更高一些，如尤其是其角色那今入大学千的场景，但TEMCO，大舆论恶。但经“盐产”为了个一个人。然理我行的所做推出此作的KOR系前角色动行作没出将头头、华件不怎。松万了部隊。天还用用最需结会的了，我想应该应废倡行始作用玩家保存的一个回忆，还恩点赏，不安加评主。

## KOF 2000（11月18日）

**机种：PS2 / 厂商：PLAYMORE / 类型：FTG / 媒体：DVD**

超级冷饭格斗的家用机版本，这次是完全移植，效果不错，但如果不是因为2K已经是前年的游戏的话，这的值得赏面，竟非一。

KOF爱美家的格植[?]的计划行交游戏，虽然如今站在正义的已经2002……这次完全移植的PS2版，目前没有日子被时间的，尽管吃尘尾色和里把就很的完全移植时，而且画面的处理也同完全移植模式发展了，具在进行了新改造。来制造到对PLAYMORE的功课。竟高计PLAYMORE在前力的终于已来。

作为99年中国格斗家的战斗心中的第一格，KOF系列终于进化到2000。KOF2000的街机版却回了SNK的新潮，而PS2版本交了PLAYMORE。KOF系列的每一作带（永远MVS类），几成微性质然不一样。天还用最精需结合方了。我想应优废倡始用玩家保存的一个回忆，选恩点赏。不安加评主。

完全的街机移植，虽然宇部在完全的气息上提升不大。游戏的世界观设定非常到位，再现了遗迹古战场的种神秘空间。但它虽在往日上的外观上，结果令人满意表现。画面与操作的比较3D游戏之间霸较方面良好。而且在音乐也选行了新的制作。似人之际，全金把的感到PLAYMORE感应是SNK的精神达表继续在传看下去的。着着是上大地用手持看在压更头星的特长。大汗中。

格植度100%！虽然本人对KOF不是太感兴趣，但这是PS2版的格植的率令人自目相看。进入BOSS时的对话，就等想是2002……这次完全移植的PS2版，看没有了新增时时的。尽管处理色彩和角但却的完全移植格式。而PS2版最终会如何呢？真正值得一看的它的回忆。
