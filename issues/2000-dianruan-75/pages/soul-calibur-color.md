# 灵魂力量中插——塞万提斯（DC）

> 中部彩插 / PDF p.57, 59 / 插16,17 / 灵魂力量角色原画

## PDF p.57 / 插16

【图】整页为《灵魂力量》（Soul Calibur）角色 + r1 + （Cervantes）的大幅CG艺术画。画面中塞万提斯身穿深色铠甲，手持巨大的双手剑，背后是夕阳映照下的中世纪城堡废墟。暮色苍茫的天空被夕阳染成橙红色，厚重的云层与古堡剪影形成壮观的构图。城堡的石墙上可见拱形窗洞。塞万提斯头戴装饰有蓝色羽毛的帽子，整体造型充满海盗与剑士的气质。画面左下角有 + r1 + 游戏logo。

## PDF p.59 / 插17

【图】整页原画插图续：灵魂力量系列角色 Cervantes（塞万提斯）。画面为夕阳背景下的海盗形象，身着深色海盗装束，头戴三角帽，独眼，手持双剑，肩部有金色穗饰。背景为火红色的夕阳与橙色天空。

右下角标注：《电子游戏软件》2000年10月
