### GROOVE系统

本作独创的GROOVE选择系统！玩家可以在CAPCOM GROOVE和SNK GROOVE之间选择：

- **CAPCOM GROOVE**——采用《街头霸王ZERO》系列的超必杀技量表系统，蓄力后可发动超必杀技。
- **SNK GROOVE**——采用《拳皇》系列的能量条系统，体力低下时可发动MAX超必杀技。

### 8方向+4键 操作系统

本游戏在操作上使用8方向和四键系统，攻击使用键：轻拳、重拳、轻腿、重腿四键。此外本作中也导入了部分SNK作品中玩家所熟悉的特殊动作 + r1 + 和 + r1 + ，可说是本作的一大特征。

| 操作 | 说明 |
|------|------|
| 键位共有4个 | 根据按键组合成变化的招式 |
| 回避动作 | 感觉与 + r1 + 中的类似（感觉与回避动作类似） |
| 前冲 | 向前方疾冲以拉近与敌人距离的动作 |
| 向后疾退 | 向后方疾退以拉大与敌人距离的动作 |
| 大跳跃 | 除通常跳跃外，长距离的跳跃动作 |
| 向后大跳跃 | 向后方跳跃会出像（向后方大跳跃的动作） |
