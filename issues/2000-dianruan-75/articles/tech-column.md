### 电软科普教程第五讲

**~游戏机进化史~**

文：扬州王昊

●周凯说：世嘉是我们的红旗令，我们是世嘉的红小兵。世嘉携手我前进。但愿最长久，千里共戏游。

……（续上期）任天堂对电玩的最大贡献在于将严格严谨的设计生产和灵活开放的营销手段引入了一项自由散漫的电玩业，而由此散漫正是雅达利倒台、美国电玩大灾难的根本原因。任氏是以近乎残酷的垄断达到这一目标的。软件商提到任氏的独裁作风就心有余悸，但为搭上FC这条大船逼着自己上了档次。精雕细琢的产品得到广大用户的认可，而出色的宣传和行销更是打开了市场。第一批电玩形象明星大金刚和马里奥就是任天堂广告的重要干将。

树立了绝对的垄断之后，任氏的制霸也走到达到令人咋舌的地步。这个不足千人的小厂一度跻身日本企业盈利榜三甲，同丰田、NTT这样十几万人的大公司并肩。家大业大再加上任氏一贯的封建作风，它对业界和用户的影响不仅未减在眼里了。批评其 + r1 + 、 + r1 + 、 + r1 + 的言论满天都是。时间进入九十年代后， + r1 + 的潮流下，任氏的帝国终于解体了。

平心而论，在八十年代初电玩急待规范，并在稳定中求得进步的时候，任氏横空出世是符合潮流的。电玩业也在其铁腕下得到整顿，并稳步壮大。但时代发展了，任天堂仍抱住死柱子就不对了。时代造就了任天堂，又抛弃了它。

虽然在当局处于颓势，任天堂凭借其无比宏伟的基业和高效益的企业体制仍保持良好状态，仍是最大、效果最壮的业内厂商。其它的软件能力也未受影响，推出《口袋妖怪》这样的名作。说不定哪天也会卷土重来的高峰也说不定呢！

FC渗及世界。在我国南方，制造FC养活了大批小电子厂，甚至造就了几个电子巨头。国人对FC的再开发更是花样百出，甚至加了上网功能。山内溥再精明，也未必料到吧。

### 第四篇　战国的辉煌（1991—1998）

历史上分裂割据的时代往往是文化高度发达的时候，如我国的春秋和古希腊城邦时代。在任氏帝国解体后，电玩业到达了一个百花齐放、百家争鸣的新时期。

早在FC一枝独秀的87年，NEC就试图以PC-E来打破任氏的垄断。这个图形机能出众、以美少女打天下的种虽然在日本成了一定气候，但在别国影响几乎是0（天注：但是在法国，PC-E的火爆到甚至超出人们意像），而且其名声由于H-GAME同其姊兄PC98电脑一样不雅。真正向任氏天下发起挑战的是街机大厂世嘉，它于88年推出的MD使游戏机迈进了16位时代，进入了一个双雄争霸的时期。傲慢的任天堂终于在90年底以SFC应战，战国开始了。

世嘉原是一家美国公司，它以美国式的进取精神开拓着电玩这块大市场，硬是从任氏手中夺下了数百万台的市场份额，在美国的销量更是达到1600万台以上。从此，软件商们又多了一个选择，不必再看山内的脸色了，竞压的创造热情空前高涨，大作频出，加之16位机出色的机能，九十年初的电玩迎来了又一春。

值得记忆的是，世嘉的国际战略为以后PC游戏的大发展打下了基础。83年电玩大灾难之后，PC由于机能够陪游戏并不发达，欧美电玩业毫毫一息。正是MD扶起和发展了欧美众多的游戏厂商。像如今PC游戏的大哥大EA，当年就是以为世嘉打活起家的。

任天堂凭借其基础和口碑，在16位机之战中取得了最终胜利，但是失去了垄断地位。厂商也认识到任氏不是不可战胜的，也不是必然依赖的。

94年底，次世代四杰登场……97年中，大战已尘埃初落定。先驱3DO黯然放弃，变成了一家PC软件公司，M2的烂摊子让松下不出流量代价仍是也不了之；斗士世嘉靠辱败之，可惜成果不大；任天堂也没有梅开二度，它的N64失之扶桑，幸好收之美国。

反而是索尼，它在电玩界没什么经验，也没包袱。其深深模模糊，时不同了，游戏规则也不一样。任氏下下的 + r1 + 的模式已经过时了，索尼在以下几个方面出手，确立了领先地位（天注：很多版面将跑去 + r1 + ）。

适应了这么多潮流与趋势，再加上索尼作为国际大厂的运作手段，等于不胜之理？

### 第五篇　进步与挑战（1998年以后）

二十世纪即将过去，风光了近二十年的电视游戏此刻却遇到了前所未有的挑战。这挑战来自PC和互联网。

PC由于机能和价格的原因，在游戏方面一直被专用游戏机抛在后面，但它一直以摩尔定理的18个月以内周期进行着更新换代，比起游戏机至少四五年才更新一次的速度要快多了。尤其在九十年代后，PC的设计引入了对多媒体硬件越来越强。95、96多媒体赛腾芯片、WIN95操作系统和蓝意3D加速卡的问世，令PC首次在游戏功能上超过了同时代的游戏机。同时，PC在联网功能、显示精度、可介入前方方面的先天优势更得到了发挥。PC进步的速度和PC软件市场增长的速度更大大超过了游戏机，成为游戏机最大的威胁。在PC平台上还出现了模拟器这样令游戏机尴尬的东西。

（在世界范围内，互联网是94年在石桥起来的，两三年功夫天翻地覆）它的潜力是大家公认的。网上虚拟空间，虚拟世界中的真人互动网络游戏将是未来游戏的方向。游戏机如果不适应这个万向的话它不是长久之计，在网络方面，PC又占了上风。

在以上两方面的挑战下，继承次世代的遗产，游戏机仍在进步之中。98年底，斗士世嘉的新机DC登场了，除了传统功能极大提高、特别重视3D机能外，网络功能的引入是特别有意义之。它标志着游戏机也迈入了网络时代。其实在SS甚至SFC、MD时代，游戏机就开始了网络通讯机能力的尝试，但收益甚微，看来先走进技术用年亦也不行，没有配套环境。

大赢家索尼已将集团的重点定在了游戏机上。它的PS2将在2000年初上世。这是一台独特的机器，内部采用封闭的专用硬件结构，外部却使用标准的电脑化接口。这个设计极有创意、标志着PC与游戏机有相互融合的趋势。任天堂的 + r1 + 它也平线上招手了。另外通讯巨头摩托罗拉、微软、英特尔也有意进入电视游戏机市场，提出什么x设备，看来下一代游戏机之战又有好戏的了。

这段时间的另一个热点是掌机的大流行。任氏的GB长期霸占市场，利润可观。到的厂商也蜂拥加入并不断推陈出新，这个小小领域也变空间活活起来。掌机也不能不考虑网络和通讯，于是手机配掌机的新玩法出现了。的确，网络的魅力是准也无法抗拒的。

新机种的大战还未展开，而电子生活发展的速度又是如此之令人蜂且结论，要是还是地面回答以后硬件会怎么样，PC会不会侵吞游戏机等等问题是相当困难，甚至是没有意义的。本文回顾了这么多兴衰成败，先是简述了一个道理，每个时代都有自己的潮流和规则，顺之者昌逆之者亡。但信息的潮流演变化实在太快，更想把自己除了一流的眼光外，运气也很重要。

我们以其苦力地追求硬件的升级、软件的进步，最终的还是提高游戏性，给予人们欢乐。追求技术进步的过程千万不能异化成为了进步而进步。以人为本，这才是真正高科技的真谛。再先进的硬件·软件也总有一天会沦为古董，但其中蕴藏的智慧的火花、艺术的沉淀和我们的感受却是永恒的。一代的游戏人和玩家最宝贵的收获既在于此。等硬件的革新、每一次软件的创新、每一次文化艺术的突破、玩家每一次的感动、激动和欢乐，这些转瞬即逝的东西四正是电玩最珍贵的部分。

计算机的发展历程了硬件主导和软件的时代，现在是更高级的内容和服务的时代。游戏机不也如此吗？硬件软件，最终部是为了充实为内容服务。所以，深厚的文化底蕴和有创造力的人才队伍在将是电玩长远发展的决定性力量。

### 碟片的选购、常见故障与修复

近几期电软中，科普园地所刊登的文章，把主机不读碟都归于光驱出问题，其实在某些情况下，也与盗版碟本身的质量有关。曾经过一些文章介绍说可拭擦真信息面使其清洁，而实际上这也可能使一张没有污点的碟也读不出。因此，我们在购买光碟时应仔细观察，觉得不好的就凭，个别的可以修复。下面进行介绍。

正常的光碟有信息面与背面两个面，信息面的信号基于某上层制压轧，激光射向它们的信息点，多少以不平的信息点、激光射向它们的信出信号；由于背面碟有反射膜，信号被反射回来得以接收，光碟就正常运行了。但如果在制作当中手法不当，光碟就有可能产生 + r1 + 、 + r1 + 等破陷，此种碟在激光射到这些缺陷时，就会产生透射而不是反射回信号，导致中止运行或死机。

光碟的信在信息面涂有一层稍厚的透明保护膜，大家在日只注意到它是否是擦伤，而背面则仅涂上很薄的有色或无色涂层，仅只印文字（D盗中最常见），由于背面碟镀膜层的防护较弱，而且大家又注意不够，结果造成碟镀膜层的人为损伤比信息面划伤带来的问题更严重。

针对上述原因，我们买碟时除去看看外观，应对着较强的光线，从信息面向背面仔细观察碟片有无透光点，也就是指碟镀膜层是否有损。

光碟的常见故障如下：

①信息面肮污（一般用干布或光盘利拭擦就可以）。②光碟镀层有损，当激光扫到破点时，没有信息反射而中止运行（修复碟镀膜层难度极高，修复材料价格高，在此不介绍）。③光驱读碟时无法读取。④碟片有许多擦痕使读碟不顺。

●对于碟片划伤和变形程度较轻者，是可以修复的。

对于划伤的碟片，首先扶去碟片上的灰尘（特别是小沙粒）。取一干净的纯棉布，以蘸水后拧到不再出水，铺在一平整的桌面面上，将 + r1 + 的碟片放在布上。然后应在碟片的信息面上拧许分鬃，再用海绵（吸一点水是可以的）在碟片上轻轻地做无规则打磨，注意将力度控制在刚刚出现泡沫并手感有极大磨擦时为最佳。

打磨完后，可用干净的棉球蘸清水从碟片中心向外轻轻擦抹，晾干后即可。切不可用酒精、汽油或腕头清洁等有机溶剂浸渍，以免产生化学反应使碟的保护层受到损坏。

●对于变形的碟片，可用两面玻璃将碟片放在中间，再用夹子夹紧，放到八十度的水中，待几分钟后，取出，OK。（天语：此方法是由重庆江津涛声亮读者提供的。而他却认为给碟片牙膏涂的应由内圈至外圈打磨。）
