## PDF p.13 / 刊页 3

### NGC正式公开！

**SPACE WORLD 2000 任天堂新主机全面揭晓**

【图】NGC（GAMECUBE）主机实物照片，体积小巧，顶部有一个提手。主机呈正方体造型，配有一个特制手柄。

任天堂在2000年8月24日召开的Space World 2000上正式公开了次世代主机NGC（GAMECUBE，开发代号 + r1 + ）的真身。在发布会上，任天堂社长山内溥亲自登台介绍了这台被寄予厚望的新主机。

NGC的外观令人耳目一新，主机体积非常小巧，大约只有15厘米见方，顶部还有一个方便携带的提手设计。主机采用紫色和银灰色两种配色方案。

#### NGC主要规格

| 项目 | 规格 |
|------|------|
| CPU | IBM Power PC  + r1 +  405MHz |
| GPU | ATI/任天堂合作开发  + r1 +  |
| 主内存 | 24MB MoSys 1T-SRAM |
| 辅助内存 | 16MB DRAM |
| 光盘 | 松下制8cm专用光盘 约1.5GB |
| 接口 | 4个手柄端口 |
| 记忆卡 | 每个手柄端口2个记忆卡插槽 |
| 串行端口 | 2个（可用于联网） |
| 预定发售 | 2001年7月（日本）/ 2001年秋（美国） |

主机采用IBM提供的Power PC架构CPU + r1 + ，主频为405MHz。GPU则是由ATI与任天堂共同开发的 + r1 + 芯片，支持硬件T&L变换与光源处理，最大同时显示600万~1200万多边形。内存方面，主机搭载了24MB的MoSys 1T-SRAM高速主内存和16MB的DRAM辅助内存。

存储媒介方面，NGC将采用由松下开发的8cm专用光盘，容量约为1.5GB。这一选择显然是为了防止盗版，但同时也意味着NGC不具备DVD影碟播放功能。

手柄设计采用了全新的布局，中央配备一个大型的模拟摇杆，右侧为一大三小的按键布局（一个大号的A键围绕着X、Y、B三个小键），左上方配有十字键，双肩各有一个模拟/数字混合的扳机键（L、R），另有一个Z键位于右肩上方。

NGC还支持通过专用适配器与GBA进行连接，实现数据交换等功能。

### 软件阵容

在Space World上，任天堂展示了多款NGC开发中的软件画面，其中包括：

- 《马里奥128》（暂称）——128个马里奥同时在画面中活动的技术演示
- 《塞尔达传说》NGC版——画面大幅进化
- 《银河战士》新作
- 《皮克敏》——宫本茂全新企划的新类型游戏
- 还有来自第三方如卡普空、南梦宫等的参展作品

【图】NGC手柄特写照片。手柄中央大型模拟摇杆，右侧A/B/X/Y按键布局清晰可见。

### 彩色WS今冬发卖！

**WonderSwan Color正式公布**

【图】WonderSwan Color主机照片，机身呈蓝色，屏幕显示彩色游戏画面。

万代（BANDAI）于8月正式发表了WonderSwan的后继机种——WonderSwan Color（以下简称WSC）。WSC预定于2000年12月9日在日本发售，定价6800日元。

WSC在保持与原版WonderSwan兼容性的同时，最大的升级就是将屏幕从黑白升级为彩色TFT液晶屏，画面表现力有了质的飞跃。

#### WSC主要规格

| 项目 | 规格 |
|------|------|
| CPU | NEC V30MZ 16bit |
| 画面 | 2.5英寸反射型TFT彩色液晶 |
| 分辨率 | 224×144像素 |
| 显色数 | 最大241色同时显示（调色板4096色） |
| 电源 | 1节AA电池 |
| 续航 | 约20小时 |
| 体积 | 74.3×121×17.7mm |
| 重量 | 约95g（含电池） |
| 价格 | 6800日元 |
| 发售日 | 2000年12月9日 |

WSC的一大卖点是向下兼容——所有WS游戏均可在WSC上运行。同时，新推出的WSC专用软件在画面效果上将有大幅提升。万代已经公布了多款WSC首发及近期发售的软件阵容：

- 《最终幻想》WSC版
- 《最终幻想II》WSC版
- 《浪漫沙加》WSC版
- 《SD高达》WSC版
- 《ONE PIECE》WSC版
- 《海贼王》WSC版
- 以及更多作品

【图】WSC与原版WS对比图，以及多款WSC游戏截图对比。

万代表示，WSC的目标是在日本掌机市场上与任天堂的GBC和即将到来的GBA展开竞争。凭借SQUARE等大牌第三方的加盟，WSC的前景值得期待。

### FF电影版最新消息

**SQUARE投入巨资打造CG电影《最终幻想》**

SQUARE投资超过1亿美元制作的全CG电影《FINAL FANTASY: THE SPIRITS WITHIN》（最终幻想：灵魂深处）的最新消息不断传来。影片由坂口博信亲自担任导演，采用最先进的全CG技术制作，目标是打造出 + r1 + 的逼真CG人物。

影片预定于2001年暑期在全球上映。目前制作进度已过半，SQUARE在夏威夷的制作工作室正在全力赶工中。

为了这部电影，SQUARE已经投入了大量的人力和财力。然而，华尔街的分析师们对SQUARE的这次 + r1 + 看法不一。有人认为这将开创CG电影的新时代，也有人担心巨额投资可能无法收回。SQUARE的股价也因此出现了较大波动。

### GT2000开发进度

**PS2版赛车大作进展如何？**

Polyphony Digital正在全力开发PS2平台的赛车游戏《Gran Turismo 2000》（暂称，后更名为Gran Turismo 3: A-Spec）。最新的开发版本展示了令人惊叹的画面效果，PS2强大的性能使得车辆模型和赛道细节都达到了前所未有的高度。

### PS2市场调查

**PS2发售半年后的市场反响**

PS2自2000年3月4日发售以来已过半年，日本市场累计出货量已超过300万台。一项最新的市场调查显示：

- 约60%的PS2用户同时将其作为DVD播放器使用
- 最受欢迎的PS2游戏为《山脊赛车V》和《实况足球4》
- 约40%的用户表示对PS2的游戏阵容尚不满意
- 软件销量最高的游戏为《真·三国无双》

### NGC发布后各社股价变动

NGC公布后，日本各游戏公司的股价均出现了不同程度的波动。任天堂股价在发布当日大幅上涨，而SEGA和SCE相关股票则出现了小幅下跌。第三方开发商中，已宣布参与NGC开发的CAPCOM和NAMCO股价微涨。

### 皮卡丘病毒来袭

一种名为 + r1 + 的电脑病毒在网络上出现。该病毒通过电子邮件传播，邮件中附带一个可爱的皮卡丘动画，一旦用户打开附件就会激活病毒，删除系统文件。任天堂已发表声明，表示该病毒与任天堂和Pokemon公司毫无关系，并呼吁用户不要打开来历不明的邮件附件。

## PDF p.16 / 刊页 6

### GBA华丽登场！

**Game Boy Advance在Space World上首次亮相**

【图】GBA主机照片，横版设计，配有十字键和A/B按键，机身呈半透明紫色。

任天堂在Space World 2000上同时公开了便携游戏机的新作——Game Boy Advance（以下简称GBA）。GBA的性能较GBC有了巨大的飞跃，是一台真正意义上的32位掌上游戏机。

#### GBA主要规格

| 项目 | 规格 |
|------|------|
| CPU | ARM 32bit RISC CPU + Z80 8bit 协处理器 |
| 画面 | 2.9英寸反射型TFT彩色液晶 |
| 分辨率 | 240×160像素 |
| 显色数 | 最大32768色 |
| 通信 | 内置通信端口 |
| 电源 | 2节AA电池 |
| 续航 | 约15小时 |
| 尺寸 | 82×144.5×24.5mm |
| 重量 | 约140g（含电池） |
| 价格 | 9800日元 |
| 预定发售 | 2001年3月21日 |

GBA最令人瞩目的特性是其强大的2D处理能力——ARM 32位RISC处理器使得GBA可以轻松实现SFC级别甚至超越SFC的画面效果。内置的2D引擎支持旋转、缩放、半透明等多种特效，对于2D游戏来说几乎没有瓶颈。此外，GBA还内置了Z80协处理器以保证对GB/GBC游戏的向下兼容。

Space World上展示的GBA软件阵容非常豪华，包括：

- 《马里奥赛车Advance》
- 《F-ZERO》GBA版
- 《恶魔城》GBA版
- 《黄金太阳》
- 《逆转裁判》
- 以及大量第三方作品

【图】多张GBA游戏截图，展示了接近SFC水准的画面表现力。

### 射雕英雄传PS RPG

**国产RPG登陆PlayStation！**

又一款国产游戏即将登陆PlayStation平台。由国内开发团队制作的《射雕英雄传》PS版RPG正式公布，游戏以金庸经典武侠小说为蓝本，讲述郭靖和黄蓉的冒险故事。

游戏采用2D画面，角色采用Q版造型，战斗系统为传统回合制RPG模式。开发团队表示将忠实还原原著中的经典情节和场景。

### System 246街机发布

**基于PS2硬件的新一代街机基板**

NAMCO正式发布了基于PS2硬件的新一代街机基板 + r1 + 。该基板采用与PS2相同的EE（Emotion Engine）+GS（Graphics Synthesizer）架构，使得街机游戏可以方便地移植到PS2家用机上。

首款采用System 246的游戏为《山脊赛车V》街机版，已开始在日本各大游戏厅铺设。

### TGS 2000秋前瞻

**东京游戏展2000秋 各社出展情报**

2000年秋季的东京游戏展（TGS）将于10月下旬举行。各大游戏厂商已陆续公布了参展阵容。

**SCE展区：**

SCE将携大量PS2新作参展，重点展示《Gran Turismo 3: A-Spec》等重量级作品。此外，还将首次展出PS2网络适配器的实物演示。

**CAPCOM展区：**

CAPCOM将展示《鬼武者》的最新版本，以及DC版《CAPCOM VS SNK》的试玩。格斗迷们翘首以盼的这款梦幻对决作品终于可以亲手体验了。

**KONAMI展区：**

KONAMI预定展出《合金装备2: 自由之子》的最新影像。这款PS2独占大作自E3公开后便一直是玩家们关注的焦点。

**SQUARE展区：**

SQUARE将展示PS2版《最终幻想X》的首批游戏画面，以及《最终幻想IX》的国际版情报。

### 世嘉经营状况

**SEGA财报显示亏损扩大**

SEGA最新发布的财务报告显示，由于DC硬件持续亏损销售以及软件销量未达预期，SEGA的经营状况依然严峻。业内分析人士指出，在PS2和即将到来的NGC双面夹击下，SEGA作为硬件厂商的前景堪忧。

有传言称SEGA内部正在讨论是否退出硬件市场，转型为纯粹的第三方软件商。SEGA官方对此不予评论，但表示将继续全力支持DC。

### 韩国游戏市场

**韩国网络游戏蓬勃发展**

韩国的网络游戏市场正在经历爆发式增长。以PC网吧（ + r1 + ）为中心的游戏文化已经渗透到韩国社会的各个角落。《星际争霸》在韩国的火爆程度已经成为一种社会现象，甚至催生了专业的电竞联赛和选手。

与此同时，韩国本土开发的网络游戏也开始崭露头角，《天堂》（Lineage）等MMORPG的注册用户数突破百万，展示了韩国游戏产业的巨大潜力。

## PDF p.20 / 刊页 10

### 中国游戏产业动态

**国产游戏进入TV GAME领域**

随着中国游戏市场的不断成长，越来越多的国内开发商开始涉足TV GAME领域。除了前面提到的《射雕英雄传》PS版之外，还有多家公司正在开发面向主机平台的游戏。

但业内人士也指出了国产TV GAME面临的困境：

1. 技术积累不足——与日本和欧美成熟的开发团队相比，国内团队在3D引擎开发、动画制作等方面存在明显差距。
2. 资金投入有限——一款PS级别的游戏开发费用至少需要数百万元，而国内大多数公司难以承受。
3. 市场环境恶劣——盗版横行使得正版游戏的销量难以保证投资回报。
4. 人才流失严重——有经验的游戏开发人才稀缺。

尽管如此，仍有一批热血的国产游戏人在坚持探索。

### 盗版问题

**游戏界的顽疾**

盗版问题一直是困扰游戏产业发展的毒瘤。在中国市场，PS和DC的盗版光碟泛滥成灾，正版游戏的销量受到严重冲击。

PS2的防盗版措施暂时有效，但业内人士预计，随着时间推移，PS2的防护也终将被攻破。此外，网络上的ROM和ISO共享也对掌机和PC游戏的正版销售造成了影响。
