## 世界足球 实况胜利十一人 2000·向U-23金牌挑战（PDF p.103 右栏）

（WORLD SOCCER 実況ウイニングイレブン·U-23メダルへの挑戦）

WE又回来了，相信这一定给许多PS玩家带来了的惊喜和振奋。

这一次的改变不像WE3到WE4那么大刀阔斧，基本上是WE4与WE2000J-LEAGUE的杂交改良版。刚上手的玩家一定会觉得在操作上似乎变 + r1 + 了，其实只要有WE2000J作铺垫，对于WE2000的变化还是可以很快适应的。不过，原系列中很多由AI进行的工作在本作中都要求游戏者独立完成，WE系列庞大的玩家群以及开发人员的丰富经验也令KONAMI有充足的勇气维续出新。作为经过数版WE的PS玩家而言，他们现在需要的已经不再是操作性和上手性，而是对于游戏难度和游戏深度的苛求。

WE2000就像世界足球的一面镜子，它并不单指抢银欧锦赛等赛事情况翻新的各队阵容，从系统设定等许多细节当中也能见到一些端倪。欧锦赛上技术足球的大潮重又翻场，而WE2000系统上的 + r1 + 性使长传冲吊、边路传中，速度就不再那么百试不爽，倒是短传渗透更见实效。这一变化是不是一口咬定是照搬葡萄牙黄金一代击败殴格兰那样完全为瞩目。

球队的实力调整也是看点之一。试以法国队为例，WE3世杯版中法国队的实力甚至不及WE3的初版，但是在WE4中就大不一样了。而法国队欧锦赛上再次捧杯，使得WE2000中的法国队再次变强。比如特雷泽盖日渐成熟，亨利日以[?]进，特雷泽盖重新复出。阿内尔卡和维埃尔托彻底的实力是不容置疑，就连杜加里也老树发了新枝。法国队的锋线用人不再捉襟见肘。

说完了别家窝，也该说说自家窝。且看中国队的数值设定——充其量是一支亚洲杯的参赛队。而且中国国奥队也在WE2000中销声盗迹了，谁让 + r1 + 的国奥队没能行签尼哦，KONAMI也只好说 + r1 + 了。

## 勇者斗恶龙VII～伊甸战士们～（PDF p.104 下半）

（ドラゴンクエストVII～エデンの戦士たち～）

机种 PS　厂商 ENIX　类型 RPG　媒体 CD×2

在颇有气氛的片头之后，初看到DQ7的游戏画面时着实吓了笔者一跳。难道ENIX就这么保守吗？！如此平面的角色和SFC上的DQ根本没什么区别嘛。再加上笔者向来对多边形的游戏不感冒，那传来转去的多变形背景只能让人头晕眼胀。因此DQ VII给我的第一印象相当惨淡。

但随着游戏地深入，我发现DQ VII把握住了一个对于游戏性而言至关重要的因素—— + r1 + 。这里讲的 + r1 + 包括两重含义。首先，在技术层面上，DQ VII竭力避免了光介质游戏的通病——读盘等待。也许现在很多玩家已经对此习以为常了，但在玩过DQ VII后，是不是有些然大悟之感呢——PS游戏原来也可以不需等待。游戏中，进门、画面切换、遇敌以及乘交通工具时载入画面都相当流畅自然。但这一作法也同样带来了 + r1 + 的弊端。SFC式的人物，SFC式的地图，SFC式的界面，加之SFC式的战斗场景，真是无法令人相信这竟是PS末期出自大牌厂商的白金作品。

如果说DQ VII对于初玩DQ的玩家而言有一种朴素的新意的话，那么对于已经过数代DQ熏陶的老玩家而言，会不会有一种裹足不前的不满呢？

当然，DQ VII在整体结构的把握上是相当出色的。游戏的构架就像一支起伏有致的圆舞曲，十分的规整。中央地点——过去地点A——现在地点A——中央地点——过去地点B——现在地点B——中央地点……的结构始终贯穿着整个游戏。一个个独立情节巧妙联系很好的避免了冗长拖拉的叙事。不过游戏序盘明显游离了这一节奏，但却像一曲轻快的前奏，预示出了游戏时间和空间的广度。

上手一段时间之后，我想大家都会有这样的感受——DQ VII是一款无华丽外表，但故事节奏错落有致的游戏。或许因为DQ根本就是一个不需要华丽外观的游戏世界吧。像FF那样把握在银幕上的视觉效作为主旨是游戏的制作之道，但像DQ这样简朴纯真的风格又何尝不是另一种制作之道呢？过去总是听别人山内片节称呼曰什么 + r1 + ，当初颇不以为然，但在玩过DQ之后，笔者似乎也明白了点几什么。

与想象中的四年磨一剑的大作相比，DQ VII显然还有很多强差人意的地方，但DQ就是DQ，作为杰作的实力是笔者不愿去怀疑的。

——教会

## 明天，没有街机的日子怎么过（PDF p.105）

文/北京　刘环宇

【图】页面上方大字标题，下方配有街机游戏截图（KOF系列画面）

这个明天已经不会太远，因为釜底抽薪，街机的前景黯淡， + r1 + 也已成 + r1 + ，我们难道注定即将在街机厅里与《拳皇2000》中的那些战士们擦肩而过了吗？难道PS2+ + r1 + 就是热血的街机仔们 + r1 + 的唯一宿命之旅？

明天，明天没有街机的日子怎么过？

### 过法之一：死不悔改的街机仔，咬牙怒玩过时游戏！

家用游戏再五彩缤纷，但也绝对找不到街机厅中的那份感觉。这是很多游戏人的真情实感。使出无限必杀时的爽快和暴烈，对战时英雄末路穷途的悲愤与苍凉，那是一个少年寻梦……和寻找友谊的地方，同时能飘来一个青春女孩关切的目光。

从 + r1 + 到 + r1 + ，那些数不清的格斗家们，他们的性格已经不同程度的溶入到我们年轻的血液中，追求荣誉为人生的理想，因此执着无悔地坚持街机路线依然是一部分铁杆玩家的选择。

由于街机游戏节目的制限，街机厅中极有可能出现的情况是：

**A. 古旧游戏的借尸还魂**

虽然 + r1 + 系列红得发紫，但这一街机支柱总会有走向衰败、当这些繁华落尽，都已成为过去的落英飞近在身后的时候，那些曾经万紫千红的游戏会不会再度异彩？

这包括红遍八十年代中后期的飞机游戏和ACT游戏，骨灰级极少玩家的怀旧和新加盟的菜鸟们都会对这些嗜玩度极高的游戏给予浓厚的兴趣！某些那个年代的经典游戏（如 + r1 + ）甚至会再度风靡？！

**B. 封神榜纪录大幅攀扬，各路英豪水平节节上涨**

可以想见，由于对街机厅的封杀，势必会使很多 + r1 + 的玩家 + r1 + 。俗语说，术业有专攻（笑），很多骇人听闻的成绩就是这么打出来的。想当年，笔者家附近的街机厅内只有一台 + r1 + ，笔者经过半个月的磨练终于打出三百多万的高分。如果现在的街机仔们真的能利用好这千载难逢的良机苦练专攻，封神榜的纪录定可大幅攀升，就是将 + r1 + 中所有人物的无限超杀全部摸定也不在不足（笑）。

总之一句话，塞翁失马，焉知非福！

**C. 各流派间的大融合**

由于新游戏已经成为过去，许多流派的高手将会融合。从前玩STG的说FTG的太呆，而对方反唇相讥，说玩STG的家伙们都是木头，冷血。

今后，这样的事情也许就会少得多了。由于没有新游戏的延续，大家都不会再把残守旧了吧，毕竟由全类型构成的游戏世界才是一个完整的世界啊！

相信随着能玩到的游戏日渐稀少，在大浪淘沙之下，留下来的个个是铁打的光棍玩家（这又叫什么话），而正是由于可玩的游戏越来越少，才出现不再 + r1 + ，游戏大家玩，各派大融合的喜人局面。

### 过法之二：拿起手柄来，打回老家去！

对于热爱街机的玩家而言，这是痛苦的选择，然而这种痛苦总比玩不到新游戏的痛苦要好得多。因此，不管是拿起手柄还是鼠标，打回家去已经是相当一部分街机仔们的必然选择了。没有英雄无敌的感觉，却多了几分平静与恬然。如果手中有铁，拿家中的彩电音响通通 + r1 + 一通，依然能够移到不是街机，也似街机的感觉，只是不必再花币了，心里多象少了些什么。

**A. 打回老家的是手柄还是鼠标？**

这里不是要争论电脑游戏和电视游戏孰优孰劣的问题，而是在讨论一种趋势，革命前辈孙中山说： + r1 + 那么电脑游戏与电视游戏哪个更符合世界潮流呢？

世界之大潮在于网络，相形之下，大概电脑游戏功能更胜一筹吧。

**B. PS到底还能打多久？**

中国的玩家们不乏有铁之笔，但绝大多数玩家还没有能力把PS马上换成PS2，于是打回老家后的问题之二就是：如果选择PS，那么它还能让人玩多久。

未经任何专家验证，据本人推断，拥有千余种节目的索尼尼还至少不会比当初的SFC差，它的生命力至少还应该有1年的时间，在加上 + r1 + 、 + r1 + 的因素，如果现在选择PS的话，相信玩到明年年底是不会有什么问题的。
