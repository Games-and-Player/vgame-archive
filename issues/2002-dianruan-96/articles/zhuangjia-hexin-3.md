# 装甲核心3

ARMORED CORE 3

曾经在PS上引发驾驶热的“装甲核心”最新作登场PS2。也许大部分玩家在看到这款游戏时，都会马上想到其中紧张多彩的任务与激烈的对战场景。然而各位是否觉得，营造这些场景的主角AC其实也是一项相当重要的内容呢？由于个人的操作特性不同，所以大家组装出来的AC自然也各有特色，并根据不同任务装备不同机体。流畅、自由和火爆构筑了装甲核心的退异世界！

| 作战领域 | アリーナ |
| 敌战力 | 不明 |
| 作战目标 | 袭击部队全灭 |
| 僚机出击 | × |

**重点指引**：建议先去竞技场打赢E-10得到CWM-560-10后装备起来，FCS也换成AOX-F/ST-6。敌方的战斗用MT需要三发飞弹才能破坏，战斗メカ约需要三～五发步枪的攻击，因为是看击破数量计算酬劳的手脚要快。另外任务进行中会有一架红色AC出来帮忙，被对方破坏的机组并不会计算在酬劳中。想多赚钱就组装轻量型AC出击。另外把不必要的装备卸下来也能增加一些机动力。

**重点指引**：枪支必须用CWG-SRF-80短击来福枪，其他装备大概只要能维持一定的机动性就行了。作战一开始就会被战斗直升机和机动型MT包围，轰炸机出现以前要不停地和这些小喽罗交战，不光是为了加赏奖金。如果光闪躲不将这些战斗直升机击落会让AC受到很严重的伤害。轰炸机出现之前会先倒数一分钟，倒计时后轰炸机开始进入作战区域。利用狙击来福枪的远射能力不停地射击。

## 第二层～第六层 任务概要

【图】各层任务战斗场景截图，展示不同AC机体在各种战场环境中作战

游戏共分为多个层级，每层包含若干任务。随着层级深入，任务难度逐步提升，敌方AC和MT的实力也越来越强。玩家需要根据不同任务的特点来调整AC的装备配置：

- 对付远距离敌人时使用狙击步枪
- 对付近距离混战时使用机关枪或散弹枪
- 对付大型目标时可以使用飞弹
- 护卫任务时注重机动性，使用轻量型机体
- 进攻任务时注重火力，可以使用重量型机体

关键在于灵活运用不同的武器和机体配置，根据任务要求做出最佳选择。
