# 识别GBA卡带

刚接到风林的“圣旨”，天语就快麻几赶来给大家介绍GBA原卡组卡的识别。盗料还是跟了一步，请各位原谅！

识别GBA卡带其实很简单，看价格就行了（笑）。

那为什么还要“识别”？通过对比原组的差异，我们更能看出为什么要打击盗版而提倡购买正版——真的，这不光是光碟的问题，卡带也是一样，卡带可能容易出现问题。现在是高科技时代，盗版商纵然再高明，事实也已无数次证明它怎么也高不过原厂！

样卡是马利A1。真是不比不知道，一比吓一跳。早期较精致的盗版与原版乍看之下是一模一样。拿过了仔细一瞧——嘛！从卡带上的贴纸的印刷精细度就已经分出真假了——不过，要是不对比的话，盗版的也还算说得过去。

其实盗版卡又有哪个地方不比原卡粗糙？接着瞧——

卡带正面贴纸的上方应有“GAMEBOY ADVANCE”刻字，原卡字大而饱满，字体为标准GBA LOGO，如图示。而组卡则随意乱弃了一个，样式单调怪异，字样根本无法严格符合下图。

【图】GAME BOY ADVANCE 标准LOGO对比

再看看卡带背面。首先我们能看到一颗卡带紧固螺丝，原卡是Y型口，组装一律十字口无疑。螺丝下面则又是刻字区域，像是铭牌，好说明此盘卡的身份。以玛丽为例，原卡有三行字，分别是“NITENDO/MODEL NO.AGB002/PAT.PEND.MADE IN JAPAN”，而组装卡则只有两行字，盗版商取消了“MADE IN JAPAN”，也算是盗亦有道了？

剥下的，看看卡带芯片小的接口。但凡原版卡，在芯片接口处都印着字，原版玛丽是“圆U C 2000-AGB-E03-01”，而组卡则什么都没有。

如果你胆子大，敢拆开盗版卡再探究，可就更有意思了。拿玛丽来说，众所周知，任天堂使用的是EPROM即内存记忆方式，而几乎所有的组装卡芯都是电池记忆，而且芯片上的集成电路竟为“黑池儿”式，就像以前的某些MD卡一样，然是难怪总有玩家抱怨“为啥我的卡无法记忆”或“出现死机”。

原因还不明摆着么！

目前，GBA大作不断，与其买一盘盘的组装卡，还不如精挑原版或使用模拟器，这是一。二，如果想体验掌机魅力，也可购入GBA卡带烧录机，可制作8MB容量游戏的机器约500多块钱，而可擦写卡则是一劳永逸的消费，百十元左右也不贵。至于这东西好不好用，国人对GBA还进行了哪些方面的发明创造，我们下期再说。
