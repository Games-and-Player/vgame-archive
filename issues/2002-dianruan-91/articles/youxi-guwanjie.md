## STAR OCEAN 星海传说

超任游戏卡

| | |
|---|---|
| 厂商 | 艾尼克斯 |
| 类型 | 角色扮演 |
| 竞买价 | 380RMB |
| 品相 | 九成新 |
| 珍藏指数 | ★★★★★ |

【图：SFC版STAR OCEAN卡带和游戏画面截图】

ENIX为SFC打造的究极RPG作品，而这盒卡带也一直是许多RPG迷的珍爱之物，其收藏价值不言而喻。

从游戏本身上来看，有很多地方都是“借鉴”NAMCO《幻想传说》的痕迹（哈，不过游戏的出色程度却绝不在《幻想传说》之下，甚至超出），尽管如此，凭借游戏独特的剧本设定仍旧赢得了日本玩家的喜爱。另外，游戏用到了SFC卡带的极限容量也是其升值的原因。比较同为48M的《幻想传说》，《星海》更为难得一见。

说起购买到这盒卡带，能够幸运的买到也颇为不易。喜欢在店里海淘游戏的我在一家小店的角落里意外的发现该卡，遇到这种千载难逢的好机会当然不会错过。对于超级游戏迷来说，能买到这盒卡真是相当幸运的事。

## 电车向前走

掌上游戏机

| | |
|---|---|
| 厂商 | TAITO |
| 类型 | 模拟火车 |
| 竞买价 | 50RMB |
| 品相 | 九成新 |
| 珍藏指数 | ★★★★☆ |

【图：电车GO!掌机版实物照片和游戏画面截图】

玩过PS《电车GO!》的朋友一定都知道这个游戏不是竞速比快，而是强调遵守规则的乐趣，难的准确入站是该游戏的最高境界。

本机采用LCD液晶显示黑白画面，全部共99条路线，每条路线有若干个车站。必须停在指定位置，否则将被扣分，分数为零的游戏结束，就得从头再来。但如果你驾驶出色，遵守信号及时鸣笛，也会被奖励加分。

这款机型为黑色半透明机身，控车键模拟真实火车的操纵杆，不愧为大型街机的口袋版。

另外，本机采用两节微型钮扣电池供电，使用期限相当长，几乎不用更换。
