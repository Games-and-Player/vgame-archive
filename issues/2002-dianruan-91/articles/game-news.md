# 游戏新闻眼

## 索尼网络计划启动 电视游戏进入宽带时代

【图】DNAS（Dynamic Network Authentication System）系统架构图，展示Publisher、Server、SCEI Server、User之间的连接关系

【图】右侧：索尼与雅虎、软银的合作同样令人关注。久多表示：今后仍会积极的与其他有特点的网络服务商或内容供应商合作。

本刊综合消息　2001年12月11日，索尼电脑娱乐公司SCE联合日本宽带网络服务商NTT-BB以及索尼集团下属索尼COMMUNICATION NETWORK（SCN）在东京都召开联合记者招待会，正式发表了其宏伟的宽带网络计划。

SCE社长久多良木健表示，PS2目前在全世界的出荷量已经达到了2313万台，现在正是发展宽带网络的最佳时刻。整个计划将于2002年4月开始全面启动，届时PS2的玩家将可以通过附带100M以太网卡的专用硬盘享受到网络化带来的游戏革命。由于该计划是由目前在日本如日中天的索尼与NTT来推广，其结果必然彻底改变网络游戏目前在日本的窘况。

### 网络服务内容

首先，当然是传统的网络服务，主要涉及单机游戏软件与网络之间的联动，包括网络对战、新关卡、新任务、新内容的下载等，玩家将不再单封闭在一张小小的光盘内容中，而可以享受到无限多的可能性。另外，与以往的家用游戏网络相比，此次网络计划采用的是宽带架构并附加大容量硬盘，使得超大容量数据传送和保存成为可能。而SCN的加入也使得整个网络并不单局限于游戏这个单一范畴，索尼在家电、音乐、娱乐等各方面的强大实力，构架出一个以PS2为中心的家庭网络系统。用户可以在网络上随时下载和了解最新的DVD、音乐、杂志及书籍出版情况，甚至还可以进行数码电视的互动播放，同时还可以将所有信息联入手机网络，使其随时随地都能与世界任何一个角落沟通。久多良木健将其称为“BROAD BAND@HOME”计划。

### 三家公司的合作

那么，SCE、NTT-BB和SCN这三家公司又是如何协作的呢？SCE扮演的是内容供应商的角色，将负责提供PS2专用的附带以太网卡的硬盘，以及保护PS2知识产权的DNAS用户认证系统（注）；同样也提供内容供应的是SCN，他们将负责游戏以外栏目的提供（主要是索尼集团旗下的音乐、音像资料等），同时将现有的SO-NET会员接入新的网络；而NTT-BB主要负责网络的铺设和维护，同时收取用户应付的费用，并将SCE和SCN应得的部分传入两家公司。目前可以肯定的是本次索尼网络计划将是有偿服务，具体价格未定，但久多良木健表示“将按照目前的市场价格”来制订。

注：DNAS全名为Dynamic Network Authentication System，网络化中必不可缺的软件版权保护和用户管理系统。该系统使用在下载和提供内容服务时，当玩家启动PS2后，网络会将主机的唯一ID与游戏的唯一ID重新编码后传送到服务器中进行比照，使用非正版游戏或主机经过改造的玩家将不能享受网络服务，甚至有可能带来法律上的麻烦（显然比DC的网络游戏更严谨、考虑更完善）。DNAS已于2001年7月开始在日本试验，将在2002年随FF11正式发售而全面启动。

### 久多良木健的意向：

1、软件方面目前主推《FF11》，其他内容将在2002年2月的PLAYSTATION发表上正式公布；

2、设备的租借是一种可以考虑的提供方式，但目前我也只是有一个概念而已；

3、SCE在美国发表了MODEM，所以，除了以太网以外，拨号上网的接续方法也在计划中；

4、与世界形势相反，随着XBOX、NGC的发售，整个游戏市场变得非常火热健康。我们从卡带与CD ROM并存的时代，走到了单一CD ROM的时代，而2002年之后，PS2又将掀起宽带旋风。进入网络时代后，“游戏统一”可能会以这种方式来实现吧？

### 与街机中心的关系：

以《赛比赛马》和《VF4》（VF.NET在2001年12月的登记会员已超过5万）率先实现街机网络化并据此大赚一笔的世嘉，早已宣布在网络通信方面与SCE、NAMCO之间的合作计划，虽然具体内容仍未公布，但很明显，PS2游戏与街机中心的网络对战和数据交流很快将变成现实。

1月底发售的VF4并未附带网络功能，铁拳4的网络对应也同样不明，但谁又能保证在宽带全面启动的4月之后，没有VF4或TK4的网络版出现呢？

除世嘉和南梦宫之外，科乐美也已实现了游戏中心通过KONAMI服务中心与手机用户、PC用户之间数据交换的E-AMUSEMENT计划。这几家公司今后的合作令人期待。

## 任天堂行销副总裁接受路透社采访

本刊美国专讯　目前，美国任天堂行销副总裁Peter Main在接受路透社访问时同时发表声明，对NGC的销售情况和公司今后的动向作出了说明。由于Peter Main的地位要职，其言论颇为引人关注。

1. NGC全球出货量已突破270万台，实际销量为250万台；
2. 今年3月底NGC的全球出货量将达到400万台；
3. 任天堂计划五年内在北美卖出2500万台NGC；
4. 有60%的GBA玩家年龄在14岁以下；

6. 在北美销量最大的GBC游戏是《口袋妖怪·水晶》，GBA版“口袋妖怪”一定会在年内推出；

## 新概念手柄发布 P5改写操作理念

ACCESSORY

本刊美国专讯　继上期本刊介绍的“发电手柄”后，一家名为EssentialReality的美国公司又在近日公开了新概念的游戏手柄，取名为“P5”。

## 卫星梦难以割舍 任天堂全新互动计划出台

EVENT

本刊日本专讯　最近，任天堂雄心勃勃的公开了一个利用GBA实现玩家与数字电视实时的互动的宏伟计划。

目前任天堂与日本的NHK和Bitmedia公司合作，针对NHK BS卫星所放送的数字电视设计了一套全新的通讯技术。这项技术的使用原理是，利用特制的GBA主机接收数字电视的信号，当电视节目中有热线问答时，问答题目就会立即显示在电视屏幕与GBA上，这样玩家就能利用GBA作出回答，并把答案立刻传送给现场播放的节目，实现与电视节目的实时互动。

任天堂高层对该计划抱有很大希望，同时他们的发言人表示，未来还会利用这项技术针对GBA与数字电视规划划出更多的互动内容，以提高用户的兴趣。

任天堂一直垂青于利用卫星传输各种数据，97年他们就曾宣布了“卫星送游戏”的计划，但是由于种种原因，这个红极一时的计划最终还是搁浅了。

## 《FAMI通》总编辑长 浜村弘一访谈摘要

TALKING

本刊日本专讯　最近，日本著名游戏周刊《FAMI通》的总编辑长浜村弘一透露了一些他对于今年日本游戏产业的看法。浜村弘一与许多业界知名的制作人交往甚密，相信他的观点会具有一定的代表性。

1. 日本游戏产业自去年夏天开始逐步升温，不仅《FF10》热卖、PS2大幅降价，软件商对NGC与XBOX也抱有很高的期望。在今年上半年，格斗和RPG游戏会唱主角，大约每个月都有两款大作推出，销量应该能保证在50～100万之间。

2. 在PS2宽带网络计划中，网络版的《FF11》扮演着重要角色。以往FF系列至少也有200万份的销量，但是《FF11》如果能卖出30万份，大概史克威尔就要开杯庆祝了。

3. 去年是日本游戏业界经历阵痛和重整的一年，期间有许多厂商被并购甚至宣告破产。因此如何有效的降低游戏开发已经在居键，估计今后软件商们会尽量省略游戏中的CG部分，以纯游戏性吸引玩家。

4. 目前日本的游戏软件市场主要以十家大公司为主，今后他们将更多的为一些有创意的中小型公司提供开发资金和发行渠道，代理他们的游戏，中小公司则把全部精力投入到具体的游戏制作中，彼此相辅相成。

### 记者的意见

2002年，随着主机竞争白热化，以及大小厂商越发趋向严重的两极分化现象，在游戏类型的探索上会有一定时间的止步不前。而随着市场的局部萎缩以及用户层重新分流组合，大硬件厂商在今年的重点课题之一。

之风将会上升到一个新的高潮，在这一年里，我们不妨惊讶于将会看见许多以前不可想像的不同立的游戏标题或软件公司代表形象被组合到一起。而主机平台越来越多样的周边口和多媒体应用也是几萎缩以及用户层重新分流组合，大硬件厂商在今年的重点课前的仿徨期，业界之内的合作题之一。

## 圣诞商战落帷幕 北美PS2获全胜

SCOOP

本刊美国专讯　尽管XBOX和NGC在美国的热度超出了人们的预想，微软和任天堂也纷纷宣称自己开创了家用机首发的最高记录，但是去年圣诞商战的最大赢家仍然是索尼的PS2。

根据第三方调查公司CSFB提供的资料，从去年11月到圣诞节，索尼在美国一共卖出了165万6千台PS2，而XBOX和NGC的销量仅有109万台和91万台，就算是在XBOX和NGC首发的11月里，PS2的销量也达到了91万9千台，超过了XBOX 72万台、NGC 66万台的销售业绩。分析报告同时指出，去年PS2在北美的年度销量为492万9千台，加上2000年售出的数量，PS2总共在北美卖出了601万7千台。

然而有趣的是，虽然PS2在获得了2001年的最终胜利，但是它在去年10月的销量仅有30万台，如果没有后来《MGS2》、《GT3》等大作刺激的话，PS2很有可能在11月被XBOX和NGC反超。

## 《DQ8》不会在今年发售！堀井雄二透露勇者新动向

TALKING

本刊日本专讯　最近，堀井雄二在接受日刊记者专访时，澄清了今年发售《DQ8》的谣言，并对8代的制作情况作了简要介绍。

## 中国自己的游戏技术大会 GTEC在香港会展中心召开

EVENT

本刊讯（记者：叶展）　2002年度香港游戏技术会议（Game Technology Conference）将于1月16日至19日在香港会展中心举办。本届大会请到了一些比较重要的业界人物，可以说GTEC就是中国的“GDC”（美国的游戏开发者大会）。

GTEC和GDC不同的一点是GDC原本是业界的会议，研究类型的大学介入其中也是近两年的事情。而GTEC的两个主要组织机构一是香港数字娱乐协会，一是香港理工大学。也就是说香港本身的市场和业界都还没有完善，但行业协会和大学反而超前了。这和美国的情况正好相反。美国是市场先行，然后开发区自己就发展起来了。中国则是先建开发区，然后希望市场起来。中国香港希望依靠内地区和台湾的巨大市场潜力，成为这个市场在世界舞台上的代言人。这个会议向我们显示出他们的努力和实力，以及进展。香港人是很聪明的！

会议的重头戏是17日开幕式的三场演讲，分别由金山公司的求伯君，台湾智冠的王俊博，和香港理工大学MIC中心的Gino Yu分别做关于内地、台湾省和香港特别行政区三地游戏市场的演讲。

中国的业界，应该注意这个会议。毕竟，它距离我们比GDC近得多。

【图】右侧：比较GTEC和美国的GDC，可以看到其会议组织安排基本上相同。也是由讲座、论坛、演讲等多个部分组成。但GTEC提供的讲座和论坛从数量上还是比较单薄，吸引到的业界一流“讲师”还不多。讲座大多是由香港理工大学的MIC教学研究人员主持，但内容还是比较丰富的，而且全部用英文言讲。这次会议的官方地址为：www.gametechnology.org。

## NOA社长更替 荒川实有望入主本社

EVENT

本刊日本专讯　据日刊FAMI通报道，2002年1月8日，任天堂正式宣布原NINTENDO OF AMERICA创始人兼社长、任天堂本社山内社长的女婿荒川实已于1月7日正式辞职。原日本三和银行纽约分行行长、2001年加入NOA担任POKEMON管理本部部长的君岛达己将代替他就任美国任天堂总裁一职。

官方声称：荒川氏的辞职是因为“目前GBA和NGC在美国正好调热卖中，前景看好。在这样的情况下把职位交付给后任是最佳的时刻”。但荒川在美国为任天堂立下的汗马功劳和其与山内家族的特殊身份使人不得不想到辞职的最终目的：取代其岳父山内博担任任天堂本社的社长。如果该猜测属实，被誉为“业界巨人”的山内社长将很有可能在年内退休。

### 新闻背景资料

京都人，出身于纺织业主家庭，毕业于京都大学土木工程学，后留学美国著名麻省理工学院，其后因与山内博的大女儿山内阳子结婚而参与任天堂事务。1980年被派往美国创立任天堂美国分部，并帮助任天堂在最困难的时候度过难关。NOA的收益目前占到任天堂所有海外收益的2/3强。

另外据说，荒川实的脾气很好，应该可以和软件商打好交道。

## 索尼续写圣诞奇迹 PS2单月销量突破500万

SCOOP

## 《合金装备》博得全球喝彩 小岛秀夫当选明日之星

SCOOP

本刊美国专讯　1月7日出版的美国《新闻周刊》评选出了七位有可能在未来声名显赫的“明日之星”，著名制作人小岛秀夫凭借《合金装备2》的出色效果荣获科技界“明日之星”。

《新闻周刊》称：小岛秀夫才华横溢，他如果从事文学创作、电视制作或者拍电影，都能够取得杰出成就，但他最终选择了游戏制作。

小岛生于日本神户，幼年时经常与伙伴们一起玩捉迷藏。他非常喜欢在墙边躲藏、在暗处窥探的感觉，也许创作SOLID SNAKE雏形的灵感就来源于此。中学时代的小岛曾撰写过五本长篇科幻小说，此后还进行过8毫米电影的拍摄，并放映给朋友们观看。今天，将丰富的电影语言融于游戏制作，奠定了小岛秀夫在游戏界举足轻重的地位。

另据截稿前得到的最新消息：截止到去年12月底，《合金装备2》在美国的实际销量已达到150万份，在日本也卖出了80万份，全球销量突破230万份。

## 游戏业继续大幅增长 年总产值可达288亿美元

EVENT

根据美国市场调查机构Group Information报道：在PS2、XBOX、NGC三家激烈竞争的带动下，今年游戏产业将大幅增长，主机、软件以及相关产品的总产值可高达288亿美元，一跃成为21世纪最耀眼的娱乐产业。

据推算，2002年全球游戏主机的总产值为90亿美元、软件为156亿美元、其它相关产品为41亿美元。到了2003年，全球游戏仍会保持旺盛的增长势头，届时总值将达到358亿美元。
