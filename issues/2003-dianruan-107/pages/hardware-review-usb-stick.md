# 良心硬件测评

## 法宝 1：新型 USB 接口 PS2＞PC 手柄转接器

【图】XG MACRO 转接器盒装产品照，绿色与蓝色两款，标注 PS-PC USB2.0 CONVERTER IV

【图】转接器与 PS2 手柄实物照，标注 XG MACRO

←在国外取得良好销售业绩的通用USB转接器，国内还比较少见。

**用 PS2 手柄玩模拟器和电脑游戏！**

这种产品是中国自行设计制造的，采用USB接口，即插即用，一般情况下毋须安装驱动程序。该制品除提供基本转接功能外，尚有更为强大的“编程功能”，可适应多种类型的电脑游戏。天语收到的最新产品是XG MACRO五代（右图和下图是五代的迷你型。左图是四代和五代的普通版），不同版本的功能略有差异（如对震动的支持）。

【图】迷你型转接器接入电脑的实物照，旁竖排文字“WINXP 下绝无拖慢”

天语将测试样品送给三个朋友，自己留了个迷你型。所有人的评价都很高，此物使用方便，功能更是远超打印口产品。

【图】显示器与 PS2 手柄，屏幕显示模拟器游戏画面

点亮红灯，十字键失灵，ANALOG 小摇杆接通！

**可接舞毯等一切 PS 周边**

注意：天语用各种版本的模拟器比如GBA和卡氏街机的，都是直接在模拟器里设定手柄按键，进而顺利游戏，全无问题。就算是玩BUG爆多、补丁无效、口碑恶劣、不负责任的“仙剑2”，也能勉强进行（时灵时不灵），但这种纯电脑游戏最好能用本制品自带的光盘，安装驱动进行手柄键位编程，只因光盘说明部分不详，天语没有试成功，有些遗憾。

## 法宝 2：ASCII 制造的专业 PS 大摇杆，可配合 USB 转接器在 PC 上使用

【图】ASCII STICK 盒装产品照，包装印有《街头霸王》与《拳皇》角色，标注 ASCII STICK Fighting Type 2 Original

↑这是卡普空指定的摇杆，ASCII制造，使用起来非常安心，用料精。

【图】ASCII 摇杆俯视照，浅蓝色面板配黑色按键与球形摇杆头，印有 ASCII 大字

↑ASCII的巨大LOGO配合浅蓝基调。天语提醒，此摇杆属于上期杂志文章中提到的“提示”型按键。

【图】摇杆侧视照，展示厚重机身与腕托

↑超流线型腕托，美观度高，手感更加舒适自然。从这个角度可以看出这款摇杆的厚重，用料绝对猛。

【图】摇杆按键排列特写

↑基本键位排列如图示。适合各种格斗游戏以及街机动作游戏。

【图】摇杆与 CVS2 出招卡片，卡片插在卡槽中，屏幕显示日文出招表

↑提供一盒CVS2出招卡片，放到卡槽里感觉新颖。

【图】摇杆斜视照，展示球形摇杆头与按键布局

↑卡氏指定ASCII制造，学名FT2。好用极了。
