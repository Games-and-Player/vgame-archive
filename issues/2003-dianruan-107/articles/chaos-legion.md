# 混沌军势

> CAPCOM PS2 动作游戏《混沌军势》（Chaos Legion）系统和全关卡简明攻略；PDF 82—83，刊页 78—79。

本次的《混沌军势》又让笔者见到了 CAPCOM 制作快餐游戏的水平，在游戏中隐隐看到了魔顿中酷度满点以及真三国中那种带着护卫兵冲杀爽快感的影子。看来“克隆鼻祖”的称号不是盖的，就让我们来见识大师手笔吧！

- 机种：PS2
- 厂商：CAPCOM
- 发售日：2002.3.6
- 类型：ACT
- 价格：6800 日元

## SYSTEM 系统

最重要的当然莫过于主角西克・瓦尔海特与七种强力唤兽 LEGION 的配合，在装备每种唤兽的时候主角都会对应技能，虽然最为实在的莫过于四连斩和六连斩。但我想无论是谁都想将战斗表现得更华丽些吧。

按照剧情的发展，唤兽 LEGION 的习得为每个场景战斗中消灭 BOSS 后出现，其顺序依次为“剑之 LEGION”、“爆弹之 LEGION”、“盾之 LEGION”、“爪之 LEGION”、“力之 LEGION”、“巨大之 LEGION”。

### 主角的基本动作（Type A）

| 按键 | 功能 |
|---|---|
| △ | 指挥唤兽集中攻击锁定敌人 |
| □ | 普通攻击 |
| × | 跳跃 |
| ○ | 锁定射击 |
| L1 | 召唤 LEGION 或收起 LEGION |
| R1 | 在两个已装备的 LEGION 间切换 |
| L2 | 切换到主角面对的视点 |
| R2 | 切换 LEGION 的攻击和防御 |
| SELECT | 查看地图 |
| START | 进入状态画面，可看道具等 |

在混乱的战斗中，熟悉各项操作是很重要的。

## LEGION 的基本动作（游戏的乐趣可全在这里了哦！）

### 弓之 LEGION

1. 按入键实行一起射击。
2. 按住 A 键不放时锁定并射击任何目标。
3. 当主角击飞敌人并使敌人浮空时，所有 LEGION 跟踪追击并形成连击，消耗 25P 的 SOUL 值。
4. 主角可用锁定攻击按住不放锁住敌人。
5. 可超长距离停止敌人的攻击。
6. 在敌人攻击瞬间锁住敌人。

### 巨大之 LEGION

1. 积极攻击靠近主角的敌人并随时跟在主角前面。
2. 可将某一敌人逼至墙角连续数下。
3. 借助时空之力减缓所有敌人的动作并发出许多次球辅助攻击。

### 力之 LEGION

1. 自动追踪并攻击敌人。
2. 守护主角并在主角身边拳打脚踢敌人。
3. 消费 50P 的 SOUL 值，在受到敌人攻击的瞬间将敌方扔飞。
4. 使得主角会冲撞攻击，即主角面向方向＋攻击键。

### 盾之 LEGION

1. SHIFT 移动时 LEGION 受攻击会蓄力反击。
2. 召唤后在主角周围移动并防御。
3. 消耗 100P 的 SOUL 值在主角身上出现防护罩，在一定时间内敌人攻击会减弱，且 LEGION 级别越高持续时间越长。
4. 使得主角会反击斩，即在敌方攻击的瞬间按攻击键。

### 爪之 LEGION

1. 在 SHIFT 移动时能对倒地敌人做到追击。
2. 召唤三个 LEGION 时可飞身攻击，即从空中穿下攻击。
3. 消耗 20P 的 SOUL 值，在地面上设陷阱使碰到的敌人自创，同时进行倒地追击。
4. 高跳时可产生 1.5 倍攻击力的剑斩。
5. 在攻击的任何时候可按跳跃键闪开，回避敌方攻击。

### 剑之 LEGION

1. 自动追踪并攻击敌人。
2. 守护主角并在主角身边斩杀敌人。
3. 消费 59P 的 SOUL 值后突进到敌人身旁并连刺。
4. 使得主角可用大连斩，即连续按下攻击键。
5. 使得主角会使用地斩，即按下主角背向的同时按攻击键。
6. 使得主角会使用爆断斩，按住攻击键蓄力后放出。

### 爆弹之 LEGION

1. 召唤单体原地自爆，消耗 SOUL 值。
2. 召唤四体原地自爆，消耗 SOUL 值。
3. 消费 50P 的 SOUL 值将爆弹弹出并发生爆炸，攻击力依爆弹之 LEGION 的级别而定。
4. 即使不装备爆弹之 LEGION 也可使用空中落斩，即在空中按下键＋攻击键，插在地上爆炸后离开。
5. 可进行高距离的二段跳。

## 关卡攻略

### STAGE 1　圣都罗塔尔

游戏的最开始，此关完全是让玩家练手用的，小怪物们不堪一击，尤其是在巨大之 LEGION 的帮助下过关更加易如反掌。此关最重要的就是练习如何与 LEGION 搭配起来攻击敌人，这也是贯穿整个游戏的动作宗旨。第一场 BOSS 战了，可以轻松解决，几秒后 BOSS 就消失了，此时巨大之 LEGION 消失，取而代之的是剑之 LEGION。

### STAGE 2　都市迦悠・街道

在第二场景的战斗中，只要玩家使用剑之 LEGION 战斗，剑之 LEGION 可以获得可观的经验点，如再加上装备剑之 LEGION 后可以使用强力的六连斩，所以对付杂兵是完全没有问题的。在有大怪兽的关卡后就可过版，在战斗中注意 SOUL 值的回复，这样才能保证剑之 LEGION 存活。在战胜 BOSS 后可得到弓之 LEGION。

### STAGE 3　都市迦悠・中央区

得到弓之 LEGION 后对付空中的敌人会非常轻松。在弓之 LEGION 将敌人射到浮空后就可使用连斩了，或在将敌人用地斩击击浮空后指挥弓之 LEGION 连击，这样会极易成功将敌方击杀。在两种已入手 LEGION 间切换是战斗的关键，建议对付 BOSS 时多用剑之 LEGION 的集体体操式六连击点刺，过版后可得爆弹之 LEGION。

### STAGE 4　穆鲁门遗迹

在穆鲁门遗迹中敌人的种类有所增加，而且随着剧情发展带着 TARGET 字样的场景 BOSS 也非常强劲，这就需要玩家在前面的战斗结束后多使用经验点增加道具，迅速地提升剑之 LEGION 的数量和 SOUL 值长度，笔者一直都是把提升数量加以 LEGION 的攻击力作为首选，其次再提升其他技能。

### STAGE 5　穆鲁门遗迹・深部

主角西克来到穆鲁门遗迹的深部后，遇见了那种拿着巨盾的青色巨汉，由于只有击毁其拿着的盾牌后才可将其击杀，所以要小心地绕到其背后攻击。另外，如果不想与一拨又一拨的敌人周旋的话，也还有一个取巧的方法，那就是直接锁定它击头戴 TARGET 字样的地域 BOSS，可以看到全部敌人立刻化为一片烟闪，不过至于 LEGION 累计经验就……在解决了不知像何物的 BOSS 后就可取得爆弹之 LEGION 过版，要小心战斗中 BOSS 放出的全屏攻击。

### STAGE 6　湖畔

在湖畔的怪物中出现的 BOSS 是一个银色半透明敌人，是必须用 LEGION 的特殊攻击解决的，这样过来所保留的 SOUL 值很保证的体力就尤为重要了，不过如果玩家们在前面的战斗就意意锻炼剑之 LEGION 的话，那么解决掉它们绝无问题，本关的 BOSS 战其实非常简单，活用刚得到的盾之 LEGION 以及及时切换到剑之 LEGION 是关键，得胜后可进入雾之溪谷。笔者建议在此关多练习爆弹之 LEGION，其必备技二段跳是接下来的剧情中拿道具必需的。

### STAGE 7　雾之溪谷

在雾之溪谷中，由于山道崎岖，加上一些视角问题，使得游戏对进行会很艰难。而空中的飞翔怪物则应用弓之 LEGION 解决，而且必须装备的二段跳技能是得到高处道具所必备的，不过由于爆弹的攻击太过强劲且消耗 SOUL 值，所以还是先积累 SOUL 值而在充满后用爆弹来对付皮糙肉厚型敌人吧。中途得到力之 LEGION，BOSS 战后得到爪之 LEGION。

### STAGE 8　大洞窟库斯卡

来到了气氛和音乐极其诡异的库斯卡洞窟，在进入主门之前，要分别进入左右两边的门内消灭所有的敌人，而后中间的大门打开，经过了一系列的苦战，大家一定已经积累了相当的灭敌经验，BOSS 战前会发生与维克多再次相遇的剧情，而后前来的女主角“银之乙女”阿西亚，林斯首次终于登场，剧情进入高潮部分。

### STAGE 9　森

剧情发生后阿西亚离开了西克来到了森林中，由于女主角的攻击普通较男主角稍弱，而且作为强力攻击的关键全屏射击并未有太强的实用性（对付本关敌人则够用了），所以还是建议大家多用阿西亚的腿技攻击，明那西的二段跳技能在进行高处门段可得到道具，而且对付高空敌人也相当好用。BOSS 依然是奇丑无比的怪物，用阿西亚的蓄力集中射击消灭它吧，获胜后得到爪之 LEGION。

### STAGE 10　禁断的封印都市·依扎克・空中回廊

带着阿西亚的祈祷和援托，西克迈向了通往圣都的征程，等待他的是诡恶的怪物军团，混沌之势。在空中回廊中的敌人相当的厉害，所以建议大家尽量让已经满的 LEGION 和新入手的 LEGION 一起切换战斗，这样一方面可以较轻松战斗，一方面又可以培养新 LEGION 为二周目作准备（汗）。在版面尽头等待西克的是浮在前方空中的巨大 BOSS，大家要小心的是其撞击地面的全屏攻击，除了会扣去主角大量的血外还会将主角震到画面边缘，是十分霸道的攻击，建议打击法：在撞击时跳跃，用剑之 LEGION 集中攻击大幅削血，大约六七个来回就可解决掉它，本关得到力之 LEGION。

### STAGE 11　禁断的封印都市·依扎克・深部

来到了禁断的封印都市依扎克深部的全图阻止主角前进的敌人蜂拥而至，此时建议大家在敌人集中时使用改造满的爆弹之 LEGION 进行战斗，得手后立刻切换至其余 LEGION，会有事半功倍的杀敌效果，由于 BOSS 为一堆老相识了，在此就不详提其消灭过程了，用上述方法过版极简单。

### STAGE 12　圣都罗塔尔崩坏的圣都

主角再次来到了崩坏的圣都罗塔尔，破败的残垣断壁诉述了邪恶势力的凶恶，在西克面前已没有退路，玩家面前当然只有一条路，那就是不断向前冲（不要告诉我你会在现在放弃），本关 BOSS 为一个巨大的持盾型特技龙的迅访特怪怪物——样绕无的大片，用攻击力大的剑斩攻击它的躯斩，BOSS 其实非常灵活，大家与他对切时要分外留神。

### STAGE 13　克雷阿大圣堂

西克终于来到了罪恶的源头——克雷阿大教堂，在这里的敌人非常强悍，相信三周目 HARD 难度的玩家会痛苦万分，但为了拿取改造所有恶兽的各项数值，大家只有努力了。特别是对付一堆血条极厚的怪物，而令人讨厌的银色金属人有六个之多，之前没有蓄 SOUL 值的人该哭了。通过此关后就是与邪恶的最后一战了。

### STAGE 14　圣棺之间

在圣棺之间，因三圣印而走上宿命之路的两位仇敌见面了，在战胜了维克多后，闯入这里的阿西亚挡在了就要击中西克的维克多前面，这一似曾相识的举动唤起了维克多关于真实的记忆，在懊悔和痛苦中，维克多落下了高台，还没来得及从痛苦中解脱的西克，将要面对的是已经被释放出来的黑暗之怪和罪恶之源，接下来就是真正的最后死斗，结局虽不圆满，但在 CG 中幻觉的世界依然那么美好。
