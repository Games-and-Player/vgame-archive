# 超级机器人大战α for Dreamcast

【图：超级机器人大战α DC版标题画面和包装封面】

**机种：DC　厂商：BANPRESTO　类型：S·RPG**

**发售日：2001年7月5日　媒体：GD-ROM**

## PS版的终极进化版本

等待已久的《超级机器人大战α》DC版终于来了！本作以PS版为基础，在各个方面都进行了大幅度的强化和改良。

【图：DC版与PS版的画面对比截图，展示DC版更精细的战斗动画】

### 画面全面升级

DC版最大的进化当然是画面方面。所有的战斗动画都经过了重新绘制，机体的细节表现更加丰富，动作也更加流畅。背景的表现力同样有了明显提升，爆炸和光线特效都更加华丽。

在战斗画面中，DC版追加了大量新的演出效果。一些在PS版中因为机能限制而无法实现的表现手法，在DC版中都得到了完美呈现。尤其是必杀技的演出，无论是动作的帅气程度还是特效的华丽程度，都远远超越了PS版。

### 新追加参战作品

DC版最大的惊喜是追加了新的参战作品！在PS版的基础上，DC版新增了以下参战机器人动画：

- 《机动新世纪高达X》
- 《超时空要塞 爱·还记得吗》（强化出场）

新参战作品的加入不仅意味着新机体和新角色的加入，还意味着全新的剧情展开。编剧组为新参战作品编写了专属的剧情路线，与原有故事线完美融合。

### 系统改良

DC版在系统方面也做了许多细致的改良：

1. **战斗平衡性调整**：针对PS版中一些过于强势或过于弱势的机体进行了数值调整，使得游戏的平衡性更加出色。
2. **新追加精神指令**：部分角色获得了新的精神指令，增加了战略性。
3. **隐藏要素增加**：追加了更多的隐藏机体和隐藏角色，收集要素更加丰富。
4. **读取速度提升**：得益于DC使用GD-ROM光盘，读取速度比PS版有了显著提升。

### 全新的CG开场动画

DC版还制作了全新的CG开场动画。在这段长达数分钟的开场中，各参战作品的代表机体以精美的CG形式悉数登场，配合气势磅礴的主题曲，让玩家在游戏开始之前就能感受到热血沸腾的氛围。

【图：CG开场动画截图，展示高达、盖塔、魔神Z等机体的精美CG画面】

### 值得入手吗？

对于已经玩过PS版的玩家来说，DC版的追加内容足以让你再次沉浸在超级机器人大战的世界中。全新的战斗动画、新参战作品、改良后的系统——这些要素加在一起，使得DC版成为了目前最值得推荐的《超级机器人大战α》版本。

而对于还没有接触过本作的玩家，DC版更是一个绝佳的入门选择。
