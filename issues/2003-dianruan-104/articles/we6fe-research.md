## 球员能力详细解说（按照能力顺序从上到下排列）

| 能力名 | 解说 |
|---|---|
| 身高 | 队员的身高。一般来说身高越高，争头球时就会更加有利，防守面积也会大一些。 |
| 擅长脚 | 队员的惯用脚。分为左脚、右脚和双脚三种类型。当队员使用非惯用脚传球、射门时，精度和力度都会有很大程度的下降。 |
| 进攻能力 | 队员进攻的整体能力。值越高，被踢或被铲后能复到较快。 |
| 防守能力 | 队员防守的整体能力。值越高，抢球及扑球的成功率会比较高。 |
| 身体平衡能力 | 队员的身体强壮程度。这项数值越高，在对抗中能够获胜概率对方。传球、射门时的时候受到影响也会比较小。同时在争头球时也比较有利。 |
| 体力 | 队员的耐力。当队员的体力下降时，奔跑速度、弹跳力、传球、射门力会全部下降，所以体力值高的队员，完成其他动作会有了充分的踢球。这一点尤其是对于在延加时赛中非常关键。 |
| 速度 | 队员奔跑的速度。值越高，跑得就越快，但是带球速度不一定很快。这和速度能力有关。 |
| 加速度 | 队员启动的速度。值越高，队员加速启动的速度就越快。这在突然过过人的时候非常重要。 |
| 反应能力 | 队员的反应能力。主要体现在一些突发情况。比如对方的反弹球反应等，还有就是在射门是站射角力手外计，反应能力强的队员会在第一时间拍马就射，把球射进门内。 |
| 盘带精度 | 队员的盘带精度。盘带精度高的队员在带球和在加速时球和两足距离会比较近。带球时的感觉就是“人带着球走”，这项能力低的队员带球感觉就是“人追着球走”。 |
| 盘带速度 | 队员的盘带速度。这项数值的高低决定了队员在带球奔跑的速度。我们经常可以看到有很多队员带球无球时速度有着较大的差距，就是和这项能力相关的。和一套就不行了，就是和这项能力有很大关系。 |
| 短传精度 | 队员短传的准确程度。这项能力越高，队员短传的准确程度就越高。但这只适用于及×地的短传，用右摇杆的短传精度不受此数值影响的。 |
| 短传速度 | 队员短传的速度。短传速度越快，防守队员就越不容易截到球。手动短传的速度不受此数值影响。 |
| 长传精度 | 队员长传的精度。只有长传精度高，长传进攻才会有威胁，手动长传进攻才会有效。影响。 |
| 长传速度 | 队员长传的速度。这项数值主要体现在底传中距。长传的速度越快，对方的已防就越容易首当其冲的倒失，手动长传的速度不受此数值影响。 |
| 射门精度 | 队员射门的精度。数值越高射门的精准程度就越高，主要体现在禁区内的低平球射门。 |
| 射门力量 | 队员的射门力量。数值越高射门的力就量越精准，主要出现在禁区外的大力远射。 |
| 射门技术 | 队员的射门技术。射门技术高的队员射门时的调整幅度比较小。在对抗中射门受到的干扰也较小。能够顺利完成射门动作。倒挂金钩等高难度射门动作。 |
| 头球精度 | 队员头球精度。这项数值高的队员，无论是在头球连续的时候都会有比较高准度两次是不准确的。 |
| 弹跳力 | 队员的跳跃力。数值高的队员在争头球时就会对手处于比较有利的位置。 |
| 技术 | 队员的技术。数值高的队员在停住球和技术动作、比如转向、停球等更动作会更加合理，完成覆盖也会比较好。 |
| 弧度 | 队员的弧度。主要体现在弧强任意球时，弧球以及月球引力的感觉。数值高的队员挡出球的穿越方向的曲折，对于对手的威胁相当大。 |
| 攻击性 | 队员在进攻时的积极性。非常有威胁，但是很容易暴动的。 |
| 心理素质 | 队员的心理素质。数值高的队员在比分落后以及体力下降等不利情况下不会受到影响的比较小，这是一个真正的球星独备的素质。 |
| 安定度 | 队员的状态安定程度。这主要体现在联赛和杯赛中。如果来连续加多场比赛，队员的状态会有不同程度的下降。这时安定度就起了决定性作用。 |
| 任意球精度 | 队员在路角球、任意球、点球时的准确程度。这项数值高的队员在踢定位球时会有很大的威胁。 |
| 配合能力 | 队员的配合能力。这项数值越高，队员在比赛中的配合位置就越合理，和其他队员进行配合也更为默契。 |

## 实战中盘带的具体操作方法

在这次的WE6FE中，球员能力有两项是和盘带技术有关的——盘带精度和盘带速度。前者的数值越高，盘带时球与身体距离越近，这样球不容易丢，也比较容易做出一个动作。后者则是表示带球跑动的速度，有很多队员速度很快，但是一带起球来就不行了。和这项数值低有很大关系。同时，队员的特技中有一项是“盘带”，有这项特技的队员在数值相同的情况下，盘带的能力更强。

### 第一部分：基本的盘带动作

**1. 普通带球** 方法是拨方向键，这是最常用的盘带动作，能够非常灵活地传球、加速、射门，也能直接切换到其他盘带动作。缺点是速度较慢。

**2. 加速带球** 方法是按R1+方向键。这也是很常用的动作，喜欢用速度快球员的玩家对此再熟悉不过了。这种盘带速度很快，但是做其他动作的时间则较长，变向也不是很灵活。主要用于利用速度强行突破对手防线的时候。

**3. 高速带球** 这是从WE6开始增加的一个新动作，方法是按R2+方向键。总的来说这是一种介于上面两种带球方式之间的一种盘带方式。在加速带球时球会被对方断下，普通带球速度太慢的情况下，可以试试这种盘带。

**4. 低速带球** 方法是按住L1+方向键。这种盘带对球的控制能力极强，但是速度几乎为0。在突破时没有任何使用价值。主要作用是护住皮球等待队友插上。

**5. 急速带球** 方法是在加速带球中连点方向键。加速度较快。

### 第二部分：特殊盘带动作

**1. 双脚晃动假动作** 方法是连点L1键。这种盘带实际操作时的感觉度大。主要用在对1对1突破的时候。

**2. 快速双脚晃动假动作** 是一种不错的假动作，让人的对很情有用。方法是连点R2键。

**3. 扣球** 这种在足球场上经常使用的动作在WE中仍然是过人突破的有效手段。同时也是平刀球的处理方法之一（可以晃过守门员）。方法是拨□+X。

**4. 横向拉球** 使用这个动作可以将球横向平拉大约1个身位。在过的时候非常有用。方法是按前的直角方向键+R2。

**5. 跳球** 在对方防守球员马上就要铲到你的时候，按R2+方向键可以跳起来，以避开对方的铲球，防止受伤。

**6. 双脚假动作趟球** 这是一种很高级的过人方式，是盘带高手的杀手锏。方法是按方向键前——剑前——前。但这一切的前提是要求球员有这项特技——两足过人。

**7. 双脚假动作后趟球** 按方向键前——R2——剑前——前。可以在做出双脚假动作后大步向前趟球，这样更加的利于突破。

**8. 反身扣球** 在盘带时向后拉方向键。可以迅速将球收回脚后，从入方向摆防守队员。实战中非常有用的。

**9. 反身大扣球** 在盘带时向后拉方向键+R1键，就可以做出幅度较大的扣球动作。和上一个动作的用途是一样的。

**10. 踩球** 在盘带时按下R1键，就可以将球来直接踩住在脚下，可以用于急停和加速中。
