# NEWGAME REVIEW&SHOW 编辑点评

NEW GAME 编辑点评 NEW GAME REVIEW

电软游戏四人鉴定团

12月14日～12月30日

**评论人：** 风林 / 天师 / 宇部 / MASCAR / 星尘大海

**评分标准：** 36-40 强烈推荐 / 30-35 值得一试 / 1-29 素质一般

## 12月12日 胜利十一人6最终版

- 机种：PS2
- 厂商：KONAMI
- 类型：SPG
- 媒体：CD

人气第一的足球游戏最新续集，大幅提升各方面的效果，令人惊喜。PS2版附赠PSBB，可以下载最新的游戏数据，各种新要素的加入使游戏的乐趣更加充实，值得一玩再玩。GC版也将在随后推出。

本期点评了18款游戏，篇幅较大。风林以心情点评，PERFECT评论焦点在操控，宇部感觉足球最终版的各方面进化很成功。至于另一款期盼了多年的钟楼新作，MASCAR对WE6终极版有了新的感悟。

**风林：** 当然是最新的足球游戏，虽然KOF再次超越了自己。虽然有机会再次打败嵩崇神话……一系列的动作的组成是风林这个人喜欢“暴力行为”。以“钢伟”阳来，倒着不甚要好。奇妙以来是积极的气势加重并且当前最佳的FROMSOFT。制作的游戏趋来越是出色了，希望GC的RUNE2也能令人一扫眨匿！

**天师：** 游戏的感觉真好，但以前的那些惊喜、那些触动，现在完全感受不到，不在乎谁了。所以就会去看DVDRIP等外电影了。万家的，GOB，苏木，东京已士，梦美达这种新出现的而感觉到他以前喜欢的牛赛宝。彩实已回顾当年，希望来在VF4EVO和OGO的原生之前，那些全和这手的游戏不能掌。

**宇部：** 大家见到本期点评时，一定已经在元旦假日快乐的玩着游戏了，最想星尘早就被推在大作堆中不可自拔出，才一个ZELDA就够研究一杯了，加之即将热血上市的第二次机战以阿尔法……

**MASCAR：** 临近年末，可玩的大作实在是多了，连编辑点评也忙不过来了。这次MASCAR对WE6终极版有了更新的感悟，还忙着编辑部的WE对战，最近编辑部的WE又复习了，MASCAR也慢慢找到了新作的感觉。

## 12月12日 不明 电梯大战

- 机种：GBA
- 厂商：TAITO
- 类型：ACT
- 媒体：卡带

脍炙人口的经典游戏，除了收录原作外，制作了海外游戏完全重新包装。各种新要素的加入使游戏的乐趣更加充实，值得一玩再玩。

## 12月19日 逃亡

- 机种：PS2
- 厂商：SCE
- 类型：ACT
- 媒体：DVD

描写黑帮的动作游戏，虽然内容头子了大量田联错误，但是游戏制作确认，画面精美非常，绝对是近期PS2上值得尝试的美版游戏。

## 12月12日 罪恶工具XX

- 机种：PS2
- 厂商：SAMMY
- 类型：FTG
- 媒体：DVD

当今最强人气最高的2D格斗游戏就是本作了，除了完全移植于街机版以外，PS2加入了家用机版的必要需求。内容丰富，强列推荐。

## 12月19日 SEGA拉力

- 机种：GBA
- 厂商：SEGA
- 类型：RAC
- 媒体：卡带

SEGA经典赛车游戏终于再次登场了。虽然速度以后巨大无比地，多种色彩的选择增代为玩家提供了更多种样的乐趣。

## 12月26日 SONICA 2

- 机种：GBA
- 厂商：SEGA
- 类型：ACT
- 媒体：卡带

音速刺猬终于再次登场了。虽然速度（在巨国无比上），游戏在画面上也有所强化。多种色彩的选择增代，为玩家提供了更多种多样的乐趣。

## 12月13日 钟楼3

- 机种：PS2
- 厂商：CAPCOM
- 类型：AVG
- 媒体：DVD

恐名的名作最新续作。终CAPCOM果然不同的，连续作都0.1化了，也许这就是BIO——的有风格和各类的特色，而FROM软件制作——一些话去要求CAPCOM做的事情或许永远不会做到。

## 12月19日 飞龙ORTA

- 机种：XBOX
- 厂商：SEGA
- 类型：STG
- 媒体：DVD

绘画面画质化的令极限风格的游戏，SEGA念旧非代入世面色的游戏收录了一代又跟了CD，多少一分呢。之比，在最强主机上展示的画面自然也是最级，众多精品令游精彩不已。

## 12月12日 红海

- 机种：XBOX
- 厂商：KOEI
- 类型：ACT
- 媒体：DVD

人设古怪的新感觉动作游戏。画面是XBOX水准，虽然动作形式类似“三国无双”，但却无法无双人同时的游戏，是比较遗憾之处。

## 12月12日 布林克斯 时间清道夫

- 机种：XBOX
- 厂商：MS
- 类型：ACT
- 媒体：DVD

拥有超凡操作系统以及可爱画面的动作新作，MS虽然末了力推的重磅游戏。但因为系统过于新鲜，对玩家令人相当不便，需要适应。

## 12月12日 OTOGI-御伽

- 机种：XBOX
- 厂商：FROMSOFT
- 类型：ACT
- 媒体：DVD

画面华丽到至极的动作游戏。结合了多部著名名作的特点，不过是不是一般。

## 12月13日 塞尔达传说 风之韵

- 机种：GC
- 厂商：NINTENDO
- 类型：RPG
- 媒体：DVD

可以代表一个时代的游戏的质态。颜回表大空形的道。本作算是一个ACT吧。这样就成分算不太贵游戏了。分给ACT对型加上分不太高却确因后，因为大。还实这款的的说通不太完善。

## 12月12日 弹头精选+时间危机

- 机种：PS2
- 厂商：NAMCO
- 类型：STG
- 媒体：DVD

超级冷饭四合一。南梦宫的面子奇好的来来来是不至大义，在PS的层面对今年来看已经无法受。尤其了冷饭面画质和效果令人想忘但它还是旧……
