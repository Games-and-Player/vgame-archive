# 街机风暴 VOL.1

**释放心灵深处的不羁与天真**

**「电软」让你感受街头玩耍的最强感觉**

炎炎夏日出去打球逛街又热又怕晒黑，还是室内运动比较好。可是室内运动除了唱歌、看电影、品茶、读书之外还有好去处吗？这时打街机绝对是好主意，而且街机的乐趣可是很多样化的呢！可以两人同乐，又可以满足个人表演欲，还能露一手功夫让女朋友尖叫，像这么好的去处没几个吧，如果是对街机陌生的读者也不要紧，接下来立刻介绍你最新最HOT的游戏，而且还有简易的说明哦！

## 1 源起

在很久以前，有个美国人觉得每天待在酒吧里除了喝酒之外没有什么好的休闲活动可以打发时间，于是便开始自行制造一种简单的电子游戏，放在酒吧里供人游玩。“两支乒乓球拍浮在空中，一颗按钮控制挥拍的动作，只需要将对手打过来的球打回去如此的简单”。后来这个IDEA被美国的大公司发觉，便开始研发出许多类型的游戏，但是几乎都是发行在个人电脑上。在当时拥有个人电脑的人是非常的少，所以销售的成绩也很差，于是就出现了所谓的“街机”。

早期的街机非常的无聊（当然是跟现在相比而言），最早大流行的就是“太空侵略者”。这是一款最最最典型的射击游戏，操作一架战斗机，然后一架一架地将敌机击落，也可以说是后来的经典名作“小蜜蜂”的前身。只是小蜜蜂加入了“敌机有强弱之分”的要素，然后以强敌机的多寡来调整难度，以避免出现像早期游戏关卡一直重复循环，耐玩性大大提升。

## 2 发展

时光飞逝，街机的成长速度也以倍速在计算，短短二、三十年的时间就演变到各种声光效果俱佳的游戏，在世界各地供各位玩家享用。不论是如何梦幻的题材，游戏公司总是能够让它成为一个游戏，创造出一个又一个的电玩高峰，让玩家体验幻想般的娱乐。在电玩迷的眼中，街机一向是电玩界中的时髦象征，使用最新科技、最接近真实、最高价位……最后便开始出现所谓的“体感机”。

体感机指的是以模仿各种形态的运动，或者是幻想的题材，让玩家享受身临其境的特殊机种，也是一般人最能接受的游戏，因为除了浅显易懂之外还更容易溶入剧情之中。所以在这三期杂志中便分各类型以连载的方式向各位读者介绍较新和较流行的各类体感游戏。

## 竞速篇

**KEYWORD SPEED 以速度来决胜负**

一般来说，在街机厅最常看到的游戏就属于赛车了。不论是什么样的店，多少都会放上一两台赛车游戏让玩家玩，而竞速游戏也已经有多元化的趋势，不再只有赛车类型一支独秀，现在不乏有赛马、划船、脚踏车……等新形态的游戏。

### 1 Daytona USA2（雷特娜赛车2）

| | |
|---|---|
| 厂商 | SEGA |
| 评价 | ★★★★★★★★ |
| 上手难度 | 中 |

著名的雷特娜赛车相信不少玩家都知道吧，可是2代却是等了很久才出现，不但画面精美度大幅提升，就连操作的难度都提高不少，有时只要一个不小心，车子就会360度大回转个好几圈。

这代同样是提供三种跑道，分别是初级、中级、高级。而排挡则是四段，不过建议赛车游戏的新手用自动排挡（AT）就好了，减速就踩煞车。跟其他车子擦撞的话，会造成自己车子的损害，这样速度会下降哦，要尽可能避免。

> **评语**
> 很单纯的赛车GAME，只是要高速飚的话，玩这台是很好的选择。其实各家的赛车各有各的优点，但是这台却是最适合新玩家上手的，一方面可以享受漂亮的背景，还可以享受高速度的甩尾，很不错吧。

【图：Daytona USA2 街机实物照片及游戏画面。】

### 2 Crazy Taxi（疯狂出租车）

| | |
|---|---|
| 厂商 | SEGA |
| 评价 | ★★★★★★★ |
| 上手难度 | 中 |

趣味型的赛车GAME，你扮演一位出租车司机（有四个角色可选），看看在一定时间内能载多少位乘客，不过乐趣就在于我们这位司机为了快速到达目的地，可谓是不择手段，逆向行驶是小意思，还有从公园、机场正中央冲过去的场面。另外一方面，在此游戏里的这个城市可是非常完整的哦，有兴趣的话不妨整个城市跑一圈，别有一番趣味。

操作只有一个方向盘，左边有排挡控制前进和后退，下面的踏板左边是煞车，右边是油门。游戏的方法是先载乘客，路上一个个被圆圈包住的就是了。再来就跟着绿色指标前进，到了指定地点将客人放下就算是完成一次行程，如此的反复行程，就可以增加游戏时间，不然画面上方的时间一到，游戏就宣告结束。

> **评语**
> 疯狂出租车是很好玩的游戏，除了题材趣味之外，还有很多爆笑的镜头，比如海底也有乘客之类的，还有乘客来不及赶到目的地时还会骂司机呢。

【图：Crazy Taxi 街机实物照片及游戏画面。】

### 3 Dunhill Bikers（登喜路脚踏车赛）

| | |
|---|---|
| 厂商 | NAMCO |
| 评价 | ★★★★★★★ |
| 上手难度 | 易 |

真正考验玩家体力的游戏恐怕就非此款游戏莫属了，因为你必须“真的”一直踩脚踏车不踩就太奇怪了吧。别担心，说是消耗体力，其实还不至于让你精疲力尽。但是在上高坡时会比较难踩，下坡时也可以省点力气，是很真实的设计。至于操作说明上其实也没有什么特别需要说明的，只不过笔者建议在踩的时候不要坐在椅子上会比较好控制，不然在你便尽全力踩的时候，想要调整重心也会变得很不容易。

> **评语**
> 对平常就有在骑脚踏车的人来说，玩这个游戏就像本来一样简单。可惜有些朋友是平时只顾玩游戏，身体因缺之锻炼而十分虚弱，玩起来是十分吃力。所以大家在玩游戏的时候也要注意身体健康的保护哦。

【图：Dunhill Bikers 脚踏车型街机实物照片，玩家骑在上面操作。“我踩我踩我踩踩踩！”】

### 4 Sega Rally 2（世嘉拉力2）

| | |
|---|---|
| 厂商 | SEGA |
| 评价 | ★★★★★★★★ |
| 上手难度 | 中上 |

什么车种最能够经得起各种路面的考验？那一定要问Rally赛的参加者，因为这里所有的车子对付平地、沙地、雪地、雨天通通没问题。Sega Rally 2里面拥有目前世界Rally赛中的各种著名赛车，让你可以充分地感受每架车子之间的优劣差异。这架赛车游戏跟一般的并没有什么不同，但是却多了一根“手煞车”（风林这个自称“解放司机”的东东居然以为手煞是MT（手动档），真可爱……），就在座位的右边而已，它可以用来甩尾过弯道，这在Rally赛中是非常简单的事，只要方向盘打到底，立刻就会出现一个漂亮的甩尾，练都不需练。

> **评语**
> 车子特殊的移动画吸引人的，毕竟游戏使用的是世界赛中实在的车子。光是看到这些赛车就会觉得能够开付这些赛圆是一件极不简单的事。

【图：Sega Rally 2 双人联机街机实物照片。】

> **游戏厅小常识 1 禁烟篇**
>
> 一般来说，游戏厅给人不好的印象就是烟雾弥漫的地方，不管你有没有抽烟，只要一进去游戏厅，出来后一定满身烟味。而现在大多数的游戏场也都有禁烟，所以各位烟友们，在玩GAME的时候，也能够发挥一下公德心，要抽烟就到吸烟区去。让不吸二手烟的玩家们有个好的游戏环境。
>
> **本店全面禁止吸烟**
>
> 在密闭式的场所抽烟，不仅会让空气变糟，也会影响到不吸烟的玩家。
