# 火炎纹章 系列小议

## 火炎纹章·暗黑龙与光之剑

| | |
|---|---|
| 机种 | FC |
| 发售日 | 1990.4.20 |
| 容量 | 2M+64K |

1990年，当时在任天堂旗下工作的加贺昭三作出了一个大胆的构思，他打算把战棋SLG与RPG的成长要素和冒险故事有机地结合起来，于是史上第一部战棋RPG——火炎纹章·暗黑龙与光之剑诞生了。作为系列的开山之作，本作在多方面为后续作品奠定了坚实的基础。虽然初代作品在今天看来无论画面还是系统都显得比较简陋，但在那个年代这款游戏无疑给了玩家们一个全新的概念。

【图：FC版暗黑龙与光之剑游戏画面截图。】

## 火炎纹章外传

| | |
|---|---|
| 机种 | FC |
| 发售日 | 1992.3.14 |
| 容量 | 2M+64K |

系列的第二作，也是系列中最为独特的一作。本作一改初代纯战棋的模式，加入了大量RPG的要素：可以在城市中自由行走、与NPC对话、在迷宫中探索等等。虽然这些变化使得游戏的战棋感有所降低，但也为系列增添了不少新鲜感。本作还首次引入了魔法消耗HP的设定，这也成为之后部分作品沿用的系统。

【图：FC版火炎纹章外传游戏画面截图。】

## 火炎纹章·纹章之谜

| | |
|---|---|
| 机种 | SFC |
| 发售日 | 1994.1.21 |
| 容量 | 24M+64K |

系列的第三作，也是系列在16位机上的首次亮相。本作分为两部分：第一部是初代“暗黑龙与光之剑”的完全重制版，第二部则是全新的续篇故事。画面和音乐较FC版有了质的飞跃，系统也更加完善。本作在日本的销量超过了77万套，是火炎纹章系列中销量最高的一作，也使得这个系列在SFC时代达到了巅峰。

【图：SFC版纹章之谜游戏画面截图。】

## 火炎纹章·圣战之系谱

| | |
|---|---|
| 机种 | SFC |
| 发售日 | 1996.5.14 |
| 容量 | 32M |

系列第四作，也被认为是系列中剧情最为出色的一部。本作的故事跨越了两个世代，前半部分的主角西格鲁特和后半部分的主角赛利斯（西格鲁特之子）分别在不同的时代为正义而战。本作首次引入了“恋爱系统”和“继承系统”，使得角色培养的自由度大大提升。宏大的剧情、史诗般的音乐以及创新的系统使得本作成为很多火纹迷心目中的最高杰作。

【图：SFC版圣战之系谱游戏画面截图。】

## 火炎纹章·阿卡尼亚战记

| | |
|---|---|
| 机种 | SFC（卫星广播配信） |
| 发售日 | 1997.9.28 |
| 容量 | — |

系列的外传性质作品，通过任天堂的卫星广播系统Satellaview配信。本作以初代和第三作之间的故事为背景，讲述了阿卡尼亚大陆在暗黑战争之间发生的一些小故事。由于是通过卫星广播发行，加上配信时间有限，使得本作成为了系列中最为稀有的作品之一。

## 火炎纹章·托拉基亚776

| | |
|---|---|
| 机种 | SFC |
| 发售日 | 1999.9.1 |
| 容量 | 32M |

系列第五作，以“圣战之系谱”第一部和第二部之间的时间为背景，讲述了李夫王子在托拉基亚半岛的战斗故事。本作是系列中难度最高的一部作品，各种刁钻的关卡设计和严苛的胜利条件让无数玩家铩羽而归。但也正是这种高难度使得本作在核心玩家中获得了极高的评价。本作也是SFC上最后发售的火炎纹章作品。

【图：SFC版托拉基亚776游戏画面截图。】

## 纹章将由谁传下去？

在加贺昭三离开任天堂之后，曾有消息称他将制作一款名为“EMBLEM SAGA”的新作，但因与任天堂的商标纠纷而不得不更名。尽管加贺昭三的离去令无数火纹迷感到遗憾，但火炎纹章这个品牌依然留在了任天堂手中。

而即将在GBA上推出的新作火炎纹章，将成为系列的全新开始。掌机平台的选择似乎也暗示着任天堂希望让更多的新玩家接触到这个系列。对于老火纹迷来说，最关心的莫过于没有了加贺昭三的火炎纹章是否还能保持系列一贯的高水准。让我们拭目以待吧。
