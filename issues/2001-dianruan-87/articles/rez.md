# REZ

**责编XTT**

【图：REZ logo，大字体设计】

| DC/PS2 | UGA/水口哲也 | 类型：STG |
|--------|----------|--------|
|        | 发售日：2001年秋季预定 |        |

SEGA以REZ来加入PS的第一款游戏，其突然态势受到各方瞩目。关于由声音和影像构成、具有完全新颖游戏性的本作，制作人自己有激烈的发言！

## 启发您未知的感官反应！由声音和光线交织而成的动态STG！！

●由于中国大陆已经成为全球电脑显象管制造业的中心，日立、乐芝、松下全面关闭日本本土和东南亚的CRT制造厂。其中日立转型为LCD、TFT制造商。受全球IT景气低迷的影响，在半导体芯片业，日立、NEC遭到创创——日立仅此一项的亏损额即达1000亿日元以上（遑再其他领域的冲击，集团全体会计收支从2800亿日元盈余降降至0日元——全球层员达30万人的日本最大的电器/电子产品制造商，2001财年，白玩！），NEC则亏损约数百亿日元。索尼本年度赤字损利下降90%。遂首买苦250亿美元并购康柏(合并后的员工数为14余万)。正是之前两家玩合员员的必然结果。要票，PC市场已经发生什么改了，大家都转到服务器基端高端去了，如日立和SUN结盟，慧普和COMPAQ再进发，就是为了打击IBM。

←大空（另一位是佐木健。一世喜拉力制大作人

■并不是追求真实感而是回到原点

“最初开始有'Rez'想法至少是在3年前吧（当初是以'K-Project'来代称），不过当时所考虑的，则是'游戏不一定要真实才会有趣'的想法。

最近的游戏，处倾向另一种朝向，那就是包含影像和音乐的所有要素，并且叫着真实感的单方向前进。我之前制作过好几款RAC赛车，今后可能画面会渐渐的真实，但同时，我也感到玩家会不会因更加重视真实性，而放弃了乐趣呢？每每一想到这个就觉得恐怖。就从这开始，即使进行时代的潮流，也并非要打场争争不可的想法就冒了出来。结果就想做出和现在的游戏方针完全相反的事物嗯。因此，同我为什么想作'Rez'？这是这个时代没有的游戏，而且实际上玩家们也在期待这样的游戏是吗？其实我也有这样想法的说。

明显的是，现在的游戏让人有以往那种'心动'的感觉，实在是意来意薄弱了。那么，这个心动感的源头是什么呢？至少可以确定的是，并非是'真实的图像'。就我所发现的，则是在极度简单且更有趣的游戏性这一方面。”

■“THIS IS REZ”1，基本上是3D-STG，但……

本作基本上是瞄准一个接一个出现的敌人并同时将之破坏。但是，攻击时发生的音响和光线的效果，会和背景流动的过场音乐相结合，而衍生出充满声音和色彩的强特世界。声音和光线的演出，就这样成为游戏性的核心。

■“Rez”操纵光线和声音将唤醒你官能反应的STG

“采用STG的原因，总之就是不必复杂地考虑，放松去玩就行。我想在我们的年代很多人玩过'铁板阵'（NAMCO/'82年），当时也吸引女性玩家的游戏。和以往相较下，现在的STG数量变少了，而我有在思考这是怎么一回事呢。'果然是太难了'之类吧。但是另一边'不能作得太难'这点，也许是游戏业界创造出的幻想也说不定。有如此一般的想法，认为STG已经到了无法再前进的地步，这是不是太过轻率的想法呢？

刚好在那个时候，碰巧在瑞士目睹了40万名年轻人参加的音乐盛会。高达40万人，配合营宫和舞美拼命舞动的光景实在是令人惊异。而且呢，他们对照明和光线也非常有用。当我看到这些和音乐相配合一起舞动的时候，才发现这不是和自己思考的游戏相符合吗？要是把自己看作玩家，而可以操作这么棒音乐和光线，说不定心情会变得很好呢！试想，这就是日本的祭典中配合着看和太鼓的节奏，而大家高与地手舞足蹈的原因一样。若是能将这种像是'群件感'的东西，而做成游戏的话那不是很棒吗！”

■玩家与生俱来的节奏感透过“Rez”而持续觉醒

“我们常说没有节奏感这回事，但每个人一定拥有自己独特的节奏感觉。就像有人说话快，有人慢吞吞说话一样。将这种自己与生俱来的节奏感自然地引出，也是这次的主题。

我觉得以往的音乐游戏是'强制'的。在这个节奏节拍某个音响起的话就算失误，就是这种感觉吧？当然也是有它的乐趣啦，不过'Rez'并没有强制玩家，可以照你喜欢的方式去玩。因为这是用自己的节奏感打倒敌人，制造出各种声音的游戏。

我想有很多人会认为自己没有节奏感吧，可是就是这样子才希望玩家去玩。以STG来说也是很稳的，因此就先别考虑节奏感来试玩看吧。不过只要持续在新手上手之中，你也会实际发现'我竟然也有这样的节奏感啊'。我想透过'Rez'，可以让人与生俱来的节奏感觉醒，或是清楚地认识自己的节奏感涌现的感觉”

**“关于Rez的魅力那真的很难说出来。总之只有说请各位玩家去玩去感觉吧。前些日子（6月27日）的'PlayStation2 Party'的舞台上，曾举行'Rez'的DEMO PLAY，不过脑中完全一片空白感觉还真的不错呢，宛如自己变成DJ一样的气氛。要当DJ和VJ时，若没有特别的技术和专用机器是不成的，不过'Rez'为了要让心情变得更好，说不定也会成为让自己变成像是DJ和VJ的'装置'吧。”**

■“THIS IS REZ”2，在谁都能享受的简单操作

按着按钮，同时用类比方向键移动游标瞄准敌人。一放开按钮，雷射就会射向敌人（也有炸弹）。操作方法极为简单，可以尝到STG独有那种射击的爽快感。收集特定道具提升自己角色能力的要素也存在呢。

■只可意会无法言传这就是“Rez”的魅力

在“Rez”这款作品上利用影像和声音并以新游戏方式呈现出来，我有这样的自信“THIS IS REZ”3，只属于每个人的“Rez”诞生了

即使拿打倒敌人的时机这点来说，依玩家的不同当然也会千差万别。当然，将复数敌人起脚准击落的场合，和个别击落的场合，声音和光线的发生方式也会不一样。要以哪种风格破坏敌人呢？还有要创造何种声响和视讯呢？全都看玩家的了。

“THIS IS REZ”4，崭新的知觉之门即将打开

随着舞台的前进，伴随BGM的节奏加快，敌人的数量也会增加。因此，发生的音响和光线也会变得更激烈，声音和光线会变成洪水般淹玩家给卷进去，这种感觉新奇刺激，相信一定能充分体验到以往游戏绝对没有的快感。以声音和光线释放出来“将玩家吸引进去”，这就是“Rez”。
