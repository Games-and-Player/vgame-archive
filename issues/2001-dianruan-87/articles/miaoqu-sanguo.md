# 妙趣横生 如此有趣的三国志

在编辑部中，似乎对三国志感兴趣的人很多，不论从前一段时间中午评书的收听情况还是游戏的多种版本的PLAY情况都证明三国志的人气在编辑部中是居高不下的……

## 很久以前、中国被分成三个国家时的故事

三国志是陈寿所作的史书，记录发生在中国三国时代的历史。大家所喜欢的小说《三国演义》则是罗贯中按照三国志所作的历史小说。我们平时说的三国志其实是《三国演义》，这部小说讲的是主人公刘备征战一生建立蜀国，并为天下统一而奋斗的故事。但做为中国的本土故事，也许我们比起日本玩家更加了解许多，随便找个人就能说出许多三国的典故……

【图：游戏《决战》的战争场面截图，火焰弥漫的战场。】

“决战”是以《三国演义》为基础，并增加许多幻想要素的作品。

> **被称为一个时代的故事**
> 三国志是指公元184年到公元263年中国汉王朝解体后诸国纷争的时代。与此同时代的日本邪马台国的卑弥呼也非常活跃。

【图：三国时代地图，标注魏、蜀、吴三国版图位置。魏在北方，蜀在西南，吴在东南。】

## 为什么如此有趣呢？——三国志的无穷魅力

### 1、拥有魅力十足的人物

下面的图是桃园结义。刘备、关羽、张飞三人不求同年同月同日生，但求同年同月同日死的誓言下一同为统一天下而奋斗。而作为刘备的对手登场的曹操与年轻的吴王孙权、天才军师孔明等等具有魅力的角色纷纷登场，是三国志最大的特色。另外如云的猛将和遍布的智将军师个个形象丰满，颇具特色，将三个不同国度的风情尽情展现。

### 2、权利阴谋相交织的政治剧

打探敌人的动向、收集敌国的情报、扰乱敌国的政局。孔明的“天下三分之计”等超有名的策略、诈降的“埋伏之计”、绝世美女貂禅的“连环计”这一切都是为了将敌国打倒，可以说三国志所描述的是一场血雨腥风的政治斗争，其实是中国社会的一个缩影，尔虞我诈，瞒天过海，破釜沉舟等等不论是计策还是人与人之间的微妙关系都得到充分的体现……

### 3、军师的智谋、猛将的武勋

三国志中有很多将帅登场，其中有天下无敌的勇者如吕布。他所骑的赤兔马据说一天能走千里（约400KM）这样的马简直可以和现在的汽车相比了，后来归仁义的象征关公所有。而孔明与司马懿、周瑜这样的名军师的对决也是非常有意思的、斗智斗勇的同时令天下人看足一场戏。不由想起今年高考的作文状元那篇《赤兔之死》的文言文作品……

# 其他人气三国游戏

以三国为舞台的游戏非常多，而且不仅是SLG类型，ACT类型的作品也是很多的，而在PC方面，以“三国志”人物为蓝本的作品中有许多是“大富翁”类型的。

事实上以三国志为舞台的游戏真是数不胜数，这里所介绍的是四部作品是在各个领域和各个时代有代表性的游戏。前2款是经典的动作类型，而后2款则是SLG的超级经典。其余的游戏也不乏有优秀的作品，但篇幅有限，恕无法在此一一介绍。

## 真·三国无双

| | |
|---|---|
| 机种 | PS2 |
| 类型 | 动作 |
| 厂商 | KOEI |

在巨大的战场上自由驰骋，将敌人打倒的爽快游戏。虽然路线简单，但是在百万军中纵横驰骋是以前任何游戏无法作到的，是最初发挥PS2基本性能的作品。作为S·P超喜欢的动作游戏，这里向大家郑重推荐。

【图：真·三国无双游戏截图，战场画面。】

> **作为敌对势力也可使用**
> 在FREEMODE中只要满足特定条件，就可以自由选择战场，和所谓的正义势力战斗。可以将张飞与曹操联手与刘备作战，体验与正常故事模式大相径庭的场面，不过特定事件在此模式中是看不见的。

## 吞食天地II 赤壁之战

| | |
|---|---|
| 机种 | PS、SS |
| 类型 | 动作 |
| 厂商 | CAPCOM |

街机版的移植作品，表现刘备建立蜀国的历程，可以选择关羽、张飞、赵云、黄忠、魏延五人作战，在曹军中冲杀，以击倒每个区域BOSS为目的，而且还穿插许多历史事件。此游戏推出近5年仍然人气不减，是编辑部里清版动作游戏的最爱，特别是用街机模拟器在PC上玩耍，更是乐趣多多。想起从前在街机厅中三人共同奋战杀敌的情形，真感动，这款数年前的名作至今仍是人气不败。

【图：吞食天地II游戏截图。】

## 三国志VII

| | |
|---|---|
| 机种 | PS2 |
| 类型 | SLG |
| 厂商 | KOEI |

光荣系列集大成之作，此次可以扮演任何一位武将，通过不同的眼光来回顾三国历史。其中充满了RPG游戏探索的乐趣，而系统的更新，画面素质的更新也使玩家非常满意。尽管8代已经推出，但本作仍称得上是三国志系列的最强作。编辑部中的彩火和莱因都是此作的顶级Fans，特别是那个被大家称为“大象”的彩火经常整晚陶醉在三国的统一霸业中，而第二天因他个糊里八涂……

【图：三国志VII游戏截图，策略画面。】

## 霸王的大陆

| | |
|---|---|
| 机种 | PS |
| 类型 | SLG |
| 厂商 | NAMCO |

最早在FC上发售的三国模拟游戏，后来复刻到PS上，而霸王大陆是中国玩家最早接触的三国游戏，其良好的游戏性至今仍为人们津津乐道。记得《电软》创刊号时就刊载了它的攻略，很受大家欢迎哦。莱因已将FC和PS版一一打穿了，还口口声说“玩游戏太害人了……”其实他已经是游戏的重度受害者了。虽然不像彩火整日陶醉在三国中，但以欺负凤林，发乱声和憧憬高达为美……
