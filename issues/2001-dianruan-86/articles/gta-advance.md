# GTA赛车

**Grand Theft Auto Advance**

厂商：Rockstar Games / Destination Software
类型：赛车/动作
媒体：GBA ROM卡
发售日：2001年

【图：《GTA赛车》GBA游戏画面截图，展示俯视角的城市赛车场景】

## GBA上的GTA

GTA系列的名字出现在GBA平台上或许让很多人感到意外。这款《GTA赛车》是专为GBA平台设计的赛车游戏，采用了俯视角2D画面。

虽然它与PS2上备受瞩目的《GTA III》有着截然不同的游戏风格，但这款GBA上的GTA同样有着不错的可玩性。

### 游戏特点

游戏以俯视角展示城市赛道，玩家需要驾驶各种车辆在城市街道上竞速。游戏保留了GTA系列一贯的自由风格——虽然以赛车为主，但玩家在一定程度上可以自由探索城市。

【图：多幅GBA游戏画面截图，展示不同赛道和车辆】

### 操控手感

GBA的按键配置下，操控手感还算流畅。A键加速、B键刹车，L/R键用于特殊动作。在狭窄的城市街道上高速飙车需要精确的操控技巧。

### 赛道设计

游戏收录了多条城市赛道，包括：
- 商业区
- 工业区
- 港口区
- 住宅区

每条赛道都有各自的特色路况和捷径。
