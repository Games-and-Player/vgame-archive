## 8柄角色佩刀的特技输入方法以及修得情况一举公开！流浪剑士的决杀心法金针度人！！

《侍》的游戏概念非常简单，玩家控制一名日本武士完成两天的剧情，可在两天内玩家可以完全按照自己的意志去发展，自由度非常之高。例如与路上的人碰面可以灭杀之，也可以放其一码。如果击倒敌人，我们就可以拾到他们的武器，但是不同武器的特技和特技修得方法截然不同，下文我们将公开部分佩刀的特技情况。　文/组体给命　责编/PERFECT

本期我们将曝光8炳佩刀的全部特技，其已公开的内容又包括：

**特技名称(指令输入方法)一修得条件一备注。**

至于大家非常关心的格技修得条件请参见右侧表格，根据厂商提供的资料，修得条件大致分为8种，下文中我们用英文字母A至H代替。备注部分包含备注经验值等其他内容。

### 隐藏技修得条件

| 代号 | 条件 |
|---|---|
| A | 获得一定经验值自动习得 |
| B | 用基础技打倒敌人 |
| C | 用基础技打中浮在空中的敌人 |
| D | 用基础技打中摔倒在地的敌人 |
| E | 在HP100以下时使用基本技 |
| F | 遭到攻击时以1/16的概率悟得 |
| G | 破解敌人所使用的同一招数 |
| H | 倒地后连续10秒以上踢地移动，并且成功重新站起 |
