# 零~ZERO~

Game SOFTWARE 攻略人行道

要说目前最恐怖的游戏到底是什么？也许会有“生化”、“钟楼”、“寂静岭”多种答案，但如果你玩过了“零”后，一定会将其他答案全部抛在脑后。TECMO原“影牢”制作组的力作，将恐怖气氛酪足足了科。这部完全将日式恐怖发挥到极限的作品绝对值得喜欢挑战“心跳数字”的玩家一试。

## 初入门道基础先知——操作解惑

1、摄影家是这样练成地：当幽灵出现时，玩家将相机对准后相机就会自动蓄气，这样才可以引发相机封印幽灵的最大攻击力。而画面中央显示范围的时候封印幽灵的话也不会有很高的威力，而在幽灵即将对玩家发动攻击的一刹那，画面中央会显示出红圈，此时封印才可以达到最佳伤害值（100-120点）。

2、镜石的用途是：镜石只能在身上装备一块，作用是玩家体力为零后可以自动补充。因此一旦用完的话就快点找另一块带在身上吧！

3、相机的多种能力：当玩家封印了一个幽灵后就可以得到经验值，满足一定条件就可以为相机增加各种能力。除了基本的“范围”、“速度”以及“最大值”外，还有辅助机能和特殊机能可供选择。在此笔者只是尽量增加了基本的三项而已，感觉已经非常够用了（拍摄灵关键还是看玩家的操作是否迅速）。至于辅助机能和特殊机能碰，如果经验值充足的话就不妨试试。其中有几项的功能还是相当有用的。

4、胶卷的数量：胶卷数量是有限的，而且封印以灵的威力也各不相同。威力最低的十四式胶卷补充数量上限是30，一旦不足30张的话可以到记录点补充。利用此方法就不会发胶卷不足了。

编辑提示——所谓“刻石棋”：游戏中经常出现的移动门板上的刻石来打开机关的迷题，在这里被称为“刻石棋”。解开迷题的方法是按照模样的摆放，将四块刻石按照门板上标注的位置移动，而移动的次数也是有限制的，成功后再将取得的刻石安装好才可以通过机关。

编辑提示——面对鬼魂：根据风林打穿游戏数遍的经验，每个鬼魂都有明显的弱点，而且都有攻击的规律，只要掌握这些就不难对付了。另外，随着玩家手中相机能力的增强，到游戏的后半程基本上二、三下就可以封印鬼魂了。关键还是把握准确，避免失误，经验值不高就可不行喔。
