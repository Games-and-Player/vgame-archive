# 编辑手札

## 有点野心，十足赤金

《电软》转眼已经八年了，无论是人情还是应酬，免不了心中有一番感慨。古时候有“山中一日，世上千年”的说法。比之千年，八年不过是千分之八。对于山中“忽悠”的樵夫而言，则八年只相当于11.52分钟，还不到上一趟厕所（有厕所看书的癖嗜）或抽一支烟的工夫。

不过，做为尘世中的凡夫俗子，就没有那么洒脱了。说到八年，第一个联想就是抗战八年。另一个是前几天才看到的，中国足球改革至今也是整整八年。说长不长，说短不短。中国足球到现在还是神经兮兮的，怪力乱神之事不断，水清河晏之期无望。真是“革命尚未成功，同志仍需努力”。

这话对《电软》也说得着。

重回八年前《电软》创刊号的两个愿望做结束语：

“第一个有点野心，就是《电子游戏软件》要做大陆电子游戏杂志的龙头老大。”

“第二个十足赤金，就是要把《电子游戏软件》办成'闲关族的家'。佛前一柱香，愿梦想成真。”

“有点野心，十足赤金，”真是神来之笔的绝对儿，好！

**宇部**

【图：宇部栏目标题插图】

GC《生化》的销量虽然不如预测的好，不过超高的制作水准使从未深入玩过该系列的宇部欲罢不能。然而本月占据我大量时间的却还是PS2的《王国之心》，个人感觉这才是史克自超任时代结束以来最好的作品。虽然限于PS2的机能，画面还未达到特别圆满，但是其游戏整体的把握却相当到位。有迪斯尼元素加盟的简单有趣且轻松活泼的动作RPG，应该能让所有玩家满足。不知会不会移植给GC呢？只是偷闲重温了一把《东京巴士》（PS2版），当我驾驶着公交车穿梭在黄昏中僻静的郊区路段上，听着那舒缓悠扬的BGM，思绪早已飞到了N年前旅日的温馨时光里，四周弥漫着小镇所特有的清澈气息……
