# 血腥咆哮 3 BLOODY ROAR 3

无双报导 血腥咆哮3

| | |
|---|---|
| PS2 | 厂商：HUDSON　类型：3D-FTG |
| | 媒体：CD-ROM　发售日：2001年春 |

本作是由方向键和4个按键来控制。4个按键分别是为G（重度防御键）、P（拳击键）、K（脚踢键）、B（兽化攻击键）。当画面下方的兽化槽蓄满后，会出现“BEAST”的发亮提示，此时可利用兽化键令角色兽化。

另外还导入了“空中连续技”和“紧急回避”的新系统。

## 介绍全部的12位角色

### 雄儿

会兽化为狼。格斗方式属于拳击类，拥有快速的步伐与重击。

【图：雄儿人形和兽化形态截图】

↑兽化后的主角，此形态的功力会更加强大。

### 加铎

会兽化为狮子。虽然动作较慢，技巧较少，但攻击力却很惊人。

【图：加铎人形和兽化形态截图】

↑这个角色为初心者最适合使用。

### 升龙

会兽化为虎。虽然格斗的类型与雄儿相似，但使用的技巧不同。

【图：升龙人形和兽化形态截图】

### 艾莉丝

会兽化为兔子。拥有相当丰富的连续技，而且兽化后连续技会增加。

【图：艾莉丝人形和兽化形态截图】

↑兔子的样式，连续攻击力大幅增加。

### 爆龙

会兽化为鳄鼠。拥有如忍者一般的灵巧与可怕的必杀技。

【图：爆龙人形和兽化形态截图】

↑好不容易才找到了多种强力的必杀。

### 布吉曼

会兽化为变色龙。可利用自由伸缩的身体进行攻击，而且还会消失。

【图：布吉曼人形和兽化形态截图】

↑变不长的……利用隐身术来攻击。

### 马贝儿

兽化为豹。可利用丰富的中段技破坏对手的武术，接招技也很可怕。

【图：马贝儿人形和兽化形态截图】

### 席欧

兽化为一种类似外星人的东西。兽化后会发挥相当可怕的变力。

【图：席欧人形和兽化形态截图】

### 斯坦

会兽化为昆虫。拥有丰富的投掷技，动作虽慢但威力却很惊人。

【图：斯坦人形和兽化形态截图】

### 珈璃子

会兽化为半人半兽的状态。虽然攻击距离短，但是攻击速度却很快。

【图：珈璃子人形和兽化形态截图】

↑利用快速连打来给予对手连续攻击。

### 胧

使用心意六合拳。虽然会兽化为虎，是一位会使用丰富的连续技的角色。

【图：胧人形和兽化形态截图】

↑空中兽化后的双中段技。

### 珍妮

会兽化为蝙蝠。利用长鞭类武器，以华丽拳的技巧与对手展开格斗。

【图：珍妮人形和兽化形态截图】

↑蝙蝠的空中用兽化中必杀技大放异彩。
