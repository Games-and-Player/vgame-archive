# 决战 II 游戏流程详解

无双报导 决战 II

**让我们来看看详细的游戏流程吧！**

此作的故事与战斗是以关卡为单位来进行的，在这里我们就简单地解说一下每一关的基本构成以及游戏的流程吧。

## 关卡的流程

| 流程阶段 | 说明 |
|---|---|
| 关卡开始 | 前一关结了后的状况在此简要说明 |
| 政略 | 进行战略行动，听部下的献策，决定实行何种提案 |
| 军议 | 决定战斗的作战等，与战前导入的原创故事 |
| 戏剧 | 战前导入的原创故事“爱与战” |
| 军议 | 决定战斗的作战等，样差用部下的提提 |
| 战斗 | 与敌军直接战斗，这种状况下根据军议决定变化 |
| 战后处理 | 根据战斗后衍生的问题来处理的部分 |
| 向下一关进军 | |

## 政略

每一关开始第一件工作就是政略进行。当战斗告了一段落后，为了继续自军阵营长时间的作战与经营，必须在这里决定战略的行动与政策、武将启用、新武器开发等工作。

【图：政略画面截图，展示武将提案界面】

↑有时所属武将也会提出建议，可以由三个提案之中选择一个执行。

→政略的效果会影响很多地方：包括故事展开。

## 军议

政略工作结束，看完故事剧情之后，进入直接战斗前的就是军议的步骤了。像是决定进军路线，或是在哪里设置陷阱，战术运用决定等工作的设定。好的在这里把握作战策略的拟定吧！

↑军议和政略一样，也是由三项提案中选出一个来进行。

↑而根据选择的作战不同，所参加的部队不同，所参加的部队从战术到行军方法都有所变化，会发生的事件也会不一样。

## 战斗

战斗可以说是每一关最大的重头戏。武将与士兵们就依照在军议时所作的自动的进行动作。不过，虽然说是这么说，但可不是叫你放着不管了。随着战况适时给予新的指示，才是掌握胜利的关键。此外，强力的必杀技如妖术、战或强力的新兵器的运用也是重点。

### 战场上丰富多彩的兵器群

| 兵器 | 说明 |
|---|---|
| 迫击弩砲 | 野战时的兵器之一，可从阵型远处发出巨大的弩箭 |
| 猛虎砲 | 也是所谓野战兵器前面，攻城战时出阵它的大炮 |
| 木兽 | 战斗队伍会出现巨大的木制野兽 |
| 雷击車 | 战斗时方可用最大的强力兵器 |

【图：四种兵器的战斗画面截图】

拥有多种变化的作战方式：野战、水战、攻城战、防卫战等……

## 魏·吴猛将

### 夏候渊 魏

（配音：�的川裕彦）

相信曹操就是“准一把平定乱世的……”，因此在夏侯渊等人自立门前竖旗，不理他勤力，对曹操对击战斗的戏剧为力，作战可以说是曹操军的战斗达人。

### 夏候霸 魏

（配音：吉水孝宏）

夏侯渊的长子。和父亲一样，窝弓的本事都相当强，以冲锋前进的战术为目的而努力着。然而这也是他的一大缺点。原来他也是张飞军的盟友。本作中会出现头角的面。

### 甘宁 吴

（配音：大场真人）

本来是出没在长江重城的海盗，后来被孙权与闰相招，而成为吴的将领。之后立下许多战功，成为吴国的大将之一。由于是海贼出身，所以相当擅长水战。

**战无不胜浩浩荡荡**
