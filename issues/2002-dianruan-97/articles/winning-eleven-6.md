## 必须透彻理解球员的基本能力与特殊能力

每位选手的特点都是由25种基础能力和18种特殊能力构成。玩家在选择球员和阵型时务必仔细考察球员的特点，根据的球员的情况布置阵型，制定战术安排。真实、严谨的完成比赛，最大限度地发挥球员的特点，取得辉人战绩。

下表为球员能力的详细解说，相信会对诸位WE玩家有所帮助。

### 基本能力一览

| 名称 | 数值解说 |
|--|--|
| 奥芬斯（Offence） | 攻击能力，数值越高越适合进攻 |
| 迪芬斯（Defence） | 防守能力，数值越高越适合防守 |
| 波迪巴朗斯（Body Balance） | 平衡性，决定队员的对抗能力 |
| 斯塔米纳（Stamina） | 耐力，耐力下降到1/2后动速度和绝对速度都会降低 |
| 斯皮得（Speed） | 速度，队员的奔跑速度，与带球速度不同 |
| 加速力 | 加速度，球员启动速度，数值越高达到最高速度的时间越短 |
| 雷斯庞斯（Response） | 反映速度，数值越高球员对球的反映速度越快 |
| 运球精度 | 带球技术，数值高的队员不容易被抢断 |
| 运球速度 | 带球速度，数值高的队员带球速度接近无球奔跑速度 |
| 短传精度 | 短传精度，数值越高短传和横传的精度越高 |
| 短传速度 | 短传速度，数值越高短传速度越快，且不容易被抢断 |
| 长传精度 | 长传精度，数值越高长传精度越高 |
| 长传速度 | 长传速度，数值越高长传和传中的速度越快 |
| 射门精度 | 射门精度，数值越高射门命中率越高 |
| 射门力 | 射门力量，数值越高射门力量越大，球速越快 |
| 射门技巧 | 射门技巧，数值越高的球员可以完成高难度的射门动作 |
| 头球精度 | 头球精度，数值越高头球成功率越高 |
| 跳跃力 | 弹跳力，数值越高弹跳的能力越高 |
| 技巧 | 技巧，数值低的队员对球的反映速度慢 |
| 弧线球 | 弧线球，数值高的队员在任意球和角球的弧度大 |
| 攻击性 | 进攻的攻击性，如果是门将的话容易占位靠前 |
| 心理素质 | 精神力，数值高的队员在劣势和比分落后的时候依然正常发挥 |
| 安定度 | 稳定性，数值高的队员能在连续比赛中保持较高的竞技状态 |
| 任意球精度 | 任意球精度，数值越高压意球落点越准确 |
| 连携 | 配合能力，数值高的队员与同伴的配合默契 |

### 特殊能力一览

| 名称 | 数值解说 |
|--|--|
| 运球员 | CPU控制球员时，球员的奔跑积极性 |
| 支柱球员 | 前场拿球后等待同伴跟进，擅长传球助攻 |
| 抢位意识 | 门前的抢点意识，抢占有利面前的必备素质 |
| 飞出 | 虽然有越位的危险，但是能始终处于进攻的最前方 |
| 前锋 | 当同伴传球或传中时，能够有意识地冲到门前射门 |
| 司令塔 | 拥有该能力的球员持球的时候，同伴的双击意识自动上升 |
| 传球手 | 对最终一传有想划知，玩家操作该球员时向伴会插入禁区 |
| 两足假动作 | 拥有该能力球员带球时可以作出虚晃球将运动方向【注】 |
| PK射手 | 主罚点球的成功率高 |
| 1VS1射门 | 一对一面对门将时的射门成功率高 |
| 长距离射 | 比普通远长传的传球距离远 |
| 直接射门 | 第一时间传球或射门的成功率高，调整幅度小 |
| 外脚背 | 根据不同情况，可以用外脚背弹射踢球 |
| 人盯人 | 位置意识很强，盯人防守的能力出色 |
| DF铁壁 | 防守线上的领袖，后卫线整齐的成功率增高 |
| 任意球 | 门将可以发出弧度较低的门将球，快速发动进攻 |
| PK门将 | 门将的扑点球能力强 |
| 受伤倾向 | 能力值分为A、B、C三档，A为不易受伤；C为容易受伤 |

【注】当拥有该能力球员带球时，快速运动方向键（或摇杆）的斜上方向，队员的双脚会作出虚球的假动作，不过并不实用。

## 队员状态对于能力值的影响

队员在场上的表现与自身的状态息息相关，正因为如此，球星们状态不佳的时候人员顶替，采用何种阵型是困扰玩家的难题。把球员的状态对各项数值的影响进行全面解析。由于每项数值的变化率各不相同，希望大家在决定出场队员阵容和战术时一定要加以参考。
