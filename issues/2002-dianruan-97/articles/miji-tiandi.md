# 秘技天地

在你心中什么才是秘技的“秘身”？什么才可称为秘技？其实很简单。只要是自己的独家心法，在这里就是OK！

当大家拿到这期杂志的时候，风林在7月期待的4款游戏都一一登告了，截稿后当然是进入紧张的“备战”状态。不知道大家怎么来排自己的暑假呢？

## GC 战斗封神

游戏推荐度：7　秘技实用度：6

### ●角色的体力与仙力数值初期化

在游戏开始时选择“はじめから”，欣赏完动画后（不要跳过），在角色选择画面同时按住L、R和START键，选择想初期化的角色。等到出现动画的时候再将三个键放开即可。

——战斗 MUMU

### ●这个世界清净了（笑）……

进入OPTION中的PASSWORD中，在打字机上输入以下密码后，按下SEND。成功的话会有绿灯闪烁。再进入BONUS下将要使用的密码开启即可。

| 密码 | 效果 |
|---|---|
| 输入WHATYOUGET | 敌人一击毙杀 |
| 输入BOING | 手榴弹会在地上弹跳 |
| 输入LONGSHOT | 所有武器冒具有狙击功能 |
| 输入GLASSJAW | 打中敌人头部才会死 |
| 输入URTHEMAN | 全被镀一击毙杀 |
| 输入WHERERU | 敌人隐形只看得到头盔，自的能杀得尽 |
| 输入BULLETZAP | 敌入子弹传不了你，但近身攻击与迫变除外 |
| 输入HABRDASHR | 人人带着武装款样的帽子，杀死后可变换 |
| 输入ORANGUTAN | 直接开启第二关 |
| 输入BABOON | 直接开启第三关 |
| 输入LEMUR | 直接开启第五关 |
| 输入GORILLA | 直接进入决战 |

——对该游戏感到很头晕的一代铁男 MUMU

## PS2 荣誉勋章·前线

游戏推荐度：9　秘技实用度：8

### ●前线无敌～

在游戏中按下开始键暂停游戏，接着顺序输入□、L1、○、R1、△、L2、Select、R2即可进入无敌状态，任敌方火力多么凶猛，也无所畏惧了。

### ●子弹无限～

在游戏中按下开始键暂停游戏，接着顺序输入○、L2、□、L1、Select、R2、△、Select即可使子弹无限，再也不必节省弹药了。

## GBA 恶魔城～白夜的协奏曲

游戏推荐度：8　秘技实用度：8

### ●隐藏角色

通关一次后，选“NEW GAME”并输入“MAXIA”作为名字，便可使用马克西姆来进行游戏。马克西姆类似“月下夜想曲”的西蒙，不能升级，不能使用道具和装备，绝招“分身攻击”（←→↓↑＋B）威力极大。马克西姆会三段跳和翻滚！空中↓＋A灵活运用可去任何地方。

### ●GOOD ENDING 达成方法

集齐所有的魔导器后，去到里恶魔城中部，地上有一扇门的地方，装备上マクシームのうでわ进去，打倒马克西姆后，真正的最终BOSS ドラキュラ，便会出现，打倒他即达成GOOD ENDING。

——恶魔マスター

## GBA 胜利十一人A

游戏推荐度：7　秘技实用度：6

### ●隐藏模式

首先开机，按住L、R、A、B和选择键，等到开场画面后，出现标题时再按暂停键。成功的话出现TEST MODE。里面有音效、效果音、语言等选项。

### ●隐藏球队

首先开机，按住L、R、A、B和选择键，等到开场画面出，出现标题后即可按暂停键（时间及难度任意）慢机，就会出现两支明星球队。

——北京

## PS 三国志7

游戏推荐度：8　秘技实用度：8

### ●隐藏模式

同时按下L1、L2、R1、R2与SELECT和START键，就会出现隐藏模式，此时屏幕出现三行字。第一行是追加扮演武将，上限8人。第二行是解除扮演武将，让其被电脑控制。第三行是追回游戏，在KOEI的三国志与也同样拥有这种模式，用来临时更变扮演武将所用。

### ●圣兽取得法

首先应提高自己名声排在奇数年代的南斗、北斗前十名，此时如果自己所扮演武将拥有十种特技，五种装备时上天就会授予圣兽特技。拥有特技后去拜访特技会无双与一骑的武装就会有机会外

出狩猎，如果遇到老虎的话就击败它，此时就有机会取得圣兽。也许一次不行要两次，反正多试几次（别人拜访自己时狩猎也可）就会简单取得圣兽。作战中使用需计策点100，召唤后这圣兽就会消失，需重新狩猎来获得它。

——安徽 王宇

1、快速升到LV99，不是攻略上讲的LV70，用了可带入道具的迷宫，在银炼房迷宫中有到的草 の杖；作用是将踩在地上的草脚，发挥到敌人身上就发挥到自己身上，利用敌人的魔法反弹。只要趁在祝福石的てんしのたわ就はわせ草上使用此两和杖！别装备ヤマビコのたて！LV升的速度会快得让你看不过来！
