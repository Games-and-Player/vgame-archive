# 游戏新作情报

【图】游戏新作情报栏目标题装饰画，卡通猫形角色

MASCAR现在已经蓄势待发，等待着年底一波接一波的大作。不过自己最期待的还是在12月12日发售的《WINNING ELEVEN 6 FINAL EVOLUTION》，入手后又可以和编辑部里的足球狂人们疯狂对战了，也能让我忘掉一件最近很苦恼的事。真是做梦都期待的大作。

### 格斗超人

| 类型：FTG | 价格：6800日元 |
| 其他：—— | |

IGN这个不知名的厂商发布了一款3D格斗游戏，从画面上看非常华丽，决不亚于《死或生3》，但是一个优秀的格斗游戏可不是光靠画面好看就能获得成功的。最重要的是格斗时的感觉，在当今VF、铁拳、DOA一统天下的局面下，我们非常期待能有一些新生势力的加入，就像《GUILTY GEAR》那样，为我们带来一些新鲜的感觉。
