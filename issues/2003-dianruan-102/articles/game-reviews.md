## PS2 真魂斗罗

| | |
|---|---|
| 厂商：KONAMI | 类型：ACT |
| 媒体：DVD-ROM | |

看着《真魂斗罗》，明人的双眼喷出了两行血泪，毕竟太感动了。对于中国的游戏人而言，她的意义不亚于1997年香港回归祖国！

游戏整体回归了MD版《魂斗罗》的感觉，但是取消了“吃枪”的系统，取而代之的是固定配备的三种效果各异的兵器，并且可以进行蓄力攻击，表面看似鸡助系统的“攻击方向固定”以及“角色位置固定”的作用在对BOSS战中体现无疑。就本作的整体难度而言实在不能令人满意，尤其是那几个BOSS，远看是BC，近看是BC，怎么看都是BC，原来就是BC……说起BOSS，这次设计BOSS造型的家伙真该拖出去毙了，太没品位了！

游戏的画面制作得颇细腻，美中不足的是1P与2P角色的颜色过于相近，实在是不太好区分。音乐、音效方面基本上都是前几作中的音乐加以重新制作，N年之后再次听到那些熟悉的BGM……明人的双眼再次流出了两行感动的血泪……

记得第一次进行游戏的时候，光顾着感动了，莫名其妙的就挂掉了，虽然起先很懊悔，但是看到主角翘辫子的姿势还是与FC同时期的时候，明人的双眼……明人贫血身亡……

——铁轩合作组：星川明人

## GBA 世界传说·换装迷宫2

| | |
|---|---|
| 厂商：NAMCO | 类型：RPG |
| 媒体：卡带 | |

【图】世界传说·换装迷宫2 游戏截图和标题画面

相信许多玩家都是从GBC一路走来的，而该游戏第一作在GBC上就好评如潮，现在第二作登陆GBA，而且进化幅度很大，确实让人感动不已！看到游戏的标题，就明白了本游戏的最大卖点便是“换装”了，而游戏中的内容也的确没让人失望，多达200种的服装让人眼花缭乱，配合以不同服装，又有不同的换装动作，相当细致的设计。穿上不同的服装，主人公的职业性质也会相应的发生改变，剑士、法师等等。

游戏中人物众多，而且都是《幻想》、《宿命》、《永恒》中的人气角色，应该说“演员”阵容强大，众多明星联袂“出演”，光凭这一点，就可以吸引不少玩家了。与制作相比，游戏的各方面都得到了大幅度的强化，其中让人觉得奇的是战斗还是可以手动控制，更令人感动的是，在每次出招时，都有人物配音，回想一下，GBA游戏中有语音的还真为数不多，而本作却加入如此丰富的语音，真是令人热血澎湃。

游戏中还会有委托事件发生，即所谓的“任务”，每次完成任务，主人公一行人都会得到一定的金钱作为报酬。

这是一款不怕的作品，也是本系列在GBA上的第一个作品，无论如何，NAMCO的这个“起点”算是十分出色，希望它可以保持下去。推荐这部作品给大家，一定要试一试，不然你一定会后悔错失佳作的。

——吉林·沈培峰

## PS2 摩尔摩斯骑士团

| | |
|---|---|
| 厂商：NAMCO | 类型：RPG |
| 媒体：DVD-ROM | |

本作是我购入PS2的第一款竟版游戏。我体会到了百分之百的传统组队式RPG情怀和百分之百的创新战斗系统。前些时间有个爱乱花钱按不说80代就是他游戏生涯的终结。此话对我来说虽然不存在，但也多少感觉到了大部分3DRPG给的好感太。我个人始终认为最好的RPG必须是传统的2D组队画面风格。所以本作成了我的救命稻草（笑）。

从一个边境村落的见习骑士开始，最终成为王国的骑兵队长。这其间主人公的戏份很少，几乎没出过什么风头。和其他两个配角的活跃相比，甚至有些沉默。但似乎就是这种沉默更令人感动难忘。冒险全程围绕七颗封印魔物的魔法之石展开，在此期间通过剧情表现出团结、亲情、友情、宿命、勇气等各种要素。另外插曲也是其中有力强调之一，但设计的这一点等弦张做作感觉，这完全是建立在优秀的剧情之上。

如果说本作的剧情是完全传统的代表，那么战斗系统则会给你完全的前卫感了。你见过不需要练级的RPG吗？本作实现了。很考3张吧？一点都不。你又见过没有商店的RPG吗？本作就不用再买任何东西。怪吧？有趣。本作的主标题为七勇士，言外之意就是战斗组里中始终的七人，分前中后三排。战斗中是否能取胜就完全要靠战略性的人员部署了。而这就是本作最大的精华所在了。如今本作的续集已经提上了发售日程，反正我是要必玩（笑）。

——南昌·严俊
