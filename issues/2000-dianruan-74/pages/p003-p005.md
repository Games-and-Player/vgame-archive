# 格斗之王2000

**THE KING OF FIGHTERS 2000**

NG、AC　厂商：SNK　类型：格斗FTG　媒体：机台、卡带　发售日：2000年夏

## 今夏也用“格斗之王2000”来决胜负！

【图】左上方为KOF2000 Logo，右上方为角色选择画面截图，可见LIN、DUCK、BAO、TAKUMA、RAMON、VANESSA等角色名

“格斗之王”系列作品向来以团体对战方式著称，是人气极旺的格斗游戏，而此系列的第7部作品也终于问世了！

“格斗之王2000”是前作“99格斗之王”的“奈斯滋篇”的续篇，主角K'与谜一般的组织展开了战斗的新局面。今年的“格斗之王”有8个队伍再加上2人，一共是34人参战，除了有5名新角色加入外，游戏的系统方面也作了部分改变。

### 格斗之王2000 序章

自从发现有如谜一般的秘密结社“奈斯滋”的存在至今，也已经过了一段时间了。然而，“奈斯滋”并不因此而停止进行组织的各项活动，而是在暗地里偷偷地进行着。而另一方面，世界各地频频有恐怖组织的活动不断地发生。“海迪兰”佣兵部队是将调查恐怖活动的任务交由牧岛及K'去进行，当两人正预备开始对“奈斯滋”展开追踪时，恰巧碰上“格斗之王开战”的通知，在此活动中聚集了许多由世界各地脱颖而出的格斗家们，K成了招待队伍的一员，而牧岛他们也会在队伍中出现。接下来两人还是得继续进行计划的第二阶段，也就是关于“奈斯滋”结社的活动调查。“奈斯滋”的活动开始是单纯的偶发事件？还是……一股不祥的预感在脑海中漂浮着，“格斗之王2000”的故事就此展开！

## 以“格斗之王99”为基准将各系统升级

【图】操作方法表格及多张游戏截图

“格斗之王2000”基本上仍然沿袭了“99格斗之王”的操作系统，不过“格斗之王2000”还在有关威力槽的特殊动作上做了多方面的变更。威力槽位于体力槽的下方，当玩家展开攻击或是防御住对方攻击时威力槽上的数值便会增加，最大可累积至3格，利用威力槽的消费可以发动右表上的各种行动。

### 基本操作方法

8方向摇杆

A键：弱拳　B键：强拳　C键：弱踢　D键：强踢

| 动作 | 操作 |
|------|------|
| 前进 | → |
| 后退 | ← |
| 小跳跃 | 快速按下↗或↑或↗ |
| 中跳跃 | 快速按下↗或↓或↑后再快速按↗或↑或↗或是在擒拿的一瞬间按↗或↑或↗ |
| 大跳跃 | 快速按下↗或↓或↑后再按↗或↑或↗或是在擒拿的时按↗或↑或↗ |
| 紧急回避（前方） | →+AB同时按 |
| 紧急回避（后方） | ←+AB同时按 |
| 击飞攻击 | CD键同时按 |
| 受身 | 倒地前同时按AB键 |
| 挣脱投掷动作 | 普通投掷后同时按AB键或者按←或→+任意按键 |
| 挑拨 | 开始键 |
| 呼叫援护 | 同时按BC键（消费1个攻击弹） |
| 援护追加攻击 | 普通投掷后同时按BC键（消费1个攻击弹+1格威力槽） |
| 反击模式发动 | 同时按ABC键（消费3格威力槽） |
| 防护模式发动 | 同时按BCD键（消费3格威力槽） |
| MAX超必杀技 | 指令+按键同时按（消费3格威力槽） |

### 消费1格威力槽

超必杀技的使用 / 防御取消紧急回避（前方） / 防御取消紧急回避（后方） / 防御取消飞攻击 / 挑拨性攻击弹补给 / 使用援护追加攻击（消费1格攻击弹）

### 消费3格威力槽

使用MAX超必杀技 / 发动反击模式 / 发动防护模式

※防御取消紧急回避必须消费威力槽1格
※防御取消飞攻击必须消费威力槽1格

### 不能闪避移动 只有紧急回避

在前作“99格斗之王”中追加的“闪避移动”不见了，取而代之的是在“96格斗之王”～“98格斗之王”中采用的“紧急回避动作”，利用前转或后转可以立刻调整与敌人之间的距离。

在前作当中的体力槽变成红色的时候，使用必杀技会成为强力MAX超必杀技，而在这一次的新作品则与体力多寡无关，只要消费3格的威力槽就可以使出攻击力极强的MAX超必杀技哦！

【图】MAX超必杀技截图

↑金的超必杀技仍为凤凰脚，对手展开突进攻击的乱舞技。

### 两个特殊模式仍在

在定时内提高威力的模式还在，“反击模式”可无限使用超必杀技，也有由必杀技所引发的取消技。“防护模式”则是即使抵挡对方的必杀技也不会有损体力，被攻击时也不会后退的超级防护状态。

【图】反击模式与防护模式截图

## 援护系统新要素大幅增加

【图】多张援护系统相关游戏截图

在“援护系统”当中，虽然玩家可以将4人编为一队，但是却只能使用其中3人进行对战，因为第4人是专门负责援护攻击的“援护”。对战中只要同时按BC两键就可以呼叫援护出来助阵，不过，呼叫援护的次数得视画面下方的攻击弹次数而定，攻击弹的初期设定数目为3个，更换角色则会增加1个，最大可累积至5个。此次的援护系统也大幅增加新元素，我们也得来个大介绍才行！

### 各种状况下都能呼叫援护——积极援护系统

将前作原有的援护系统提高其自由度后，就成了本作的“积极援护系统”了。“积极援护系统”除了在前作原有的倒地状态下可以呼叫援护外，另外还增加了跳跃中、攻击中、倒地前等等可以呼叫援护的时机，而且在普通投掷后呼叫援护的情况下还可以使用专用“援护追加攻击”。不过，玩家必须注意的是，1个攻击弹必须消费1格威力槽才能换得。

【图】积极援护系统截图

↑金在双援护当中呼叫出其中之一的援护芭妮莎出来帮忙。

←真吾用普通投掷将金摔倒在地，援护随即乘胜追击。

### 附属援护——存在各角色的背后

此次参加大会的角色共计34人，各个角色的背后其实都存在着“附属援护”，也就是在战斗中专门用来作为援护使用的人格特质。在选择画面上决定援护时，玩家可以决定选择使用团队中的第4人作为援护，或者是使用存在于该角色体内的“附属援护”哦！
