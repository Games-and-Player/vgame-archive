> 插16 / PDF p.58（中插第1页）

## 游戏界过去也曾有过的例子！？

以 + r1 + 来解释的话，除了现在 + r1 + 的例子之外，在过去的游戏界里也曾经有这样子的新硬件推出哦！以下是相关情况的报道。

### NEC SEGA

【图】左侧展示了NEC和SEGA历代主机的缩小化演变过程：

**NEC系列：**
- PC Engine → 世界上第一台6位[?]家用主机。简称PC-E。
- ↓（变成这样）→ PC-E GT：过去享有盛名的8位主机（可外接CD-ROM）简称PC-E。
- ↓（变成这样）→ PC-E LT：1991年12月发售的PC-E LT也是延用HU卡来玩游戏。整体造型改成美似笔记本电脑的模样，但机能与PC-E GT差不多。
- ↓（再变成这样）→ 超级任天堂的进化版。机身略小，机能及规格不变。不过主机下方（原本预定要外接CD-ROM）的扩展槽被除了。
- →应该没有人不认识 + r1 + 吧？

**SEGA系列：**
- MEGA DRIVE：16-BIT主机。
- ↓（变成这样）→ 与JAL航空合作的新机种，用的同样是MD的卡带。机身只有按键和卡带插槽。要玩游戏的话得接上飞机座位内的小屏幕才行。
- ↓（再变成这样）→ NOMAD：前几年才推出的掌上型主机。对应 + r1 + （也就是美国版的MD）的卡带系统。当然，日本的MD卡带也能使用。附液晶屏幕，直接插上卡带就能玩。
- ↓不朽的游戏机之王，简称FC。
- FAMILY COMPUTER
- ↓（变成这样）→ 1993年与 + r1 + （卡带版）同时发售的新机种。去掉十几年来的红白造型，改为模仿自SFC的机身。另外，AV端子无法使用以往传统的 + r1 + 。
