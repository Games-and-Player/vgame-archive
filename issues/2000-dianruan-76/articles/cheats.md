## PS2 三国无双 HP=10（PDF p.84）

**调出所有28名武将：**有关PS2画面的讨论应该告一段落，仍然有不少人说本作的锯齿严重，胖子问为什么不换电视？

道具出现法：一般是指回复包子、弓箭、攻UPC剑、防UPC盾的道具。胖子认为，特殊道具只要打败副队长就能出现，种类则依队长的名字来决定，并得是有名的 + r1 + 才行，否则他不一定会持有道具。另，虽然每破8人，持有的道具会提高等级（回复弓箭即是如此，16人便是等级2包子），但有一些没有道具的一般部队长，却会让你的等级变为0蛋。可见欺杀散入后所得道具的数据为 + r1 + 。不过，如果连续打出超过8个的杀敌数，即使是一般兵士，你也能从他们身上得到回复道具，这是极难的，注意，几乎所有武将都可用 + r1 + 踢起，然后可不停地连续接发试验。

关于得点法：总武勋点数越高，则能得到大将军（张角为天公将军）、虎豹、东将、旦将军等一系列名号，没有什么意思。那些复杂的计点法对于玩家来说还一点儿都用都没有。

关于用秘技选出各国武将的办法，胖子认为既然有那么一下子就能出28人的指令，何必再登出那些麻烦的东西呢？在模式选择画面下，口口L1 L2 R1 R2 口口（成功会有 + r1 + 的声音）即可，重新后，吕布、貂蝉、袁绍、张角都有。R1 R1 R2 R2 L1 L1 L2 L2可在BGM TEST中听到全部曲子。

## PS 太9 HP=8（PDF p.86 右下）

●拍卖行购物法：先不报价，当拍卖师第二次问有没有人出价时，再加价100元可获得该物。这样电脑是不会再加价的。

●创卖物品：用上法在拍卖行购得 + r1 + 四件物品后，可分别发给冒险家、贵族、手和合成屋的学徒，除 + r1 + 外每可否对方第一次出价对相同回答。出售，则也会再出一个更高的价，此时才可出售。

●不装备 + r1 + 也可使放入的 + r1 + 无效，方法是使攻方人处于 + r1 + 状态。对方放出 + r1 + 的时使用魔法反弹至放方时可穿容放方的魔法防护门，对方无法反弹回来。另外，第一次的时候可以使用 + r1 + 则可使魔法效力加倍。

●陆行鸟零中悬尘中的隐BOSS战法：我方上场人员为主角、公主、女剑（无等级为5的信赖的人），全员装备至、睡眠属性吸收的防具，装备 + r1 + 的能力，开满 + r1 + 。女可，主角都应使气槽满至被攻击一次即会变身（可去记忆的场所打怪人）。到文可写相符合上述要求后场处从队中换下，当主角气满时，上文可，先挑战试碰敌BOSS。与BOSS对战时，女可变身连用两次白魔法 + r1 + 可给BOSS1万千多点HP；主角变身用目主杀，可给BOSS9999点HP；前面在前三回合可进攻，但最好使用 + r1 + ，目雷三连第三回合格都部一直用 + r1 + 以防BOSS使用我方全体变小附加各种异常状况的招法；公主们着意怎么办就跑怎么用。这样在女可变身状态解除前就解除前一回合BOSS必死。（我是立可变身解除后一回合，主角变身一招里把们干掉了BOSS）（江西赣州 赖敏建）

## PS DQ7 HP=7（PDF p.86 右中）

**DQ7序章之迷题：**进入 + r1 + 内的古遺跡内部后，前面会碰到几个迷题。下将部分较难的迷题解法告诉大家。

①取得 + r1 + ：过一吊桥，进入一洞，会有四尊 + r1 + 像正面围着个火坛。在火坛左边（正規规角，按START）调查之，可将其瞬灭。之后，右边的 + r1 + 会移过来将火坛重新点燃。抓紧时间走到移过来的 + r1 + 的原来位置，会有一机关，跌之，出现一门，进去，可发现 + r1 + 。（云南曲靖 一中铁杆 ZJ）

②四个宝具与宝箱之对应： + r1 + —— + r1 + ； + r1 + —— + r1 + ； + r1 + —— + r1 + ； + r1 + —— + r1 + 。

③抽象的壁画：进入一门，内有八幅壁画围在四周，四角各有一个机关，踩之会出现相应的石柱（放大镜）用来看壁画，壁画记载了 + r1 + 。看壁画的顺序正确的话会出现东西，但我一直没解开此谜。不过放心啦，解不开也可继续剧情，虚惊一场！

④推石碑：跳过上面的迷题。可来到一地，在通路两旁各有三块石碑和两个机关。石碑上有怪物的像，机关在前方墙壁下，此题多试便可，把正确的石碑推到正确的机关下，会有一清楚的响声，四个都正确后，通过。

⑤点圣火：来到一地，左右下角各有火把一支，中间九个裂又的火坛。神像对应火把颜色。用青色火把把 + r1 + 神像的火把点着，便会出现提示。依提示把火坛用青色火把点着：然后换火把，依上行事，便会开启机关，大门打开。

还有几个迷题，不过不难，多尝试便可。
