### 阵型及攻击判定

战斗前先决定怪兽的阵型，可选择预定的阵型（选第1项）或随机配置（选第2项），配置完毕后进入战斗画面，当己方攻击敌方MC时会显示命中率，并要用掷2粒10面骰子的方式计算攻击判定，掷出的骰子数若低于命中率攻击就成功，反之攻方就能通过攻击。当掷出特定的数字后，可获得特殊效果：①骰子数为00，超级临界点，获得3倍攻击力；②骰子数01～09，临界点，获得2倍攻击力；③骰子数95～99，攻击失败，己方怪兽受到相应的攻击。

## 真·完全攻略（PDF p.71）

在DEATH-T的死斗完结数月，游戏和同伴们收到一封邀请信，希望他们探望一下尚未恢复意识的海马，以帮助海马尽快恢复。当大家应邀来到海马的别墅见到他时，突然一道强光闪过，除了游戏其余5人都昏倒在地，他们的灵魂都被一种神秘力量强行带走，封印在人偶里面……

原来海马早已恢复意识，先设下陷阱引诱游戏等人前来，再用魔法将游戏的同伴封印在人偶里，以此强迫游戏参加由他生办的DUEL TOWER中举行的MONSTER WORLD大赛，并要游戏以千年积木木为赌注。游戏对此非常愤怒却无可奈何，为救同伴回伙，游戏决定接受挑战共战5层的DUEL TOWER。

在塔中，海马的管家间暗地说出了比赛的规则，并将5个星章交给游戏就离开了。一开始会被强制在转蛋机中抽取一只MC，种类随机而定。得到MC后就可挑战其他的参赛者，游戏的同学花叹、根津丸、孤狐野等都在这里，因为是第一层，他们都不很强，正好可以熟悉一下操作，顺便磨点经验值。当打败对手后会得到星章，星章主要用来在转蛋机中抽取MC（每次消耗1个）和打开白通往黑暗支配者（ダークマスター）房间的大门（消耗数视层数而定），但无论怎样使用，至少要保留1个星章，否则就会失去比赛资格。

注：此时建议多收集一些星章到转蛋机换取MC，使作战的MC达到4个。由于此时敌人的MC都是1到2只左右， + r1 + 绝对有利不用担了吧。另外，最好缩小作战队伍中MC们的等级差别，因为若有其中一两个等级过高，整体所得到的经验值就会减少， + r1 + 结果造成低等级的MC升级困难，所以一定要活用 + r1 + 。

当收集了10个星章后，就可开启通往黑暗支配者房间的大门，途中，海马的管家出来挑战，很轻易就击败了他。经过重重的大门，终于见到了第1层黑暗支配者——主平，身为海马弟弟的他，设计了第1层的 + r1 + 。（如原作中一样，每个怪兽世界都是黑暗支配者设计的小RPG，由你扮演勇者，只要完成任务就打败怪兽BOSS，就算打败了黑暗支配者）。

进入孔雀舞设计的怪兽世界，一开始就在山上碰见一人倒在地上，已经奄奄一息。一问之下才知他叫タオ，为了将传说中的龙蛋带回村，中途却遭到ハービィレデー的袭击而受到重伤，所以只好委托游戏将龙蛋带回マダ村。游戏接过龙蛋正想离开，ハービィレデー突然出现，为タオ报仇的机会来了，这家伙刚打了一合，还是赶路吧。突然从蛋里传来声音，要游戏将它带到附近的ランシングクリフ，在那儿的茶合上，ハービィレデー又追过来了。这次绝不能放过它。将它击败后，蛋裂开了，一头小龙从里面走了出来，游戏上面有几个兄弟，原来小龙是被退化之龙所退化的强大龙族，封在蛋中已有1千年，由于蛋合的关系解除了部分退化才恢复为小龙的形态。为了找到彻底解除退化的咒的方法，游戏和小龙向マダ村进发。

穿过山路到达山脊ステイープステップ，这里有一些可以推下的巨石，推动就能造出新路。在途中遇到快要从山崖掉下的爷子，救回她就能得到进化胶囊。越过山脊终于到达マダ村，但向周围所有村人都找不到解决方法。没办法，当小龙当初被退化的地方为カースマウンテン看看有什么线索吧。上山的路有守卫者，从上方的房间打败壁画怪就能通过。在山脚处遇到一位老伯，他交给游戏のろいふうじのケイ，说是对退化有利的东西，暂时还用不上，先放着吧。到达山顶时遇到一条恶魔龙，说明来意后，却被告知老龙已因病去世，能够解除退化的咒的方法再也没法知道了。失意之余返回マダ村，村长建议找回以前退化士的后代是关键。于是便向西边的山岳地带出发了。

来到半山腰，山顶突然传来一阵巨响，几块巨石滚落下来砸向游戏，幸亏有人相救，游戏才捡回了小命。正想问却对人谢谢，那人却已匆匆离去了。只是只好继续赶路，穿过崖上的森林（かけのうえのもり），就到达了闻名遐迩的退化士的隐居地，但退化法师只是要维持世界的平衡而不是将特别的退化魔法封印，理由是传承运命是不可改变的。但当游戏数回退化法师的徒弟テント后，退化法师为答谢游戏，破例使用时间退化魔法，将游戏和小龙带回1千年前……

1千年前的カースマウンテン，为了防止退化发生，游戏便打倒了退化之龙。当众人回到现代时，小龙并没有恢复原形，难道退化之龙还未死？这时有人告诉游戏着到カースマウンテン上有巨龙飞舞，于是上去看一个究竟，原来那是魔龙是罪魁祸首，是它令退化之龙复活并将小龙变成蛋的， + r1 + 的故事再次上演，打败退化之龙和恶魔龙后，DQ8也完结了，请大家继续期待DQ9吧。从扎雀舞手上取回杏子的人偶，向最后一层前进。

最后一层对战对手只有花叹、蝶名姐妹三人，收集够20个星章才能进入黑暗支配者房间，磨够正欲进入时，黑暗杀手出来挡路，唯有打败这个不识趣的家伙才可继续前进。接下来主平再次挑战，但他用的MC非常差，有什么理由不败呢。之后主平告诉游戏海马从某日开始就有时像人偶，有时又浮说怪话，好像被鬼魂附身一般，担心海马会有事，于是请求游戏一定要救回他哥哥。（漫画原作中主平与海马的兄弟之情有多处渲染，其中在单行本13卷中更得到了升华，曾一度令笔者非常感动），游戏答应并安慰了主平，就踏进了黑暗支配者的房间，见到最后一层的黑暗支配者兼大赛主办人海马后，果然发现有些东西附在他身上，看清楚了竟是千年轮的邪恶意识……

### 场地效果与支援效果

MC共分草原（そうげん）、荒野（あれち）、山岳（さんがく）、海（うみ）、森（もり）、光（ひかり）、暗（やみ）等7种属性。当在对应属性的场地战斗时，攻击力及命中率都会提高，即 + r1 + ；至于 + r1 + ，就是当 + r1 + 和 + r1 + 重叠覆盖于被攻击的己方MC身上时，进行攻击的MC将获得额外的攻击力。命中率亦会提高。攻击范围重叠的MC数越多，额外攻击力与命中率提升的幅度就越大。所以，善用场地效果和支援效果，一定能满击败人，令战斗更轻松。
