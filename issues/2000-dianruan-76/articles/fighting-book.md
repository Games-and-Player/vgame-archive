## 难舍97（PDF p.67）

**北京 赵庚**

现在我和几个好友对KOF'97已到了着迷的地步，天天疯狂练习，现在摸索出了一些极其鲜为人知的连续技，并发现了不少奇异现象，我想让大家开开眼界。特别值得一提的是八神13HIT的最高连数已成为过去，现在的最高连数是14HIT，而且绝对可连，除此之外，还有几套构成12～13HIT的连技，请广大KOF爱好者密切注意。

### KOF'97指令简化、连续技及不思议现象：

### 一、指令简化：

在KOF'97中有许多指令可以简化，例如：←↙↓↘→的指令可简为←↙或→；→↓↘→的指令可简为→↘……这些都是极其常见的，人人都知道。我今天要说的是怎样把指令的简化融入到连续技当中。

小红丸：↓B、立B） + r1 + ，其实此技很常见，但大部份看手快才能连接，而现在只需输入↓B）→B↓→A/C便可轻松使出，除此之外，未听说过任何人用此简易。需要说明的是→B的时机很重要，否则就会变成→B特殊技了，如掌握不好，把立B换成立A就万无一失了。

2、草薙京：↓立、立B) + r1 + ，与红丸同理。但要注意在↓↘→A/C时需准确，如输入成↙↓↘→A/C则会出 + r1 + ，而输入成↓→A/C时就变成 + r1 + 了。

3、八神：↓B↓↓A）→A）→↓↙←A/C就可轻易使出葵连技。

4、克里斯（真·克里斯）：↓B↓A）cA↓↓A便可轻松接超必杀。

5、大门：站立任意键）↘C） + r1 + 可简成→＋任意键）↘C）→↙←↓↘→B/D；↙↓↘→A）↘C） + r1 + 可简为↙A）↘C）←↓↙→B/D。

6、特瑞：↓B）下A）↘C） + r1 + ，可简成↙B、A）↘C）→↓↘→B/D 要注意↓↘→B/D 要准确，如输入成↙↓↘→B/D常会出 + r1 + ，输入成↓→B/D会出 + r1 + ；站立任意键）↘C） + r1 + 也和大门的简化一样。

### 二、不思议现象：

1、双方八神前冲中同时使用 + r1 + ，屏幕中的两个八神会定住的1秒左右，此时画面会变亮，而后双方向后弹开并签居局刚开始的距离，又定1秒左右，双方才能动，如还不能动，则死机，除非关机了。

2、大门跳起输入 + r1 + 指令，在快落地时，对方八神使出 + r1 + ，此时二人都像晕点一样，方向控制无效，只可使用通技，但谁也不会击中对方。

3、夏尔米的→↓↓←←×2A/C和八神的 + r1 + 同时使出，夏尔米会闪到八神身后，不停用腰部撞击八神腰部，双方控制完全失效，直至本局结束。

4、比利使出MAX版 + r1 + 时，红丸闪到其身后，使用本应6HIT的重 + r1 + 会有11HIT之多。

5、玛丽在版边跳防红丸的空中↓D特殊技，未落地时输入 + r1 + 指令，玛丽会在空中使出此招后浮空，此时可行走或使出通常技，但2秒左右，就会自动落地。

### 三、只有我和极少数人见过的连续技：

1、草薙京在版边用 + r1 + 击↙对手后的第一时间用下A化解可接MAX版 + r1 + ，通常版没有试过，所以不敢肯定能否连接。另外，↓B）立C是很常见但又不是大家都会的招式，但↓A）立C我就只见过两个人能接上（包括我一个）。

2、大门：轻攻击）↘C）→↓↘→B/D，其实此技一点儿难度没有，但除我之外从未见人使过，不知为什么？

3、八神：我认为此角色是整个KOF'97中最神秘的一位，他的连技源源不断的被人发现，可还有多少未曾发现的连技谁也说不清，而且此人的 + r1 + 可说是异常神秘，变幻无穷，下面我介绍几种几乎无人知晓的连技。⑤跳C＋D(COUNTER)） + r1 + 。和'99中草薙→1的倒地追击同理，而且对手无可逃避，但能不能接上，就要看玩者的天份了；②轻 + r1 + 第一段与红丸的 + r1 + 第一段同时击中对我双方，八神可用 + r1 + 追击；③对方蔡宝健在版边跳起时可用一段轻 + r1 + 接 + r1 + ；④版边：两段轻 + r1 + ） + r1 + 或 + r1 + 。若说接 + r1 + 不算十分稀奇，有不少人接上过，但接 + r1 + 恐怕是大家闻所未闻的。其实要点同样在于 + r1 + 应空中击中对方，且第一段 + r1 + 击中对手的位置高低和两段 + r1 + 之间相差的速度快慢都必须掌握好。如果 + r1 + 将在版边跳起的对手定住，就更好接了。下面我要介绍的是极限连续技，连打数至少12HIT：①跳B）立B）→A）轻 + r1 + ×2） + r1 + ，13HIT。此技需在版边，两段 + r1 + 之间的速度要慢，如对手是蔡宝健，可用跳C后连接后面的攻击。②己方在版边，对手需陈可汉： + r1 + ）立C）→A）轻 + r1 + ×2） + r1 + ，13HIT。③版边，对手限定为韩国队的一大一小：↓B）立B）→A）轻 + r1 + ×2） + r1 + ，13HIT。此连技和上述两条连技不同，第2段 + r1 + 要求速度极快，尤其打蔡宝键时，稍慢一点就确不着对方了；打陈可汉时可把立B换作下A或立A。

④八神的立A可连接立C，所以 + r1 + ）立A）立C）→A） + r1 + 也是成立的。（12HIT）

⑤己方在版边，且对方离自己不远的距离 + r1 + 击中： + r1 + ）立B）→A·A）轻 + r1 + ×2） + r1 + ，14HIT。此技中2段 + r1 + 之间要不快不慢，掌握节奏至关重要。另外，我和一位好朋友在试验此招时，打八神、草薙、莉安娜三人从未接上过，不知道打过三人是否可连。这可不是胡说八道，为了证明此技可行，我把此技全过程图片寄去，14HIT的字样清清楚楚。

## KOF 2K的系统和实用连技（PDF p.68）

**上海 LION.C**

### 系统

#### ①紧急回避

本次的 + r1 + 采用的是97、98的紧急回避系统，所以 + r1 + 中类似ABC爆能量后回避攻击接必杀技或BCD后（俗称 + r1 + ）在角落里令对手浮空后的无限连击是无法在 + r1 + 中实现的。

#### ②援护（俗称 + r1 + ）

本次最大的特色之一：每个角色在作为援护攻击时都有两种选择，另一人可称之为角色的负面人物，有的角色如草薙、八神、蔡保健、大铁球等有隐藏的负面角色，调出方法为（例草薙）放在草薙的负面角色上，摇柄上左左右右左左右右即可使用草薙柴舟、新装八神、英俊型的蔡保健和大铁球等角色，如此援护便多达六十人以上（笔者心想：有那份闲功夫不如多作几个可选择出场战斗的角色，那么许多援护除了搞笑外，大多功能重复，且眼见如此多的角色无法使用作战斗主力，不是有心让玩者不爽么！）但不可否认，某些 + r1 + 的确利害，缺之便难取胜。

#### ③开始键的功能

本作的开始键在战斗中基本功能除和大多格斗游戏一样外，还有将能量点一个转换成一个援护攻击的作用。在 + r1 + 放完或觉得不够用时可用。但必须注意在按开始键中有一定硬直时间，无法作任何动作。不看时机使用，必受对手冲打。

#### ④援护时间（随时放 + r1 + ）

本次最大的特色之二：本次 + r1 + 的战斗中，除硬直状态（指受伤硬直）和超必杀技放出中外，可随时放 + r1 + 。这样便使许多不可能的连续技变为可能，也就有了下文中的一些 + r1 + 特有连续技。合理使用还可减少对战中进攻后的破绽。如：对空技失去攻击判定后还未落地便可放一 + r1 + ，对手如上前动手却反被 + r1 + 咬。又如：连续技打击中途放一 + r1 + 使本来无法再继续的连续技又再产生攻击判定。

本作最大特色之三： + r1 + ，即向已倒地的对手追放一 + r1 + ，将其踢得飞起后追加攻击。使被击倒方在倒地瞬间紧急受身更为重要。

#### ⑤取消了某些无赖技

如99'中包的CM后↓↙←→A接↓↙←→A/B，蔡保健的→A也无法击破对手防御，而椎拳崇的→↓↘↘A/C出招后的硬直时间也加长了等。又：96～99一直为对手不齿的 + r1 + BUG经试验也不成立了（至少按原方法无效）。
