## 桑巴！狂舞吧！现在

从街机移植到DC上的 + r1 + 将可让您在家享受响铃沙沙的乐趣哦！游戏的规则很简单，玩家只要在画面中央飞出的圆珠和排列在外圈的圈圈重叠时，摇动和该圈圈相对应的拉丁节奏就快出现在你家哦！

而这次要为您介绍部分收录在 + r1 + DC版中的模式，每个模式的内容都十分充实，玩家可得瞪大眼睛看仔细，保证你一定会爱上它，简单又有趣的拉丁节奏就快出现在你家哦！

### 挑战模式

以成为 + r1 + 为目标，进入单人模式挑战看看吧！从 + r1 + 开始共有5个阶段，只要玩家能通过各个等级的考验就可以获得属于该等级的称号。而在获得 + r1 + 这个称号后，玩家在此模式里所演奏过的歌曲也会在原创模式中出现。

### 战斗模式

如梦一般，而且是原创版所没有的 + r1 + ……现已在DC版 + r1 + 上推出了。这个模式的游戏规则是正确的摇动响铃，使对方中央的炸弹不断膨胀，当炸弹膨胀到一定的程度时便会爆炸，对手的体力也会因此而减少。所以就请跟着歌曲节奏摇动你的响铃吧！如此一来就能迅速地使炸弹爆炸并达到攻击对手的目的，体力先降至0的一方就算是输了。

**快速地使炸弹爆炸**

↑玩家的技巧若是太差的话，炸弹可是一点儿也不会变大哦！

**真不甘心输给对手**

→一炸弹终于爆炸了！对方的另一个炸弹膨胀更大。爆炸后又得重新让......

**咚！爆炸啦！**

↑最后会有成绩表示出谁胜谁败，要是输了那可真令人泪丧。

### 恋爱模式

恋爱模式虽然和战斗模式一样是属于双人模式，但是这个模式却可以利用响铃诊断出你和另一个人到底适不适合。而游戏的规则是，两人随着歌曲节奏而摇动响铃，若双方摇动响铃的时机如果能完全吻合的话，位于画面上方的恋爱槽便因此而上升。当然失误愈少的话，那就表示双方默契十足又很合得来，恋爱度也会提高哦！一首歌过关后就可知道双方的契合度如何了！

↑如果两人跟着歌曲的节奏同时摇动响铃，画面上便会出现爱心符号 + r1 + 。同时，恋爱槽的指数也会上升哦！

**已经无法停止了**

→虽然一个人比两个人更快进入状况，但如果技巧太差的话还是会陷入辛苦哦！

**恋爱加速**

↑哇！两人的契合度真是世间无人能比！亲爱的，我们做到了！

↑两人的契合度以及等级当然也会在最后一一的表示出来。

**两人的爱是100分！**
