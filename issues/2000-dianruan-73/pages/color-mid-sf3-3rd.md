### 5位新参战的角色

新作除了前作原有的15位角色外，特别让在名作 + r1 + 中使用华丽足技的春丽也加入，另外还加入了4位喜好战斗成瘾并且以此为乐的新角色。

**雷米**——排回任爱与恨之间

**春丽**——再现华丽的腿部线条美

一心为了复仇却导致将心坠入黑暗阴影之中的青年，是一位属于擅长对空技的角色。

**象道**——一般存在的极具个性化的新角色！

是机械还是人呢？是个充满谜团的角色，使用的是突进的必杀技。

**真**——超级派王手道少女

为了要振兴名门道场 + r1 + 而出外旅行的少女，使突刺及手力等空手道的招式战斗。

**多艾鲁布**——矮日却来抛弃机

战斗时会改变外形的杀戮机器，是尼克鲁的强化改良型。

世界闻名的格斗女英雄，新超级必杀技 + r1 + 的无敌时间更长，尤其对于对空技及攻击十分有效。

### 即时通信对战第3弹！

 + r1 + 系列的最新作品中，另外追加了5名新的角色，整个游戏中共有19名的角色可供玩家选择，而且此次还加入网络通信的设计，玩家们只要利用电话线便能够挑战在全国各地的街霸玩家们并且进行即时对战哦！

继 + r1 + 以及 + r1 + 之后，又一个和全国格斗高手接触的好机会！

说到具有通信对战功能的格斗游戏，即将带动第三波风潮的当然是非此款游戏莫属了。在通信对战的系统方面，接续的方法以及通信的画面并没有特别微细小的改变，而玩家的等级别对战或和特定人选的战斗方面似乎也承袭了某些机能。

↑一幕近身体攻击的情景，伴子的挣扎真的很逼真。

→有很多新世代的格斗家会出场与你交手，快来享受激烈战斗的乐趣！

## 页2（PDF p.65）

CAPCOM 火爆新作来袭！

### 为了使战斗更强烈、刺激、完美而采用新系统！

这款以完美的战斗为竞赛目标而采用 + r1 + 的游戏，可不是只要将对手打倒这么简单哦！还要看你如何打败对手，依据所剩余的时间、体力及战斗方式计算出等级，玩家若想得到较高的评价就非得了解它的战斗系统不可。象是瓦解对手防御的 + r1 + 或者是能够完全防守对方攻击的 + r1 + 都是改变战斗流程的要素，经过充分的练习之后就可以在通信对战上展示纯熟的技巧了。

### 选择 + r1 + 

选必杀技/超必杀角色之后就同时确认，一伸缩自如的这招这么也有一种超级的味道。

↑发动超级必杀技必须要消耗右画面下方的计量数值，这一击是否能够成为获得胜利的主要关键呢？

一级必杀技是作为新角色雷米的必杀技。

← 不断攻击对手一个劲儿Q只知道 + r1 + 地攻击对手也是不行的。

### EX必杀技

→在放出必杀技之后最多能再以消费在杀技计量器的前提下使用出来。

### 急速跳跃攻击

↑急速跳跃攻击是瓦解对手蹲下防守时的特技，跃起后紧接着攻击蹲缩的对手的脑门，使用的时机很重要！

### 绊倒技

↑绊倒技是能够守住对方攻击的防御技，就连对手所使出的连续攻击也能轻易地防御，使用绊倒技后所采用的攻击有可能会导致战斗流程的改变。

### 个人专属动作

→所有的角色都有特别设计了专属的效果！其中当然也计算了每一级。
