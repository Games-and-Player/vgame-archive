# 闯关族的家

## PDF p.69

本月是非常热闹的一个月。一方面，对电子游戏、电脑游戏的批评在升温，有些报刊直称电子游戏为 + r1 + 。与此同时的，D版集团不但没有丝毫收敛，反而重拳出击，矛头直指自以为固若金汤的DC等软件，称得上是 + r1 + 。下面我们就谈谈具体情况：

●读者可能已经看到了，在本期杂志 + r1 + 的第一条新闻就是国务院办公厅批转七部委《关于开展电子游戏经营场所专项治理的意见》）。这是近十年来对电子游戏市场最严厉，最彻底的一次整顿。猛辞之严厉，措施之彻底是前所未有的，对街机市场可以说是近似毁灭性的打击。这项通知的要点有：一、任何形式的具有赌博功能的游戏机都将被没收销除出街机机厅。二、停止审批新的街机机厅，也不审批现有机厅增添或更新任何类型的电子游戏设备。也就是说，基本维持现状，直至街厅自然死亡。更加严厉的是，停止有关街机设备及零附件的生产及行销。这就意味着外国的最新街机设备进不来，国内几十家生产街机机板及设备的厂家都要转产改行。无怪乎中国游艺机游乐园协会副秘书长陈守维对此言辞激烈；早就听说对街厅要整顿，但还是没有想到会有这么严厉。

大家可以回想一下，每次社会上有什么风吹草动，矛头都会对准电玩。抛开其他一些因素，街机业本身是不是也太脏了。我们看一看周围那些 + r1 + 的街机机厅，空间狭小、灯光昏暗、室内烟雾弥漫、声音嘈杂。为了 + r1 + 一把，多数街机厅都摆上赌博机。于是出入分子更加混杂，加上有了利润，二十四小时营业，无形中成了问题少年、逃家或是罪犯躲身的地点。当然也有如北京SOGO、新世界商城等几千平米、宽敞明亮、卫生洁净的街机机厅，但那毕竟是少数。虽然恰恰说： + r1 + 但也不能 + r1 + 吧。这次严厉的打击的确是一剂猛药，可以清理市场，清洁环境，让街机拥有个重

塑形象的机会，也有利于缓解以至完全消除社会的批评，避免成为舆论的中心。

但盼赴抽薪式的大 + r1 + 之后，也很希望七部委能拿出建设性的意见来。比如：营业登记的分类、公共安全的标准、摆置机台的标准、出入人员的限制等，这才是一劳永逸又不失公平公正的办法。

（照片：北京一些正规的大街机厅并未受到《通知》的影响，照样生意兴隆。只是以后……）

●《游戏批评》将于九月份出版，每月一本，本期杂志插一破了大幅广告。这是中国游戏业的一件大事。为什么这么说呢？大家一定会注意到，街上的游戏杂志或与此有关的杂志已经泛滥成灾。但没有一本杂志专门对游戏及游戏业进行批评和评论，帮助读者欣赏游戏，了解游戏，感悟游戏。

《游戏批评》的大部分文章都是大陆玩家原创的，可以说是大陆玩家的一块精神乐园。在编辑方针上，我们制定几项不同于时下杂志的标准：一、不刊登广告，与各游戏厂家及商家保持适当距离。二、一个游戏软件既是一件 + r1 + ，又是一件 + r1 + ，《游戏批评》更愿意站在 + r1 + 的角度上去评论它。三、对游戏的批评不能仅以游戏时间来评判，而是努力理解制作者的创作意图方面提来赏阮。四、游戏批评应该诚恳善意中肯，应以建设性的角度做出评论。

从以上的编辑方针，大家可以看出，《游戏批评》是一本 + r1 + 而不是 + r1 + 的书。希望看《游戏批评》是坐在椅子上，至少是躺在床上，而不是蹲在厕所里。

《游戏批评》不是 + r1 + 。

大家可以从中看到游戏主机近期的走势和升降对比。另一个就是 + r1 + 。 + r1 + 区别于 + r1 + 的地方在于八卦新闻大半是传闻，小道消息，不是厂家正式公布的。因此它的可信度就要打个问号。但无风不起浪，也不一定一点根据也没有。编辑部首次做 + r1 + 是在《2000年增刊》上，受到读者的好评。因此决定每月都设1-2页 + r1 + ，并标上可信度及编辑部对该条新闻的意见，算是严需新闻的一点调料吧。
