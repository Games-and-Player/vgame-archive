### PS聚焦线圈两种故障的维修

光驱中的聚焦线圈在读取光盘信息过程中起重要作用。透镜固定在线圈上，线圈通过一弹性塑料片与底座相连。线圈在驱动电路控制下进行聚焦，循迹动作，使激光束准确落在光盘上。用万用表RX1挡测量时，线圈有上下或水平方向的位移。

PS机光驱使用久了常有扣机器倒置才能读盘的状况，这与连接线圈和底座的弹性塑料片老化有关，此塑料片老化后透镜距光盘距离被拉大了，激光束不能准确落在光盘上，以前有位玩友把光头卡脚滑块下移提高整个光头组件来解决这个问题。本着学术研讨的态度（作一本正经教授讲课状）我们认为有所欠缺。①卡脚滑块下移后光头的移动不顺畅，下移距离也难控制、掌握。②下移后光头固定卡难安装，不安装固定卡的活光头齿轮不能互相吻合，常有不能移动的情况发生，以前曾看到过一种移高线圈的方法，在两种方法进行尝试、对比的前提下，我们认为后者较好用。现推荐给玩友：找一杆内有弹簧的圆珠笔，取出弹簧，拉直。剪下一小段，一端从弹性塑料片孔中穿入。另一端用502胶固定在底座上，细钢丝的作用就好比一只有弹性的杠杆，将物镜弹起而又不失其活动性。注意：细钢丝固定好后线圈应比原先位置有所上移，见下图。

（透镜、聚焦线圈、弹性塑料片、细钢丝挑起塑料片示意图）

## PS记忆卡使用窍门二则

关于记忆卡故障和D盘的问题，我曾经写过一篇短文给贵刊科普园地。可是近几期依然在龙哥热线栏目中出现记忆卡的问题，而龙哥的解答也似是而非。我想不是我那篇短文在内容上太肤浅，太简陋的话，就是该编辑认为我那篇短文送得不是地方。

目前市面上1M（15格）的记忆卡共分三种（大致上）：原装（记忆体为记忆颗粒），芯片卡、电池卡。下面主要说芯片卡和电池卡。

电池卡记录时间为三个月到五个月（新电池），在电池卡电池电耗尽的情况下仍可记忆，即使按RESET键，记忆也不丢失，但关机后记忆消失，由于使用不便，目前市面上已无发售。而芯片卡目前是市场主流，但由于该芯片的记忆原理区别于以上两种，所以在使用的尤其是使用金手指管理时会出现特别的现象，令玩家苦恼。其实很好解决，首先找一块电池卡（记录满），然后把该芯片卡和电池卡插入卡匣。打开金手指，接上电源开机，选记忆卡管理栏进入，90%的情况下芯片卡那栏会要求你将芯片格式化。格式化后马上复制电池卡中的内容，全面复制后，删除芯片卡中全部内容，静等几秒后，不要回到金手指主画面，直接按RESET键即可，若不行可多试几次99%会成功。有时电池卡的内容在金手指会显示不出画面，那么就换别的记录试试。

另外市面上有一种1M的芯片卡，由于使用2M的电路，而该2M卡是对应手柄L1、L2翻页的，所以买回芯片卡后应试一试，按L1、L2键看翻不翻，否则记录时乱按就麻烦了。

### 一、PS在街机上显示图像

首先购一个制转器，报废的也可以。拆开后，电路板上有8条线与多脚插头连接，一般标有Vcc（从PS中取的+5V电压，它给芯片和视频到频率转换机构供电）、R（红色信号输出）、G（绿色信号输出）、B（蓝色信号输出）、SYNO（同步信号输出）、AVR（音频R输出）、AVL（音频L输出）、GND（地线）。将这8条线功能记住，然后拆掉下、制转器弃之不用，只留插头。对应扫描板的R、G、B、S、GND（扫描板的5条线分别是红色——红色信号输入，绿色——绿色信号输入，蓝色——蓝色信号输入，白色——同步信号输入，黑色——地线）接好。

### DC的VGA连接法须知

读者甲：游戏机在电脑上显像就能变成640×480！
读者乙：你说得不大对，只有DC能将VGA进行到底！
读者丙：走，咱们向电软去！

考虑到越来越多的玩家拥有时尚的DC主机，而且朋友们对高级输入方式也愈发地重视起来，本刊今特公开以VGA端子连接DC的相关事宜。（提供先进的游戏方式亦是本小栏目的宗旨之一。）

想获得真正的640×480（点像素）映像，需要游戏机硬件本身的支持，在概念上并非 + r1 + 就可以了。PC也可以通过加装一种电视卡的电脑来显像，但这时的彩色只不过是相当于一台彩色电视罢了，其 + r1 + 功能完全没法子在电脑上得到体现。（创意/老猫，又/老昵）

DC机所配显卡为8MB记忆体，POWER VR2芯片则有绝对的VGA显像能力。我们只要买为DC派遣一个小小的VGA转接器，就能从DC主机内直接输出最高RGB映像。

测试用的是仿原装的PANTHER牌DC专用VGA BOX（约260元），各项功能均与原装相同，使用效果令人比较满意。而和价百元以下的VGA转接器，建议大家应先让BOSS试机，再行掏钱购买。

显示器我们用的是飞利浦 + r1 + 105G，将彩显的15针插头直接驳在VGA BOX的入力端（用螺栓紧固），再将VGA BOX的另一端直接与DC上的音视频输出端相连，之后请务必检查VGA BOX上的TV/PC转换开关是否在PC档上?PC专用立体声音响声再接入有源的连接线是否与VGA BOX上的相应端子相连？确认 + r1 + 后即可打开彩显，启动DC。如DC里放的是正版的对应VGA输出的游戏，你的眼前将展现出语言所完全无法形容的鲜丽映像。美轮美奂，温柔终极。

**提示**

1. 原装或精工细做仿原装VGA-BOX提供与电视相连的功能，即不必从DC上下VGA BOX以更换DC随机线或S端子线，只需保持VGA BOX与DC的连接状态，将独立的视频（或S端）线、音频线（红、白双路立体声）连到VGA BOX上的相应端子上，再将音、视频三条线的另一端送入电视监视器即可。同时务必记住，在DC关闭的状态下对VGA BOX上的TV/PC转换开关进行切换。

2. DC的D版引导系统的菜单画面不对应VGA输出，所以就算D碟（硬碟）支持VGA，但你却进不去，看不到可爱的 + r1 + ，怎么玩游戏呢？只能用电视监视器来玩D. VGA BOX和DC只认原版。经试用冒险办法——启动用VGA BOX上的PC/TV切换开关试图引出D碟画面并强行转接至PC彩显，完全失败。彩显出现 + r1 + 字样。我们暂将正版进行到底。

3. 使用VGA BOX接彩显后，音频将无法输出至功放。

4. 一些特定游戏画面（如VF3菜单画面下），出现了摩尔纹效应。造成波纹问题的原因，有视频干扰和扫描干扰二种之分。DC使用VGA-BOX后出现的这种，原因不明且无法消去。就算高档彩显有摩尔纹调节功能，想必也毫无能为力。注意，这种情况仅仅存在极个别的静帧画面，面会出现，游戏画面并未发现任何问题。其实KX炫示无发纹。

5. DC的VGA为水平31K，垂直60Hz，严格审判的说法，在特定画面（如大片白色）会感到屏幕上存在闪烁。建议将色温设在最低。

6. DC的VGA输出是ANALOG（模拟）RGB标准三行15针。多数常规彩显均具此连接。苹果专业BNC插21'彩显（SONY制）不可。飞利浦半专业型大彩显和大众型苹果小彩显统统可以连接DC。

7. 在KX炫上看无错误、马赛克的游戏，到了 + r1 + 上出现了许多不应出现的问题。VF3锯口致人，而莎木更是抗锯单纯但马赛克现在远处景物上的表现好似SFC。当一台主机的性能不变时，显示器材越高级，则DC的缺点就越就暴露。显存，8MB不安。
