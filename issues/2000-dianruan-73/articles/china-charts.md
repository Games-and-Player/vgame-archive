## 排行榜缺少大作刺激，投票量继续下滑！

由于本期排行榜选票累计阶段正逢期末考试，加之没有抢手大作刺激，所以投票量依旧处于低谷。不过笔者预言，排行榜投票量会在后两个月里渐渐回升，逐步达到今年4、5月份的巅峰时期。

当月榜方面，PS和街机分别出现了 + r1 + 、 + r1 + 两款新作上榜。虽然近期SNK的业绩一蹶不振，部分游戏的质量也有所下降，但是 + r1 + 还是凭借流畅的操作和种种令人忍俊不禁的动作而大受欢迎。相信随着该作的普及，其榜位还会继续攀升，毕竟 + r1 + 和 + r1 + 均是稳身5强的作品。此外，在PS榜中， + r1 + 、 + r1 + 和 + r1 + 这三款系统性极强的游戏都有着不俗的表现，分别提升了各自的榜位。这也从一个侧面说明了游戏性的重要性，有了丰富而严谨的系统设定，游戏自然就会受到玩家的关注。

累计榜上，任天堂的看家法宝 + r1 + 继续前进，以7886票的成绩挤进了前十强的行列，成为了前十名中唯一一款GB游戏。

日本方面， + r1 + 在7月7日已经发售，其发售前的预约量就突破了百万大关，达到了135万套。相信其登上 + r1 + 的前5强也只是时间问题。除 + r1 + 外，BANPRESTO的 + r1 + 也有着首发43万的佳绩。SRWα不仅战斗动画干净利落、原作剧情丰富，厂商对各项细节设定也进行了调整，堪称机器人系列中最完善的一部作品。
