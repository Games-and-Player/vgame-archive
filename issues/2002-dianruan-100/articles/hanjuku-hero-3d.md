# 半熟英雄对3D

**HANJUKU HERO TAI 3D**

| 项目 | 信息 |
|------|------|
| 平台 | PS2 |
| 类型 | 策略RPG |
| 发售日 | 2003年（预定） |
| 开发/发行 | SQUARE |

【图】半熟英雄对3D标题画面和搞笑风格的角色立绘

SQUARE旗下的老牌搞笑策略RPG系列"半熟英雄"终于要登上PS2了！从系列第一作（FC）到第二作（SFC），"半熟英雄"一直以其独特的幽默风格和出色的战略性深受玩家喜爱。如今时隔多年推出续作，想必让不少老玩家感到激动不已。

本作的最大变化当然是全3D化。不同于以往的2D画面，本作中所有的角色和场景都以3D方式呈现。但SQUARE表示，虽然画面全面升级，但系列一贯的搞笑风格不会有任何改变。

【图】3D化的战斗场景和角色模型

在系统方面，传统的半熟英雄式玩法将得以保留——玩家依然需要通过派遣"蛋"来孵化士兵，然后指挥军队在大地图上进行战略级别的战斗。而当两支军队交战时，则会进入即时的战术画面。

系列标志性的"搞笑合体变身"系统也将完整保留。通过让不同的蛋进行合体，可以诞生出各种奇奇怪怪的搞笑角色和强力单位。
