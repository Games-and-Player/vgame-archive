# 生化危机0 / 电脑战机MARZ

## 生化危机0

**BIOHAZARD 0**

| 项目 | 信息 |
|------|------|
| 平台 | GC |
| 类型 | 恐怖冒险 |
| 发售日 | 2002年11月21日 |
| 开发/发行 | CAPCOM |

【图】生化危机0游戏画面，列车内部场景

NGC独占的《生化危机》系列最新作。故事发生在初代生化危机事件之前，讲述了S.T.A.R.S. Bravo小队成员蕾贝卡·乔伯斯和前海军陆战队员比利·乔恩在充满危险的列车和研究设施中逃生的故事。

本作最大的特色是"搭档互换系统"——玩家可以随时在蕾贝卡和比利之间切换操作。两人各有所长，蕾贝卡可以调配药品，比利则拥有更强的战斗力。合理利用两人的特长是通关的关键。

## 电脑战机MARZ

**VIRTUAL-ON MARZ**

| 项目 | 信息 |
|------|------|
| 平台 | PS2 |
| 类型 | 动作 |
| 发售日 | 2003年（预定） |
| 开发 | Hitmaker |
| 发行 | SEGA |

【图】电脑战机MARZ游戏画面，机甲战斗场景

SEGA旗下经典机甲对战游戏《电脑战机》系列的PS2新作。与以往纯粹的对战模式不同，本作加入了完整的故事模式。玩家将在剧情推动下，驾驶各种机甲（Virtuaroid）进行战斗。

游戏收录了系列历代的各种机体，玩家可以根据自己的喜好选择不同的机体出战。每种机体都有独特的武器配置和操作特性。
