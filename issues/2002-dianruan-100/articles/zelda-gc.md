# 塞尔达传说GC

**THE LEGEND OF ZELDA: THE WIND WAKER**

| 项目 | 信息 |
|------|------|
| 平台 | GC |
| 类型 | 动作冒险 |
| 发售日 | 2002年12月13日（预定） |
| 开发/发行 | 任天堂 |

【图】塞尔达传说风的智慧标题画面，卡通渲染风格的林克在海上航行

NGC上最受期待的大作之一终于要来了！尽管当初公布卡通渲染风格时引来了不少争议，但随着更多情报的公开，《风的智慧》正在用实际画面证明——这种画面风格不仅别具一格，而且在表现力上丝毫不逊色于写实风格。

本作的舞台设定在一片广阔的大海上。与以往的塞尔达不同，这次没有连绵的大陆，取而代之的是散布在海面上的无数小岛。林克必须驾驶帆船在这片大海上航行，寻找线索、探索迷宫、击败敌人。

【图】林克驾船航行的海洋场景和岛屿探索画面

航海系统是本作的一大特色。玩家可以通过使用"风之杖"来改变风向，从而控制帆船的行进方向。在广阔的海洋上自由航行，探索未知的岛屿——这种冒险感是以往任何塞尔达作品都无法提供的。

在战斗方面，林克可以使用系列传统的剑和盾，也可以拾起敌人掉落的武器来使用。战斗动作方面加入了更多的招式，包括闪避、反击、跳跃斩等。

卡通渲染风格的角色表情丰富到了极致——林克的一颦一笑都通过夸张的面部表情来表现，敌人被击中时也会有各种搞笑的反应。这些生动的表情让整个游戏充满了活力和趣味性。
