# 克罗诺亚的冒险 传说的星之勋章

**KAZE NO KLONOA: DENSETSU NO STAR MEDAL**

| 项目 | 信息 |
|------|------|
| 平台 | GBA |
| 类型 | 动作RPG |
| 发售日 | 2002年（预定） |
| 开发/发行 | NAMCO |

【图】克罗诺亚和伙伴们的角色立绘

NAMCO旗下人气角色克罗诺亚（Klonoa）的GBA新作。与以往的平台动作游戏不同，本作是一款动作RPG，克罗诺亚将在一个更广阔的世界中展开冒险。

游戏的画面采用了可爱的2D像素风格，但动作部分的手感依然保持了克罗诺亚系列一贯的流畅感。克罗诺亚可以使用招牌的"风弹"来攻击敌人和解谜，此外还加入了RPG式的升级和装备系统。

【图】GBA版游戏画面，2D横版冒险场景

故事讲述了克罗诺亚和他的朋友们为了收集传说中的"星之勋章"而踏上旅程。星之勋章拥有强大的力量，如果落入坏人之手将造成不可挽回的后果。在冒险途中，克罗诺亚将遇到形形色色的角色，有的会成为伙伴，有的则是需要面对的敌人。

在战斗系统方面，本作采用了即时动作战斗，玩家可以直接操控克罗诺亚进行攻击和闪避。随着冒险的推进，克罗诺亚可以学习新的技能和魔法。
