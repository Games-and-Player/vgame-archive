# 异星物体X

**THE THING**

| 项目 | 信息 |
|------|------|
| 平台 | PS2 |
| 类型 | 动作冒险 |
| 发售日 | 2002年秋 |
| 开发 | Computer Artworks |
| 发行 | Vivendi Universal |

【图】游戏标题LOGO"THE THING"，寒冰风格字体

在1982年由约翰·卡朋特执导的那部经典科幻恐怖电影《THE THING》（怪形/异形奇花/突变第三型）问世20年后，一款以该电影为背景的游戏终于登场了。不同于以往那些粗制滥造的电影改编游戏，《异星物体X》的制作组对原作电影有着极深的理解，在游戏中完美还原了那种来自未知恐惧的绝望氛围。

## 电影的延续

故事紧接电影的结局展开。当美国南极考察队的基地被彻底摧毁之后，军方派出了一支特种部队前往调查。玩家扮演的是这支特种部队的队长布莱克（Blake），带领队员们深入冰天雪地的南极腹地，去探查那个已经变成废墟的基地中到底发生了什么。

游戏的故事在原作的基础上进行了合理的延伸。你不仅要面对那些恐怖的异形生物，还要应对队友们逐渐崩溃的心理防线。这一点恰恰抓住了原作电影中最精髓的部分——人与人之间的互不信任。

【图】白雪覆盖的南极基地外景，风雪弥漫

## 信任系统

本作最大的特色就是独创的"信任（Trust）"系统。在游戏中，你的队友们会根据实际情况对你产生不同程度的信任感。如果你能合理分配武器和弹药，在战斗中保护好每一个人，队友们就会逐渐信任你并服从你的指挥。反之，如果你在战斗中表现糟糕，或是做出了一些令人怀疑的举动，队友们就会对你产生怀疑，严重的话甚至会拒绝执行命令、精神崩溃，乃至开枪射击你！

这个系统的存在使得游戏的紧张感大增。你永远不知道身边的队友中是否有人已经被异形寄生了，而队友们同样在怀疑——你是不是也已经不是人类了？

【图】基地内部的走廊场景，灯光昏暗，血迹斑斑

## 恐惧感的营造

游戏在恐惧感的营造方面做得相当出色。首先是画面上的表现——昏暗的光线、血肉模糊的尸体、突然从暗处窜出的异形，这些都能给玩家带来极大的心理冲击。

音效方面也是本作的一大亮点。风雪呼啸声、金属碰撞声、远处传来的不明声响，以及队友们恐惧的喘息声，这些都在不断地挑战玩家的神经。

【图】异形怪物的特写，触手状的肉体组织从人体中爆裂而出

## 队伍编成

玩家在游戏中可以指挥一支最多4人的小队。每个队员都有不同的专长：士兵（Soldier）擅长战斗、工程师（Engineer）能修理设备和开锁、医生（Medic）可以治疗伤员。合理编排队伍对于通关至关重要。

在某些场景中，你必须让工程师去修复被损坏的发电机才能打开某扇门，或者让医生去救治重伤的NPC才能获取重要情报。如果关键的队员在之前的战斗中已经阵亡或精神崩溃，某些路线就会被封锁。

【图】玩家带领小队在冰洞中探索，手持武器戒备

## 战斗系统

武器方面，游戏提供了手枪、霰弹枪、突击步枪、火焰喷射器等常见的枪械。其中火焰喷射器是对付异形最有效的武器——这一点完全忠实于原作电影。被枪械击倒的异形如果不用火焰烧掉，过一段时间就会复活，而且可能会变异成更加恐怖的形态。

游戏还加入了"血液检测"的要素。在电影中，角色们通过检测血液来判断谁被异形寄生了。游戏中同样保留了这个经典桥段，你可以用检测器对每个队友进行检测，但检测的结果未必100%可靠……

【图】战斗场景，火焰喷射器正在焚烧异形

## 总评

整体而言，《异星物体X》是一款难得的佳作。它不仅忠实地还原了原作电影的恐怖氛围，还通过独创的信任系统为游戏增添了独特的策略性。对于喜欢恐怖游戏的玩家来说，这绝对是今年秋冬不可错过的一款作品。
