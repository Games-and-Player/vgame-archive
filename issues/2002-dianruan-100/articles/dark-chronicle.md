# 黑暗编年史

**DARK CHRONICLE (DARK CLOUD 2)**

| 项目 | 信息 |
|------|------|
| 平台 | PS2 |
| 类型 | 动作RPG |
| 发售日 | 2002年11月28日（预定） |
| 开发/发行 | LEVEL-5 / SCE |

【图】黑暗编年史标题画面，男女主角的卡通渲染风格立绘

由LEVEL-5开发的人气动作RPG《黑暗之云》系列的第二作。与前作相比，本作在各方面都有了长足的进步，尤其是独特的卡通渲染画面让人眼前一亮。

## 卡通渲染画面

本作最引人注目的就是采用了"卡通渲染（Cel Shading）"技术。所有的角色和场景都呈现出类似动画片的画面效果，色彩鲜艳、线条明快。这种画面风格不仅让游戏有了独特的视觉魅力，更赋予了角色们丰富的表情和动态感。

值得一提的是，LEVEL-5的技术实力在本作中得到了充分的展现。虽然使用了卡通渲染技术，但画面的精细度和光影效果丝毫不逊色于写实风格的作品。

【图】卡通渲染风格的游戏画面，展示角色在城镇中探索

## 双主角系统

游戏有两位主角——少年马克斯（Max）和少女莫妮卡（Monica）。马克斯是一个充满好奇心的发明少年，擅长使用各种机械装置；莫妮卡则是来自未来的公主，擅长使用魔法和剑术。

玩家可以在两人之间随时切换，利用各自的特长来克服不同的难关。马克斯可以使用"发明"系统来制造各种有用的道具和武器，而莫妮卡可以通过"变身"系统变成不同的怪物。

【图】马克斯使用发明装置和莫妮卡战斗的画面

## 乔布托系统

前作中广受好评的"乔布托（Georama）"系统在本作中也得到了大幅强化。玩家可以在探索迷宫的过程中收集各种素材，然后利用这些素材来建造和装饰自己的城镇。

乔布托系统不仅仅是一个附加要素——通过建造城镇，玩家可以改变未来世界的面貌。换句话说，现在的建造行为会直接影响到未来世界的发展，这种"因果"设定与游戏的时间旅行主题完美契合。

【图】乔布托建造界面和建成的城镇全景

## 武器进化系统

本作的武器系统也很有特色。武器可以通过不断使用来积累经验值并"进化"。每次进化时，玩家可以选择不同的进化路线，使同一把武器最终变成截然不同的形态。

此外，马克斯还可以将不同的零件组合在一起来"发明"全新的武器和道具。发明系统需要玩家收集各种灵感素材，然后通过独创的"发明照相"功能来获取灵感。
