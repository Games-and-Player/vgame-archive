# 巧克力战争 来自宇宙的侵略者

**CHOCO SENSO: SORA KARA NO SHINRYAKUSHA**

| 项目 | 信息 |
|------|------|
| 平台 | GBA |
| 类型 | 策略RPG |
| 发售日 | 2003年（预定） |
| 开发/发行 | 未定 |

【图】巧克力战争游戏画面，战棋风格的战斗场景

以巧克力为主题的GBA策略RPG。游戏的世界观设定在一个由巧克力构成的奇妙世界中——突然有一天，来自宇宙的侵略者入侵了这个和平的世界，为了保卫家园，巧克力们挺身而出，组成军队迎击敌人。

游戏的玩法是标准的战棋式策略RPG。玩家指挥由各种巧克力角色组成的军队，在网格地图上与敌人交战。每种巧克力角色都有不同的属性和能力，如何合理搭配队伍是取胜的关键。

【图】多种巧克力角色的立绘和战斗场景

虽然题材看起来有些儿童向，但游戏的策略深度并不亚于一般的战棋游戏。而且可爱的画风和轻松的氛围也让不少玩家对这款游戏产生了兴趣。
