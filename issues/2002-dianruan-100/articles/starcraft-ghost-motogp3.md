# 星际争霸：幽灵 / 摩托GP3

## 星际争霸：幽灵

**STARCRAFT: GHOST**

| 项目 | 信息 |
|------|------|
| 平台 | XBOX/PS2/GC |
| 类型 | 动作冒险 |
| 发售日 | 2003年（预定） |
| 开发 | Nihilistic Software |
| 发行 | Blizzard |

【图】幽灵特工Nova的角色设定图，身穿蓝色紧身战斗服

暴雪终于宣布将旗下的经典RTS游戏《星际争霸》搬上家用机平台了！不过这次并不是简单的移植，而是一款全新的第三人称动作冒险游戏。

玩家扮演的是人族的幽灵特工Nova，一位拥有强大超能力的女战士。游戏将以星际争霸的世界观为背景，展开一段全新的冒险故事。在游戏中，玩家不仅可以使用各种高科技武器，还能发动隐身、精神控制等超能力。

## 摩托GP3

**MOTO GP3**

| 项目 | 信息 |
|------|------|
| 平台 | PS2 |
| 类型 | 赛车 |
| 发售日 | 2002年（预定） |
| 开发/发行 | NAMCO |

【图】摩托GP3赛车画面，高速弯道场景

NAMCO的摩托车赛车游戏系列第三弹。本作在画面和操控方面都有了进一步的提升。赛道数量增加到了20条以上，同时收录了2002赛季的全部真实车手和车队。

在操控方面，新作加强了摩托车的物理模拟，车辆在弯道中的重心转移、刹车时的前倾等细节都做了更真实的处理。
