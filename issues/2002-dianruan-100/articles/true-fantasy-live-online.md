# 真梦生活online

**TRUE FANTASY LIVE ONLINE**

| 项目 | 信息 |
|------|------|
| 平台 | XBOX |
| 类型 | 网络RPG |
| 发售日 | 2003年（预定） |
| 开发 | LEVEL-5 |
| 发行 | Microsoft |

【图】真梦生活online标题画面和游戏世界概念图

LEVEL-5为XBOX量身打造的网络RPG大作。作为《黑暗之云》系列的开发商，LEVEL-5的实力已经得到了业界的认可。这次与微软合作开发的网络RPG，有望成为XBOX平台上的杀手级应用。

游戏的世界观设定在一个充满幻想色彩的大陆上。与其他网络RPG不同的是，《真梦生活online》非常重视"生活"的感觉——在这个虚拟世界中，玩家不仅可以战斗和冒险，还能享受各种日常生活活动。

【图】卡通渲染风格的游戏世界和角色互动场景

玩家可以建造自己的房屋、种植作物、饲养宠物、与其他玩家交流互动。游戏中的NPC也有着丰富的日常行为，让整个游戏世界充满了生活气息。

在战斗方面，游戏采用了即时动作战斗系统，多名玩家可以组队进行合作战斗。LEVEL-5精心设计了大量的迷宫和BOSS战，确保冒险部分同样精彩刺激。

游戏的画面采用了与《黑暗编年史》类似的卡通渲染风格，角色表情生动、动作流畅。由于XBOX的在线网络功能完善，本作可以支持大量玩家同时在线。
