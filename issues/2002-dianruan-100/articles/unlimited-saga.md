# 无尽的沙加

**UNLIMITED: SAGA**

| 项目 | 信息 |
|------|------|
| 平台 | PS2 |
| 类型 | RPG |
| 发售日 | 2002年12月19日（预定） |
| 开发/发行 | SQUARE |

【图】无尽的沙加标题画面，以水彩画风格呈现的角色群像

SQUARE旗下另一大RPG系列"沙加（SaGa）"的PS2新作。本作由系列之父河津秋敏亲自操刀，在游戏理念上做出了大胆的创新。

最引人注目的是本作独特的画面风格。《无尽的沙加》并没有采用当下流行的全3D写实风格，而是以水彩画和版画为灵感，创造出了一种极具艺术感的独特画面。整个游戏世界看起来就像一幅活动的水彩画卷。

【图】水彩画风格的冒险场景和角色特写

在游戏系统方面，本作也延续了沙加系列一贯的"自由"理念。游戏有7位主角可供选择，每位主角都有各自独立的故事线。玩家可以自由选择攻略顺序，不同的选择会导致不同的故事发展。

迷宫探索采用了"棋盘"式的移动方式——玩家在棋盘格上移动，根据停留的格子触发不同的事件。这种独特的移动方式虽然与传统RPG不同，但很好地体现了桌游（TRPG）的感觉。

战斗系统则采用了"转盘"机制。角色的行动效果由一个旋转的转盘决定，玩家需要在正确的时机按键来停住转盘，以获得最佳的行动效果。
