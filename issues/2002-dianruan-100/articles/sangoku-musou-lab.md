# 真·三国无双2猛将传 全武将武力值&连技

**游戏研究所**

文／小孔

猛将传在日本已经突破50万套大关，向着真三国2的全球一百万记录进军。在国内，《猛将传》基本上也是近期配套主机销售的必备游戏了。发售两个月，玩家的5武基本上应该都已经拿齐了吧？不过，为了达到真正完美的境界，还需要更深入地研究才行。

## 表格注释

| 图标 | 说明 |
|------|------|
| 攻击力（攻） | 表示通常攻击（□）和蓄力攻击（△）的基本攻击威力 |
| 马攻击（马攻） | 在骑乘状态时的攻击力，包括骑着马到骑马之间的攻击力 |
| 无双槽（无双） | 表示无双槽长短的数值，越长的话无双乱舞的持续时间更长 |
| 弓攻击（弓攻） | 关系到弓嫌的攻击力。三种不同的弓攻击，其防御值也不同 |
| 防御力（防） | 武将的防御力。值越高，受到攻击的伤害越小 |
| 骑乘防御（马防） | 骑乘状态时的防御力，一般来讲比常态的防御力要低些 |
| 耐力横（体力） | 表示体力横长短的数值。横越长者越大，耐打 |
| 移转力（移转） | 关系到跑跃距离的高度。这里指的是踏空的移转距离 |
| 跳跃力（跳跃） | 关系到跳跃距离的高度。值越高跳得远 |
| 华丽连击（华丽） | 受到弓攻击时的防御能力。可以说是真三国无双中最重要的能力值1 |

5段评价中，即使同样得到满分，也有将近千差万别的差异。
