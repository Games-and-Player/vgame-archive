# 陆行鸟乐园

**CHOCOBO LAND A GAME OF DICE**

| 项目 | 信息 |
|------|------|
| 平台 | GBA |
| 类型 | 棋盘游戏 |
| 发售日 | 2002年12月（预定） |
| 开发/发行 | SQUARE |

【图】游戏标题画面，陆行鸟角色在色彩缤纷的棋盘世界中

在最终幻想系列的人气角色陆行鸟又有新作登场了。这次来到GBA平台的《陆行鸟乐园》是一款以掷骰子为核心玩法的棋盘类游戏，类似于大富翁式的游戏形式。

游戏的玩法非常简单直观——掷骰子前进，到达不同的格子会触发不同的事件。有的格子可以获得道具，有的格子会遭遇敌人，有的格子则会发生特殊事件。游戏中加入了魔法卡片的要素，玩家可以收集各种魔法卡片，在关键时刻使用来扭转战局。

【图】棋盘游戏画面，展示陆行鸟在棋盘上移动

本作支持多人对战模式，最多4名玩家可以通过GBA连接线进行对战。在对战中，玩家之间不仅要比拼运气，还要善用手中的魔法卡片来阻碍对手或帮助自己。

角色方面，除了主角陆行鸟之外，还有莫古利、仙人掌等FF系列的经典角色登场。每个角色都有自己独特的特殊能力，为游戏增添了策略性。
