# N.U.D.E. / 混沌军势

## N.U.D.E.@Natural Ultimate Digital Experiment

| 项目 | 信息 |
|------|------|
| 平台 | XBOX |
| 类型 | 交流模拟 |
| 发售日 | 2003年（预定） |
| 开发 | RED |
| 发行 | Microsoft |

【图】N.U.D.E.游戏画面，机器人女孩P-Chan的3D模型

XBOX独占的全新类型游戏。玩家通过语音识别和XBOX的通讯设备与一位名叫P-Chan的机器人女孩进行交流。P-Chan会根据玩家的语音指令做出各种反应，随着交流的深入，她会逐渐学习并成长。

游戏利用了XBOX的语音识别技术，实现了一种全新的人机交互方式。玩家可以通过语音来命令P-Chan做各种动作，她也会用语音来回应。这种交流方式让游戏充满了新鲜感和未来感。

## 混沌军势

**CHAOS LEGION**

| 项目 | 信息 |
|------|------|
| 平台 | PS2 |
| 类型 | 动作 |
| 发售日 | 2003年（预定） |
| 开发/发行 | CAPCOM |

【图】混沌军势游戏画面，主角挥剑战斗

CAPCOM的全新动作游戏。游戏的世界观设定在一个充满黑暗与混沌的中世纪奇幻世界。主角是一位能够召唤"军势"（Legion）的骑士，这些军势是由各种魔物组成的战斗部队。

战斗系统是本作的核心。主角不仅可以使用剑进行近身战斗，还能召唤不同类型的军势来协助作战。不同的军势有不同的特性——有的擅长近战，有的擅长远程攻击，有的则具备辅助能力。如何在战斗中合理搭配和切换军势，是取胜的关键。
