# 秋冬27款RPG大作通缉令

【图】特辑标题页，深色背景配大字标题"秋冬27款RPG大作通缉令"，周围环绕各RPG游戏的截图

**RPG WANTED**

在今年的TGS2002上，各大游戏厂商争相公布了大量的RPG新作。从这个秋天开始，一直到明年春天，将有超过27款RPG大作陆续登场。这些作品涵盖了PS2、GC、XBOX、GBA等多个平台，从传统的日式RPG到创新的新概念RPG，阵容之豪华令人目不暇接。

本特辑将为大家逐一介绍这些即将到来的RPG大作，让玩家们提前做好"银弹"准备！

**收录游戏一览：**
- 最终幻想战略版ADVANCE（GBA）
- 王国之心FINAL MIX（PS2）
- 真·女神转生III nocturne（PS2）
- 宿命传说2（PS2）
- 黑暗编年史（PS2）
- 半熟英雄对3D（PS2）
- 无尽的沙加（PS2）
- 塞尔达传说GC（GC）
- 真梦生活online（XBOX）
- 巧克力战争 来自宇宙的侵略者（GBA）
- 克罗诺亚的冒险 传说的星之勋章（GBA）
- 口袋妖怪 红宝石·蓝宝石（GBA）
……等27款
