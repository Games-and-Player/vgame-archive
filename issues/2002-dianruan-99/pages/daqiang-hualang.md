# 大墙画廊 vol.97

【图】读者投稿的游戏同人画作，本期收录多幅作品：

**《心跳回忆3》** 广西 官忠宁
【图】心跳回忆3女性角色插画，橙色头发的女孩

**《沙卡特的表弟——》** 广西 莫宁
【图】CAPCOM风格的搞笑漫画，有问号和感叹号的角色互动

**《八神暴走之谜》** 鞍山 刘璇
大蛇堆对火前问？

**《黄金的光头》** 福建 季翔
【图】四格漫画风格的搞笑画作

**《KOF 玛利》** 三个字：太美了。
【图】KOF2001中的MARY角色插画，标注“KOF2001 MARY”

**《舞》** 内蒙古 RICKY
【图】不知火舞的插画，标注“RICKY”

**《永恒传说之梅露蒂》** 贵州 陈筱沙
不知道陈小姐有没有看约《传说》的动画？非常的精彩，音乐更是好听的没话说，推荐你看一下永恒。

**《桔右X》** 云南 李毅
李读者来信严厉批评攻略质量要加强，我们虚心接受，今后也会在这方面下一定工夫。

**《鬼武者们》** 广西 卢凯
据说很心疼，打到到一半的时候，PS2“咔吧”了……

**《邂逅》** 广东 罗建东
看来身经百战的特种兵与新上任的小警官的确不是一个级别，利昂汗都下来了，斯内克楞是连眼睛都不停……其实风林玩MGS时也觉得初遇不死男的场景非常有BIO的感觉呢。
【图】生化危机与合金装备角色的跨作品同人画，利昂与斯内克

**《樱大战·疯林入队》** 北京 筋肉人
说实在的，起初看到还真有些反胃液的感觉，为了不让筋肉先生再寄来更加恶心的画稿，在此回答一下筋肉先生的问题——圆珠笔画不行！再看看这幅画……真是着实的“恶心”啊！

**《夏日·乐》** 重庆 胡乱飞

**biohazard:zero** 山东 周磊
这个偏作品不用说，“赶紧发售了”，讲话是在给GC和BIO宣传了，说这是广告吧？那快发售！不知道届时周读者会不会在第一时间购买？2DVD，7800日元，也达送送一块“卡吧。

**《最终幻想X》** 江苏 邵明儡
老朋友了，不得不佩服其画稿的精美……
【图】FINAL FANTASY X角色插画，标注”FINAL FANTASY“
