## 玛莉赛车64

| | |
|---|---|
| 厂商 | 任天堂 |
| 类型 | 动作RAC |
| 娱乐度 | ■■■■■ |
| 稀有指数 | ★★★★☆ |

这款N64游戏发售于1996年底，至今仅在日本就已售出228万套，在全球更取得了900万套的惊人销量。我是在1997年初托人从香港SOGO买回来的，刚到手试过后不是很满意，感觉太简单有些失望。后来偶然在网上发现日本的网站上有许多本作的研究和隐藏要素，以及单机挑战时间模式的排行榜，这些内容重新激起了我对玛莉赛车64的浓厚兴趣。此后的很长一段时间里，我的这盘卡都没从N64机上

拔下来。通过不断的练习和钻研，深刻体会到玛莉赛车64的独特魅力，并且在时间模式中打进了日本网站排行榜的第二名（海边赛道）。看到自己的签名和成绩登录在异国也乡的网站上，心情无比喜悦的同时更加期待续作的到来。

——江汗

## 铁臂阿童木

| | |
|---|---|
| 厂商 | KONAMI |
| 类型 | FC游戏卡 |
| 娱乐度 | ■■■□□ |
| 稀有指数 | ★★★★☆ |

柯那米公司出品《铁臂阿童木》（见图）是一款动作解谜游戏。总共只有8关，因为有解谜要素，还是很耐玩的。有一关居然是播一段向八音盒一样的音乐后，要你敲击5口音韵演奏出来，真想得出来。阿童木飞起来很英武，而一旦能量用完了来水博士就会到出来忙前忙后的修理，游戏的音乐富有童话色彩，所有这些让人通关后回味深长。

——将霸奋

## 塞尔达传说64

| | |
|---|---|
| 厂商 | 任天堂 |
| 类型 | 3D动作RP |
| 娱乐度 | ■■■■■ |
| 稀有指数 | ★★★★★ |

经典之中的经典，获得40分的评价曾经一度成为人们津津乐道的话题。它的推出，告诉了人们什么是游戏，游戏到底是什么样子。游戏的音乐效果无比的震撼，尤其是选择SURROUND音效的时候，那强大的音场让人如同身临其境。游戏的音效可以在立体声、单声道、耳机、环绕声四种里选择。受到卡带容量的限制，游戏的人语十分的少，玩惯了PS游戏的人看着屏幕上一行行无生生蹦出的小字可能会有一点不适应。游戏画面有着电影般的效果，镜头的推拉摇移的运用有着很高的专业水准。游

戏结束后的ENDING画面，儿时的LINK与ZELDA公主相见的蒙太奇镜头令人感动不已，有情人终成眷属。在操纵上，更是用上了N64手柄的全部按钮，值得一提的是，PS2手柄的256阶感应在早在N64手柄上就已经体现，只用摇杆，你可以控制LINK进行4种不同速率的移动，随着移动操作的力度不同，你可以让LINK做出各种幅度的动作。游戏本身可以储存三个记录。本游戏对应震动，借助震动，你可以发现游戏里的更多秘密。本人是在玩了7遍以后模拟器尝试全身解数后才得到这盘全新的卡带的。

——赵琳
