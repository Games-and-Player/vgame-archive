● 上期对XBOX的正确开关机的方法进行了详细说明，这次将其他机种一并补充，以飨读者。

——GBA——

开机：没什么特别的，把卡带插实，拨动左下的开关即可。

关机：先同时按下“A + B + START + SELECT”四个键，使游戏回复到标题画面，然后再拨动开关即可。

——GC——

开机：插好电源，按OPEN打开主机盖放入游戏，合上盖子按下POWER即可游戏。

关机：先按RESET键将游戏回复到标题画面，按OPEN键打开盖并取得游戏，合上盖子关机即完成。

PS2的方法在以前的杂志中提过，在这里就不再重复。

作为一名《电软》的元老级读者（我从第一期到现在都有），想对《电软》的最近的改革说两句。《电软》作为TV游戏杂志界的龙头老大（至少我是这样认为的），真的有很多令人担忧的问题。《电软》给人的感觉是越来越酷漂亮了，但是里面的内容却越来越空洞，使可看性越来越低了。据我所见，目前很多《电软》的老读者都是凭着和《电软》深厚感情去买《电软》的，因为这已经成为了每月的一种习惯了，我也是这样的。《电软》目前在不断的改版，应该说这是一种进步，但是《电软》的改版给人的感觉有随波逐流之嫌，在我的印象中，以前《电软》总是敢为人所不为，总是走在整个TV游戏杂志的前列，但如今《电软》却在模仿别的刊物进行改革，在这里我想说的是，《电软》改革应该搞自己的东西，而且是能留住老读者、吸引新读者的东西，假如再这么久下去，真的想让《电软》到底还能走多远？再说一句，《电软》最近两期的改版的一些好的冬都还不错，给我们很大的方便，但是《电软》上了巷之后从这么又多大攻略呢？不感觉有点面积也派走的吗？

再说说点评部分。看起来四位编辑除PERFECT君外都很喜欢硬派游戏，那么给“R”28分我也无话可说。最不能容忍的是game bar，看着重着都写了些什么，“游戏居然进化到如此的地步，要远超越PS”绝对是没有人有异议的。“超酷PS？”弄！

——伪机战迷 胡宾 艾泰

谢谢指出那些峰的缺点与问题，我们会尽快联系作者联系，并督促其改进。

说到点评嘛，始终是相当人化，只能作为参考，而实际情况则需要自己亲身体验才能下结论。

常有来些游戏迷问题：这游戏也们打了吗？就给这么低的分？实际情况如果真大的时，也不可能把每年月十数款游戏统一打看，又且因为截稿时间与工作交替的问题，大部分游戏，评论的编辑尽可能将其完结加赛跑。因此，编辑点评的形式比较给某游戏打了低分，那么这游戏别的渠道同样可能有相关的高分评价（笑）。总的试说，回位评论之人的口味截然不同。
