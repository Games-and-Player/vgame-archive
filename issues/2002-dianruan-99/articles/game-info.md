## PS2 鬼泣2

| | |
|---|---|
| 厂商 | CAPCOM |
| 类型 | AVG |
| 发售日 | 2003年1月31日 |
| 价格 | 未定 |
| 其他 | —— |

大名鼎鼎的帅呆比酷游戏鬼泣已经出了二代。动作上比一代更要丰富，MOTION更加多彩，STYLISH COMBO特意追加了双枪乱打和刀枪并用型。STYLISH的英文意思是什么，大家可以查一下字典。显然，卡普空一方面扮酷装蒜，另一方面还不忘去“恶心人”，瞧那BOSS。

【图】鬼泣2游戏截图两张，展示但丁的战斗动作及BOSS战画面，标注“©CAPCOM CO., LTD. ALL RIGHTS RESERVED.”

## GC 瓦里奥世界

| | |
|---|---|
| 厂商 | 任天堂 |
| 类型 | AVG |
| 发售日 | 未定 |
| 价格 | 未定 |
| 其他 | Treasure协力? |

超有名的坏蛋角色WARIO在NGC上登场了。这次的游戏好像有财宝公司参入，不知会增加何种新鲜要素？但有一点，场景变成了全3D，瓦里奥的动作更加变化多端，这是可以肯定的。其实解谜要素应该不会被削弱，只会更强。NGC的长处是巨型BOSS和光影效果，相信会让迷友满意。

【图】瓦里奥世界游戏截图两张，展示瓦里奥的3D动作场景及COMBO连击
