# 无双报道

## 汽车模型 Auto Modellista（PS2）

PDF 118-119 / 刊页116-117

厂商：CAPCOM　类型：RAC　媒体：DVD

CAPCOM推出的独特赛车游戏，最大的特色是采用了卡通渲染（Cel-shading）画面技术，使整个游戏看起来就像是一部动画作品。

【图：Auto Modellista游戏画面截图，展示卡通渲染风格的赛车画面】

游戏中玩家可以自由改装车辆的各个部件，从引擎、悬挂、轮胎到外观涂装都可以自由定制。改装系统的深度相当可观。

此外游戏还支持网络对战功能，玩家可以通过PS2的网络适配器与其他玩家进行在线竞速。

【图：车辆改装界面截图】

## 装甲核心3 Armored Core 3（PS2）

PDF 122 / 刊页120

厂商：FROM SOFTWARE　类型：ACT　媒体：DVD

FROM SOFTWARE的经典机甲动作游戏系列最新作。玩家操纵高度可定制的装甲核心（Armored Core）机甲执行各种任务。

游戏延续了系列一贯的高自由度机甲定制系统，玩家可以自由组合头部、核心、手臂、腿部、武器等各个部件，打造自己理想中的机甲。

## 节奏武术 Martial Beat（PS）

PDF 123-125 / 刊页121-123

厂商：KONAMI　类型：ACT/音乐　媒体：CD

KONAMI推出的独特音乐动作游戏，将格斗动作与音乐节奏结合。玩家需要跟随音乐节奏进行格斗动作，包括出拳、踢腿、防御等。

### 6大游戏模式

游戏提供了6种不同的游戏模式，从单人故事模式到双人对战模式，玩家可以根据自己的喜好选择。

### 基本模式

基本模式是游戏的核心，玩家需要按照屏幕上显示的节奏指示做出相应的格斗动作。准确度越高，攻击力越强。

### 攻击模式

攻击模式中玩家可以使用更多的连续技和特殊技能，增加了游戏的策略深度。
