龙哥您好。

您的信已收到多时，只等（电软十期）上以刊登 + r1 + 中的游戏难题。刊登了我的那封信使我吃惊不小，仅过数天，全国各地的信件就像雪片一样飞来，我一直遵循 + r1 + 的家训。一时间，忙碌不亦乐乎。来信的内容，赐教甚多，正确率约40%。更多时是在游戏中遇到的各种难题，以求交流。几乎每封来信，都好奇地打听我年龄这么大大还着地玩游戏机的原动力，也都提到了怎样练字的问题，所以再去信给您，想借贵刊一角，给那些写了信的、正在写信的、准备写信的和无暇写信的玩友们，答复大家关心的问题。可否？

## 老玩童的一封信（自题）

《电软》十期刊登我一封求教信后，全国各地的来信像雪片一样飞至，就朋友们关心的问题再写一信，让玩友们参考。

一、 + r1 + 是一部知识性很高、紧张和轻松相结合的优秀电子游戏，特别是隐藏了中国女将——李华梅，将可歌颂争霸世界的内容，激励国人不玩到底不罢手的信心，但多数的出场，又必须将游戏原设定的三人其一——通关方可，而这三人通关成机就成了玩友们交流的热点，难题却出在最后一个上，玩友来信指教和试做的经验写在下面：

**1. 葡萄牙航海家ラファエル（拉斐尔）**到日本大阪后，酒吧八姑先收了从新德哥尔摩金买来的 + r1 + 这件礼物，然后以美丽的面容和迷人的眼光告诉你，她想尝尝葡萄酒是否比日本的酒好喝？你远游澄洋，在远东西半球，送上地中海产的葡萄酒后，她又提出想看穿丝绸的嫁衣，这样子得八姑高兴以后，领你去城外金阁寺看到那令人面色以鬼的老和尚指点，去库页岛北纬51度引一半地图就是了，这丝绸的嫁衣，要去E日买洋好买。

**2. 蟋蟀船队提督ホトラム（荷特达妈）**到日本大阪后，酒吧八姑见魅力值为100的伊邦三王女七5（蒙拉）在其左右，不敢猎狂只收 + r1 + 礼物后，她指点于了金阁寺，不料老和尚竟要见 + r1 + 所谓元帝之形，不是画像、照片之类，而是一柄 + r1 + ，获得大刀的条件是必须有非洲的金币（阿克斯姆王的金印），到中国泉州港广场，遇到谋的老人，他验证金印后，告诉你/大刀的信息，然后你就去找吧，找到后不要拔去，去见和尚，老和尚指点迷津。

**3. 荷兰商人りりル（莉露）**最后一站是加勒比海的哈瓦那（现在的古巴），同业工会要求你在地中海制做或买红柿的流行（トマト）在这里你还可以看到西红柿的种子，到意大利的热那亚那，让神父在广场配布商品，制造西红柿的销售流行，如果在地中海种植了西红柿，就不必穿越大西洋。同业工会找来当地土著，帮你去遗址找到有另一半地图的小刀了。

顺便提一下，我89年出差泉州时，在广场拍照时拾到公文包在路旁栏杆上，走时忘了拿，公文包的丢失当然是我自己的责任，一点不能怨泉州，后惹来了一堆麻烦，所以玩游戏时，也不再去广场了，自然见不到迷的老人，但却发生了这样的事，到了地中海和的大港时，碰上成败流落街头的海盗头子，他送给了我这把大刀！只是后来去大阪时装备在中间身上，老和尚不认。我想游戏中还隐藏着其它情节，只是不知罢了。

二、电子游戏和电视剧、电影一样，是一种健康的娱乐活动，电子游戏给你提供了广阔的空间，任凭你去发挥自我。提高想象力，学习知识，解脱积累的压抑。说白了，电视剧、电影是导演在 + r1 + 我，电子游戏是我玩它，怎能不得人喜爱呢？仅是知识一项，不是吹牛，我现在可以不用地图，就可以勾划出世界地图和中国地图的基本图来，只要你随便讲出一个经纬度，我可以准确的指出它的地理位置，问回到的老家IX，也行吗？（地理学家除外）。至于上年纪的人，大都对电玩有偏见，我不愿瞒我的看法，其原因第一是他不懂，第二是也没那福气！我曾给一位玩友复信中写到：秦始皇何等伟大，没有用过手电筒，唐太宗何其英出，也没有骑过自行车！原因是世代之差，现代就是电子时代，电子娱乐你不去学学，这要横加干涉，怎不叫小辈们耻笑！啃老卖老者，常常把自己摆在优瓜的位置上。当然，我也不是劝望要劝只要电玩，不要学习的小朋友们增壁，学习是第一重要的哦！我真的很能收到比我年纪大的玩友来信。

三、题外之谈，龙哥刊信时附言我的字写的好，真是着亲我也，其实龙哥的字在我之上，有雄厚的功底，机智而豪放，很有书法家之风，真是后生可亩啊！至于练字，古人训：字无百日功，苫日可练察出来的字，该不比找到 + r1 + 难上，方法是，找一本自己喜爱的钢笔帖，买一本方格稿纸，一百页，从簡入难，一字一行，以实照写，前十日间直不是写，是照着认真画（画不像不要紧，但这三个月中，千万不要用原来字体写任何文字。三个月后，你会大吃一惊的），原来的字体想写也写不出来了，夺回的字体也会使你的字体也会让同学朋友不断地赞叹。

是龙哥把我带入了一个美妙的世界，一封充满真诚热心和友谊的信到了我手中，体会到人间真诚的关心和爱，十分激动，这和团队精神，早已超出交流电玩的范围，这么多朋友一下子出现在面前，感觉真好！谢谢龙哥！

（信致：新疆乌鲁木齐市博物馆小区68幢02室 王道勤，830000）
