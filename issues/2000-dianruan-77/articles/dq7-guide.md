## 被神秘石版引导的少年们在未知的世界中展开冒险！

### 攻略要点提示

A. 游戏进行的一个关键是石版的搜集。除了参看本攻略的说明之外，一条捷径是前往现在的佛利休村（フォーリッシュ，也就是那个曾发生过机器人事件的村子）东边的盆地中找一位老者询问石版的下落（游戏中确实有许多即使完成了情节也无法直接入手的石版，本人认为这是DQ VII系统的一大弊病！），不过她的提示相当隐晦，绝非 + r1 + 、 + r1 + 那么简单明确的说明，还是找一个懂日语的 + r1 + 吧！

B. 游戏中有很多宝箱在初次碰到时是无法开启的，往往要等到游戏推进到一段，得到钥匙后才能解决（如 + r1 + ）。玩家遇到这样的宝箱时不妨做个笔录，因为游戏的世界实在太大了，恐怕在进入后盘时你已经将未开启宝箱的位置忘记了。

C. 游戏中 + r1 + 或 + r1 + （ + r1 + 或 + r1 + ）的选择很多，一般分为三种情况：一是根本无关所谓，选什么都不会影响情节的发展；二是会引起短暂的分支，但最终会强制到达同一结果；三是真正意义上的分支，毕竟主角们是创造历史的英雄，在过去的时代进行的错误选择必然会影响历史的面貌。不过好幸游戏中90%以上的选择都是前两种情况，因此在通常情况大可直接选 + r1 + 了事。

## 起点——鱼铃村（フィシュベルの村）

游戏开头的世界只限于这个小小的渔村。虽然看起来有很多离开这儿的方法，但游戏的系统却把它们一一堵住了，只有老老实实的回家睡觉（在二层的床前调查即可）。这是不需要花钱的宿屋，游戏初期钱很紧，不妨经常回这儿休息。

第二天起床拿了三文治去码头找父亲，老爸让主角下船帮忙打扫卫生，结果扫出了船里想偷偷出海的玛莉贝尔（マリベル），她是主角青梅竹马的好朋友。

渔船在大家的欢呼声中出海了，主角则在回家的路上碰上了国王的士兵，他们主角转达了国王的邀请。那么回家和母亲打个招呼，拿了袋子后与玛莉贝尔一起进入更广阔的游戏世界吧。

## 世界唯一的城市——艾斯达特城（エスダート）

背负继承国位使命的基发（キーファ）并不是一位和顺的王子，因为他总向往着冒险，希望去探索出更加广阔的世界，而艾斯达特城下町的一间隐秘屋中蕴居的主角的叔父洪达拉（ホンダラ）那儿的 + r1 + ，另外一件是在地下阶梯旁边的井中得到的 + r1 + 。只要找到一件就可以去无名遗迹了，把得到的道具试着镶在石像上，没有任何反应，但却由此发现了基法在石像上留下的纸条—— + r1 + 。那么返回艾斯达特城，见到基法，这时那位学究先生的解读也完成了。原来解除封印并不需要什么宝石，而是需要具有特殊宿命的人用心去祈祷。竟然这么简单，一行人兴冲冲地赶往遗迹，但是前来接王子的士兵却挡住去路，无奈，只有一个人先回家。

晚上两个人碰头后再去遗迹，在石像前祈祷一阵后神殿的封印果然打开了。大家在其中四处乱转，解开若干个谜题后来到了神殿深处的一大堆石版台面前，不过现在还拼不出完整的一块，只有再去寻找。

主角独自回村，老爸已经丰收而回，而且还带来了一块从海里打捞上来的石版。于是带着石版找到基法，正当主角准备再次进入遗迹时，玛莉贝尔突然出现，看来只有结伴同行了。

在完成了第一块石版后，神奇的事发生了……

## 通往过去世界的大门——无名遗迹

艾斯达特城的西部有一座的神秘殿，大家则不知道这是什么人建造的，也不知道建造时间和建造目的。

当主角来到遗迹时候恰逢王子基发在这里独自调查，基发拿出 + r1 + 查阅，但结果却一无所获。于是基法委托主角去寻找能够看懂 + r1 + 的人，自己也去找其它的线索了。

其实艾斯达特城下町东北角的地下阶梯下正住着这样一位世外高人，把古代文书留在那里即可。由于解读古代文书需要一段时间，所以主角现在可以去想办法解除那座连王家秘石都没能解除的塑像的封印。

这时能够找到两件似乎有用的道具，一件是在艾斯达特城下町的一间隐秘屋中蕴居的主角的叔父洪达拉那儿的 + r1 + ，另外一件是在地下阶梯旁边的井中得到的 + r1 + 。只要找到一件就可以去无名遗迹了。

盛开着同样花朵的地方——伍德帕尔纳

在穿过一道光的旋涡后，三个人来到了一片旷野上，谁也不知道这是哪儿。玛莉贝尔摆起了小姐脾气，反怪主角和基法把自己带到了奇怪的陌生地方，一个人嚷着要回家就离开了。结果却碰上了三只史莱姆（スライム），这在艾斯达特城的历史上可是传说中的存在。三人合力干掉史莱姆，开始探索事情的究竟。来到一片基地前（其实是两座孤岛），自称玛梅尔达（マチルダ）的美女（可能是！）正在这里扫墓，吃惊之余她自言自语，要是有花就好了。确实，在伍德帕尔纳竟然看不到一朵花，玛莉贝尔热心的拿出花将送给了玛梅尔达，玛梅尔达非常高兴，并主动为主角一行带路前往附近的村庄。

但在进村时，玛梅尔达却不辞而别了。

照旧，这又是一个面临灾难的村子，魔物还在蹂躏这座村民，它们抓走了村子里所有的女性，还摧毁村子里所有建筑物，并且不许重修。剩下的男人们或坐或躺，老老实实的等待着末日的到来，而村子里仅存的勇者也被魔物所伏，卧床不起，只有他的孩子独自照料他（躲在村中唯一还完好的屋子里）。人命要紧，大家要赶快找到能治百病的绿色晶石。

主角在西南的废矿山中见到了玛梅尔达，她提醒主角注意矿井中的魔物，而后又匆匆离去。当你不容易来到最深处看到绿色晶石，玛梅尔达又突然出现，告诉主角绿色晶石易破碎，一有震动就会变成粉末，说罢大显身手，用魔法切取一块绿色晶石后再次离开了。

果然是好药，勇者的病情很快好转。主角决定先去宿屋度过暂一觉。次日清晨，大家与恢复后的勇者一同赶往了旁边的塔。

进塔后先干掉石头人，再把一只小螃蟹打得半死，小螃蟹临死一直喊着 + r1 + 。果然老大出现了，竟然就是玛梅尔达，不过她手起刀落杀掉了小螃蟹。

原来玛梅尔达是伍德帕尔纳前任勇者的妹妹，前任勇者也曾单枪匹马杀入魔窟，不过运气较差，没了个有来无回，而胆小的村民始终坐视不管，无奈之下玛梅尔达只得孤身一人去救哥哥（或送死），但是魔窟中的总BOSS竟然说服了玛梅尔达，这样玛梅尔也成了魔族中的一员。现在总BOSS不知如何，玛梅尔达自然就成为了这里的总BOSS。但她人性未泯，所以才一再帮助主角们。不过现在的玛梅尔达已经下了必死的决心，无反顾的让勇者们杀死自己，因为她的生命就是能使被石化的女人们获得自由的钥匙。主人公三人下不了手，从战斗中跳出来，但勇者还是狠下心来把玛梅尔达杀了。玛梅尔达临终前告诉主角，只要回到来时的地方就能返回自己的世界了。

经过和来时一样的光之旋涡，三人又回到了神殿。

在艾斯达特城，人们正在因为在艾斯达特城北边出现新的陆地而奔走相告。而主角的父亲正好去王城报告到新陆地考察的情况去了。于是大家去皇城找基法，可基法不在王城。最终大家在翻译古代文书的老者学究家找到了基法，基法对国王不让自己去考察新大陆非常不满，叫嚷主角在村里的老地方等他。

村里的那个洞穴可以通向一个地下码头，这里藏着主角三人合力整修的一条船，那么去探险吧！

原本在地图上并不存在的陆地真的出现在了三人眼前，而这里的村子同样也叫伍德帕尔纳，但物是人非，伍德帕尔纳再没有恐怖的气氛，勇者和魔物，不过勇者从魔物手中拯救村子的传说却在这里广为流传，同样遗留下来的还有那开遍村子的艾斯达特城特有的花朵……

神殿原来是通往过去世界的大门，由于近古发生的灭绝，使伍德帕尔纳所在的陆地从世界上消失了，但经过主角们的努力，伍德帕尔纳逃过了毁灭的命运，重新在世界上出现了，主人公一行三人成了改变历史的英雄。

### 迷信的火祭——恩果

在现在的伍德帕尔纳村中可以找到一块石版，而在曾找到绿色晶石的矿山中也能找到一块。这是游戏中惯用的手法，因此旧地重游是绝对必不可少的！

回到艾斯达特城找国王汇报，不过国王和老爸的谈话还在继续。趁此机会大家可以在王宫里四处转转，在一廊通往地下的兵发生了争执，王子出面解决，四人一起进入了地下通道。

在地下又有一位老者，主角把这次的事原本讲了一遍，老者似乎明白了什么，问老者学究是不是要把那个东西给主角一行，老者学究笑着点了点头，于是三人照着主角，把古代文书和石版交给了主角。

在神殿中又完成了一块石版，在这次到达的陆地东南方，有一座名为恩果（エンゴウ）的村子，这里的人们崇拜火的力量。在村中最大屋子中找到村长，村长高兴地邀请这三位旅行者参加一年一度的火之祭典，不过时候还未到，需要先去宿屋住一晚！

但是在村中德高望重、懂得占卜和治病的巫女却极力反对今年举行祭典，她认为那样会引起火山喷发。可是村人并不相信女巫的言论，没办法，巫女只有委托主角一行去解救恩果村。由于火山在祭典进行到高潮时才会开放，因此只有再去宿屋消磨时光。

祭典开始了，大家举着火把向火山出发，主角一行人有幸成为今年第一个往火山口下方的洞口扔火把的人。扔下火把后，赶快前往火山口下方的洞口，在火山口的底部肯定有什么东西存在。

每前进一段距离就会有一个村民扔下火把，按照巫女的预言，当最后一个火把投下时，火山就会大爆发。幸好在此之前，主角已经赶到了火山底部，这里一个石像怪正在用村民扔下的火把蓄聚村民的信仰，令人邪恶的黑色火焰不断膨胀。主角三人冲上前去消灭了石像怪，但黑色的火灾却没有因此消失，反而飘到了火山口。遵照巫女的叮嘱，消灭这邪恶的火焰必须依靠具有神圣力量的东西，而所谓神圣的东西就是在神殿通往石版入口上的七彩泉水，而叔父洪达拉的房间中正有许多空瓶，还是回现代一趟吧。

找到叔父洪达拉，没想到他已经为主角准备了一瓶冒着的圣水（すごい圣水）。那么赶快返回恩果火山口泼灭黑色火焰吧。至此，主角们又一次拯救了世界。

返回恩果的巫女站，她又给了主角一块石版。

### 寻找未来的希望——戴亚拉克

经过一番与家庭的抗争后，三个人又走到一起了，并在现代的恩果火口找到了一块石版，这样又可以前往新的领域了。

这次的小岛上只有一个孤伶伶的村子，而且村子里除了好多石像外，只有一位老者。他告诫大家不要在这儿逗留太久，并把一瓶能解除石化的药交给了主角。

主角决定先在宿屋里休息一下。深夜，屋外却传来了哭诉的声音，主角独自出屋，发现石像们都在闪光，主角试着和他们对话，一段段回忆流在主角的脑海中。

原来戴亚拉克村极少降雨，每年都要通过求雨仪式迎接仅有的一次降雨。在某一年的求雨之前，那位当时还年轻的老人出村去买种子，但可怕的事情发生了，紫色的雨水把村民全部石化了，由于老人不在村中才躲过了这一劫难。为了解救村民，他开始奔走四处寻找能解除石化的灵药。但他花了太长的时间，石像被风化得过了片厚，再也无法复原了，老人得在村子里陪伴着这些石像渡过自己的余生。

主角希望能够为这座村子做点什么，因为在村子里石像中少了一个叫约瑟夫（ヨゼフ）的少年。而在村子里，似乎还有一个约瑟夫当时常去玩耍的秘密基地，通过种种线索，主角在枯树的后面找到了秘密基地的入口，但约瑟夫并不在其中，根据种种迹象表明，约瑟夫还有其他的秘密基地，那么另一个秘密基地的入口在哪儿呢。为了寻找约瑟夫其他的秘密基地，主角来到村子的最高处，也就是空心石头柱的顶端（可以从秘密基地里度上去！），撒下了天使之泪，这时唯一不在户外的约瑟夫显然也被石化了，但因为躲藏身处而没有被风化。孩子使用老者找到的药后恢复正常。来到时唯一不在户外的约瑟夫也成了石头，老人看到了未来的希望，他告诉主角一行一个人要带着这个孩子离开这儿到世界各处去旅行，告诉人们这可怕的黑色雨云的存在，而主角则可以在约瑟夫的第二个秘密基地中找到一块石版。

### 动物町——奥菲

回到现代的戴亚拉克，这里已是一片荒地，但可在石柱旁捡到一块石版。这里有一位老人对主角诉说了自己的愿望——在废墟上重建村庄，他委托主角把自己的想法告诉世界各地希望重新开拓自己生活的人们，这也是游戏中的一大系统——移民系统，来到在现代的世界各地都会有一些人问你哪儿有新兴的城镇，把他（她）们都骗到这儿来就可以给它命名了。

这次高人住在艾斯达特岛的西南角，他的动物好像难以沟通，只得和那几位说兽语的人交通，原来在若干年前，这里曾魔物横行，但同样英勇的白狼用它们的 + r1 + 把魔物消灭殆尽，而且只白狼把它们的BOSS封印在了村子西面的洞窟中，但白狼一族也付出了几乎灭绝的惨重代价。战争后，唯一幸存的白狼是一位身怀六甲的母亲，她在生下小白狼后便一命呜呼。而封印也因年久而失效，当年的BOSS也和人和动物互换了身体。

现在的任务很明显了，赶往西山吧。跟着一只狼进到洞窟中，在最深处，狼已被杀死，而在村子里被牺牲的那个小孩子也出现了，伏在白狼身旁痛哭不已。这时BOSS现身，经过一番无法使用魔法的恶斗，大家把BOSS关了笼电一震，可他准备故伎重施，要把主角们也变成动物，这是那个小孩突然冲到了主角面前，一口咬住了BOSS，BOSS碰巧全身麻痹。现在他终于明白了——原来这个小孩就是白狼一族唯一的幸存者，不过现在变成了人的样子。BOSS气急败坏之下，仅有的力量使小白狼再也不能变回原来的样子，然后跳进了石柱中，四人一合力把石柱再次盖上。

小白狼变成的男孩不会说话，但也自称主角，希望和他们一块继续旅行，而他的养父则跟着动物先生回到了现代。在洞窟更深处可以找到另一块石版。

### 人与机器人的故事——佛洛德

这次的世界非常广阔，先去西南方的村落，向西可以抵达犹巴一族的营寨地。犹巴一族是专门寻找并解除神的封印而周到处流浪的种族。这里正在举行选出新一代神之舞姬和神之乐师的仪式，主角们可以先去西面小商店买到石版然后出发，拿到一块石版。

仪式结束，神之舞姬和神之乐师在众人的喝彩下走出帐篷，大家开始一起庆祝。而且基法则好像迷上了神之舞姬，一直围着她转。最后三人一块畅饮犹巴一族特有的饮料，其间神之乐师闯了进来，原来神之乐师一直就在追求神之舞姬，现在半路杀出个程咬金，自然心中不安，不过气氛逐渐缓和，四人一块畅饮起来。

晚上主角偶然醒来，却不见了基法，基法则在英雄救美。妖怪逃走了，但神之舞姬却受伤昏迷。于是明天一早就要去水底神殿解除封印，神之舞姬为了照看父亲只有等到一天出发，但是高开大火入马，安全就没了保障，不过基法决定留下来保护她。

第二天从宿营地的另一端前往水之神殿，在途中的山路会再次宿营。翌日出发后不久要到达了水中神殿附近。神之乐师和主角一块进入洞穴，用大地之鸟护送到水底神殿的湖水，其间可拿到一块石版。

来到神殿前，调查石版后就可以进入神殿，取得两样神器，分别是神之乐师使用的乐器和神之舞姬穿着的舞裙。这时基法也背着神之舞姬赶到了。

原来神之乐师希望在种族的宿命完结后和神之舞姬结婚，而神之舞姬也并不喜欢现在的生活，在各自自由的驱使下，两个人分别使用神器开始了祈求神灵复活的仪式。但奇迹并没有发生，神之乐师失去了精神支撑，说出了自己按照族规并不能和神之舞姬结合的事实，本来以为一族的使命结束后族规也不用再遵守了，神之乐师因而一直隐瞒了事实真相，但现在神之乐师满怀着失望和忏悔离开了犹巴一族。而主角则留下来去把湖水恢复原状。

仍然是在刚开始的宿营地，基法也作出了重大的决定，他要一辈子留在犹巴一族中间，留在神之舞姬的身边。而身份则是犹巴一族的守护者，为此基法还经过了犹巴一族的单挑考试。

基发把主角一行送到了回到现代的光之旋涡旁，在告别后他委托主角把一封信带给国王，最后还把自己的装备扔给了主角。

听到此事的国王当然伤心不已，于是把一块本来准备给基法的石版交给了主角。

在现代的犹巴大陆上，已没有了犹巴一族的踪影，但仍可找到一块石版，于是又可以去新地方冒险了。

### 小雷音寺——达玛神殿

在新陆地的西边有一个为人们而住在达玛神殿（ダーマ神殿，也就是转职神殿）而修建的一个中转站，这里有宿屋、有赌场，也有商店。而再向西就是气派的达玛神殿了。神官长原然竟应让主角三人去转职，在选定理想的职业后，神官长让主角们到身后的水池中洗礼。但是水池却吸走了主角们的力量，在特技和咒法都无法使用的情况下被扔到了一个类似 + r1 + 的世界中，一群被吸收力量的人在这里弱肉强食，靠暴力维持着生态平衡。在村子西边会看到一个昏倒被人打劫，犹义勇为之后来到东边遇到一名原神官卫队队长和一个盗贼的对话，原来盗贼希望加入到神官队伍中，而原队长则希望杀回神殿夺取被夺去的力量。盗贼请主角帮忙，并暂且主角们一下马哉（这一仪似乎输无妨），随后在村子背北的地方出现了BOSS，他赶走了盗贼，并给了主角们一个下马威！

主角苏醒来时发现自己身处一个陌生的小屋，原来是对他依为大姐的姐姐教养了自己。姐姐为人善良，但天生有着腿残的怪病，好在前面提到那位将官战士一直在帮助她，两人之间也似乎有了感情，但弟弟由于太喜欢姐姐，有点嫉妒两人的关系，因此总是气鼓鼓的。离开小屋，再次看见神官战士和盗贼在策划着杀回神殿的事。见到主角到来，盗贼会请主角帮忙并暂且主角们以奇迹之石（可在战斗中无限次回复少量HP）。
