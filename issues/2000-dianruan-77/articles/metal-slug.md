## 大型机METAL SLUG2的游戏技巧（终极权威版）

《合金弹头2》自九八年问世以来，至今还较为流行，对于无数次通关的ACT迷们来说，下一步的追求是什么呢？当然是最高分记录了！因此，笔者就来谈谈获高分的方法。

首先清几条在过关中较实用的小技巧：

**1.** 当你已有 + r1 + 或 + r1 + 弹时，再获取同样的子弹，加150发，当你有 + r1 + 、 + r1 + 或 + r1 + 弹时，再获取同样的子弹，加10发。因此，若你有20发 + r1 + 弹，而马上又有一 + r1 + 弹可获取时，可先将20发先打掉，再去吃 + r1 + 弹，这样就有200发子弹，否则就只有170发。同理，若你有……

**2.** 乘上 + r1 + （即乘物）后，在危急时刻可拉杆 + r1 + 将 + r1 + 启动到开仓状态，然后立即跳出乘物，则此时属于安全状态。但 + r1 + 启动到开仓状态的速度不同，由快到慢的顺序为：骆驼、飞机、坦克、跳蚤战车。

**3.** 只有与敌方的机械兵器，包括飞机、坦克、装甲车及BOSS等物近身时，才可以快速连续地掷手雷，否则一次只能掷两枚。

**4.** 将一种子弹打光后，你会自动进行一个大约要持续1-2秒的换枪动作，此时很容易被敌人偷袭，而在换枪时下蹲一下或跳一下就可消除这个动作，且在用L、H弹时，可用此法来消连发。

当然，游戏前还得注意几条得高分的基本准则：

①尽量一条命不死地通过一关，因为若在一关内死过的话，则你生前所救的俘虏就不能过关，而过关后，每名俘虏加1万分。若是背了包的女孩或是会发气功波的俘虏，则每名加3万分，但救获10个（或以上）俘虏过关，则可额外获 + r1 + 奖分10万。

②尽量用乘物打出BOSS，这样过关后乘物可加10万分，而若跳出乘物打出BOSS，即使乘物未损也不给分。

③尽量近身攻击敌人，这样，无论是用刀砍、锤敲、拳打、脚踹都是一记500分。对于要打高分的玩手来说，要多用此法，尤其是俘虏的绳索、宝箱等等毫无危险之物，要用刀割开，且用刀割一种手持滑膛枪的小兵是一记1000分。

④对于敌方的机械兵器，要尽量用手枪或H、L枪敌乘物的机枪打，而不要用手雷、炮弹或其它武器，在这其中，用L枪最划算。手枪、H枪或乘物的机枪打中敌人一发获100分，而L枪打中敌人4发就获1100分，且若用上述的 + r1 + ，则打一枪L弹有400-500分。

下面将介绍在各关中的赚分技巧。

### ● MISSION1

在途中会遇到三座炮台。可不去打炮台，而去打打炮弹赚分，当H弹快要耗尽时，可将其中两个炮台打掉，再用手枪打剩下一个炮台所发出的炮弹，用此法可在此处赚分5-6万。

过了炮台往前走，会遇上一辆导弹车，不要将其击毁，百弹乘物的机枪打它所发出的导弹以此赚分，较好的方法是：用机枪的子弹做导弹所形成圆的内切线（用此法有一定的技巧，只有多加练习才能做到既保全生命又不打毁敌车又获高分）。

在使用此法时，玩友们会发现：若有个发气功波的俘虏跟在身后，则不准一合几功夫，俘虏就会将敌车击毁，若不去就这个俘虏也并不划算。建议可用此法摆脱他：在敌获此俘虏后会来到三座炮台处，在炮台要出现时，走到最左端，然后从左到右依次干掉这三个炮台，等到一可以走动时，就往前猛冲，则这名俘虏被你摆脱了。而过关后他的记分（3万分）还在。

### ● MISSION2

在此关中，有个鲜为人知的分数密技：在3处宝箱中可能得到 + r1 + （打开宝箱后，若发现打出了 + r1 + ，则不要将其打死，而应将其获取，可得3万分），而玩手若能一条命不死地获取到前两只金蝙蝠和两个阿拉丁神灯（10万分），则他获取到第三只金蝙蝠时，可得30万分。

下面就将方法介绍给大家：首先，在关卡首金字塔斜坡上，会有一个俘虏送你一发火箭，不要去获取。然后，在获取阿拉丁神灯的这条密道内，有两块凸起的方形巨石，且前方有两个宝箱，蹲在第一块巨石的右端，向第一个宝箱掷手雷，可能炸出金蝙蝠，同法，再蹲在第二块巨石的左端向第二个宝箱掷手雷，也可能炸出金蝙蝠，接着去逗阿拉丁神灯，尚若余不得那太大批的金币，可在神灯变灯神的一瞬间获得神灯获取，则还可获取金币，在关尾前打完最后一批木乃伊后，往左走，前方有一宝箱，向它掷手雷（具体位置因机器的差异而异），也可能炸出金蝙蝠。

以上是笔者的多年经验，但玩手们若想获取到那只30万分的金蝙蝠，最重要的还是得有极好的运气，自最《合金弹头2》98年问世以来，笔者从未看到过他人在一次游戏中打出三个金蝙蝠。而笔者本人也只成功过两次，因此可以说，在一次游戏中炸出三只金蝙蝠，其概率不亚于摸到彩票头奖。使用笔者所介绍的方法时，若在前两个宝箱中炸出0-1个金蝙蝠，则在第三个宝箱处，炸出金蝙蝠的可能性较大；若在前两处都炸出金蝙蝠，则要在第三个宝箱处炸出金蝙蝠的可能性较小。当然，上述所写的不一定是唯一方法，望有知道好方法的高手能在电软发表一下高见。

### ● MISSION3

在此关中有许多地方可赚取分数，例如在此关中有许多手持圆牌盾的小兵，可先用枪打他们的圆牌28下，再用刀去砍他们两下（一下1000分），则一个小兵就让你获5800分。在火车的车身有两节车厢，会有许多小兵从中间爬出来，可用刀将他们砍死，再往前，来到与之鳄快艇对战处，可不断地打它们所发出的导弹以此无限循环赚分。
