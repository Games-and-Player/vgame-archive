## 恐龙危机 2（DINO CRISIS 2）

**机种** PS　**厂商** CAPCOM　**类型** AVG　**媒体** CD-ROM

【图：恐龙危机2游戏画面截图】

这恐怕是CAPCOM为PS所制作的最后的重量级作品了。前作是99年E3展上的AVG状元，两年后，二代终于登场了。

其实CAPCOM制作 + r1 + 这个系列，很显然就要借 + r1 + 所带来的成功为自己在AVG领域的霸主地位上一个双保险。幸运的是， + r1 + 成功了，很快的创下了全球二百万的销量。但是，对此的 + r1 + 基因总是让人觉得 + r1 + 只是前者的COPY外传。所以，为了确立 + r1 + 在AVG领域的地位，二代明显渐渐区别于 + r1 + ，已让人有要划清界线的感觉。

如果说一代中众多的谜题是借鉴 + r1 + 的话，那么二代中与恐龙的周旋则成了自己风格。 + r1 + 中几乎没有可以困住人的谜题，而且活动范围也很小，最有乐趣之处就是消灭恐龙赚取pt值，购买道具武器。一改一代中风格，杀不尽的恐龙（其实可以杀尽，但要有耐心）与令人兴奋的各式武器，使 + r1 + 显得分外火爆。因此，战斗就成了这部游戏中的最大亮点。

另一个与 + r1 + 区别的就是在操作上去除了 + r1 + 键。没有了走，是直接就是跑路，只有端枪的时候主角才会走走。

CG非常精彩。事实上在 + r1 + 时强调电影化的表现手法就已让人对CAPCOM眼服不已了。而在游戏的画面方面我将得到更多赞叹。二代中的CG背景，尤其是雨林，若用一代时的表现手法PS肯定不行，如今二代中也有明显的远近视差，已经让人发觉PS机也已经老了。画面解析度较低，人物与恐龙的材质感略与一代的水平相同，只有亮暗光源处理才能衬托出实体感。而在众多时间处理的事件播片时，加入了模糊残像处理，令画面表现流畅（与 + r1 + 中重放时是同一手法）。可见，今后AVG已显然在高位机种上出现了，特别是这种电影式的表现手法，画面就显得尤为重要。（但剧情方面表现平淡）

看来PS真是到了该回家的时候了。但 + r1 + 做为PS上最后的AVG大作，用以前说的 + r1 + 来形容并不为过。——六面兽

## KHAMRAI -神来-

（カムライ -神来-）

**机种** PS　**厂商** NAMCO　**类型** RPG　**媒体** CD-ROM

【图：KHAMRAI 神来游戏画面截图，角色持枪的3D场景】

一直以来NAMCO在RPG游戏的制作上是颇有一些天赋的，《宿命传说》的成功就是很好的例子，这款《神来》似乎是在一些新东西的尝试，游戏确实有些亮点，但总体上还不是很令人满意。

游戏中讲述的是一个发生在神界中的故事。人物形象很漂亮，画面以3D到45度视角构成，这样的游戏一般看起来会令人头晕，本作亮点做的还可以，但这样的界面往往在没有什么亲切感觉，至少方向感很差的笔者一时间是无法适应。游戏的系统比较简洁明快，很容易上手，令人耳目一新的是战斗系统，摒弃了传统RPG的回合制，加入了即时性的要素，而且角色不需要自己控制会自动作战，对于想 + r1 + 的玩家来说实在很方便。它会影响到以后战斗的相互配合程度，有些育成的味道。不过游戏最大的诟病就是遇敌机率实在太高，大约2至3步即遇敌，令人无法忍受，笔者最终也是因此而放弃了此游戏——实在是浪费不起时间。

虽然是这样，但这部游戏还是给笔者留下了很深的印象，不妨让喜欢尝鲜的玩友大可一试，至少它会带给你一些不同的感受，而这正是现在许多游戏所缺少的。

## 怀旧，源于永恒

**文/浙江　魏恺丰**

前阵子，FF9还没上市的时候，FF迷们期望也颇高。一天，在网上和几个Game fans聊天，有位仁兄说盼FF9已经到了一夜不能寐的程度。我问他FF系列最喜欢哪一部，他很哲学的说了一句：永远是下一部。我说我FF从4玩到8，最爱的还是6代。他说我这是怀旧，那好，我就谈谈我为什么怀旧。

我认为玩GAME与喝酒相仿，有几个阶段。十年前，我只是个十五、六岁的少年，玩 + r1 + ，玩FC，颇有顽童偷酒之意。那时的游戏好比米酒，偶得一口，不醉且甜美。 + r1 + 和 + r1 + 是必修课，不过，我倒是被迷进一阵 + r1 + ，这也许暗示了将来的GAME发展之路。

到了十一、八岁，有了MD，也爱喝啤酒了。这时的游戏也许并不完美，但有数不完的创新，极有冲劲，像酒吧里琳琅满目的啤酒。当然，年轻人免不了吃仓龙[?]的苦头。管它是百威、喜力、嘉士伯，或是青岛、燕京、三得利，一铜端了。结果是反胃、恶心、呕吐，醒过来除了头发晕脚趾还特别的苦。这个习惯到SFC时期还常犯，最晕的一回是猛 + r1 + 了三天 + r1 + ，对于还沉浸在 + r1 + 的我来说，玩 + r1 + 未免有些酿酒的味道。 + r1 + 得我休息了一个星期。如果以情节和人物塑造来说， + r1 + 还是完整和丰满的。可惜，原始化的操作系统实在不敢恭维，不进则退吧！此外，最高难的一次恶意 + r1 + 是在完全无助的情况下和一位仁兄整夜整夜研究 + r1 + 。就靠着对文字中片假名的一知半解和对只有人影的游戏过程的无边想象，硬是面对几百个一三选一或四选一的问答，试图摸住凶手。是不是有些自虐？现在看来，那着实是喝了一回 + r1 + ，受了一回 + r1 + 。

又长大了一点，有阵子开始学人喝黄酒。黄酒不好喝，有药味，但不容易上头，喝惯了很温和。类似于黄酒的游戏不是谁都能欣赏的，许多人 + r1 + 一下就退缩了。喝黄酒是一种主观要求的表现，就好比坚决不用金手指和以最高的标准难度完成游戏。例如，以全天候和高级索救完成MD的 + r1 + 。除了会遇到那传说中的超级大雪和严寒，还会面对难以预料的遭遇战。在这种条件下攻打苏联，成功的可能几乎为零。还有，以不练等级和不死一人的方式打完SFC的 + r1 + 。这个游戏中电脑IQ出奇地高，完全遵循以优势围攻弱势的原则。因为新人等级都是1，所以越往后越不能死人，敌人也越强。这样通关的可能性也小到了极限。但是，喝黄酒的特点就在于重过程，品内涵。关键是喝的过程，能不能喝完全凭兴趣。不过，有一点很重要，没有一定的酒量喝不得黄酒；没有对游戏的彻底研究， + r1 + 的玩法纯属瞌睡。
