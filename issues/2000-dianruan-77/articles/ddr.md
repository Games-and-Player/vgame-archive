## 玩家在DDR理念上的差异吧！

近期《电软》上关于DDR的内容出现不少，亦有几位舞友对DDR展开讨论。我并未能完全理解他们的表达意图，只知 + r1 + 、 + r1 + 、 + r1 + 这些名词总是频繁出现。

DDR得分的高低取决于连击，由于得分是按连击百数呈复制递增，因此即使评价相同，得分也会因连击数而相去甚远。说到评价，A以上有S，S以上有SS，就算是双S级也会因PREAFECT和GREAT的多少而有所差异。常听理论派说： + r1 + 高手 + r1 + 高脚 + r1 + 未免把高手这个词看得太肤浅了！ + r1 + 舞蹈革命 + r1 + 本地高手 + r1 + 迴向滑步 + r1 + 花式 + r1 + 要酷组 + r1 + 都市网SUPERMASTER + r1 + 这次比赛把DDR的内涵发得很惨！ + r1 + 我把每一场比赛都当作一次考试…… + r1 + 看来 + r1 + 因是深入人心哦！为求高分不惜抹杀个性才能，如此说来比赛与考试的 + r1 + 看着惊人的相似。想标新立异吗？想与众不同吗？那就等着被海浪出局吧！

我并不指望 + r1 + 中有多少人会倒戈，也知道国内 + r1 + 的现状亦不可能因以上文字有多大的改变，各位大可将之当成偏执狂式的胡言乱语。不过就观众的视角而言，跳出一两亿分和有时对着屏幕翻个要买人也是是闻而易见吧！若是有一天能在DDR的舞台上感情挥洒，全然释放，骑上那么一回，就许亦会有非比寻常的收获。

### 附1： + r1 + 

几乎是众多DDR爱好者的必修曲目，但我并不认为此曲有多难，至少 + r1 + 还是首可跑高分的曲子，曲速较快节拍类易于掌握，与DDR3中的不少曲子相比也是小巫见大巫。毕竟只有几个小学生玩银脚 + r1 + 也能跳出S评价来。关于此曲高潮部分的数十个8分连打该怎么踩，我觉得无须将自己的方法强加于人。本地几个能跳出SS级340连击的人中只有我一个是用旋转踩来踩那一段的，其他舞友均是正统的东乐东步，关键在于舞频度，当然也有点运气因素。仍要指出的是一味求速亦非DDR高手们的康庄（庄？）大道。不信？来首 + r1 + 之类的轻盈，试试，绝对让跳惯了 + r1 + 的朋友有种忘穿鸽翅的感觉。

### 附2

五一期间我加入了旅游狂潮，只身来北京。北京之行让我也认识了几个像我一样的DDR狂热爱好者，唏嘘出名的只有北大的那常亮。最近还在 + r1 + 有关美年达举办的DDR大赛的电视和报道中看到了他与人比拼 + r1 + 的身影。想起当时与他交换花式技法与当心烦时的情形真是记忆犹新。总体感觉北京的高手（先不论是跳分还是跳花式）并不如苏州地区多见，想来主要原因在于价格上。北京的舞机很少有低于2元一次的，组装机亦然。即使是上海，除大商场外也只是一元一次。昌山几音乐游戏均为1元一币，两币一次，而苏州有5角一次或一元一次的，且均为5首曲子。北京和苏州玩家的经济负担相去甚元。由此可得一公式：游戏记（计？）费标准与高手数量成反比。天师，还是写了一堆，DDR能写的东西真的太多了，望勿见嫌！
