在Ⅱ代《暗界决斗记》推出一年后，Ⅲ代终于携着 + r1 + 而 + r1 + GBC。作一看标题，还以为今作设定了漫画原作中无敌的三枚幻神卡，不禁令笔者有想买正版的冲动。しかし，残念ですね！话又说回来，今作新系统新要素大大增加，而且游戏性比较PS版毫不逊色，绝对是所有 + r1 + fans不能错过的佳作，但由于是GBC的专用软件，没有彩色GB的玩友尽早update吧！

## 探索新系统新要素

**★ 原创卡片合成模式（コンストラクション）**：在今作中新增的模式，只要经过战斗胜利后得到的卡片零件（カードパーツ）以上半身和下半身加以不同组合就得到不同卡片。每个卡片零件都有上半身星数和下半身星数，而且都可作为上半身或下半身零件使用，合成规律就在这些星数中。多尝试不同组合，也许你能合出只有自己才有的原创卡片喔。据说原创卡片总数有1万种以上，以32M的容量来说，能否达到这么多卡片非常令人怀疑，相信还应该是KONAMI的一种宣传策略。

**★ OCG的生泰系统完全导入**：OCG全称OFFICIAL CARD GAME，公式卡片游戏，这种风靡日本的公式卡在国内已有得卖，不知各位是否有兴趣收集呢？这次Ⅲ代加入的生泰系统，就是在战斗时，4星级以下的怪物可以直接派出场，5至6星级的怪物则必须将派出场的任一怪物作为祭品（选择いけにえ指令）才可召唤出场，而7星级以上的怪物则要2只祭品。因此这等于高等级的强劲怪物出场的关键，这就使得战略性大为提高。

**★ 效果怪物登场**：OCG中非常活跃的效果怪物在Ⅲ代中登场了，总共设定了51只，还有不少是原创的喔。要注意的是，效果怪物必须在覆盖状态（ふせ）时才可发动效果（选择こうか指令），一旦翻开就无法使用。因不同局势灵活运用不同效果，有时能获得出奇制胜的法卡更强的支援作用喔。

**★ 新角色＆新卡片**：除了增加对战的8位新角色外，在保留Ⅱ代720张卡片的基础上，再加入了80张新卡，其中有漫画原作中的 + r1 + 、OCG中的 + r1 + 等强力魔法卡，使高度战略的运用空间日益熟化。

**★ 仅式怪物的召唤变得简单化**：Ⅱ代中仪式怪物的召唤必须要3只特定的怪物作祭品，这就使得将它们全部召唤变得很困难。而Ⅲ代虽然也必须3只祭品，但只需指定1只特定另2只任意即可，因此召唤变得简单容易化，成功率也增大，由于所有仪式怪物都属于神魔族，只要能成功召唤出来，离胜利已不远矣。

**★ 在手牌中能够直接融合怪物**：前作中怪物的融合只能在战斗场上进行，这样的缺点是融合的素材怪物很容易被对手打倒。今作可以直接在手牌中将怪物融合了，但融合后要等下一回合才能派出场，而且如果超过4星级的话变品也是必须的。

**★ 魔族的相克原则**：原则为水魔族（みず）>炎魔族（ほのお）>森魔族（もり）>风魔族（かぜ）>土魔族（つち）>雷魔族（かみなり）>水魔族；白魔族（しろ）>恶魔族（あく）>幻惑魔族（げんわく）>黑魔族（くろ）>白魔族。（注意：无论多么强小的怪物，只要是属于克制对手的魔族，就能将对手瞬间击溃，有时利用此招就能反败为胜！）。此外，Ⅲ代中还新加入了神魔族（かみ），神魔族不仅攻击力高，而且不会被其他魔族所克制，要打败它们一定要靠实力或使用好充系魔法才行。

**★ 通交换·对战·融合**：通讯是GB的强项，当然少不了交换、对战、融合等等增大游戏乐趣的手段啦。①交换：不仅可以在Ⅲ代之间交换卡片（注：原创卡片交换后会还原为零件），也可与Ⅰ代、Ⅲ代进行交换，让你以前的心血不会白费。这点或许也仍然了《口袋妖怪》吧。②对战：以可将自己组配段程序所编成的AI人工智能是无穷大。人脑相比的，只有与人对战，你才能真正感受到 + r1 + 的最大魅力。③融合：只要将3张卡一次性传送到对方GB机里，就能永久地融合成1枚新卡，例如将189、399、415这3枚卡通讯融合就能得到773神剑翼人，部分怪物卡必须运用这种方法才能得到，玩友们可多尝试一下。

**★ 密码模式——获得卡片轻而易举**：大家如果有收集市面上的公式卡的话，蒂了，只要将卡片在下角的8位数密码输入，就能轻而易举在游戏中获得该卡，输入次数无限制而且不会降低DC值（DUELCOST）。由于公式卡有不少在游戏中是没有被设定的，输入这些密码时就会被判无效。

##  + r1 + 全领域全面观

谈到KONAMI的 + r1 + ，就不能不说到它的母体——漫画。自从96年在周刊《少年跳跃》上连载以来，一直好评如潮，其中攻打柏纳索斯阵的剧情，就是围绕卡片的战斗来进行的，情节扣人心弦，高潮迭起，漫画迷们对此都津津乐道，漫画的作者高桥和希也因此人气急升。

在所有漫画迷的企盼下，漫画中的卡片终于实体化。KONAMI于99年2月4日率先推出VOL.1锡纸装公式卡，全部共40款，每包只装入其中5张，售价150日元，当时引起了抢购热潮。能体验漫画所描绘的那种战斗乐趣，当然使很多漫画迷陷之若鹜，就连未看过漫画的人也是跃跃欲试！当时漫画迷们讨论最多的活题就是公式卡技术的运用及自己得到了那些珍惜卡牌。

此后，KONAMI再接再厉，陆续推出VOL.2～7系列、BOSSter1～7系列（此系列只在抽卡机中出现）、Starter Box系列（附战斗地图及赛例）、Magic Ruler系列、Dark Ceremony Edition系列以及EX系列等等，卡片达800种以上。这些系列设定了很多漫画中没有的卡牌，令战略性大为增加，当然原画设定还是由高桥和希操刀。

随着Magic Ruler系列公式卡的登场，游戏王OCG的赛例也得到了修改，全新的专业赛网令OCG进入新时代。 + r1 + 的热潮再次掀起，玩卡者兴致高涨，在专卖店出售的卡牌更是供不应求。除了在专卖店出售的各系列公式卡外，还有限定版通过购买攻略书，购买特定套装卡、预约和预购游戏软件、参观及参加全国大赛，在大赛中获得优胜等方法才能得到的限定卡。由于限定卡发行量极少且很难得到，成为许多卡迷争相追猎的对象，持有限定卡是非常引以为荣的事。

在 + r1 + 的人气直升时，KONAMI决定将OCG卡游戏化，于是在GB上推出最初的 + r1 + ，并出人意料地取得了空前成功，销量突破百万。为感动FANS们的热情，99年2月21日KONAMI在东京假座举行了GB + r1 + 全国大赛，冠军1名，奖品是独一无二的 + r1 + ；亚军2名，奖品 + r1 + ；季军3名，奖品 + r1 + ；第4位4名，奖品 + r1 + 。以上特制限定卡均为镀片制造，有凸印感，全世界仅有几枚，珍贵无比。为了得到这些限定奖品，参赛者都涌跃万分参数，角逐异常激烈，特别是OCG卡的比赛，志能亲临观看，真是不枉此生。

此后，99年7月8日KONAMI再次于GB上推出了 + r1 + 。游戏的热卖已在预料之中，销量轻易突破百万。
