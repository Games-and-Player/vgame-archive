### ①简化技之补：

97中简化技层出不穷，11期赵鑫之简化技，在南京几乎全都是厩民连技，绝不稀罕！另外补充几种简化方法。

Ⅰ. + r1 + 法，这是我自己命名的。此法用来简化超杀。超杀的前半段指令多为 + r1 +  + r1 + 和 + r1 + ，前两种可简化为 + r1 + ，而后两种可简化为 + r1 + 。（注：只可简化前半段，后半段不可）

例：红丸：蹲BX3）雷光拳可简化为↗BB↘B↗→A。草薙：蹲BA）无式，可简化为↗B↘A）↗→A。

Ⅱ．在超杀中有 + r1 + 指令，此时输入攻击钮，之后继续绕完超杀指令则可与↓+攻击连上。如看不明白，见例子就会明白。

例：草薙↓BA）无式 简化为↓B↘→↓A↘→A
马丽↓BA）↓↗→B 简化为↓B↗→↓A↗→B

Ⅲ．利用角色无必杀技的特性，完成连技简化。

例：克拉克立C（1HIT）》超杀投，可简化为→↘↓↙←→↘↓↗←C 克拉克无必杀，所以会出立C。

Ⅳ．利用角色如被按住一个键则无法使出必杀技，只可出善通技和特殊技的性质，可简化一些连技。

例：八神：↓B 近立B）梦弹（1HIT）>/八雉女。可简化为↓B 立近B（B不松）→↗→A（松B）↘↓↗←A。

八神屑风后梦弹（1HIT）》八雉女，简化为屑风后C不松→↗↓↘→A（松C）↘↓↗←A

### ②神秘的八神：

Ⅰ．八神连技几乎已被挖空，但贵刊未曾登过这一连技：屑风抓对手入角落梦弹（2HIT）轻葵花2）/八雉女。此技要点在于轻葵花之间的间隔。对草薙，二阶，莉安娜等要求间隔略短，对八神，特瑞等则要求间隔长，对大门，拳崇等则要求间隔适中。但此技对克丽丝，罗伯特不成立。对他们则要立A近C）轻葵花2）/八雉女，对二阶，草薙也可行。

### Ⅱ．八神鬼步无限连技：

屑风鬼步前进近C）屑风鬼步前进近C）屑风……

此连技只在无能量宝石时方可发出。

若想练出此连技，先了解一下鬼步。（以八神为例）在后紧急回避结束时输入↘↓↗→+A不松，则八神会在紧急回避后向前快速滑出1/3屏幕。

发出条件：无能量宝石时，（MAX态下也可）。

其实八神在任何招术后均可 + r1 + ，包括跳鞭，就是不能直接发出，必需在一招快结束时输入↘↓↗→+A不松，八神才会在这一招结束后发出鬼步。

再讲解无限连杀：

屑风动作结束前↘↓↗→+A不松，八神鬼步走过去立即近C）屑风……

初学者可一定要注意以下3点：

① + r1 + 输入时间要恰当，过早则走不出鬼步，过迟则会出→A或葵花。

②近C出招时间恰当，过早则屑风够不着，过迟则对手来的及防住。

③屑风在近C后要接的恰当，过快则出鬼烧，过慢则屑风接不上，早好用↗→A来接屑风，此法不会出鬼烧。

八神的鬼步无限连击5次即晕，晕点后再七次又晕。三次鬼步后立C）重葵花×3可打晕对手。对麻宫、草薙、大蛇、克丽丝等鬼步无限连极易成功。相反坂崎良、蔡宝健、京、陈可汉却不易成功，原因是不同角色需要走鬼步的长短不同。

打麻宫时八神只需走出一点远即可立C）屑风，打坂崎良时鬼步走完也接不上近C）屑风。

初练者可用95模式来练习鬼步。

### ③鬼步的活用：

八神鬼步不仅可向前，还可向后。指令为↘↓↗→↗→←或↗↓↘→+A不松。并不是所有人的前鬼步和后鬼步指令都刚好相反，如玛丽的前鬼步为↘↓↗→↘↓↗→B不松，而后鬼步为↗↓↘→A不松。还有很多人先后鬼步如草薙、克拉克。还有大门根本就没有鬼步。为什么呢？是因为鬼步是在无能量宝石时输入非近身投必杀的超杀指令与后角色才会向前或相后突进。

鬼步时可使出普通技，也可作出任何攻击，由此鬼步可作为突进技，后鬼步可作花招或疲惫迷使用。

### ④无敌的TERRY

TERRY VS BILLY时，BILLY在角落，TERRY先能量补充，然后再等半秒，再↓↗←BXn，是TERRY无需MAX态下的无限连击，且只对BILLY成立。另外TERRY MAX态下用能量补充撞对手入角落之后隔有同隔开↓↗←BXn的无限连击对八神、阪崎良，TERRY则不成立。另外TERRY其实是可以↓BBA）步步高/补充）……，原理同二阶↓B×4相同。

KOF系列打的就是一个 + r1 + 字。97丰富多彩的连续技令原本就处于巅峰状态的KOF一举登顶，笑傲江湖；而99STRIKER系统的导入，则使KOF仅有一词可以形容：独孤求败。最后，笔者练出了一套邪门功夫，于KOF本无裨益，却多少可以使战斗更为精彩些，因此献出，贻笑大方。

本门功夫暂称Counter超重击，即利用超重击后产生的Counter进行追打。超重击在近距离内一般有三种用途：偷袭、试探、先读。今天我们谈的是先读，所谓先读，指的就是对手在出招前被己方识破，并以进推有效的招式加以破坏。而先读成功之后，则必定出现Counter。伪使用的是出、收招均快的超重击先读，此时便能轻松追打。追打的情况大抵有三种：

**1. 普通状态下的追击。**由于Counter的出现只是使浮空的对手再次产生攻击判定，对于滞空时间并无影响，所以最好以突进系的（超）必杀技进行追击，如颚的 + r1 + 、拳崇的 + r1 + 、极限流的 + r1 + 等。原则上采用1HIT的强力必杀，若采用HITS的必杀，则应注意该必杀的 + r1 + 性。试举一例，红丸在超重击后用 + r1 + 或 + r1 + 追打，但由于 + r1 + 性不够，对手很快脱身并进行反击，与其如此倒不如采用 + r1 + （99中只好用 + r1 + 了）追打，安全且HIT多。对于蓄力角色，在打超重击时，摇杆仍拉拉后蓄力，如玛丽：一超重击→> + r1 + 。但有的蓄力角色，如拉尔夫，并无合适的必杀技追打，怎么办呢？EASY，用超杀得了，拉尔夫的 + r1 + 、薇的 + r1 + 等都是Counter的首选。最后还有一点要注意，即空中超重击向亦可Counter，情况分两种：a. 有空中（超）必杀技的，如麻宫的 + r1 + 、 + r1 + 以及莉安娜的 + r1 + （绝对够快够酷）等；b. 落地后以出招快、判定强的招式打，如K的 + r1 + 、MAXIMA的 + r1 + 等。

**2. 版边的追打。**众所周知，版边是连续技的天堂，化梦幻为现实的地方在此。在版边，几乎各式追打均可成立，笔者不再赘述，大家可以自己去试。我们着重要介绍的是，以能再次产生攻击判定的格式Counter，从而达到 + r1 + 无绝期的目的。能再次产生攻击判定的格式有：京的 + r1 + 、东丈的 + r1 + 、克拉克的 + r1 + 等等。笔者认为最恐怖也是迄今为止不连超杀威力最大的一招是KING的：超重击》SURPRISE ROSE》站D》站B》SURPRISE ROSE》TORNADO KICK'95（横线部分可防，但极阴）。由于SNK可能对Counter后追加的招式的特性作了修订，所以难度提高了不少，笔者是在98中暴气后VS拉伦成功的。京、K'亦有类似连技，但K'在蹲C后加上蹲B）蹲A） + r1 + 极易被识破，偶尔用一两次就可以了。另外，投系角色在此均可用A或B使对手着地，再以指令投追打，同样是阴对手的招式。

**3. 另类。**99'中草1等人具有DOWN攻击特性的特殊技也可用于超重击的追打。97'、98'中大门超重击后后向前走1、2步则刚好接上 + r1 + 。但最早引笔者入此旁门左道的却是神乐千鹤的：超重击》（→↘↓↗←D）》（→↘↓↗←D）。以上都是无须出现Counter即可连击的特例。另外，特瑞的：超重击》能量喷泉可以用来阳喜欢用CG次飞的对手。

看到这里是不是觉得爽啊，笔者打的时候就爽。但有一次爽过头了，被京以 + r1 + 袭得欲哭无泪。Counter成功与否取决于超重击是否先读中对手，但对手共有三种招式可以还击，须慎之又慎：1. 打击防御技，如京的 + r1 + 等；2. 指令投，或和指令投一样有超强判定的普通技，如镇元斋的 + r1 + 或蔡宝健的 + r1 + 等；3. 瞬间超杀，即瞬间产生无敌时间和攻击判定的超杀，如97'薇的 + r1 + 、98'琢磨的 + r1 + 等。

### 1. 98夏尔米浮空

98中夏尔米（普通）用（→↓←→）×2+A/C挺住大门时，无论是否站在版边都可以浮空。这样，大门也有存在星了。

### 2. 双人配合产生浮空

98中夏尔米（普通）与98/99玛丽也可，方法是对手在三角跳的瞬间用投技挺住对手，夏尔米用（→↓←→）×2+A/C，玛丽用必杀投技，至于别的投技角色也可能行（至少我还没有尝试出来）。在97中的暴走莉欧娜也可浮空，方法是暴走和欧娜的回旋镰快回来时，对手用真·七枷社的→↓←+A/C挺住莉欧娜，这样莉欧娜便浮空了，而真·七枷社用两种必杀投技去挺此的莉欧娜，会有有趣的现象，其它投技角色也可以，玩友不访自己试一试。

### 3. 利用三角跳浮空

这是浮空技中最难的，但在97中有指令简化的设定，使必杀技更容易使出，那么浮空也不再是难事儿了。只要会三角跳的角色站在角落里输入地上的必杀技指令再输入前斜上后按键则可在空中使出必杀技，超必杀技。例如：（以角色在左角落里为准）麻宫→↘↓↗←→A/C，不知火舞→↘↓↗←→A/C，蔡宝健→↘↓↗←→A/C，而且舞与蔡还可在空中发出超必杀技，方法是：舞←↓→×2→+A/C，蔡→↓→×2→+A/C。98，99中也可这样发出，不过太难了，不必用特殊技来得简单，关键感觉，感觉到了就会使出，只要多试几次就会找到感觉。

99的无限连技是历代格斗之王中最多的了。（KOF2000可能更多，我还没玩过）除了十几期的玩友介绍的以外，麻宫、膝堂香澄，板崎由利均可在AM状态下用回避攻击打击N次在空中且角落的角色，或呼叫上打型援助时AM暴气发出。还有的角色只能打几下，如罗伯特，二介等，京的→↘↓↗←A/C×N只能在对手是板崎良时才能连上（别的入我从来都没有连上过，望高人们指点。）
