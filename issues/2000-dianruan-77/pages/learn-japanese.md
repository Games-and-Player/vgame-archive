# 彩页 - 看广告学日文之《高尔夫天堂》（PS2）

> 插8 / PDF p.10

【图】整页以PS2游戏《高尔夫天堂》（ゴルフパラダイス）的日文广告为素材，标注数字编号①—⑥，对广告中出现的日文词汇逐一讲解。广告画面展示三人在高尔夫球场的场景。

## 看广告学日文

PlayStation.2

**PS2のスゴさをいまいち満喫できないあなたに。**

---

### ① 给到现在还不能充分体会到PS2优越的你

◆スゴさ（su-go-sa）这里的スゴさ其实是从すごい（su-go-i）变来的。すごい是形容词，有很多意思：象是可怕、吓人或是厉害，还有非常了不起的意思。而すごい去掉 + r1 + 加上 + r1 + 就是这个字的名词。

◆満喫（ma-n-ki-tu）这个字的意思就是饱尝，在这里S·P根据前后语调翻译为充分体会。

◆できる（de-ki-ru）这个字的意思有很多，也常常可以看到，在这里的意思是能、会。而できない是否定型，所以当然就是不能、不会啦！

◆いまいち（i-ma-i-chi） + r1 + 汉字写作 + r1 + ，就是现在的意思。而 + r1 + 不是第一的意思哦！这里的 + r1 + 当副词有最接近的意思，所以整句说来就是 + r1 + 。

### ② 不喜欢格斗，赛车也不拿手啊

◆キライ（ki-ra-i）汉字写作 + r1 + 也就是 + r1 + 讨厌的意思。如果讨厌还不足以形容你心中讨厌的程度，当然还有更讨厌的说法！所以这个时候你可以说 + r1 + （だいきらいだda-i-ki-ra-i-da）最讨厌了！

◆ニガテ（ni-ga-te）にがて　汉字写作 + r1 + ，顾名思义就是很不拿手的意思哦！而且既然有不擅长，当然也有擅长的啦！汉字写成 + r1 + 。（とくいto-ku-i）

### ③ 只拿来看DVD太浪费了吧……

◆もったいない（mo-x-ta-i-na-i）这个字虽然也有不敢当的意思，可是在这里是滥用、觉得可惜的意思。

### ④ 买起来很轻松，玩起来很简单　借着游戏 + r1 + 你也来充分体验一下PS2吧！

◆気軽い　きがるい（ki-ga-ru-i）形容动词。轻松、爽快的意思。形容动词后面有动词的时候要加上 + r1 + 再接动词，别忘了哦！

◆手軽い　てがるい（ti-ga-ru-i）形容动词。简便、简单的意思。

### ⑤ 立刻去买吧！

◆さっそく（sa-x-so-ku）副词，汉字写作 + r1 + ，是立刻、马上的意思。

◆買いに行く（かいにいくka-i-ni-i-ku）这是一个句型， + r1 + 以什么为目的去做什么……所以这里总而言之就是叫你快去买哦！

### ⑥ 游戏名：高尔夫天堂

◆ゴルフ（go-ru-fu）外来语，就是英文的 + r1 + ，高尔夫球的意思！

◆パラダイス（pa-ra-da-i-su）外来语，就是英文的 + r1 + ，有天堂、乐园的意思。S·P觉得这款游戏还是叫 + r1 + 比较好听……\*o\*
