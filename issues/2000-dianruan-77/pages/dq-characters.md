### 勇者斗恶龙 Dragon Quest 历代角色讲习班

 + r1 + 在睽违玩家五年后，终于在今年8月26日于PS上推出了。尽管遭到许多玩家的批评，但当年与 + r1 + 系列势均力敌的它虽然失去了当年的如虹气势，可仍不失为一部RPG巨作。

为了更进一步了解 + r1 + 在角色上的细心刻画，这一次就带领大家来瞧瞧，游戏中所登场的主角以及可靠的伙伴们，看看他们到底有什么差异，也借此来探讨角色间的个性与特别的人际关系吧！

### 小小兵　大人物！？　FC~SFC BOY TO MAN!

在FC上的 + r1 + （以下简称DQ）系列发售的有 + r1 + ，除了 + r1 + 以外，前三部作品都已移植到SFC上，而游戏的画面也因此一代比一代强。

在同样的游戏内容与世界观下， + r1 + ～ + r1 + 于FC和SFC转变上，主角与伙伴的样子确有明显的不同。衣着方面还算类似，但身高、面容、整体等，FC转为SFC犹如小孩变大人一般。我们可以由图中清楚地看见两部作品之间的差异。

###  + r1 + 主人公

在一代中，主角的目的共有两个，其一就是要解救被抢走的公主并将其平安地送回王宫。另外，还必须将扰乱世界和平的龙王打倒。

#### 趣味考察

在一代中，玩家必须一个人自立自强地展开冒险之旅。特别之处是进入战斗永远都是一打一。可见 + r1 + 的敌人还算有骨气，不会驱使勇者而进行群殴式的打法。但是把勇者打得满地找牙也令可怕的勇者花一半的资金去看尽医……是从这一代开始沿袭的。

另外，救到公主后的主角如果不快点把公主直接带回国宫，而抱着她在客房睡一觉、嘿嘿，骗天老爷奖还会问主角肝脏是否是HAPPY！可见得主角跟公主是先上车后补票。也因此有了 + r1 + 那三位小毛头的出现。

###  + r1 + 主人公

到了第三弹之后，新增了可以任意选择同伴的 + r1 + 和任意进行转职的 + r1 + 两地。除了主角可以做男、女两种大小的变化之外，其他伙伴都会因职业的不同而有不同的外表（但没有自己独特的个性与特色，全凭职业来分别）。

在本作主角就是 + r1 + 系列洛特传说中的第一位必须完成神圣使命的勇者。衣着方面则是显然地要比之前两部作品的主角都来的轻便，而洛特的系列装备，在这洛特传说里也更名并改变样貌了！

#### 趣味考察

在SFC上增加了一项新系统（性格），因应不同的性格，主角所提升的能力数值也会有所差异。而游戏中有各式各样的改变性格之书，玩家可以借着这些东西来使主角改变个性，但可惜的是，改变成不同的个性，除了能力的提升有所不同以外，在说吐、战斗等地方并没有特别的改变。也就是说设计主角是个没个性的奇特分子！

另外，如果你是动漫名作《龙珠》的Fans的话，一定对在旁边那位持剑的勇者形象既熟悉。对了，鸟山明的人设使本作与《龙珠》中的人物极其相似，这位就很象那位超强的悟吉塔了，只是没带耳环……

### 天空传说始动　充满个人风格的 + r1 + 人物登场

 + r1 + 是 + r1 + 系列全新的开始。原本的洛特传说到了这一代则变成了 + r1 + ，只有传说中的勇者才能使用天空装备的传统是从本作开始的。

游戏一共分为五个章节，玩起来就象是在看一篇篇动人的小小故事，相当感人。在舍弃 + r1 + 的 + r1 + 世界里，角色基本上也就无法进行转职，取而代之的是主人公与其伙伴们真的被赋予了个性，并在 + r1 + 中活灵活现的表现各角色自己可爱的一面哦！

###  + r1 + 战士莱安　第一章

为了解救被绑架的小孩而开始展开世界之旅的勇猛战士莱安，想必他那呆呆的可笑模样，应该令不少老玩家印象深刻。莱安不是笨，只不过次缺思考，所以他也成了一位得靠药草活下去的苦命男子（药罐子？）。

#### 趣味考察

战士莱安小时候相当强壮，几乎大部分的武器和防具都能活用自如，简直象个 + r1 + 版桃太郎。在第一章的旅途中，才偶然地认识了一只卯伊米史莱姆，并一同展开了冒险之旅。这点就能看出，莱安还不算个坏犬，有怪物加入自方还能坦然接受，搁不赖的。再加上游戏里，莱安还让一对相爱的恋人解除彼此之间的误解，然后再度重逢。没想到莱安在感情的思维上还颇有一套，所以他的本事还不能简单地称为笨，只能说他呆。

###  + r1 + 商人特鲁内克　第三章

想必大部分的玩家对这位胖胖商人多少都有点眼熟吧！没错，商人特鲁内克最初就是在 + r1 + 中出现的，当时的特鲁内克就已经抱着要成为天下第一商人的志愿而到外地展开冒险。最后是自己跳脱了 + r1 + 的领域，以 + r1 + 俘略玩家的心，并拓展了 + r1 + 系列的疆域。

#### 趣味考察

在特鲁内克一开始的村庄中，会遇到一位想要前往教堂做祷告的人。如果好心的把他引到教堂之后，还能获得他所给予的金钱报酬。当然，起初的打工小游戏也是相当有趣。看着商人特鲁内克跟来到商店中的客人你来我往的杀价，看来特鲁内克一旦认真起来，就连客人是小孩子也不会放过。俨是要好好的赚一笔，真是恐怖。

###  + r1 + 顽皮公主三人组　第二章

睽违已久的 + r1 + 三人团队在 + r1 + 的第二章又再度复活。顽皮公主（武术家=罗雷西亚王子）加上爱说教的老头（魔法师=姆普鲁古公主）和开心过头的帅哥（僧侣战士=萨玛鲁多利亚王子），这简直就是 + r1 + 的角色复刻版。

玛利娜公主从小就爱好武术，所以学了一身的好功夫。一天，无意间见到一份传单，传单的主要内容是告知天下英豪在某日将会举办一场世纪武术大会。武闘公主当然不会放过这个机会，所以她就偷偷的溜出城去参加这场盛会。

屡劝不听的顽皮公主，在好不容易溜出城堡时被布莱老师和细心的克利福特塔伯大哥逮到，但深知劝不动公主的他们最终还是决定继续任由公主的放纵，保护地前往目的地……参加武术大会。

#### 趣味考察

虽然恣意妄为的公主是很潇洒，但如果这时再回到王宫会发现，国王也甚应宝贝女儿的要求，并不会增派加以阻挡。可见公主还是很开通的。或许是因为如此的新生愉怀，才会培育出这种调皮捣蛋的公主吧！

###  + r1 + 天空的花嫁

 + r1 + 的附标题 + r1 + 翻译过来就是 + r1 + 。而图中的美人儿芙罗拉就是主角新娘的第一候补者。瞎扯！比安卡不是新娘，主角还可决定跟别人在一起？读者们别着急，这就容·P慢慢道来。

#### 趣味考察

萝拉波涅村有一位大财主，芙罗拉则是他唯一的女儿。说穿了这位财主不是凡人，他乃是天空血统的继承人，过去的勇者曾把一头巨大的魔物封在一个壶内，他们家族历代的使命就是要保护世界和平并看守这一壶。等哪日魔物重见天日，必须靠一己之力将之打倒。后来在主角的帮助下，芙罗拉自然成为勇者的女儿。芙罗拉的身体里自然也流着天空的血液，所以就算跟芙罗拉结婚生下的小孩，也不须担心孩子不会成为勇者哦！

另外，如果新娘选择了比安卡，那芙罗拉则会在不久后嫁给一位一直深爱着她的痴情男子，要是玩家娶了芙罗拉，那比安卡则会回老家去，陪伴自己的父亲共渡余生。爱着芙罗拉的痴情男子他会因此死心，而且因为其父亲为大财主的缘故，每过一段时间，就会有士兵送旅费和道具来帮忙主角。这点倒是挺特别的。

###  + r1 + 谜之少年与谜之少女

游戏进行到中盘，主角在拿到了天空之剑后，发现自己竟然无法使用自如。数年后，这一对小小少年二人组现身在主人公的眼前，不只是天空之剑，其它的天空系列装备在这金发少年的使用下犹如天生勇者一般……

#### 趣味考察

其实这一对小朋友都是主角的孩子，金发的原因大概是比安卡的遗传（如果跟芙罗拉产了，为什么不会是蓝发呢？）。而天空勇者的眼睛诡异的跟主角有几分神似，至于勇者的主角，为何无法使用天空装备呢？其实拥有天空血统者并非主角，而是主角的一半—— + r1 + 。但她还必须通过合主角的血统才能创造出真正的勇者。原来主角的母亲是流着天空血脉的勇法师，所以主角他就因此有着神圣的血统。这也是为什么主角能轻松收容魔物的原因——都是因为继承了母亲的血液。看来，当勇者不仅要艰苦的修行，与生俱来的身世也是必备的要素之一。否则什么所谓的神圣的血统不就全部 + r1 + 了……

### 五年的时光　使主角再度小孩化！

###  + r1 + 角色群

主人公是一位住在山顶某座小村的少年，与妹妹相依为命。因为举行庆典的缘故而首次离开村庄，开始了他的第一次旅途（这点跟 + r1 + 的主角有点类似，也是因为庆典而开始冒险的）。武斗家哈桑在现实世界中只是一位不平凡的木匠，因为向往成为武斗家，再加上他条件本就不错，所以在梦境世界里就成为一名不折不扣的一流武术家。后来他就朝着一方面不断努力锤炼自己的武艺。魔法师芭芭拉，不知为何被封印在 + r1 + ，等待旅人的搭救。她的身世一直是个谜团，早就想知道自己到底是谁？其实她之所以会使用数种强力的攻击法术，全因她身上流着大魔女芭蕾拉的血液……僧侣查摩罗的个性有点带有 + r1 + 游玩者的感觉，非常爱搞笑，也不太合群。不过后来获认主角的能力之后，便随伙同行给予主角协助。占星师米蕾尤，其装备、谈吐，职业都跟 + r1 + 的占星师米蕾亚有几分相似，连名字都差不多，或许有些什么血缘关系也不一定。她是唯一知道幻之大地秘密并告诉主角的伙伴之一。剑士特瑞想必有不少玩家已经对他有点印象了，其实他的姐姐乃是稳重的占星师米蕾尤。姐弟俩会跳出游戏在GB上以新作 + r1 + 登场，可见特瑞的人气度还真的是颇高哦！

#### 趣味考察

比安卡小时候的个性活象个霸道的野丫头，非常难以伺候。还记得拖她跟主角结伴一同前往冒险时的，不慎被魔物抓走。主角后来好心把比安卡救了出来，反而还被愤怒责问： + r1 + 唉，她就是这样，不过到了后来就变成一位既柔美又稳重的美少女啦！

 + r1 + 的世界观非常繁琐，玩家是生活在现实与梦境的两个世界中，这也就是附标题 + r1 + 的真正含义。而不同的角色也会因为现实与梦境的不同，而反映出两种不同个性与身份。当然主角也会因为两个世界的缘故而分成两个不同的身份。起初会令人玩得 + r1 + ，但只要能仔细回味个几遍，本作也是相当具有魅力的。（游戏的转职系统也对提升娱乐性方面功不可没）

###  + r1 + 角色群

在游戏中，一口气就安排了三位战士类型的角色，感觉好象不是很平均。而角色方面，除了主人公以外，另外也还有一位小孩带着一只狼作为宠物，感觉有点 + r1 + 的味道（主人公竟然着一只杀人狗）。而女性角色，有一位头上包着头巾的女孩，造型倒也跟 + r1 + 的公主有几分类似。

本作跟 + r1 + 一样掺入了职业，不知他们在转职以后的外表是否也会有所更动。不管如何， + r1 + 已经出了有几个月的光景了，你们会从游戏中慢慢了解了他们的个人资料。

###  + r1 + 辣妹二人组　第四章

手上拿着占星球，为村民解决烦恼的占星师妹妹米蕾亚，和手握花蝶扇子哥米斯镇受到村民喜爱的活泼舞娘姐姐玛妮亚两人。虽然长相有点雷同，个性却相差了十万八千里。

妹妹米蕾亚相当的稳重，并以回复系魔法为主；姐姐反而比较粗线条、贪玩（到后来还爱上了赌博），以火炎美拉系和闪光基拉系的攻击魔法为主。其一攻一防的魔法搭配，能力可是不在话下的哦！

#### 趣味考察

在一开始的村内，因为姐姐玛妮亚的活泼，所以不少村民都很喜爱这对姐妹花，尤其是年轻男子更是对姐姐的舞姿欲罢不能，几乎是每晚必看，要不然就是睡不着的。

第五章换成主人公后，主角最先遇到的伙伴就是这对姐妹。你会看到，妹妹很努力的靠自己的第6感赚钱，打算到圣地去占卜找寻守护自己。但姐姐却在地下一楼的赌场不停的游乐，把妹妹辛辛苦苦赚来的钱一点一点花光，导致她们也一直停留着于此，无法出发去寻找勇者。也因为这样，当勇者来到这座城镇，才能顺利地认识她们（可见得姐姐还真是个好赌的徒呢！）

###  + r1 + 主人公　第五章

到了第四弹， + r1 + 系列的主角唯一的特征就是 + r1 + ～ + r1 + 主角所拿的剑都是同一把（图中可见）！在衣着上，四代比较特别的好象就是头上的那顶头盔，其它也就只是一些普通的布料，然后将自己的身体团团包住。

其实这一系列下来，本次的主角身世一开始就显得略为模糊，不像之前都可很明显地知道，主角就是继承洛特血统的勇者。所以在游戏的过程中，逐一地发现主角的身世和秘密也就成了本作的乐趣之一了！

### SFC版的全新出击　最坎坷的主角登场！

###  + r1 + 主人公

要说 + r1 + 系列以来历经最多沧桑的主人公莫非五代莫属了！在 + r1 + 首次将主人公先小孩化，并让玩家慢慢游戏从幼年开始直到成年中间的人间万变。母亲的下落不明、父亲的死亡、主角与好友被活捉当奴隶、结婚生子、妻子被抓走、与孩子分离数年再相遇，反应了现实的人生百态，也描绘出主角那苦到不能再苦的命运。

###  + r1 + 主角之父帕帕斯

在一开始就登场在游戏画面中进行着一段段的故事，他也身兼慈母职养育主角长大。起初带着年纪尚小的主角出海旅行，并带了一项找寻已久的宝物回到一座乡镇。父亲象是隐瞒了些什么似的，很多事情都不希望儿子知道。唯有仆人桑丘，一直是帕帕斯最好的倾吐心事的对象。

#### 趣味考察

帕帕斯身为一名战士，理应无法使用任何魔法才对，启奇怪的，帕帕斯不但拥有魔法值MP，更能施展伊米之回复法术。后来才知道这些技俩是跟自己的妻子学来的。在细心的学习和高明的教导之下，这才让一向对魔法很 + r1 + 的战士帕帕斯学会了施放魔法。帕帕斯相当疼爱自己的孩子，而且可以说是过份的关心。遭遇战斗、帕帕斯不但会一合攻击两次，而且在每次的战斗过后都会施加回复伊米在主角身上。就算本身的伤不算严重，甚至受伤了，老爸还是对自己的儿子进行治疗。而且最令人不解的是，不管帕帕斯使用多少次回复伊米，其MP值都不会有任何增减，这真是太奇妙了！

###  + r1 + 青梅竹马～比安卡

小时候老爱欺负主人公的比安卡（她比主角还大两岁），也是 + r1 + 的最佳女主角。当然她跟主角一样，也分了幼年期和青年期两大阶段来游戏。比安卡有着相当仁慈的心。一回在与主角一块在街上闲逛，后来见到一群小孩子在欺负一只小花豹，便兴起了拯救小花豹的念头，开始了一连串的故事……
