# 第一特集：焦虑、猜疑、失望、或者欣喜 以关键词回顾2002年游戏业界

应该说2002年是精彩的一年，众多重大事件都在这一年内经络加密。我们已这次编辑回顾了一年中的所有重大事，从下面的文字中，相信有很多都会成为今后闲谈时的话题。

## 搜索关键词 X（xbox）

**解释：** X看上去像是去年最红的字母——邮只求好看，不讲内容的《XXX》一出现就常见到美国原房第一，而一台画着大的游戏机也成功地完成了从初生到势力扩张所需要的一系列步骤：总体来讲，“X”BOX去年的成绩是相当不错的。

3DO的首席执行官Trip Hawkins在前年年底曾经公开表示，“XBOX撑不过2001年年底”。这是他终当初拍错了3DO之后再押错宝，不过质吉本来就不好做，业界里业人员的斤斤计较对外失误。事实上当初很多人确实不看好微软，其主要原因就是不知道比赛淡到底成为多大的能力和财力来玩这个游戏——迎过机团金大丁的人至今仍心有余悸，毕竟这还不是普通人能承担的。

不过2002年的实际发况充分证明了微软对家用游戏市场的认真与信心，而通常一旦微软开始认真对待某个东西就会变得相当可怕。在美元和广告的强力推动下，当2003年新年钟声敲起的时候，XBOX通过在欧美的胜利已经基本确定了业界老二的地位，并且把GC排挤到了一个尴尬的局面。

现在没有人再会对微软的财力以及决心表示出任何怀疑了，在短短的一年之内，X已经成为了少一个老牌游戏软件硬件厂商的的字号，不过这样吉本来就不好做，业界的问题和压力，将会在未来很长一段时间继续下去，甚至有可能成为家喻户晓的强大势力，就要面临新的挑战和考验。

游戏业界从任天堂、世嘉、NEC包打硬件天下，到如今微软加入这个混战，天堂对他们对手来说只是一个“游戏”这个圈子，那时的游戏业是相当封闭的环境，而索尼与微软的介入则完全打破，微软也从此成为了绝对商业化的产品，与多元融合的时尚产品。可以这么说，只有在这两家公司面前，小孩子的把戏才第一次成为了你死我活巨人的角逐，至于其它人则只有旁观的命，却越来越有说话的权利。未来业界的控权将很快集中到具有绝对统治力的硬件厂商手中，它可能会因为两家的残酷竞争激烈化人心，但选择的残酷竞争激烈必然将来越来越远20年前如BFO带来的会以FD带来的会以理念。

作为一个从业人员，我很难用“好”或者“不好”来评价这种改变，但相信过去玩游戏的那种纯粹感，以后将无以言表。

无论在英语还是中文里，都不含一个充满暖昧意味的字母。也许正是看中这模棱两可的含义，TECMO才把自己的排球游戏定名为DOAX（死或生极限沙滩排球）。如果要评选2002年游戏业界的最丰富宣传，DOAX肯定将高居榜首。在整整一年的时间内，几乎所有的游戏传媒都热衷于引导着人们去关注这些女玩家上装满流式样花花公主，以及指挥沙的颜色，说几个人想到在几秒或者几行行的一下排球的基本规则以及控制方法——虽然相信TECMO在这方面可能也做得确实不错。

确实，一定会有很多人对这个游戏表现出理所当然的不屑一顾，但一边扭捏着头大叫“It's Crazy”一边引不转睛的老外我也看到不少。DOAX不是男性游戏玩家的极致梦幻，同时也有着很难以预料的意义。

**编辑部的意见：** 完全站在纯性年龄层面的GC机中，有着与其他两种硬件不同的市场。尽管这么说也许有些矛盾，但事实是这个个人袋妖怪已经在家里上过了原有主机的问题，但仅仅依靠自己的销售依然可以保证任天堂的问题。而这，我们过去有着红蓝的GBA计算在内，任天堂的2003年过分担心显得有些多余。

# 搜索关键词 中国（china）

**解释：** 在日本商界，2002年最红的一个名词就是“中国”。确实，当中国已正式开始WTO瞩目之旅的时候，当世界其他地区的经济增长速度变得缓慢至停滞的时候，“中国”这个名词，带着巨大的市场潜力与近乎无限的商机，成为了投资者追捧的对象。

索尼对中国的立场在2002年有了180度的大转变。从当初严格限制PS2相关产品在大陆销售，到发布许最援待的时候，索尼最终宣布推出大陆版PS2主机。索尼在一年里完成了自己新商业重点的转移，而这一切，都与整个业界激烈的竞争意愿相关。

日本娱乐和电器市场趋于饱和，所制了索尼对这两个行业的进一步发展，而微软就来越急必须打开新的巷道打拓兵的市场。从商业的角度理智地看，大陆版PS2的发售不是大陆玩家扩大内需消费的方式，而是要由于受到竞争环境优化所带来的贪欲不已，也遂设索尼可以想的“商”的独立开发工作。当今出经消费者对不可想象。

现在的没有多少人不知道手的手机的游戏大战，甚至在他的内容都服务和提供方面也做得非常不能。软件公司窘况与美国推出的60万套PS2网络硬件设备的对时的，这或许在未来给PS2的网络计划带来相当大的阻碍。

相比之下，XBOX的网络方面就便利和完善的，而微软从2002年下半年开始，也取得各种手段要求或引诱软件开发商改支持XBOX的网络化的方式。这种强制手段很快使得更多的软件商掌握XBOX网络化的技术，至少目前来说，除了PS2的网络化2产品化，网络化成为将不低于FF12的梦幻之星网络版之外，True Phantasy Online和真实3D网络在中国这两款RPG大作也十分令人期待。

三大主机中，GC是对网络态度最冷淡的。除了完全可以复制物理层的Bug被证实完毕，网络游戏对于这2大主机来说基本上已经绝对——至少在2002年内是这样的。任天堂可能更感兴趣，是构建一个由一台GC与多个GBA组合在一起的相对封闭网络，而不是传统意义上的Internet Game。

网络游戏对游戏改变会怎样呢？至少以此这一时期，虽然谁也无法清楚未来展现的规模。微软试图把竞争转移到网络游戏方面，或许并不代表它完全认可对游戏发展的真正认识。对于目前这一代主机来说，或许仅有的关联仅仅只是单机游戏并非网络游戏。

2002年里，关于网络的单词说的最多，但实现的却在太少。这是就他也代表了整个业界的最感觉不到，而这一现象，无论是SCEI对目前的策略仍然是模糊不清、无所适从，或将在未来给PS2的网络计划带来相当大的相当大的阻碍。

**编辑部的意见：** 网络游戏也许会在未来席卷业界，但是它目前的能量还远远无法与单机游戏相比。在这一点上，本刊的意见同样立场先生完全一致——对于目前这一代主机来说，决定胜负的关键仍然只是单机游戏而非网络游戏。网络游戏充其量可以给目前的竞争带来一些变数，但绝对不会决定性因素。因为它现在的真正的距离还相当遥远。

# 搜索关键词 任天堂（nintendo）

**解释：** 尽管PS2的浪潮已不可逆转，但任天堂的获利仍然是业界之最。GBA年末未卖到了近乎疯狂的地步，GC家立也因完美无瑕的表现博得了满堂喝彩，“任天堂”——我们不得不将这三个字另眼相看。

实际。应该说，山内溥和任天堂似乎已经是两个不可分割的名词，但他们最终还是分开了，在表面上，在2002年。

现在回想起来，山内溥在这个关键时刻却把荒川实从美国召回，并不是为了让他继承自己的位子，而是为了削寺他年轻的岩田聪留下太多的阻碍。毕竟荒川这样有能力又有资历的元老存在本身，就是对新人的一种压力，岩田聪就算有再大的抱负再多的构想也难以实现。应该说，山内溥在这个关键时刻却把荒川实从美国召回，并不是为了让他继承自己的位子，而是为了削弱他年轻的势力，免得给年轻的岩田聪留下太多的阻碍。

表面上看，GC的销售不力是由于当今软硬件两大企业不懈重强力打压造成的，但实际上更深层次的问题却来自任天堂内部。进入2002年之后，任天堂的游戏遭遇到了从未好的困境，就连“阳光马里奥”、“塞尔达传说”之类的大作都没有获得多少加分的作用，这也就中有任天堂所强调的比其网络化与内碎手机接受能力之间的矛盾。任天堂这几个大作的质量当然是不容置疑的，但想一想“阳光不容置疑”，日本本届老玩家不过比之凡出一个月的冷饭改?（真三国无双2？》而更看出任天堂新兴的东西已经离玩家的口味越来越远。

时间在变化，环境也在改变，一切都已经20年前大相径庭，当初热爱任天堂游戏的孩子如今已经长大成人，当今主流的强大惯性推动他们仍然会成为任天堂的拥趸，但任凭仍然会感能这些大人满足吗？另一方面，新降生的孩子也不再由任天堂。

天堂伴随着成长，在他们许多的眼里任天堂才是电视游戏世界的主宰，任天堂对他们来说是只一个学或者一个口袋妖怪的代名词。任天堂放弃主机普及量纯粹追求利润所带来的副作用，随着时间的推移将会越来越明显。

虽然微软与索尼成为了2002年业界的主角，但任天堂却是最引人注目的话题企业。它真的会成为又一个不受欢迎的公司吗？在过去还是N64时代那样出乎，意料成也可算大丰收于游戏界持有这两种看法的人都不多，也许说出讲了看这样明天不希望任天堂真的这样明确表示了这样明确。

**编辑部的意见：** 完全站在纯性年龄层面的GC机中，有着与其他两种硬件不同的市场。尽管这么说，日子快至超越了原先的PS，索尼最终虽然依靠仅靠可保证任天堂的问题不多。而这，我们过分担心显得有些多余。

# 搜索关键词 挣扎（struggle）

**解释：** 正如前面所说的，2002年是大多老牌的开发者都感到来自利润的压力已变得比以往任何时候都要“严峻”的时候，用“挣扎”这个词形容世嘉在乎次次求下的困境是最恰当不过的了。

世嘉退出自己以往它的十几年来，曾经集中在它身自己的眼光都以前的胶光当中投投心的困难，已迎接乐观。它真的会成为社长、跨平台、纯软化上等等施并没有能够让这个公司在短期内重新振作，相反，除了“最完大冒险”、“VF4”和“创造球会”这三个大作之外，和其他软件品牌都已经优势尽失——这其中受打击最大的就是曾经让SEGA Fans引以为豪的家用Sports，在北美和EA的竞争中被打得一败涂地，完全不能获成任何威胁，而其后的几个创新产品如Rez、Space Channel5、莎乐蒂等，虽成换了新主机新平台也，但结果实在令人失望。

世嘉去年的主要利润来源仍然是街机市场，如果没有VF4，微紫费用等大作的支持，2002年的世嘉将样大幅下滑——对此，世嘉的公报显示表示公司损主要是由于大川所赠送的有价证券价格下跌所惨成的。但其价格之价格会下跌，除了日本股市本身的不振之外，还与索尼的这次大幅度调整了原定年度2000万套软件的计划指标，而新任社长动的“世界第一软件商”的目标。

仍然处于挣扎中的世嘉一年内内涵不断，先是公司干将纷纷跳槽，接着就连王牌制作人铃木裕都传要去微软的消息。至于微软收购计划，任天堂对S克威尔和艾尼克斯的合并之势力再度重组的十几发，令世嘉更是雪上加霜。

# 搜索关键词 后续（continue）

**解释：** 受欢迎的作品总是有一批人期待着它的续作，受欢迎的主机也不也是如此。2005年春风尚早，XBOX2与PS3的计划就纷纷公布也透露出来，这无疑是向人们展示自己雄心壮志的同时，也意味着“后续”的竞争已悄然展开。

如果说2002年在这方面这一时期，那么2005年将要来到的两大主机之争就有可能是空前而白热化的重要性和革命性大挑战。从2D跃入3D的时候便是如此，那些将来的游戏将不会有当时的公司的效率之比。据说SQUARE和EFF注册到了十好几代，一个公司如果想要摆脱出自己的过去，只能依靠不断维持自己当时的成就。这就意味着？

**编辑部的意见：** 推出后续主机是理所当然的事，但是缺乏创新的续集编制精心一侧面展现了了广经营状况的窘迫程度。也许这些游戏在为的将新的东西能够让人满意，但是没有创新的东西一直会成为游戏业的负担。

# 搜索关键词 暴力（force）

**解释：** 911的硝烟不但唤醒了人们对恐怖真实的警惕，同时也使得人类的心黑暗面完全觉醒。一个视现代主义与伦理道德为儿戏的游戏2002年最赐给人的消息，这是一个让人无法感到高兴的消息。游戏中的“暴力”在2002年全面出击。

去除搜索一个游戏，你会发现自己已经深陷欲望与GTA（横行霸道）和Blade II是2002年血腥游戏典型的代表，而残忍的比开发商在打击游戏出击的一年。今的游戏里不但承受，而且真是更加突出。这也许根据商极限也一样很多人向敢于突出，这是因为游戏从来没有像今天这样真实清晰，日本内为道德问题禁止了GTA上市，那么其他国家呢？那么今天的呢？我如此为中国游戏业的未来担心。
