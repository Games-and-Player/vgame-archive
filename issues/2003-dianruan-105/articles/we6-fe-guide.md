总有玩家抱怨WE系列的操作太复杂，不太容易上手，其实她的操作比起FIFA那可是简单多了。上期我们讲了盘带的基本操作，这次我们来说说传球和射门，希望对广大玩家能有所帮助。随后我们再来谈一谈大家非常头痛的战术设定，让大家成为本阵的高手。

## WE6FE中传球的基本技巧

| 传球名称 | 使用方法 | 实战要领 |
|---|---|---|
| 短传 | 按X键 | 比赛中80%的传球都是这种方式，传球的效果取决于传球队员的短传精度和短传速度。可以在没接球之前就按键，可以在第一时间做出传球动作。 |
| 脚后跟短传 | 按反向键+X键 | 用脚后跟向后传球，可用在一些逢边的配合中，但是传球的力度不是很大，不能用于长距离的传球。 |
| 长传 | 按○键 | 长距离的传球，队员的长传精度和长传速度越高，长传的效果就越好。 |
| 穿越球 | 按△键 | WE的招牌动作，能否合理地运用这种传球是区分高手和菜鸟的重要标志之一，传球的效果取决于传球队员的短传精度和短传速度。 |
| 空中穿越球 | 按L1+△键 | 传出一个高球吊过对方球员，除了下底传中的时候外，其他的时候作用不是很大。 |
| 高球传中 | 按○键 | 最普通的传中方式，如果在中路高中锋，那么这就是最有效的进攻方法，可以形成头球攻门。 |
| 半高球传中 | 连按两下○键 | 半高球传中，适用于那些前锋身高不是很高但是灵活比较灵活的球员，抢到的点后往往是要以头抢或最佳中顶等高速度球。 |
| 低球传中 | 连按三下○键 | 快速低球传中，往往用在边路快速反击中，这是现代化足球中越来越重要的分手段，但是在游戏中的作用不是很明显。 |
| 高轨道传中 | 按R2+○键 | 这种传中比正常的传中更速度高。笔者至今也没有发现过这种传中的实际作用，希望各位高人赐教。 |
| 吊高球 | 按L1+○键 | 向禁区内吊高球，如果传球能力强，那么就可以穿过对方后卫或门将成攻。 |
| 手动短传 | 按右摇杆 | 高级的传球方式，方向由右摇杆的方向决定，力度由玩家推动摇杆的力度决定。 |
| 手动长传 | 按L1+右摇杆 | 右摇杆的方向决定传球的方向，推遍摇杆的力度决定长传的力度。 |
| 取消传球 | 按传球键后按R2 | 取消传球，避免一些不必要的失误。 |

## WE6FE中射门的基本技巧

| 射门名称 | 使用方法 | 实战要领 |
|---|---|---|
| 普通射门 | 按□键 | 最基本的射门，一般在禁区内射门力度不要超过30%，地滚球的射法是守门员最头疼的，在禁区外的远射力度也不要超过50%，否则你会打飞。 |
| 高轨道吊射 | 按L1+□键 | 射程比较远的吊射，作用不是很大。 |
| 低轨道吊射 | 按R1+□键 | 很实用的吊射，在守门员出击的时候非常有用，可以将球挑过守门员。 |
| 取消射门 | 射门后按R2键 | 可以取消射门动作，利用这个动作可以晃过守门员。 |

## CHALLENGING MODE中关于传球和射门的练习

**■长传打靶　★★★★★**

规则很简单，用键长传球，要将球落在数十米外靶子里面，注意得分不只是和距离命中相关，的速度快慢也是评分的要素之一，球速越快，得分越高。

一推荐使用长传精度高的球员

**■任意球射门　★★★★★★★**

利用直接任意球的机会将球射向靶子，球离靶心越近，球速越快、弧度越强，得分就越高。笔者最高得分2287分，使用球员为阿根廷老将的马拉多纳。

**■手动传球　★★★★★★★**

利用手动传球，把球从两个球杆之间穿过，球速越得分越高。

编者注：如果某位读者对此模式有很深的研究，每项训练得分均在2000分以上，可向研究所投稿挑战。（游戏研究所所长MASCAR）

本作中增加了一项新的操作，那就是在对方罚任意球的时候可以控制本方人墙的行动，这样就可以积极地防守了，而不是像以前那样干等着对方射门了。具体的操作如下：

| 操作时机 | 效果 |
|---|---|
| 对方踢球瞬间按×键 | 人墙站定不动 |
| 对方踢球瞬间按□键 | 人墙就跳起 |
| 对方踢球瞬间按R1键 | 队员上前封堵射门 |

## 基本战术和团队战术详细讲解

### 中路进攻

【图】战术示意图：阵型向中路收缩

阵型向中路收缩，比较适合于中路突破，边路得球后向中路直传会有很好的效果。

### 右路进攻

【图】战术示意图：右侧队员边路扯动

阵型右侧的队员向边路扯动，适合于右路的下底，中路得球后向右路传球会有很好的效果。

### 左路进攻

【图】战术示意图：左侧队员边路扯动

阵型左侧的队员向边路扯动，适合于左路的下底，中路得球后向左路传球会有很好的效果。

### 长传转移

【图】战术示意图：两侧大范围转移

两侧的大范围转移，在某一边路得球后可以向另一侧长传，和边路进攻结合起来使用非常有效。

### 交叉换位

【图】战术示意图：两前锋左右换位跑动

两侧的前锋左右换位跑动，如果对方采用的是盯人防守的话，这种战术可以扰乱对方的防守。

### 中后位压上

【图】战术示意图：中后卫压上助攻

中后卫压上助攻，对对方的前锋是一种巨大的压力，但是很容易被对方打反击。

### 区域压迫

【图】战术示意图：本方队员对球围抢

对方队员得球后本方队员对其进行围抢，防守的效果很好，但是体力会下降地较快。

### 防守反击

【图】战术示意图：前锋滞留在前场

本方退守的时候前锋滞留在前场，有利于打反击，但是有中场脱节的现象。

### 造越位

【图】战术示意图：后卫向前压上

后卫向前压上，造成对方前锋越位，如果使用得好的话对方很难使用穿越球。

## 四种团队战术

**队形压上：** 如果设定的等级高，整体队形就会积极向前压上，大大提高进攻能力。

**区域压迫：** 如果设定的等级高，队员围抢的力度会增大，大大提高防守能力。

**造越位：** 如果设定的等级高，造越位就会更加积极。

**防守反击：** 如果设定的等级高，前锋回撤的距离减小，更加有利于反击。

## 团队战术的三种等级

- **A级：** 积极实施所选战术，但是体力会消耗很大。
- **B级：** 适当地实施所选战术，体力消耗正常。
- **C级：** 基本上不实施所选战术，体力消耗较小。
