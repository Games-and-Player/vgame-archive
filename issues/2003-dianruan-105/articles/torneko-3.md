## 游戏的第二周目 异世界的迷宫攻略

## 完美的壶的识别

在异世界的迷宫里到处都是未识别的道具，所以对道具的识别就显得异常重要。即使消费几回使用次数，也要尽早识别该壶的用途。我们把道具装进壶里，然后观察道具的变化就能知道该壶的用途。但是某些壶的用途并不是马上就能识别出来的，而这样的壶只有4种：合成壶、草之神壶、火药壶、普通壶。由于除了合成壶以外，其它三种都并不是那么重要，所以我们只要立即识别出合成壶就OK。

【图】游戏截图——壶的识别场景，对话框“ポポロは 静かに 眠っているようだ……”

当觉得该壶很有可能是合成壶的时候，不妨装个未识别的戒指试试，不会造成浪费。

| 名称 | 效果和识别方法 |
|---|---|
| インパスの壶 | 装进未识别的道具后识别该道具的功能 |
| 保存の壶 | 能够取出装人的道具 |
| 祝福の壶 | 装人的道具上出现祝福的标记 |
| 诅咒の壶 | 装人的道具上出现诅咒的标记 |
| 合库の壶 | 道具装进去会消失！ |
| 合成の壶 | 将武器、盾、戒指中的两种或两种以上装进去能够合成 |
| へんげの壶 | 道具装人后变成其它道具 |
| うそつきの壶 | 装人的道具会变成其它道具，但是每次它的名称都会改变 |
| 神々の壶 | 单单装人道具没有变化，但装人草后会发挥效果 |
| 火药の壶 | 装人的道具会变化，将其抓之打碎后会爆炸 |
| ふうつうの壶 | 装人道具也没有变化，摔碎它也没有变化 |
| 回复の壶 | 按下时HP回复すいこみの壶按下对时消灭附面的道具 |
| ものの壶 | 按下时特殊范围内爆出周围的道具 |
| とじこめの壶 | 得到时壶的使用回数只有一次 |
| 大炮の壶 | 能够发射装人的道具 |
| 水がめの壶 | 得到时的开始就能够识别 |

## 完美的戒指的识别

由于戒指的效果多为解毒、混乱等正面效果，而负面效果的戒指为数甚少，所以即使不知道它的效果也不 妨装备上试试。一装备马上就能识别的戒指有个。下面来让我们看一下常见的戒指的识别方法。

| 名称 | 效果和识别方法 |
|---|---|
| ちからの指轮 | 体力增加，装备后马上就能识别 |
| 爆发の指轮 | 偶尔会爆炸的戒指，装备上以后如果发生爆炸就能识别 |
| ルーラの指轮 | 偶尔会瞬间转移的戒指，装备上左侧移动就能识别 |
| 远投の指轮 | 变成远投状态，把没有用的道具扔了它 |
| まがの指轮 | 拾的道具撞到墙壁上后会拾回（变盒），扔扔看吧 |
| ワナみての指轮 | 道具被拾摔时不会飞去，在有陷阱的房间时试试 |
| へん盘投げの指轮 | 打不准时就是它 |
| ふしぎ投げの指轮 | 道具飞行的方向和你的方向不同 |
| 通过の指轮 | 能够在水上行走，在有水的地方试试 |
| たれ流しの指轮 | 会去失（遗落）道具，带上一会看看 |
| ザメーの指轮 | 会吵醒熟睡的怪物，识别起来很困难 |
| 痛悔の指轮 | 容易遭受痛的一击，当遭受概率比平时时就是它 |
| 痛みよりの指轮 | 武器、盾等之备品不会痛了，利用陷阱和特殊攻击识别 |
| 混乱よりの指轮 | 在遭遇混乱攻击时不进入混乱状态，吃几招特殊攻击试试 |
| 毒けしの指轮 | 即使中毒也不减体力，利用特殊攻击识别 |
| ドラゴンの指轮 | 减少灾杀打，挑几下轮试试 |
| 人形よりの指轮 | 削弱或无效化人形化怪物的攻击 |
| 眠らずの指轮 | 即使遇到睡眠攻击也没事，试试特殊攻击 |
| 咒よりの指轮 | 即使遭到诅咒攻击也没事，试试特殊攻击 |
| しあわせの指轮 | 遭到攻击后经验值反而提升。 |
| ハラペコの指轮 | 肚子容易饿（满腹度5饿减少1） |
| ハラモチの指轮 | 肚子不容易饿（满腹度20饿减少1） |
| ハラ守りの指轮 | 使“肚饿攻击”无效 |

## 其余的道具的识别方法

其余的道具的识别在这里简单说一下。“杖”的识别方法很简单，除了“万能之杖”在使用后不知道效果以外，其它的杖一使就识别出来了；“草”只能通过饮用才能识别，但是万一手里的草是“世界树之叶”就太可惜了，不过世界树之叶在未识别状态下也能发挥效果，所以在手里物品不是很多的情况下就一直拿着好了；考虑到某物的负面效果，所以在下楼梯时在楼梯上使用为妙，得到祝福之壶后将所有道具变成祝福状态也读解是一种方法；有合成壶时可以准备几件武器和装备试试。
