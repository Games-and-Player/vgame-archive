## 游戏要点

开始游戏后要先选择召唤的同伴，要以自己的荷包为准哦。召唤之后确认后可以立即投掷色子，召唤同伴的地方可以是停在4色魔石的任何一个，选择召唤，也可以是经过起点召唤。另外4个魔石上还有一个选项，使用可以给占领的地盘升值，榨取对手更多的钱。此外，你的地点上后，可以给地盘升值提高伙伴的人数，最多上限为3人，注意这里指的是同样的伙伴。

还有对于召唤攻击魔石时，只要经过召唤屋就可以，要适当选择用于阻挠对手。另外如果对手攻击我方时，手中有相同的资本也可以让魔石也会消掉（有特殊能力的伙伴也能抵消相应的攻击）。另外一个就是在到达对方领地时有相应的概率可以用己方的伙伴代替对方的伙伴，从而占领。

## 游戏规则

其实这个游戏的规则很简单，有玩过《大富翁》的人应该就清楚啊（毕竟是大富翁？我的天）。就是要在规定时间内达到游戏的最高CP数，之后回开召唤屋就能获胜。好了，下面先讲解游戏中的几个常见场地的用处。

【图】スタートマス图标——开始点和结束点，达到过关要求后回到这里就会结算事宜。在缩略地图上为4色边的方框。

【图】召唤魔石ぇマース图标——在这里可以通过花钱召唤攻击魔石。在缩略地图上为白色方框。

【图】マース图标——空地，到这里以后就可以把召唤来的伙伴放在这里占地。缩略地图上蓝色方框。

【图】切り替えポイントマース——切换点，到这里后要选择切换方向，红色是可通行方向。缩略地图上是十字标记。

【图】チェックリスタル——4个吕石，拿着他们回出发点可以换相应的钱。地图上是相应颜色的方框。

好了，开始游戏，首先要起名字了，自然还是用mine了，呵呵。另一个嘛，就叫做“ムム”吧。俺的偶像叫（风ムム：我倒……）。进入游戏，讲座开始！

始就把伙伴招集满8个，很浪费，而且到后面买魔石经常出现没钱的情况。

对于行进路线，最好是先选择有召唤屋和魔石的线路，起先装备上攻击魔石，不仅可以抵消对方的相同魔石的进攻，还可以抗先制人。使用魔石也带来以限制对方行动的魔石为主，为开始游戏抢地盘争取有利的回合，等到自己占据了一定比例的空地后，就不再频繁地使用限制行动的魔石，最好是用青蛙这种可以行动但是不可以使用魔石，可以安全地给自己带来些额外的收入。踩到4色魔石上的时候，如果不想为自己召唤新的伙伴那也不要放弃给自己土地提升等级的机会，虽然要花些CP，但是敌人踩到扣留的CP会更多。

对于抢占土地，最好是把一块块土地连起来，在地图上这样的地方比较是土地和其他诸如魔石、召唤屋之类的分界点的几块土地，全部占有后合出现字幕提示。能大大增加钱给的机会。如果再在里面配上诸如マッドマン、ホーリードラゴン这样可以让对手下次只能撂1的伙伴就更加地道。

机会了，也可以给对手使用“减速”魔石……另外就是自己的伙伴有能长对方面效果和改变对方行动方向的魔石，也不要忘记，也很好用的。选择伙伴的时候好好考虑一下是一定的。踩到对方地盘，有时候会出现“是否兼并”的提示，这时候要选择是那你自己的伙伴给赶走，不过也要付钱就是了，如果果钱还是够用的就一定不要犹豫了，毕竟这是抢占对方地盘的唯一途径，而且机会还比较难得。

避免到达对方的地盘而被放血的话，可以向对手的伙伴使用攻击魔石，像“催眠”、“石化”等效果就可以避免，另外还有“ベヒーモス”、“キングベヒーモス”这样的攻击魔石，可以一下减少一个或几个对方地盘的等级，减少被抢占CP。

一下子讲了那么多，大家应该能好游戏了吧。下面再给大家讲讲游戏中其他要注意的东西。

## 魔石活用指南

★攻击魔石可以对对手或自己使用，用于阻挠对手和便于己方行动。

| 魔石名称 | 效果 |
|---|---|
| ワーム | 使对方睡眠，睡眠期间停止行动。 |
| ギガントード | 使对方变成青蛙，变身期间禁止使用任何魔石。 |
| コカトリス | 让对方石化，强制停止活动1回合。 |
| ワイルドラット | 加速，连续2次投掷色子只出1、5、6。 |
| スラグ | 减速，连续2次投掷色子只出1、2、3。 |
| ラミア | 使对方混乱，不受自己控制。 |
| サボテンダ | 效果为中毒，每回合行动时损失金钱CP。 |
| ベヒーモス | 对占有土地1格攻击，降低土地价值。 |
| キングベヒーモス | 对占有土地进行3×3格攻击，降低土地价值。 |
| サクルエリア | 下次投掷色子只能投1。 |

「隐藏的斗技场」这个地方比较特殊，它是和「いにしえの遗迹」在所有地图全部挑战一次通关以后，再次取回过进度出现的。每次挑战时的地图不仅会相应的变化，而且对手也是不确定的，这一点大家要注意啊。

对于大家苦苦战达的地图，汗水和苦水应该早已流成，在游戏开始的时候选择“おまけを见る”和“おんなく”，这里有着所有挑战过而而出现的音乐，总共有26首之多，也算是对大家游戏时间的一点激励吧。

有玩过的全部地图还有几个我们没有玩过的地图可以选择，真是高兴啊。除了对地图的选择还可以修改目标CP，在“其他设定”中可以修改任意1P-4P1的伙伴魔石和攻击魔石的开开关，以后游戏中就不能使用了，最后全部设定完了以后，可以随机和任意调整人物的出场顺序，确认以后第三个进入游戏。

SQUARE还真会为玩家着想呢，这个功能让游戏的可玩性大大地增加了，人和人较量才能让大家得到满足啊，毕竟电脑在S/L大法面前再牛也白搭，对于另一个多机对战要求就高一点了，除了有多台主机外还都有卡。真会骗钱啊，难道1卡多机就是这么啊？大概是唯一的一点遗憾了。
