# 游戏新闻眼

2002.4 特报 GAME NEWS

## 离异五年后史克威尔重归任天堂怀抱！？

3月9日，日经新闻以大篇幅报道了一则爆炸新闻，一时间在业界引起了轩然大波！！

去年下半年，由于FF电影失利而陷入危机的史克威尔多次向任天堂表示了和解的意愿，但是均遭到了山内社长的坚决反对。此后，为了缓解公司财政压力，史克威尔接受了索尼投入的146亿日元。正当业界普遍认为其与任天堂之间的矛盾将永远难以调和的时候，曾被山内称为“绝对不可能”的事情竟然真的发生了。

本刊日本专讯　来自此间的消息表明，在经历了五年的离异生活之后，史克威尔与任天堂终于重新走到了一起。

日本经济新闻3月9日以大幅标题对此进行了报道。据称，任天堂与史克威尔的再次合作是在3月8日达成协议的，双方协定由任天堂与史克威尔共同出资成立新软件公司，负责在任氏系列主机GBA和NGC上推出FF系列作品。

鉴于任天堂与史克威尔之间曾经有过的不和，加上史克威尔目前特殊的身份，使得该公司不适合以第三方软件商的名义直接加入任天堂的软件阵营。但是任天堂的山内社长于今年设立的、专为小型软件商投资的游戏开发基金“FOUND Q”却成为了双方重归于好的一块跳板：史克威尔首先出资490万日元，支持FF系列的剧情设计及导演之一河津秋敏【注】成立了新软件公司GAME DESIGNERS STUDIO，然后FOUND Q又向该软件公司注资510万日元，使其成为了任天堂控股、史克威尔参股的软件制作所。据悉，GAME DESIGNERS STUDIO目前的主要计划是制作全新的、可在NGC与GBA之间连动的FF作品，并预定在今年年中发售。公司目前有开发GBA软件的计划，但尚未考虑NGC。FF11、FF12等史克威尔主力软件的开发工作仍然以PS2为主力平台而展开。

目前SCEI官方并未对这个消息做出任何反馈。有消息称，GAME DESIGNERS STUDIO将会把目前在日本播映的FF动画TV连续剧改编成GBA游戏，而玩家想要在NGC上看到FF11、FF12等所谓“真正的最终幻想”系列，现在还完全没有可能。

### NEWS连报　本刊记者对于以上报道的看法

新闻中明确地提出了河津秋敏新成立的公司将会给NGC和GBA制作全新理念的“FF”作品，似乎在2002年的E3大展前已将一直偏颇于PS2的天平向GC略略倾斜了一点。然而，无论谁都不会忘记史克威尔意欲加入任天堂的商业目的，更不会忘记索尼这个史克威尔的大股东会出于什么心思默许旗下合作厂商的它投。总之，在GC普及率未达到500万之前，这一切只是三万尺以外照不到的一个帽子罢了。新厂商的作品恐怕不会冠以“SQUARE”的名字，史克威尔的主流作品暂时也还只向最主流的平台——索尼的PS2输出罢了。（记者：SILENCE）

### NEWS连报　史克威尔与任天堂之间的纠葛

史克威尔曾是任天堂最亲密的合作伙伴，在FC与SFC时代曾经发表大量优秀作品。但由于任天堂对软件商的要求过于苛刻，加上索尼的诱惑与品牌魅力，史克威尔于1996年彻底脱离任天堂，将FF等系列转移到PS系主机上，此举被视为任天堂次世代主机竞争失利的一个主要原因。史克威尔与任天堂之间的关系也由此彻底恶化。去年下半年史克威尔因严重的经济困难多次向任天堂表示了和解的意愿，却遭到了山内社长的坚决反对。而后，由于史克威尔接受了索尼的146亿日元，业界普遍认为其与任天堂之间的矛盾将永远难以调和，但3月9日的消息却令人跌破眼镜。对此，史克威尔的官方声明是：GAME DESIGNERS STUDIO是由河津秋敏个人出资51%、SQUARE出资49%成立的新会社，会社以开发“新类型”游戏为目的，故此接受了来自FOUND Q的经济援助，而“新类型”指那种并非“复刻版”或者“RE-MAKE”的游戏。

【注】河津秋敏是史克威尔的董事之一，曾担任FF1、2的游戏设计；SaGa、SaGa2的导演兼剧本；浪漫SaGa系列的导演兼剧本；SaGa开拓者2的制片；以及Wild Card的导演兼设计。

## 日经公布厂商排名　KONAMI拔得头筹

SCOOP　本刊日本专讯　最近，日本经济新闻就“增长性”、“开发能力”和“社会性”等因素，对日本企业在去年的运作情况进行了排名，在前300家业界优秀公司中包含了7家游戏厂商（由于索尼并不是单纯的游戏公司，所以本刊没有得到相关数据），其中KONAMI的排名最高，居第13位，而后依序是BANDAI（第100位）、第102位KOEI、第155位CAPCOM、第164位任天堂、第223位SEGA、第267位NAMCO。

另，在前两年排名靠前的史克威尔，由于去年FF电影失利在本次排名中名落孙山。

## 机战宠物热销日本　玩具哈罗全面脱销

HARDWARE　本刊日本专讯　由著名玩具厂商BANDAI制造，在机动战士高达中登场的宠物机器人哈罗的玩具版本日前在日本全面上市。

2月底的发售当日，首批出货的宠物哈罗被一抢而空。到了下午，所有模型专卖店门前的看板上都出现了“十分抱歉，哈罗无货”的字样。其人气之高令人咋舌。

玩具哈罗的直径约为10CM，大小相当于原作设定的四分之一，非常适于摆放在书桌上。而且在装入电池后还可以听到在原作中担任哈罗声优的井上瑶小姐的原声配音。

## 游戏制作强中强　宫本茂再获大奖

EVENT　本刊日本消息　奇才宫本茂的杰出创意再一次得到了业界的肯定。在本届由日本文化厅举办的“第五届媒体艺术节”上，由宫本大师开发的GC游戏《PIKMIN》荣获“数字艺术优秀奖”。

凭借马里奥等家喻户晓的游戏，宫本茂一手缔造了任天堂帝国的无限辉煌。自1990年至今，他在日本国内获得了九项大奖，这其中还不包括“E3终身成就奖”等海外奖项。

- 1997年　第五届日本软件大奖“MVP”

## 微软再抛橄榄枝　任天堂Ken Lobb跳槽魔盒

EVENT　本刊美国专讯　继本多好尾（日本任天堂高层）入驻微软后，又一位来自任天堂的高层跳槽到了XBOX事业部，魔盒的实力再一次得到了提升。

根据美国方面的消息称：美国任天堂高层Ken Lobb已于近日辞职，转而进入了微软的XBOX事业部。而在他离开任天堂前，还在负责GC版《银河战士》的开发工作。

Ken Lobb曾担任过N64《007黄金眼》和NGC《星际大战·侠盗中队2》的开发总监，对任天堂游戏在美国的普及做出了重大贡献。

## PS2网络计划启动！生化系列仍然榜上有名

NETWORK　本刊日本专讯　2月13日，索尼PLAYSTATION MEETING 2002在东京举行，PS2的2002年战略构架将以网络化为中心全面铺开，而早先宣布“NGC完全独占”的CAPCOM名作“生化危机”系列也以网络版的形式重新在PS2上复活。

会上发表的网络游戏共有30个，除了上文提到的“生化危机网络版”和早已耳熟能详的“最终幻想11”之外，GT4、首都高速、信长野望、大众高尔夫等传统名作也陆续以网络版形式登场，而参与PS2网络计划的更有包括世嘉、KONAMI、NAMCO等软件大鳄，索尼希望借助这些软件开发商的力量使得网络化游戏在日本真正地成为一种时尚。

与亚洲其他国家尤其是中国相比，网络游戏在日本一直处于比较萎缩的态势。这次由SONY来主推，是否将给这一局面带来些新的气象呢？相信我们不久便能够看到。

### 索尼网络计划的详细内容

除软件以外，索尼还公布了网络计划的详细内容，其中包括通过网络提供PS游戏的下载供PS2玩家使用、网络音乐下载通过PS2播放、以及PS2与电视、电脑、手机等媒体信息互动等内容。同时索尼也表示PS2将可兼容REALPLAY格式，从而使这个网络上最流行的影像格式得以在家用游戏主机上出现。

新加入的网络服务商还有OCN、BIGLOBE、@NIFTY和PURARA。目前NTT BB将以每月限额1500日元的价格为PS2宽带用户提供ADSL接入和所有相关服务（包括下载等）；硬件方面，用户可通过分期付款的方式购买价值18000日元的PS2专用网卡，每月费用在1160日元左右。

## GBA SP——GBA的后继机种？

HARDWARE　本刊日本消息　继PS2推出改良机型之后，任天堂的GBA似乎也有推出改良版本的打算。据称，任天堂已经向日本专利厅申请了“GAMEBOY ADVANCE SP”的商标。

关于GBA SP的详细情况目前还不得而知。但从商标申请的内容来看，它应该是一款GBA的改良版本。由于目前的GBA存在着屏幕不够明亮的缺点，因此外界普遍猜测GBA SP很可能会在屏幕方面做出重大改进。

## XBOX发售一个月售出50万台

HARDWARE　本刊日本消息　微软的XBOX在日本发售满一个月后，累计销量突破了50万台大关。虽然这个数字不及PS2和NGC的同期表现，但对于一个初次进入日本市场的海外厂商来说，已经算是相当不错的成绩了。

不过，XBOX的软件销售情况却不太乐观。除了《死或生3》等少数几款作品之外，大部分XBOX软件的销量都不尽如人意。如何吸引更多的日本软件商为XBOX开发游戏，将是微软在今后面临的最大课题。

## 生化危机　GC版销量突破百万

SOFTWARE　本刊日本消息　CAPCOM的GC版《生化危机》在全球范围内的销量已经突破了100万套大关。这个消息对于CAPCOM来说无疑是一剂强心针，也为三上真司“生化危机系列NGC独占”的决定提供了有力的支持。

在日本国内，GC版《生化危机》的销量约为30万套，北美地区约为50万套，欧洲地区约为20万套。考虑到GC的装机量远不及PS2，这个成绩可以说是非常出色的。

## 影院化游戏能走多远

COLUMN　近年来，游戏与电影之间的界限越来越模糊。从最初的简单像素画面，到如今堪比电影的CG动画，游戏在视觉表现上已经取得了长足的进步。然而，过度强调“电影化”是否会让游戏失去其作为互动媒体的本质特征？这是一个值得所有游戏人深思的问题。

以《最终幻想》系列为代表，史克威尔一直在“影院化”的道路上不遗余力地前进。FF电影的失败虽然给公司带来了沉重的打击，但这并没有阻止游戏业界向着更加“电影化”的方向发展。《合金装备2》、《鬼武者》等作品都在竭力营造电影般的叙事体验。

问题是：当玩家长时间坐在电视前观看CG动画时，他们还是在“玩”游戏吗？互动性——这个游戏最根本的特质——正在被华丽的视觉效果所侵蚀。也许，在追求画面和叙事的同时，我们不应该忘记游戏最初带给我们的纯粹乐趣。

## 任天堂财报发表　GC价格下调

FINANCE　本刊日本专讯　任天堂发表了2001年度的财务报告。受GC销售不及预期的影响，任天堂的营业利润有所下滑。为了刺激GC的销量，任天堂宣布从5月起将GC的价格从25000日元下调至19800日元。

GBA方面的表现则依然强劲。凭借《口袋妖怪》等强力软件的带动，GBA的销量继续保持着良好的增长势头。截至3月底，GBA的全球累计销量已经突破了2000万台。

## SQUARE新作连发

SOFTWARE　本刊日本消息　史克威尔在春季集中发表了多款新作的消息。除了《王国之心》已经发售之外，《最终幻想11》将于5月发售，而备受期待的《最终幻想10国际版》也预定在今年内推出。

此外，史克威尔还公布了一款名为“UNLIMITED:SaGa”的新作，这是SaGa系列的最新作品，预定在PS2平台上推出。
